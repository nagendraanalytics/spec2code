Report ID: RID277

Report Title:
Mismatch of total Dose Amount between STR and SME

Description:
This report will output subject with mismatching dose Amount between STR and SME

Column Heading:
1. Country

2. Site

 3. Subject Number

4. Total STR dose amount

5. STR unit

6. Total SME dose amount

7. SME unit

Logic:
This report will output subject with mismatching dose Amount between STR and SME

For each subject

   -Total STR.Dose amount= Sum all the doses reported in STR. Dose Amount for the same Subject Number

   -Total SME.Dose amount= Sum all the doses reported in SME. Dose Amount for the same Subject Number

Scenario 1

If STR. Please Indicate if this is the Last Dose for this Label Description <> NULL

AND

STR.Dose Unit= SME.Dose Unit

AND

Total STR.Dose amount <> Total SME.Dose amount

Output is required.

Scenario 2

If STR. Please Indicate if this is the Last Dose for this Label Description <> NULL

AND

If STR.Dose Unit <> SME.Dose Unit, Please transform the Total SME.Dose amount value to the same units as Total STR.Dose amount (See Note 2).

AND

Total STR.Dose amount<> Transform Total SME.Dose amount

Output is required.

Note:

1. Exclude deleted records

2.Please transform the Total SME.Dose amount value to the same units as Total STR.Dose amount using the following reference values:

1 cGy= 1 RAD

100 cGy= 1 GY

100 RAD= 1GY

For example, if STR.Dose Unit= GY and SME.Dose Unit= cGy and  Total SME.Dose amount 2000, please transform the Total SME.Dose amount as follows.

Transform Total SME.Dose amount= Total SME.Dose amount/100= 2000/100=20.

Transform Total SME.Dose amount=20

Report Scenarios:
Scenario A, Output: Yes

      Dose Amount for First and/or Last dose are different between STR and SME

Scenario B, Output: No

      Dose Amount  for First and/or Last dose are identical between STR and SME

Scenario C, Output: No

       First or Last dose indicator is not checked in STR or SME form

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, Site, Subject Number, List of Subjects,

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Sum all the doses reported in STR. Dose Amount

5.STR.Dose Unit

6. For Scenario 2 display the transferred Total SME.Dose according to Note 2; leave blank for Scenario 1

7. For Scenario 2 display the transferred Total SME.Dose Unit according to Note 2; leave blank for Scenario 1
