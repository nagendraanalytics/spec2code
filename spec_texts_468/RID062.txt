Report ID: RID062

Report Title:
Mismatch between DS01 form and PMS1/PMST

Description:
The report displays subjects who have disposition status in DS01 form and corresponding in PMS1/PMST is not completed

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Study Treatment Form

6. First Dose Date

7.PMS1 form

8. PMS1 Date of Assessment

9. DS01 Date

10. DS01 Status

11. Error Message

Logic:
Report Logic:

Logic 1: Subject Status Missing/Medication Status Missing

Logic 1.1: DS01.Select the Status of the Subject for the Study <> null

AND

Logic 1.2: "SM Form". Start Date is not null

AND

Logic 1.3: "SM Form". Please Indicate if this is the First Dose for this Label Description = First Dose

AND

There is no PMS record meet below criteria:

Logic 1.4: "PMSf"."PMS Itemquestion" is not null

AND

Logic 1.5: "PMSf".Visitmnemonic = "PMSv"

Logic 2: Subject Status Mismatch/Medication Status Mismatch

Logic 2.1: DS01.select the Status of the Subject for the Study <> NULL

AND

Logic 2.2: DS01.Date of Disposition <> null

AND

Logic 2.3: "PMSf".Date of Assessment <> null

AND

Logic 2.4: "PMSf".visitmnemonic = "PMSv"

AND

Logic 2.5: "PMSf"."PMS Itemquestion" <> null

AND

Logic 2.6: "PMSf".Date of Assessment > DS01 form. Date of Disposition

Logic 3: DS01 Status missing

Logic 3.1: "PMSf".Select the Status of the Subject for the Next Trial Segment like ‘Not Continuing%’

AND

Logic 3.2: DS01.Select the Status of the Subject for the Study = NULL

Note：

1. "SM Form","PMSf", PMSv" are from supporting document.

2. The logic will check Subject Status or Medication Status based on "Status" column in supporting document

3. "PMS Itemquestion" refer to Status of Subject at End of This Trial Segment (for “Status” is “Subject Status”)/ Status of Medication at End of This Trial Segment (for “Status” is “Medication Status”).

4. Please exclude deleted record and Erroneous Visit from programming.

5. Please exclude Screen Failure subjects whose DS01 form = Screen failure.

6. For column 10 display, please refer to below:

Display "Subject Status Missing"/"Medication Status Missing" based on supporting document for logic 1

Display "Subject Status Mismatch"/"Medication Status Mismatch based on supporting document for logic 2

Display "DS01 Status missing" for logic 3

7. Requires supporting document to be named DS004_supp_<xxxxxxx>.csv and will contain the following columns and associated content.

1) Status - Required, enter Subject Status/Medication Status (One row per status)

2) PMSf - Required, enter PMST/PMS1/PMS1<A,B>

3) PMSv - Required, visitmnemonic where PMS Form should be located

4) SM Form - Required, enter SM/SMAU/SMAB/SM01. For multiple value, please use '|' to separate, eg. SM|SMAB, then logic will check SM and SMAB value globally.

e.g.

Status, PMSf, PMSv, SM Form

Medication Status,PMS1,Discontinuation visit,SM|SMAU

Medication Status,PMS1,Discontinuation visit,SMAU

Subject Status,PMS1A,Follow-up Day 30,SM

Subject Status,PMS1A,Follow-up Day 30,SMAU

Subject Status,PMS1A,Follow-up 1,SM

Subject Status,PMS1A,Follow-up 1,SMAU

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
Scenario 1: Subject/Medication Status missing

Scenario 2: Subject/Medication Status mismatch

Scenario 3: DS01 missing

When logic in each scenario meets criteria, then output will generate for Scenario 1,2,3;

When logic in each scenario doesn’t meet the criteria, then no output will be generated.

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, Default as N), Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
Forms.Items: 1. Subject Assignment. Country

2. Subject Assignment. Site

3. Subjectst. Subject Number

4. Protocol Milestone Status Form.Visitmnemonic

5. SM/SMAB/SMAU/SM01. Formmnemonic – leave as blank for Logic 2 and 3

6. SM/SMAB/SMAU/SM01. Start Date/Time – leave as blank for Logic 2 and 3

7. Protocol Milestone Status. From Mnemonic

8. Protocol Milestone Status. Date of Assessment

9. DS01. Date of Disposition

10. DS01. select the Status of the Subject for the Study

11. Error Message
