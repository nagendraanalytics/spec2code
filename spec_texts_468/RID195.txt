Report ID: RID195

Report Title:
Study Medication Administration order

Description:
This report will review the order in which Study Medications are entered according to Protocol.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Form

6. Seq

7. Study Medication

8. Study Period

9. Scheduled Time

10. Start Date/Time

11. Current Order

12. Expected Order

13. Reason for Dose Variation

Logic:
Logic:

<Criteria Form1>.<Criteria Itemquestion1> = <Criteria Value1>  AND

<Criteria Form2>.<Criteria Itemquestion2> = <Criteria Value2> AND

<Criteria Form3>.<Criteria Itemquestion3> = <Criteria Value3> AND

<Study Medication Form>.<Study Medication> <> NULL AND

(<<Study Medication Form>.<Study Medication>.Dose Amount <> 0 OR <Study Medication Form>.<Study Medication>.Numbers of Units Taken <> 0) AND

For each <Study Medication Form>.<Study Medication> defined within the same <Group> with the same  <Study Medication Form>.<Study Period> AND <Study Medication Form>.<Scheduled Time>:

Verify that the <Study Medication Form>.<Study Medication>.Start Date/Time is entered in the corresponding ascending order according to the <Order> provided per the supporting document

Notes:

1.Please do not consider deleted records and erroneous visits.

2. The <Group>, <Criteria Form1>, <Criteria Itemquestion1>, <Criteria Value1>, <Criteria Form2>, <Criteria Itemquestion2>, <Criteria Value2>,<Criteria Form3>, <Criteria Itemquestion3>, <Criteria Value3>,<Order>,<Study Medication Form>, <Study Medication>,<Study Period> and <Scheduled Time> are values provided in the supporting document and the logic should work for those values

3. When the time section of the <Study Medication Form>.<Study Medication>.Start Date/Time = UNK:UNK or does not exist, only consider the date portion，default it to 00:00 or 23:59 according to UNK flag in supporting document.  .

4. If there is more than one <Study Medication Form>.<Study Medication> with the same Study Period AND/OR Scheduled Time, consider the EARLIEST <Study Medication Form>.<Study Medication>.Start Date/Time to perform the sorting

5. Logic should verify that each <Study Medication Form>.<Study Medication> that has the corresponding <Study Period> AND/OR <Scheduled Time> per supporting document, is entered in the expected ASCENDING <Order> per supporting document

If <Study Form> AND/OR <Study Period> AND/OR <Scheduled Time> are entered as “NA” in the supporting document, consider all the.<Study Medication> entered with the SAME value (<Study form> AND/OR <Study Period> AND/OR <Scheduled Time>)

If <Study Period> AND/OR <Scheduled Time> are blank in the supporting document, do NOT consider the corresponding items for programming

6. If an specific Study Medication is not provided or is a zero dose (<Study Medication Form>.<Study Medication> = NULL OR <Study Medication Form>.<Study Medication>.Dose Amount = 0 OR <Study Medication Form>.<Study Medication>.Number of Units Taken = 0), Logic should check that the ascending order of the completed Study Medications ascending is still correct

For example:

Expected order per supporting document:

1. -3475

2. Lenvatinib

3. Oxaliplatin

4. Capecitabine

Data entered in Inform

1. -3475

2. Oxaliplatin

3. Capecitabine

In such case (since the ascending order is still correct, even if Lenvatinib is not present) an output is NOT expected

7. The report should show one row (one output) for each <Study Medication Form>.<Study Medication> that is not given in the correct order as per supporting document.

8. If there is more than one <Study Medication Form>.<Study Medication>.Start Date/Time with the same date and time, it should not output.

9. Requires supporting document to be named SM029_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each group of SM/SMAU/SMAB Study Medication order based on criteria, study period and/or scheduled time that are required per protocol.

1. Group - Unique key for the group of Study Medications to consider in the sorting, NOT NULL.

2. Criteria Form1 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA

3. Criteria Itemquestion1 - Arm/Cohort/Stratification Itemquestion1. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion1 is not applicable for the protocol, enter NA

4. Criteria Value1 - Arm/Cohort/Stratification Value. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the itemValue1 is not applicable for the protocol, enter NA

5. Criteria Form2 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

6. Criteria Itemquestion2 - Arm/Cohort/Stratification Itemquestion2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion2 is not applicable for the protocol, or is not needed enter NA

7. Criteria Value2 - Arm/Cohort/Stratification Value2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value2 is not applicable for the protocol, enter NA

8. Criteria Form3 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

9. Criteria Itemquestion3 - Arm/Cohort/Stratification Itemquestion3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion3 is not applicable for the protocol, or is not needed enter NA

10. Criteria Value3 - Arm/Cohort/Stratification Value3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value3 is not applicable for the protocol, enter NA

11) Study Medication Form - Study Medication Form Mnemonic, specified as "NA" if Study Medication should check across forms.

12) Study Medication - Value for each specific Study Medication

13) Study Period - Value for specific Study Medication - Study Period, specified as “NA” if SM order is same for all Study Period. Leave “blank” if Study Period does not apply for trial

14) Scheduled Time - Value for specific Study Medication – Scheduled Time, specified as “NA” if SM order is same for all Scheduled Time. Leave “blank” if Study Period does not apply for trial

15) Order – Provide the expected Study Medication order per protocol

16) UNK flag – UNK time default value, enter MAX/MIN(MAX: UNK time default to 23:59, MIN:UNK time default to 00:00). If Start Date/Time is not collected time, leave it blank.

Note:

1.Supporting document is required, if it is not provided, display the message as "SM029_JR_STD Supporting Document Not Present for This Trial".

2.If Criteria(s) are provided as 'NA' in the supporting doc (columns 2-7), check SM order for all subjects.

3.IF SM Label Description and SMAU/SMAB Dose Number are exactly matched within forms For SM/SMAU/SMAB Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number directly.

4.If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_<xxxxxxx>.csv to define the mapping.
