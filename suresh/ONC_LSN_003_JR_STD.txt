Description:
This report will list subjects who are missing a Lesion Evaluation for each lesion every specific interval of time following the randomization date/start date of the corresponding treatment phase

Logic:
Prior to processing the logic, apply condition(s) according to the supporting doc to check if subjects match the criterial or not.

"Criteria Form1"." Criteria Itemquestion1" = "Criteria Value1" AND
"Criteria Form2"." Criteria Itemquestion2" = "Criteria Value2" AND
"Criteria Form3"." Criteria Itemquestion3" = "Criteria Value3" AND

Logic 1.
Logic 1.1 There is a 'PMS Form' record with Trial Segment Reference = 'Trial Segment Reference'
AND
Logic 1.2 There is no LSN eCRF."DATE OF LESION EVALUATION" for each LSN records that belong to the corresponding treatment phase meet below criteria:
Logic 1.3 LSN eCRF."DATE OF LESION EVALUATION"  >= DOV. Date of Visit where 'PMS Form' is located - 'Lower window of days'
AND
Logic 1.4 LSN eCRF."DATE OF LESION EVALUATION" <= DOV. Date of Visit where 'PMS Form' is located + 'Upper window of days'
AND

25-     'Expected Timeframe' will be calculated using the items 'Minimal start timepoint', 'Start week', 'Stop week', 'Frequency', 'Lower window of days', 'Upper window of days'.
Steps to calculate the 'Expected Timeframe':
A.      Calculate different timepoints by doing the following mathematical operation:
Timepoint 1: Minimal start timepoint + Start week
Timepoint 2: Minimal start timepoint + Start week + 1*Frequency
Timepoint 3: Minimal start timepoint + Start week + 2*Frequency
Timepoint N: Minimal start timepoint + Start week + (N-1)*Frequency
B.      Timepoints calculated on step A should be: Minimal start timepoint + Start week <= Timepoint N <= Minimal start timepoint + Stop week
C.      Expected Timeframe = From Timepoint N - 'Lower window of days' to Timepoint N + 'Upper window of days'
Example:
A.      Minimal start timepoint = 01-Jan-2020
B.      Start week = 6
C.      Stop week = 30
D.      Frequency = 6
E.      Lower window of days = 7
F.      Upper window of days = 7
Timepoint 1 = 01-Jan-2020 + 6 weeks = 12-Feb-2020
Expected Timeframe 1 = From 05-Feb-2020 to 19-Feb-2020
Timepoint 2 = 01-Jan-2020 + 6 weeks + 6 weeks = 25-Mar-2020
Expected Timeframe 2 = From 18-Mar-2020 to 01-Apr-2020
Timepoint 3 = 01-Jan-2020 + 6 weeks + 12 weeks = 06-May-2020
Expected Timeframe 3 = From 29-Apr-2020 to 13-May-2020
26- For Logic 2.1, Logic 2.4 and Logic 2.13 use the maximum date of the range for calculation e.g., if the range is "From 01-Jun-2020 to 10-Jun-2020" use 10-Jun-2020. For  Logic 2.7, Logic 2.8, Logic 2.9, Logic2.10, Logic 2.11 use the minimum date e.g., use 01-Jun-2020.
27 - For Logic 2, if Expected Timeframe of treatment phase X overlaps with start date of treatment phase X+1 then no output should be produced for treatment phase X. For example: if phase 2 starts on 14Feb2018, '45 week' check for phase 1 is on 10FEB2018 and acceptable timeframe is 03FEB2018~17FEB2018 (lower and upper window is 7 days) then no output is produced for '45 week'.
