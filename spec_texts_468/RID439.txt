Report ID: RID439

Report Title:
Missing, incorrect or duplicate SPECT tests by visit

Description:
This report displays missing, incorrect or duplicate SPECT records based on "Scheduled Time", "Testing to be performed" and " Medium or Sample Type" items and protocol requirements.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Scheduled Time

6. Medium or Sample Type

7. Testing to be performed

8. Group

9. Scenario: Scenario 1/Scenario 2/Scenario 3

Logic:
Scenario 1:

Logic 1.1: Subject non-initialized on SPECT form (NOTE 5)

OR

Logic 1.2:

Subject meets Criteria

AND

SPECT.Visitmnemonic  = 'Visitmnemonic'  of supp

AND

    (

    SPECT.Scheduled Time = NULL

    OR

    SPECT.Testing = NULL

    OR

    SPECT.Medium or Sample Type = NULL

    )

OR

Logic 1.3:

Subject meets Criteria from supporting document

AND

SPECT.Visitmnemonic  = 'Visitmnemonic'  from supporting document

AND

    (

    supp.Scheduled Time not exists in Spect.Scheduled Time on the same row

    OR

    supp.Medium or Sample Type  not exists in SPECT.Medium or Sample Type on the same row

    OR

    supp.Testing to be Performed not exists in SPECT.Testing to be Performed on the same row

    )

Scenario 2:

Logic 2:

Subject meets Criteria

AND

SPECT.Visitmnemonic  = 'Visitmnemonic'  of supp

AND

There is duplicate records that meet below logic

(

SPECT.Scheduled Time = 'Scheduled Time' of supp on the same row

AND

SPECT.Testing  = 'Testing' of supp on the same row

AND

SPECT.Medium or Sample Type = 'Medium or Sample Type' of supp on the same row

)

Scenario 3:

Logic 3.1:

Subject meets Criteria

AND

SPECT.Visitmnemonic  = 'Visitmnemonic'  of supp

AND

(

SPECT.Scheduled Time <> NULL and SPECT.Scheduled Time <> 'Scheduled Time' of supp on the same row

OR

SPECT.Testing <> NULL and SPECT.Testing  <> 'Testing' of supp on the same row

OR

SPECT.Medium or Sample Type <> NULL and SPECT.Medium or Sample Type <> 'Medium or Sample Type' of supp on the same row

)

Logic 3.2:

Subject didn't meet Criteria

and there is a scheduled time not equal "Unscheduled" on SPECT.Visitmnemonic='Visitmnemonic' of supp

Logic 3.3:

For all subjects

There is a scheduled time not equal "Unscheduled" on SPECT.Visitmnemonic not equal 'Visitmnemonic' of supp

Note 1: If supporting doc is not provided, display the message as "ONC_SPECT _001_JR_STD Supporting Document Not Present for This Trial".

Note 2: Please exclude deleted records and erroneous visits from programming.

Note 3: Only display outputs when DOV of respective visit was initialized by providing Date of Visit.

Note 4: Please exclude Scheduled Time “Unscheduled” from Logic 3 programming.

Note 5: If parameter “Output for non-initialized SPECT form” is selected as Y then display output for Logic 1 for visits with non-initialized and initialized SPECT form, if parameter is selected as N then display output for Logic 1 only if SPECT form was initialized on the visit.

Note 6: ‘Group’ will only be considered in scenario 1, not for scenario 2 and 3

Note 7: For scenario 1, if two records are in the same group, one record match logic and one record does not, then output is not expected.

Note 8: Scenario 1 only check the values supp doc defined

If there is a special character in item question, then quotes need to be used.
