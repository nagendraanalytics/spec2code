Report ID: RID093

Report Title:
External Vendor Data Listing

Description:
This report displays the external vendor data loaded into the LABS views of the InForm reporting schema.  If Blinded Flag is set on a LABS record, the fields with blinded data will display 'xxxx'. Recommended format: Excel or csv.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. eCRF

6. Seq

Specific fields of LABS eCRF

Logic:
This report should retrieve all external vendor LABS data.

If Blinding flag='B' for LABS then the following fields should display 'xxxx':

- Specimen Condition

- Lab - Specimen Comments

- Investigator - Specimen Comments

- Test Level Comments

- Reported Text Result

- Reported Numeric Result

- Conventional Text Result

- Conventional Numeric Result

- SI Text Result

- SI Numeric Result

- Alert Flag

- Toxicity Grade

- Toxicity Grade Code List

Report should not display deleted records.

This report applies to LABS eCRF up to version from 08Mar2016.

If any of the field names on the eCRF coincide with the standard report fields, then the form mnemonic precedes the eCRF field name.
