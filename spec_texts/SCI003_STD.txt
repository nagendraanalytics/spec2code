Report ID: SCI003_STD

Report Title:
Reconcile Substudy Consent with Specimen Collection

Description:
This report has cross-checks between SCI and SSTC to confirm consent was obtained prior to specimen collection

Column Heading:
1. Country

2. Site

3. Subject Number

4. SSTC Seq

5. SSTC Consent Obtained

6. SSTC Consent Date

7. SCI Visit

8. SCI Seq

9. SCI Specimen ID

10. SCI Specimen Obtained Date

Logic:
This report has cross-checks between SCI and SSTC to confirm consent was obtained prior to specimen collection:

Type of substudy =cerebrospinal fluid

and

SCI Speciment type =cerebrospinal fluid

and

SSTC substudy consent obtained is Yes, yet SCI Specimen ID is blank for the visits selected by user. Do not output when DOV is not completed for the visits selected by user. If the parameter selection for visit mnemonic is not selected, default to check all of the visits with SCI form.

or

SSTC substudy consent obtained is No, yet SCI Specimen ID is not blank.

or

SSTC substudy consent obtained date is after the SCI Specimen(s) obtained date ( only consider date).

or

SCI is present, yet SSTC is null.

or

SSTC completed SSTC substudy consent obtained is Yes, SCI is null for the visits selected by user. Do not output when DOV is not completed for the visits selected by user. If the parameter selection for visit mnemonic is not selected, default to check all of the visits with SCI form.

 This report should not display deleted records. Erroneous visit should not be considered in programming or output.

Report Scenarios:
A- Yes

SSTC substudy consent obtained is Yes, yet SCI Specimen ID is blank.

B-Yes

SSTC substudy consent obtained is No, yet SCI Specimen ID is not blank.

C- Yes

SSTC substudy consent obtained date is after the SCI Specimen(s) obtained date ( only consider date).

D- Yes

SCI is present, yet SSTC is null.

E-No

SSTC substudy consent obtained is Yes and SCI Specimen ID is not blank and SSTC substudy consent obtained date is before or equal to the SCI Specimen(s) obtained date

F-Yes/No

Deleted record

G-No

Type of substudy <>cerebrospinal fluid or Specimen type <>cerebrospinal fluid

Country, Site, Subject Number

Parameter Selection:
Country, Site, Subject , Visit, Randomized Only
