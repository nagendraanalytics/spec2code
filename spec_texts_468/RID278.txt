Report ID: RID278

Report Title:
Missing Overall Response and/or Best Overall Response

Description:
This report displays subjects with missing Overall Response and/or Best Overall Response.

Column Heading:
1.	Country

2.	Site Number

3.	Subject Number

4.	Screening Number

5.	Vendor eCRF

6.	Vendor Category

7.	Vendor Date of Measurement

8.	Scenario

Logic:
Logic 1:

Logic 1.1:

There is at least one "External Form" record with the following criteria: ("External Form"."Vendor Name"/"Transmission Source ID" = "Vendor Name" per supporting document AND "External Form"."Category" = "Category" per supporting document AND "External Form"."Test Short Name" = "Overall Response" per supporting document)

AND

Logic 1.2:

There is NOT at least one "External Form" record with the following criteria: ("External Form"."Vendor Name"/"Transmission Source ID" = "Vendor Name" per supporting document AND "External Form"."Category" = "Category" per supporting document AND "External Form"."Test Short Name" = "Best Overall Response" per supporting document)

Logic 2:

Logic 2.1:

There is at least one "External Form" record with the following criteria: ("External Form"."Date of Imaging"/"Actual Collection Date and Time"/"Date/Time of Measurement" NOT NULL AND "External Form"."Vendor Name"/"Transmission Source ID" = "Vendor Name" per supporting document AND "External Form"."Category" = "Category" per supporting document)

AND

(

Logic 2.2:

If parameter Consider Scheduled Time = Y AND “External Form”.Scheduled Time Name= “Scheduled” for (("External Form"."Date of Imaging"/"Actual Collection Date and Time"/"Date/Time of Measurement") +/- parameter Window of Days for Scheduled), there is NOT at least one "External Form"."Test Short Name" = "Overall Response" with "Result or Finding in Original Units" NOT NULL.

OR

Logic 2.3:

If Consider Scheduled Time = Y AND “External Form”.Scheduled Time Name = “Unscheduled” for (("External Form"."Date of Imaging"/"Actual Collection Date and Time"/"Date/Time of Measurement") +/- parameter Window of Days for Unscheduled), there is NOT at least one "External Form"."Test Short Name" = "Overall Response" with "Result or Finding in Original Units" NOT NULL.

OR

Logic 2.4:

If Consider Scheduled Time = N for the same "External Form"."Date of Imaging"/"Actual Collection Date and Time"/"Date/Time of Measurement" there is NOT at least one "External Form"."Test Short Name" = "Overall Response" with "Result or Finding in Original Units" NOT NULL.

)

Notes:

1-	Logic 1 will check at subject level.

2-	Logic 2 will check at “External Form"."Date of Imaging"/"Actual Collection Date and Time"/"Date/Time of Measurement" level.

3-	Deleted records are excluded from programming

4-	Do not output for logic 2, If "External Form"." Baseline Flag “is Y OR do not show output for the first set of the patient data as per External Form"."Date of Imaging"/"Actual Collection Date and Time"/"Date/Time of Measurement" level OR do not show output for sets of patients data before “Date of Visit”.”DOV”.”Visit Mnemonic” where Visit Mnemonic = parameter First Visit after Baseline

5-	If study does not have item “External Form”.Scheduled Time Name report should ignore logic 2.2 and 2.3.

Supporting document notes:

If supporting doc is not provided, display the message as "ONC_EVD_015_JR_STD Supporting Document Not Present for This Trial".

Requires supporting document to be named ONC_EVD_015_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. External Form – Provide external data form mnemonic, e.g. GEFCF, CIMG.

2. Vendor Name - Provide the name of the vendor as transferred to the corresponding external form.

3. Category – Provide the lesion evaluation category according to the protocol, e.g. RECIST 1.1, irRECIST 1.1.

4. Overall Response – Provide the test short name for “Overall Response” as per PSA.

5. Best Overall Response - Provide the test short name for “Best Overall Response” as per PSA.

e.g.

External Form,Vendor Name, Category,Overall Response, Best Overall Response

GEFCF,PAREXEL,irRECIST,OVRLRESP, BESTRESP

CIMG,BIOCLIN,RECIST 1.1, OVRLRESP, BESTRESP

CIMG,BIOCLIN, mRECIST, OVRLRESP, BESTRESP

CIMG,CALYX,iRECIST , OVRLRESP, BESTRESP

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

	Output Yes

b)	If logic 2 is met.

Output No:

b)	If logic 2 is not met.

Sorting:
