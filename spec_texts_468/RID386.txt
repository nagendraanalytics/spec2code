Report ID: RID386

Report Title:
Prior oncologic surgery reconciliation

Description:
This report lists subjects that do not have record of Prior Oncologic Surgeries according to protocol requirements

Column Heading:
1. Country

2. Site

3. Subject Number

4. Date of Randomization

5. Current Oncological Disease Details Form

6. Expected Oncologic Surgery

7. Error Message

Logic:
Logic 1:

“Did the Subject Have Oncologic Surgery” in the <Current Disease Oncologic Form> = “Yes”

AND

There is NO (

OS.LLT = <Oncologic Surgery >

And

OS.Date Performed < SR.Date of Assessment

)

Logic 2:

<Current Disease Oncologic Form>. <Item Question > = <Expected Option Selection>

AND

There is NO

(OS.LLT = <Oncologic Surgery >

and OS.Date performed >= SR.Date of Assessment - <Allowed Number of Weeks>

and OS.Date performed <= SR.Date of Assessment

)

Requires supporting document to be named ONC_OS_003_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each scenario

1. Scenario

2. Current Disease Oncologic Form (include CDDU, CDDB,CDDG,CDDGY,CDDH,CDDHN,CDDM,CODD)

3. Oncologic Surgery

4. Item Question

5. Expected Option Selection

6. Allowed Number of Weeks

(For scenario 1 leave in blanks columns 4, 5 and 6. If any scenario is not needed, it can be excluded in the Supporting Document and the report will not output for that)

E.g.

Scenario	Current Disease Oncologic Form	Oncologic Surgery        	Item Question	Expected Option Selection	Allowed Number of Weeks

1	CDDU	Radical

2	CDDU	Nephrectomy	Metastasis	M0	12

2	CDDU	Nephrectomy	Metastasis	M1	52

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Note 1: Only output for randomized subjects (SA. Did subject meet all eligibility criteria? = Yes)

Note 2: Deleted records and Erroneous Visits should not be taken into account for programming

Note 3: When UNK is selected as the day in OS (OS.Date Performed), use the first day of the month instead

If UNK is selected in Month Option, consider the last month of the year (December).

Report Scenarios:
Scenario 1:

Output: Yes - “Did the Subject Have Oncologic Surgery” in the Current Disease Oncologic Form is marked yes; however; there is no record for a certain surgery on the OS eCRF.

Output: Yes - “Did the Subject Have Oncologic Surgery” in the Current Disease Oncologic Form is marked yes; and there is a record for a certain surgery on the OS eCRF, but Date of Surgery is on or after date of randomization.

Output: No - “Did the Subject Have Oncologic Surgery” in the Current Disease Oncologic Form is marked No and there is no record for a certain surgery on the OS eCRF.

Output: No - “Did the Subject Have Oncologic Surgery” in the Current Disease Oncologic Form is marked yes and there is a record for a certain surgery on the OS eCRF, prior to Date of Randomization.

Output: No - Did subject meet all eligibility criteria? = No

Scenario 2:

Output: Yes – A certain Item Question is reported as a certain option, however there is not a surgery reported within specific time prior to randomization.

Output: Yes – A certain Item Question is reported as a certain option, however there is a surgery reported, but, on the same date or after the date of randomization.

Output: No – A certain Item Question is reported as a certain option, and there is a surgery reported for a certain number of weeks prior to date of randomization.

Output: No - Did subject meet all eligibility criteria? = No

(All the information required will be provided by a supporting document described in logic section)

Sorting:
Country, Site, Subject Number, Date of Randomization, Current Oncological Disease Details Form, Expected Oncologic Surgery, Error Message

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Supporting Doc Page (Y)

Form.Item Names:
1. SA. Site Country

2. SA. Site Mnemonic

3. SA. Subject Number

4. SR.Date of Assessment

5. Current Disease Oncologic Form (According of what is entered in the Supporting Document Column 2)

6. Oncologic Surgery (According of what is entered in the Supporting Document Column 3)

7. Display 'Scenario 1' if Logic 1 is met or 'Scenario 2' if Logic 2 is met
