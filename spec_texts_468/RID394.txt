Report ID: RID394

Report Title:
Missing oncologic signs and symptoms

Description:
This report will list subjects who are missing oncologic signs and symptoms that should be assessed every time Lesion Evaluation is done including at baseline.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Seq number

5. Date of Lesion Evaluation

Logic:
Logic 1: LSN. DATE OF LESION EVALUATION <> Null

AND

Logic 2: There is no OSS record with OSS. Date of Assessment = LSN. DATE OF LESION EVALUATION from Logic 1                                                                                                                                                                                                                                                       Note1: Deleted records should not be displayd in output.                                                                                                                                                                                                                                                                                                                                                 Note2: This report uses the LSN global supp doc, Date of lesion evaluation comes from the supp doc.

Report Scenarios:
REPORT SCENARIOS:

A - Yes:

There is no OSS. Date of Assessment = LSN. DATE OF LESION EVALUATION.

B - Yes:

LSN. DATE OF LESION EVALUATION <> Null AND (OSS. Date of Assessment =Null OR OSS Form not initiated).                                                                                                                                                                                                                                                                      C - No:

There is one OSS. Date of Assessment = LSN. DATE OF LESION EVALUATION

D- Yes:

when OSS is deleted

E- No:

when LSN. Date of Lesion evaluation<>NULL and LSN. Date of Lesion evaluation is deleted

Sorting:
(Defaulted to Country, Site Number and Subject Number if not specified): Country, Site, Subject Number.

Parameter Selection:
Country, First Site, Last Site, First subject, Last Subject, List of Subjects, Randomized only (N/Y, default as N)

Form.Item Names:
1. SA.Country

2. SA.Site

3. SA.Subject Number

4. LSN. Formidx

5. LSN. DATE OF LESION EVALUATION
