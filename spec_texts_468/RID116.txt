Report ID: RID116

Report Title:
Missing Test Result for a specific visit

Description:
This report displays all tests that should have at least one valid Result reported in the vendor transfer on LABS and GEFCF. If there are only records with Completion Status as Not Done for selected tests, outputs will be displayed.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. Visit

6. Form

7. Vendor

8. Test

9. Test short name

10.Specimen ID

11. Completion Status

Logic:
This report lists all tests that should have at least one valid Result reported in the vendor transfer on LABS, GEFCF and Completion Status =Not Done

1.Output Yes

A.

GEFCF. Subject Number is equal between records for same GEFCF.Test Short Name and same GEFCF.Visit Name

AND

GEFCF.Result or Finding in Original Units is NULL for ALL records

AND

GEFCF.Completion Status = Not Done for ALL records.

B.

LABS.Subject Number is equal between records for same LABS.Lab Test ID and same LABS.Visit Name

AND

LABS. Reported Text Result is NULL for ALL records

AND

LABS. Test Status in ('N','X') for ALL records.

2.Output No

A.

GEFCF. Subject Number is equal between records for same GEFCF.Test Short Name and same GEFCF.Visit Name

AND

GEFCF.Result or Finding in Original Units is ≠ NULL for at least one record

B.

LABS.Subject Number is equal between records for same LABS.Lab Test ID and same LABS.Visit Name

AND

LABS. Reported Text Result is ≠ NULL for at least one record

Note:

1.Report should not display records in erroneous visits or  DOV.Date of Visit for the visit is Null

Report Scenarios:
Scenario 1 :

Output Yes

Output should be displayed if:

A.GEFCF:

For same subject at same visit, all the rows for the same test have Completion Status as Not Done.

B.LABS

For same subject at same visit, all the rows for the same test have Test Status in ('N','X')

Scenario 2 :

Output No

No Output is expected if:

A.GEFCF:

For same subject at same visit, at least one record for a test have Result or Finding in Original Units completed.

B.LABS

For same subject at same visit, at least one record for a test have Test Status as D and corresponding Reported Text Result completed.
