Report ID: RID079

Report Title:
Missing Medication Derivations

Description:
This report displays a listing of all Medication terms where Encoded Drug Name is not null but at least one of following is null: Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term OR where Encoded Drug Name is null, but at least one of the following is not null: Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF

6. Seq

7. Medication Name

8. Encoded Drug name

9. Standardized Medication Name

10. Broader term

11. Medication Class Code

12. Medication Class Term

13. ATC1 Term

14. ATC2 Term

Logic:
The report should display output if

1) Encoded Drug Name is not null but at least one of following is null:  Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term or

2) Encoded Drug Name is null, but at least one of the following is not null:  Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term

Display row count in footer

Report should not display deleted records.

If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
Refer to Test data

Sorting:
Country, Site, Subject Number, Visit, eCRF, Seq

Parameter Selection:
Country, Site, Subject, Randomized Only, Visit, eCRF, List of Subjects
