Report ID: RID157

Report Title:
Missing Follow-Up Forms per schedule

Description:
This report displays subjects who are missing a Follow up Assessment based on specific interval.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Stratification

5. Start Form of Follow Up

6. Start Date of Follow Up

7. Form for Calculation

8. Date of Calculation

9. Follow Up Visit

10. Missing eCRF

11. Week

12. Expected Assessment Date Range

Logic:
There is NO ‘End of Follow Up CONDFORM.End of Follow Up CONDITEM’ that meets condition provided by ‘End of Follow Up CONDSYMBOL’ and ‘End of Follow Up CONDRESULT’

AND

‘CONDFORM.CONDITEM’ provided in Supporting document is <> NULL

AND

‘CONDFORM.CONDITEM’ meets condition provided by ‘CONDSYMBOL’ and ‘CONDRESULT’

AND

There is NO ‘eCRF.DATE OF eCRF’ in ‘VISIT’ which is within the ‘Week’ (see note 8) timeframe ‘DATEFORM.CALCDATE’ AND that is after ‘CONDFORM.CONDDATE’

Logic 2: ‘Criteria form.Criteria itemquestion’ meets condition provided by ‘Criteria Value’

Note 1: Deleted records and Erroneous Visits should not be taken into account for programming.

Note 2: CONDSYMBOL can be entered as “=” that means that CONDFORM.CONDITEM should be = to CONDRESULT, or can be entered as “<>” that means that CONDFORM.CONDITEM should be <> to CONDRESULT

Note 3: End of Follow Up CONDSYMBOL can be entered as “=” that means that End of Follow Up CONDFORM.End of Follow Up CONDITEM should be = to End of Follow Up CONDRESULT, or can be entered as “<>” that means that End of Follow Up CONDFORM. End of Follow Up CONDITEM should be <> to End of Follow Up.CONDRESULT

Note 4: CONDRESULT can be entered as a Value or can be entered as “NULL”. NULL value means than CONDFORM.CONDITEM should be “=” or “<>” (according to CONDSYMBOL) to blank/null/not completed

Note 5: End of Follow Up CONDRESULT can be entered as a Value or can be entered as “NULL”. NULL value means than End of Follow UpCONDFORM. End of Follow UpCONDITEM should be “=” or “<>” (according to CONDSYMBOL) to blank/null/not completed

Note 6: For Column #12 display the date range expected by showing (the minimum day to maximum day) using the format: (dd-Mmm-yyyy TO dd-Mmm-yyyy). This expected range will be calculated using the items 'CALCDATE', ‘Expected Week’, 'Minimum days allowed’, 'Maximum days allowed'.

Steps to calculate the 'Expected timeframe':

A.      Calculate different timepoints by doing the following mathematical operation:

Timepoint 1: CALCDATE + Expected Week

Timepoint 2: CALCDATE + 2* Expected Week

Timepoint 3: CALCDATE + 3* Expected Week

Timepoint N: CALCDATE + (N)* Expected Week

B.      Timepoints calculated on step A should be: CALCDATE + Expected Week <= Timepoint N <= CALCDATE + (N)* Expected Week

C.      Expected Timeframe = From Timepoint N - 'Minimum days allowed’ to Timepoint N + 'Maximum days allowed'

Example:

A.      CALCDATE = 01-Jan-2020

B.      CONDDATE = 20-Feb-2020

C.      Expected week = 6

D.      Minimum days allowed = 7

E.      Maximum days allowed = 7

Timepoint 1 = 01-Jan-2020 + 6 weeks = 12-Feb-2020  [NO OUTPUT, Outputs should only start for timepoints after CONDDATE]

Expected Timeframe 1 = From 05-Feb-2020 to 19-Feb-2020  [NO OUTPUT, Outputs should only start for timepoints after CONDDATE]

Timepoint 2 = 01-Jan-2020 + 6 weeks + 6 weeks = 25-Mar-2020  [OUTPUT]

Expected Timeframe 2 = From 18-Mar-2020 to 01-Apr-2020  [OUTPUT]

Timepoint 3 = 01-Jan-2020 + 6 weeks + 12 weeks = 06-May-2020  [OUTPUT]

Expected Timeframe 3 = From 29-Apr-2020 to 13-May-2020  [OUTPUT]

For column #11 the number will be equal to (N)*Expected Week

Note 7: Report should OUTPUT when the specific entry in eCRF in the specific VISIT is missing according to the timeframes defined (Expected Assessment Date Range). However, report only should display an output when the Maximum day expected for the eCRF is LESS than Current System Date.

Note 8: Report should OUTPUT UNTIL there is a End of Follow Up CONDFORM. End of Follow Up CONDITEM (= or <> according to End of Follow Up CONDSYMBOL) to End of Follow Up CONDRESULT

Note 9: Criteria Form, Criteria Itemquestion and Criteria Value can be entered as “NA” in supporting document. In that case Logic 2 is not applicable. In the report display “NA” for Criteria form.Criteria itemquestion.

Note 10: Report requires supporting document to be named PMS002_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Criteria form- Unique value in each group, specified as per each protocol and should reflect the appropriate form used to the stratification of the subjects. Specified as ‘NA’ if no criteria form is expected for any subject.

2. Criteria itemquestion- Unique value in each group, specified as per each protocol and should reflect the cohort or arm that subject was randomized in. Specified as ‘NA’ if same cohort or arm with no different value in day window is check for all subjects.

3. Criteria Value- Unique value in each group, specified as per each protocol and should reflect the study medication assigned for subjects regarding stratification form and cohort or arm.  Specified as NA if same medication and frequency is check for all subjects.

4. VISIT– Follow Visit in where form is expected to be completed

5. eCRF – Expected Form to be completed during the Follow Up Visit

6. DATE OF eCRF – Date of the expected assessment

7. CONDFORM - Conditional form from which the count of follow up visits will start (PMST/PMS1/NATS/NAPS/SM/SMAB/SMPB/STR/TACE).

8. CONDITEM - Conditional item question within the CONDFORM form

9. CONDSYMBOL – Conditional logic symbol expected for the CONDRESULT within the CONDITEM (= or <>)

10. CONDRESULT - Condition result expected according to CONDFORM and CONDITEM (if it is expected that CONDITEM is not completed enter NULL)

11.CONDDATE - Condition Date item question according to CONDFORM- CONDITEM- CONDSYMBOL and CONDRESULT and from which the count of follow up visits will start

12. DATEFORM – Form where the calculation date will be present

13. CALCDATE - Condition Date item question according to DATEFORM from which the count of follow up visits will start

14. Expected Week Frequency – Frequency week after CONDATE in which form is expected to be completed, entered in number of weeks

15. Minimum days allowed – Minimum window of days from expected Week

16. Maximum days allowed - Maximum window of days from expected Week

17. End of Follow Up CONDFORM – Cut off form for Follow Up Visits

18. End of Follow Up CONDITEM - Cut off item form for Follow Up Visits

19. End of Follow Up CONDSYMBOL - Conditional logic symbol expected for the End of Follow Up CONDRESULT within the End of Follow Up CONDITEM (= or <>)

20. End of Follow Up CONDRESULT - - Condition result expected according to End of Follow Up CONDFORM and End of Follow Up CONDITEM (if it is expected that CONDITEM is not completed enter NULL)
