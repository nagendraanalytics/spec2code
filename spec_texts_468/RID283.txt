Report ID: RID283

Report Title:
Unblinded External Data Listing

Description:
This report outputs data from the GEFCF specified in the parameters based upon the Blinded_flag provided in the Protocol-Specific Addendum of External Data (PSA)

Column Heading:
For both Regulated BA Table and Unmasked Table:

1. Country

2. Site

3. Screening Number

4. Subject Number

5. eCRF

6. Seq - Specific fields of  GEFCF eCRF

Logic:
This report should retrieve all external vendor GEFCF data.

Note 1: For Regulated BA Table, if Blinded Flag is set on a record, the below fields will display as 'xxxx'.

- Result or Finding in Original Units

- Original Units

- Character Result/Finding in Std Format

- Numeric Result/Finding in Standard Units

- Standard Units

Note 2: Report output display message When there is no records from Vendor and External Data Form ""No records meet the test condition""

Note 3: Report should not display deleted records.

Note 4: If any of the field names on the eCRF coincide with the standard report fields, then the formmnemonic precedes the eCRF field name.

Note 5: As a clarification:

* If the Blinded Flag is completed and Regulated table is selected, the mentioned items in note 1 should be 'xxxx'.

* If the Blinded Flag is completed and Unblinded table is selected, the mentioned items in note 1 should be populated as entered in GEFCF.

* If the Blinded Flag is empty, doesn't matter which table is selected, the mentioned items in note 1 should be populated as entered in GEFCF.

Report Scenarios:
Output Yes:  For Regulated BA Table

List of external vendor data loaded into the GEFCF views of the InForm reporting schema, but the fields as Result or Finding in Original Units, Original Units, Character Result/Finding in Std Format, Numeric Result/Finding in Standard Units and Standard Units with blinded data will display 'xxxx' if Blindede Flag is set o a record.

Output Yes:  For Unmasked Table

List of external vendor data loaded into the GEFCF views of the InForm reporting schema.

Sorting:
Country, Site, Subject Number, eCRF

Parameter Selection:
Vendor, Table (Regulated BA Table/Unmasked Table)

Form.Item Names:
For both Regulated BA Table and Unmasked Table:

1. Subject Assignment.Site Country

2.Subject Assignment form.Site Mnemonic

3. Subject Assignment form.Screening Number

4. Subject Assignment form.Randomization Number

5. Form Mnemonic

6. Formidx. Specific fields from GENERIC EXTERNAL FINDINGS Form
