Report ID: RID431

Report Title:
Missing New Non-Study Anti-Cancer Therapy according to Label Description Status

Description:
This report displays missing New Non-Study Anti-Cancer Therapy based on the reason for discontinuation selected in Label Description Status in SM, SMAU, SMAB, STR.

Column Heading:
1. Country

2. Site

3. Subject number

4. Visit Mnemonic

5. Study medication form

6. Seq #

7. Study Medication

Logic:
Report will output the subjects who meet following criteria:

Logic

Logic 1: SM/SMAB/SMAU/ STR. Label description status/Study Medication Status/Radiation Status in (New Non-Study Anti-Cancer Therapy, Need for Excluded Medication Discontinuation Criteria).

AND

Logic 2: There is no ODBF/ODBHF/ODBNF/ODBCF /ORAD2/ OSOF/OSOFL.date >= min SM/SMAB/SMAU/SM. Stop date/time in Logic 1

Note 1: Erroneous visit or deleted record will not be considered in the programming or output.

Note 2: If "Ignore Surgery done per protocol " prompt is yes, Ignore OSOF/OSOFL records with OSOF/OSOFL Is This Surgery With Curative Intent (Definitive Surgery)? =  Yes OR Intent of Surgery = Curative

Note 3: If "Ignore Palliative Radiation " prompt is yes, Ignore ORAD2 records with Reason for Radiation response contains the word “Palliative” OR Treatment Category response contains the word “Palliative”

Note 4: for dates comparison in ODBF/ODBHF/ODBNF/ODBCF eCRFs use Imputed Start Date of Medication OR Imputed Start date of regimen , for OSOF eCRFs use Date and Time Performed and for ORAD2 use Start Date.

Note 5: If Date/Month is UNK, please apply below hardcode rule:

UNK day=first day of the month

UNK month=first month of the year

Note 6: If both dates Start Date of Medication and Start Date of Regimen are present on the ODBF/ODBHF/ODBNF/ODBCF  forms, please use minimum Start Date of Medication for comparison

Report Scenarios:
Report Scenarios

SCENARIO 1 [Output = Yes]

A - YES

Label description status at SM/SMAB/SMAU OR Radiation Status at STR = New Non-Study Anti-Cancer Therapy AND ODBF/ORAD2/OSOF = NULL

B - YES

Label description status at SM/SMAB/SMAU OR Radiation Status at STR = New Non-Study Anti-Cancer Therapy AND date in ODBF/ODBHF/ODBNF/ODBCF is less than SM/SMAB/SMAU.Stop Date/Time

C - YES

Label description status at SM/SMAB/SMAU OR Radiation Status at STR = New Non-Study Anti-Cancer Therapy AND date in ORAD2 is less than SM/SMAB/SMAU.Stop Date/Time

D - YES

Label description status at SM/SMAB/SMAU OR Radiation Status at STR = New Non-Study Anti-Cancer Therapy AND date on OSOF is less than SM/SMAB/SMAU.Stop Date/Time

E – NO

Label description status at SM/SMAB/SMAU OR Radiation Status at STR = New Non-Study Anti-Cancer Therapy AND there is any date in ODBF/ODBHF/ODBNF/ODBCF /ORAD2/ OSOF/OSOFL >= SM/SMAB/SMAU.Stop Date/Time.

F - YES

Label description status at SM/SMAB/SMAU OR Radiation Status at STR = New Non-Study Anti-Cancer Therapy AND ODBF/OSOF = NULL AND all ORAD2 records have Reason for Radiation = Palliative Treatment or Symptom Control OR Palliative Treatment or Symptom Control of Metastatic Disease when "Ignore Palliative Radiation" prompt is yes

G - Yes Label description status at SM/SMAB/SMAU OR Radiation Status at STR = New Non-Study Anti-Cancer Therapy AND ODBF/ODBHF/ODBNF/ODBCF /ORAD2 = NULL AND all OSOF/OSOFL Records with Is This Surgery With Curative Intent (Definitive Surgery)? =  Yes OR Intent of Surgery = Curative

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, Randomized Only(Y/N Default as N)  Ignore Palliative Radiation (No/Yes, Default Value = No, required), Ignore Surgery done per protocol (No/Yes, Default Value = No, required )
