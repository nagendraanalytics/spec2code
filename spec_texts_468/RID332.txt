Report ID: RID332

Report Title:
Initial Overall Response vs Lesion Evaluation measurements

Description:
This listing contains details about the type of lesions reported under Tumor Identification item on LSRIR (Target, Non-target, and New) and the corresponding RECIST and irRECIST Responses (Target, Non-Target and Overall Response) recorded in RIRR.

- For the Target lesions (Target or Target Nodal or Target Extra Nodal) the listing will show the Target Lesion

Measurement for each lesion and the Summatory of the diameters (SOD) for the all the lesions evaluated on the same date. If the item "Was the Lesion Evaluable?" is selected as No, the lesion will appears as Not evaluable.

- For the Non-target lesions (Non-Target or  Non-Target Nodal or Non-Target Extra Nodal), the listing will show the total number of lesions for each Non-Target lesion status  (Baseline, Absent, Present, Worsening, Not evaluable) evaluated on the same date.

- For the New lesions (or New Lesion Since Last Evaluation), the listing will show the total number of lesions for each New Lesion status  (Absent, Present, Worsening, Not evaluable) evaluated on the same date.

SOD = sum of all Target lesions (nodal and extra-nodal) for each time of assessment.

Logic:
Report will output the subjects who meet following criteria.

(Logic 1: RRIR, 'Date Response Determined' AND 'Overall RECIST Response' or 'Overall irRECIST Response' are not Null

AND

Logic 2: LSRIR, 'Tumor Identification'=Target or Target Nodal or Target Extra nodal; or Non-Target or  Non-Target Nodal or Non-Target Extra nodal; or New Lesion Since Last Evaluation AND

Logic 3: LSRIR, Evaluation Entry with 'Date of Lesion Evaluation' or 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam)'  is within 'Date Response Determined' of RRIR minus 0~3 days)

OR

(Logic 4: RRIR, 'Date Response Determined' AND 'Overall RECIST Response' or 'Overall irRECIST Response' are not Null

AND

Logic 5: No LSRIR record which 'Tumor Identification'=Target or Target Nodal or Target Extra nodal; or Non-Target or  Non-Target Nodal or Non-Target Extra nodal; or New Lesion Since Last Evaluation WITH 'Date of Lesion Evaluation' or 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam)'  is within 'Date Response Determined' in RRIR minus 0~ 3 days in Evaluation Entry)

OR

Logic 6: LSRIR, 'Tumor Identification'=Target or Target Nodal or Target Extra nodal; or Non-Target or  Non-Target Nodal or Non-Target Extra nodal; or New Lesion Since Last Evaluation AND 'Date of Lesion Evaluation' or 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam)' is out of any 'Date Response Determined' minus 0~ 3 days in RRIR form

OR

Logic 7: LSRIR form, Was the Lesion Evaluable? =No

Note4:

The supporting document is required for all trials if treatment phase is applied to logic even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp _< Vxxxxxxx csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required, the order on which phases will appear on protocol

2. Treatment Phase: required, name of each study phase (Initial Treatment Phase, Neodjuvant Phase, Second Course Phase)

3. First Visitmnemonic of Treatment Phase: required, the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Note5: Output is not expected to be produced for lesions and responses entered after the first confirmation of PD (RRIR. Overall irRECIST Response = irProgressive Disease)

take into account that first confirmed irPD is true when:  Overall irRECIST Response is completed as "irProgressive Disease"  and there is NO an error message in column 25

Note 6:

The report logic should be checked within the same treatment phase defined in the supporting document.

For example 1, if user provides one Treatment Phase in supporting document like below:

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Second Course Cycle 1

AND LSRIR.Tumor Identification = Target Extra Nodal OR Target Nodal

AND LSRIR.Tumor Identification <> New Lesion Since Last Evaluation

The treatment phase will be identified as following:

Initial Treatment Phase: DOV.Cycle 1 >= Form.Date < DOV.Second Course Cycle 1

Second Course Phase: DOV.Cycle 1 < Form.Date <= Second Course Cycle 1

18. SOD is calculated as Sum of ‘Target Lesion Measurement’ and 'Longest Diameter (Extra Nodal Lesion)' and ' Short Axis (Nodal Lesion)' of all records of  Evaluation Entry of LSRIR which 'Tumor Identification'=Target, Target Nodal and Target Extra nodal AND have same Date of Evaluation or Date of Current Lesion Evaluation (Scan/Image/Physical Exam). SOD should only display for logic 3, 5 and 6 when 'Tumor Identification'= Target, Target Nodal and Target Extra nodal.

Display the whole addition expression like “1.5+2.5=3.0”, not only “3.0”. Note: for SOD only consider the items present int he eCRF of the study. If Longest Diameter (Extra Nodal Lesion) and Short Axis (Nodal Lesion) are present, if Tumor identification is Target Extra Nodal only consider Longest Diameter (Extra Nodal Lesion); if Tumor identification is Target Nodal only consider Short Axis (Nodal Lesion).

19. % Change from Baseline is calculated  as [(SOD from current Timepoint - SOD from Baseline)/SOD from Baseline]*100%. Baseline SOD corresponds to the SOD of the Baseline assessment, i.e., evaluation done prior first Dose. If lesions are re-evaluated prior to a subsequent treatment phase Cycle 1 (i.e., second course phase, Cycle 1 < Date of assessment in LSRIR < Second Course Cycle 1), consider the SOD as the re-baseline SOD. If SOD from Baseline is equal to 0, ignore calculation and display "Baseline is zero".

20. % Change from Nadir is Calculated as  [(SOD from current Timepoint - SOD from Nadir)/SOD from Nadir]*100%. Nadir SOD corresponds to the smallest SOD of all prior lesion evaluations of current Timepoint. If lesions are re-evaluated prior to a subsequent treatment phase Cycle 1 (i.e., second course phase, Cycle 1 < Date of assessment in LSRIR < Second Course Cycle 1), consider the smallest SOD since re-baseline as the SOD from Nadir. If SOD from Nadir is equal to 0, ignore calculation and display "Nadir is zero".
