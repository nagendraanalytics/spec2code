Report ID: RID234

Report Title:
Cardiac Imaging Method Reconciliation

Description:
This report displays subjects with inconsistent Cardiac Imaging Method when it is expected to be same for each subject throughout the study.

Column Heading:
1. Country

2.            Site

3.            Subject Number

4.            Visit

5.            DOV

6.            CIM Seq

7.            Date/Time of Assessment

8.            Current Method

9. Earliest Method

Logic:
Current CIM.Date/Time of Assessment <> Null AND

Current CIM.Method <> Earliest CIM.Method

Note 1: Report should not take into account Deleted records or erroneous visits

Note 2: If time is UNK use 00:00:00

Note 3: If there are two or more records with the earliest date, use the record with earliest DOV and lowest sponsor ID number.

Report Scenarios:
Scenario A: Output = Yes

Current method of assessment is different from the earliest method in CIM form.

Scenario B: Output = No

Current method of assessment is equal to the earliest method in CIM form.

Sorting:
Country, Site, Subject Number, Visit, DOV,CIM seq, Date/Time of Assessment, Method

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N, Default as N)

Form.Item Names:
1.              SA.Country

2.            SA.Site Mnemonic

3.            SA. Subject Number

4.            Visits.Visit Mnemonic

5.            Visits.DOV

6.            CIM.Sponsor ID number

7.            CIM.Date/Time of Assessment

8.            CIM.Method

9. Populate with the CIM.Method earliest record pero report logic.
