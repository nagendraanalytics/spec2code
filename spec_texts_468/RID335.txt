Report ID: RID335

Report Title:
Duplicate NAPS

Description:
This report will list duplicate NAPS records.

Column Heading:
1. Country

2. Site

3. Subject Number

4. NAPS Visit

5. Associated Sponsor ID Number

6. NAPS Indicate the Phase Not Started by the Subject

Logic:
IF There is more than one entry of NAPS record with the same “NAPS. Indicate the Phase Not Started by the Subject” throughout the visits OR within the same visit, for the same patient.

Note 1: Do not consider deleted records and erroneous visit.

Note 2: Do not consider blank records.

Note 3: If NAPS is set as a common form within a study, then display "CCRF" on NAPS visit column.

Note 4: for “NAPS visit” column display duplicate visits separated by a comma

Note 5: for “Associated Sponsor ID Number” column display duplicate Associated Sponsor ID numbers separated by a comma

Report Scenarios:
Scenario A: Yes

If There is more than one entry of NAPS with the same “Indicate the Phase Not Started by the Subject” item for one patient

Scenario B: No

There is more than one entry of NAPS with different “Indicate the Phase Not Started by the Subject” item for one patient

Scenario C: No

There is no NAPS entered

Scenario D: No

There is only one entry of NAPS completed

Sorting:
Country, Site, Subject Number, Indicate the Phase Not Started by the Subject, Visit, Seq

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, default as N).

Form.Item Names:
1. SA.Country

2. SA.Site

3. SA.Subject Number.

4. NAPS.NAPS Visit (display visit as per logic Note 4)

5. NAPS.Associated Sponsor ID number (display duplicate Associated Sponsor ID numbers as per logic Note 5)

6. NAPS. Indicate the Phase Not Started by the Subject
