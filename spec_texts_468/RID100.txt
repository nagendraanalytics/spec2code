Report ID: RID100

Report Title:
Missing Lab Tests by Subject

Description:
This report lists subjects missing lab tests at scheduled visits.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Randomization Number

5. Subject Number

6. Visit ID or Number

7. InForm Visit Mnemonic

8. InForm Visit Date

9. Comments

10. Vendor

11. Battery ID

12. Specimen Type

13. Planned Collection

14. Missing Lab Test ID

15. Subgroup

16. Requisition Number

Logic:
The report should use the expected tests per visit and vendor, provided by the user, to identify the initialized scheduled visits with missing lab tests. If there are multiple visits with the same Visitmnemonic in InForm, the supporting spreadsheet for visits provided by the user should be retrieved from the environment where the report is going to be run.

Comments are obtained from the corresponding DOV and SCI forms and all comments should be concatenated in order to avoid multiple rows for multiple comments.

Missing Lab Test ID is based on the concatenation of the Lab Test IDs (vendor). Records with ""Cancelled' or ""Not Performed' test status should not be considered as missing.

If all tests are missing for Battery ID at a given visit, Missing Lab Test ID='Missing [Battery ID]'.

If the number of records for a given subject, visit, test, specimen type is not according to the number of records expected, it should be outputted on the report.

Country/Site/Randomization Number and List of Subjects prompts can be used independently. If both are used at the same time, the output will match both conditions.

The subjects provided in the List of Subjects should match the subject number format.

The Subgroup prompt allows to select one option as follows:

- Enter the value for exact match, e.g. Group1.

- Enter the value between percentages(%) for approximate match, e.g. %1%.

- Enter 99999 for subjects with blank subgroup.

Do not consider erroneous visits.

Do not consider deleted records.

Do not output if all Battery ID and all tests are missing for a visit.

Column for Accession ID or Number will have no data as report shows missing LABS.

This report requires 2 supporting documents and the naming conventions are as below.

1)For Visits : EVD021_supp1_<xxxxxxx>.csv

2)For Tests : EVD021_supp2_<xxxxxxx>.csv

EVD021_Supp1_<xxxxxxx> requires the following items.

1)visit_name : External vendor Visit name as per PSA

2)ecrf : Formnemonic of External vendor data

3)vendor : Vendor name as per PSA

4)visitid_or_number : visit number's given in column 'Visit ID or Number' as per PSA

5)visitmnemonic : Visitmnemonic from T&E

e.g.,

visit_name , ecrf,vendor,visitid_or_number,visitmnemonic

Screening, GEFCF,Q2LAB,1,Screening

EVD021_Supp2_<xxxxxxx> requires the following items.

1)ecrf : Formnemonic of External vendor data

2)vendor : Vendor name as per PSA

3)visitid_or_number : visit number's given in column 'Visit ID or Number' as per PSA

4) psa_vendor_test_id: Vendor test id as per PSA

5) psa_vendor_test_name: Vendor Test Name as per PSA

6) psa__test_id :  test id as per PSA

7)psa__test_name:  test Name as per PSA

8)psa_ battery_id : battery id as per PSA

9) planned_coll_time_desc: Planned Collection Time as present in External form, or NA if not applicable.

10)multiplicity : number of times particular test is required for particular visit, or NA if not applicable..

11)specimen_type : Provide unique specimen type, or NA if not applicable

12)subgroup : provide the value as per required sub group, or NA if not applicable.

Report Scenarios:
1) Multiplicity not met - Output=Yes

Expected: Lab Test ID=GLC, Visit=2, Multiplicity=2

Data: Lab Test ID=GLC, Visit=2, Multiplicity=1

2) Missing Lab Test ID at a given visit - Output=Yes

Expected: Lab Test ID=GLC, Visit=2, Multiplicity=2

a) Data: Lab Test ID=GLC, Visit=1, Multiplicity=2

b) Data: No Lab Test ID=GLC

3) Cancelled/Not Performed Test - Output=No

Expected: Lab Test ID=GLC, Visit=2, Multiplicity=1

Data: Lab Test ID=GLC, Visit=2, Multiplicity=1, Status=Cancelled/Not Performed

4) Missing Planned Collection Time Description - Output=Yes

Expected: Lab Test ID=GLC, Visit=2, Planned Collection=2h Post-dose

Data: Lab Test ID=GLC, Visit=2, Planned Collection=10h Post-dose

5) Matching Data - Output=No

Expected: Lab Test ID=GLC, Visit=2, Planned Collection=2h Post-dose/Multiplicity=1

Data: Lab Test ID=GLC, Visit=2, Planned Collection=2h Post-dose/Multiplicity=1
