Report ID: RID409

Report Title:
Incorrect RRIR Response

Description:
This report will display subjects with inconsistencies reported in RRIR between RECIST and irRECIST

Logic:
Scenario 1: 

Logic 1: RRIR form. Overall RECIST Response <> NULL.

AND 

Logic 1.1: The same RRIR form. Overall irRECIST Response is initialized 

AND

Logic 1.2. RRIR. Date Response Determined in Logic 1 = RRIR. Date Response Determined in Logic 1.1  

 

Scenario   2:

Logic 2.1: There is a RRIR. Overall RECIST Response = Progressive disease and RRIR. Date Response Determined <> NULL

AND

Logic 2.2: There is a RRIR. Overall RECIST Response <> NULL with Date Response Determined greater than RRIR in Logic 2.1 

 

Scenario 3:

Logic 2.3: RRIR form. Overall RECIST Response = Progressive Disease and there is not a SM/SMAU/SMAB/STR form. Start Date/Time greater than or equal to RRIR form. Date Response Determined    

AND 

{

Logic 2.4: (TBRP form The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression = Yes with TBRP form. Date of Assessment equal to RRIR form. Date Response Determined in Logic 2.3

OR 

Logic 2.5: TBIRP form The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression = Yes with TBIRP form. Date of Assessment equal to RRIR form. Date Response Determined in Logic 2.3)

OR

Logic 2.6: RRIR form. Overall RECIST Response = Progressive Disease and there is SM/SMAU/SMAB/STR form. Start Date/Time greater than or equal RRIR form. Date Response Determined

AND 

{

Logic 2.7: (TBRP form The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression is Null or <> Yes with TBRP form. Date of Assessment equal to RRIR form. Date Response Determined in Logic 2.6

OR 

Logic 2.8: TBIRP form The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression is Null or <> Yes with TBIRP form. Date of Assessment equal to RRIR form. Date Response Determined in Logic 2.6

Scenario 4:

Logic 3: There is a RRIR form Overall irRECIST Response <> NULL with Date Response determine completed. 

AND 

Logic 3.1: There is no RRIR form.Overall RECIST Response = Progressive Disease with Date Response Determined < Date Response Determine RRIR record in Logic 3

Note 1: Please exclude deleted records from programming

Note 2: Please output ONLY the scenarios selected in the ‘Scenarios’ prompt

Note 3: The logic should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Treatment Phase Order, Treatment phase,First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1 

2,Second Course Phase,Second Course Cycle 1

 

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

 

Form.Date include: RRIR. Date Response Determined, SM/SMAU/SMAB/STR_Form.Start Date, TBRP/ TBIRP_form. Date of Assessment

 

Requires supporting document to be named xxxx_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1) Treatment Phase Order - Treatment Phase chronological order. Required, enter "1" if only one treatment phase in study

2) Treatment Phase - Treatment Phase defined in protocol. Required, enter "Initial Treatment Phase" if only one treatment phase in study

3) First Visitmnemonic of Treatment Phase - Required, enter First Visitmnemonic of treatment phase if only one treatment phase in study

 

e.g. 

Treatment Phase Order,Treatment Phase,First Visitmnemonic of Treatment Phase 

1,Initial Treatment Phase,Cycle 1 

2,Second Course Phase,Second Course Cycle 1

3,Crossover Phase,Crossover Cycle 1 

 

If there is only one treatment phase in study, consider entering as follows: 

Treatment Phase Order,Treatment Phase,First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

Report Scenarios:
Scenario 1:

A.Output No

There is an Overall RECIST Response completed and an Overall irRECIST Response provided with different dates on Date Response Determined in RRIR form.

B.Output yes

There is an Overall RECIST Response completed and an Overall irRECIST Response provided with the same dates on Date Response Determined in RRIR form.

Scenario 2:

C.Output No

There is RRIR form. Overall RECIST =  Progressive Disease and there is a new entry in RRIR form. Overall irRECIST Completed with Date Response Determined after RRIR form. Overall RECIST = NULL.

(Only 1 RECIST = PD should be reported in RRIR).

D Output No

There is one entry for RRIR form. Overall RECIST = Progressive Dissease and there is a new entry in RRIR form. Overall irRECIST Completed with Date Response Determined previous to RRIR form. Overall RECIST <> NULL.

E.Output yes

There is an Initial Overall RECIST Response as PD but there is a new entry with Overall RECIST Response completed (RRIR. Overall RECIST Response <> NULL). (Not 2 or more entries for RECIST = PD should be reported in RRIR).

Scenario 3:

F.Output No

There is an Initial Overall RECIST Response as PD and a new entry in RRIR with Overall irRECIST Response Completed  and subject continues treatment in SM/SMAU/SMAB/STR and there is a TBRP/TBIRP Date of assessment equal to Date Response Determined  of Overall RECIST Response as PD and this TBRP/TBIRP has the item “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression/ The Investigator Believes the Benefit”/”Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression” completed as Yes.

G.Output Yes

There is an Initial Overall RECIST Response as PD and a new entry in RRIR with Overall irRECIST Response Completed  and subject continues treatment in SM/SMAU/SMAB/STR but there is Not a TBRP/TBIRP Date of assessment equal to Date Response Determined  of Overall RECIST Response as PD that has the item “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression”/ “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression “completed as Yes.

Start Date/Time greater than or equal to RRIR form. Date Response Determined of the Overall RECIST Response as PD and there is a TBRP/TBIRP Date of assessment equal to Date Response Determined of the Initial Overall RECIST Response as PD that has the item “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression”/ “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression” completed as Yes.

Start Date/Time greater than or equal to RRIR form. Date Response Determined of the Overall RECIST Response as PD and there is a TBRP/TBIRP Date of assessment equal to Date Response Determined  of Overall RECIST Response as PD and this TBRP/TBIRP has the item “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression/ The Investigator Believes the Benefit”/”Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression” completed as No.

Date Response Determined of the Overall RECIST Response as PD but there is Not a TBRP/TBIRP Date of assessment equal to Date Response Determined  of Overall RECIST Response as PD that has the item “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression”/ “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression “completed as No.

K.Output Yes

There is an Initial Overall RECIST Response as PD and a new entry in RRIR with Overall irRECIST Response Completed and subject continues treatment in SM/SMAU/SMAB/STR and there is a TBRP/TBIRP Date of assessment equal to Date Response Determined of the Initial Overall RECIST Response as PD that has the item “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression”/ “The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond irRECIST Disease Progression” completed as Null or No.

Scenario 4:

L.Output No
