Report ID: RID456

Report Title:
Duplicate and missing STR records.

Description:
This report will list subjects with duplicate Radiation records

Column Heading:
1.Country

2.Site

3.Subject Number

4.STR Seq (For outputs related to scenario 2 leave this item blank)

5.STR Start Date/time (For outputs related to scenario 2 leave this item blank)

6.ORAD2 Seq

7.ORAD2 Start Date

8.ORAD2 Stop Date (For outputs related to scenario 1 leave this item blank)

9.SFU DOV   (For outputs related to scenario 1 leave this item blank)

10.Scenario

Logic:
-	LOGIC 1:

STR “Start Date/Time” <> NULL AND STR “Start Date/Time” = ORAD2 “Start Date”.

-	LOGIC 2A:

ORAD2 “Start Date” <> NULL AND ORAD2 “Start Date” < DOV for Survival Follow-up VISIT AND

-	LOGIC 2B:

ORAD2 “Stop Date” <> NULL AND ORAD2 “Stop Date” < DOV for Survival Follow-up VISIT

AND

ORAD2 “Reason for Radiation” <> ‘Palliative Treatment or Symptom Control’ OR ‘Palliative Treatment or Symptom Control of Metastatic Disease’ if ‘Exclude Palliative Radiations’ = Y

Notes

Note1: Deleted records and erroneous visit should not output.

Note2: For Logic 1 should not output if ORAD2 start date the day is completed as UNK.

Note 3: For logic 2A and Logic 2B if Exclude Palliative Radiation prompt = Y, please only include outputs were Reason for Radiation in ORAD2 is <> to Palliative Treatment or Symptom Control OR Palliative Treatment or Symptom Control of Metastatic Disease

Note 4: For logic 2A and Logic 2B if Exclude Palliative Radiation prompt = N, please show all records regardless of Reason for Radiation.

Note 5: For logic 2A AND Logic 2B if day in start date OR stop date is entered as UNK verify if Moth is < DOV for Survival Follow-up VISIT AND Year is <= DOV for Survival Follow-up VISIT include the output; otherwise should not output

Report Scenarios:
-	Scenario 1 – Yes

If STR Start Date/Time is entered AND the date is equal to ORAD2 Start Date.

-	Scenario 2A – Yes

If ORAD2 Start Date is entered AND date is before DOV for Survival Follow-up VISIT AND if ‘Exclude Palliative Radiations’ = ‘Y’ then Reason for radiation is <> to Palliative Treatment or Symptom Control OR Palliative Treatment or Symptom Control of Metastatic Disease

  AND

-	Scenario 2B – Yes

If ORAD2 Stop Date is entered AND date is before DOV for Survival Follow-up VISIT.

-	Scenario 3 – No

If STR Start Date/Time is entered AND the date is different to ORAD2 Start Date.

-	Scenario 4 – No

If ORAD2 Start Date OR Stop Date is entered AND date is AFTER DOV for Survival Follow-up VISIT.

Sorting:
Country, Site, Subject Number, STR Seq

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, randomized only,  Exclude Palliative Radiations (Y/N, Default as N)

Form.Item Names:
1.Subject Assignment.Site Country

2.Subject Assignment.Site Mnemonic

3.Subjects.Subject Number

4.STR.Sponsor ID number

5.STR.Start Date/Time

6.ORAD2. Sponsor ID Number

7.ORAD2.Start Date

8.ORAD2.Stop Date

9.DOV. Date of Visit (Display DOV on Survival Follow-up visit)

10.Display what scenario is being outputted: show “Scenario 1” if Logic 1, is met AND “Scenario 2” if Logic 2A, Logic 2B is met.
