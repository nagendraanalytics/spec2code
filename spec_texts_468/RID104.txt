Report ID: RID104

Report Title:
Missing eDiary Records

Description:
This report lists subjects that have DOV that is not null but there are missing external eDiary records before the current maximum DOV.

20. Required # of records

21. Scenario

Logic:
Scenario 1: Title = Missing Visit-Based eDiary Records

For each subject's required Vendor data and required visits, output subject and visit if:

DATE OF VISIT.DOV <> NULL AND

There does NOT EXIST at least 1 corresponding SME record WHERE

[ SME. Vendor Name = required Vendor name AND SME. Label Description = required Label Description AND

SME. Study Medication= required Study Medication in SM AND

Absolute Value (SME. Start Date/Time – (minus) DOV) <= X (selected in selection criteria or defaulted to zero)]

* X is allowed time window that to collect SME data.

* If SME Start Date/Time includes the time (e.g. ‘2012-02-02T09:33:00’) then use only the Date for the difference calculation.

* Report should not consider deleted SME records / DOV records where Erroneous Visit checkbox is checked (is not null).

End of Scenario 1

Scenario 2: Title = Missing eDiary Daily Records

For each subject, Vendor Name=required vendor, Label Description = required Label Description, Study Medication= required Study Medication, there does NOT EXIST at least 1 corresponding SME records which have SME.Start Date/Time on every day. Each Day should have a record between each cycle.  (Minimum DOV provided in supp doc and maximum DOV initializated in InForm and present in supp doc)

Daily records are expected by visit according to the visits specified by supp document. All SME records should be considered, even those that are beyond the defined timeframes. The maximum time point will be the current maximum DOV.

* If SME. Start Date/Time includes the time (e.g. ‘2012-02-02T09:33:00’) then use only the Date for the calculation.

* Report should not consider deleted SME records / DOV records where Erroneous Visit checkbox is checked (is not null).

End of scenario 2

Scenario 3: Title = Missing Multiple times eDiary Records within a day

For each subject,

Vendor Name=Required vendor, Label Description = required Label Description and Study Medication= required Study Medication, AND (there are less than ‘X' number of corresponding SME records which have same SME. Start Date/Time on every day) during the time span (Minimum DOV provided in supp doc and maximum DOV initializated in InForm and present in supp doc).

'X' need be provided by user. (Supp Document)

* If SME. Start Date/Time includes the time (e.g. ‘2012-02-02T09:33:00’) then use only the Date to calculate the records number on same date.

* Report should not consider deleted SME records / DOV records where Erroneous Visit checkbox is checked (is not null).

* Column 19, if all the X record is missing for a single day, please hardcode the missing Date in this column; if less than X records for a single day, please display the missing Date in this column.

End of scenario 3

This Logic requires Supp Document that should be named as EVD027_supp_XXXXXXX.csv

Visit Mnemonic, Vendorname, Label Description, Study medication, SME records

Visit Mnemonic: The visitmnemonic where the DOV should be compare with SME records

Vendorname: unique vendor name, specified as 'NA' if it is checked for all vendors.

Label Description: Value for specific SME Label Description

Study Medication: Value for specific Study medication in SM.

SME records: Number of doses expected for each day in SME.

EX.

Cycle 1, QARC, Olaparib/Placebo,Olaparib/Placebo ,2

Cycle 2, QARC, Olaparib/Placebo,Olaparib/Placebo ,2

Report Scenarios:
Scenario 1:

A – Yes

Visit Mnemonic = Required Visits AND

DOV is not null AND

There do NOT EXIST any corresponding SME records WHERE

Vendor Name = required vendor, Label Description = required and Study Medication= required and the record Start Date/Time is within +/- X days of the DOV.

B – No

Visit Mnemonic = Required Visits AND

DOV is not null AND

There DOES EXIST at least 1 SME record WHERE

Vendor Name = required vendor, Label Description = required  and Study Medication= required  and the record Start Date/Time is within +/- X days of the DOV(inclusive).

C – No

Visit Mnemonic = Required Visits AND

DOV is NULL

(The visit has not been initialized and therefore there is no reference DOV for ePRO records.)

D-No

No required visits.

Scenario 2:

A – Yes

Vendor name= required vendor, Label Description = required and Study Medication= required, Records are missing for at least 1 day between starting time point and stopping time point (inclusive).

B – No

Vendor name= required vendor, Label Description = required and Study Medication= required, NO record is missing between starting time point and stopping time point (inclusive).

Scenario 3:

A-Yes

Vendor Name=Required vendor, Label Description = required and Study Medication= required, there does not exist 'X' records.

B-No

Vendor Name=Required vendor , Label Description = required  and Study Medication= required, there are less than 'X' records.
