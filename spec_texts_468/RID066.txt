Report ID: RID066

Report Title:
Device Malfunction Assessment vs. Adverse Event

Description:
The report displays subjects who have Device Malfunction Assessment entered due to an SAE but SAE criteria is not selected on provided AE seq number.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Device Malfunction Assessment Seq

5. Date/Time of Assessment

6. Associated AE Seq

Logic:
Output = Yes

The report should display output when item 'Date/Time of Assessment' is provided on the DVA eCRF

AND

Item 'Associated Sequence Number(s) From AE Form' is entered on the DVA eCRF

AND

Provided AE record/records from 'Associated Sequence Number(s) From AE Form' does/do not have checked 'Serious Criteria (check all that apply)' (is not SAE) on the AE eCRF

OR

provided AE record/records from 'Associated Sequence Number(s) From AE Form' in DVA eCRF is deleted in AE eCRF.

Note 1 : 'None' option in item 'Serious Criteria (check all that apply)' or blank item = it is not SAE. The rest of available options = SAE.

Note 2 : Please disregard deleted rows from DVA eCRF (deleted Date/Time of Assessment).

Output = No

The report should not display output when item 'Date/Time of Assessment' is provided on the DVA eCRF

AND

Item 'Associated Sequence Number(s) From AE Form' is entered on the DVA eCRF

AND

Provided AE record/records from 'Associated Sequence Number(s) From AE Form' has/have checked 'Serious Criteria (check all that apply)' (is SAE) on the AE eCRF.

Report Scenarios:
Yes: If Satisfies Logic

No: If doesn’t Satisfies Logic

Sorting:
Coutry, Site Number, Subject Number

Parameter Selection:
Country, First Site No. (or leave blank for all), Last Site No. (or leave blank for all), First Subject No. (or leave blank for all), Last Subject No. (or leave blank for all), List of Subjects, Randomized Only

Form.Item Names:
1. SA. Site Country

2. SA. Site Mnemonic

3. SA. Subject Number

4. DVA form.Formidx

5. DVA form. Date/Time of Assessment

6. DVA form. Associated Sequence Number(s) From AE Form
