Report ID: RID141

Report Title:
OLAB duplicate records

Description:
This report generates a list of randomized subjects with duplicate OLAB records.

Duplicate OLAB records are defined as two OLAB records with the same Start Date Specimen Collected, Test name, Numeric Test Result and Test Unit and Character test result.  Check for duplicates should span across Visits.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. DOV

6 Seq

7 Test

8. Start Date

9. Test Result

Logic:
At OLAB form within the same randomized subject (Treatment/Randomization Number<>Null), Output is produced if there are duplicate lab records in the OLAB eCRF.

If a duplication is found for:

- Start Date Specimen Collected,

- Test Name,

- Numeric Test Result,

- Numeric Test Unit,

- Character Test Result

Check for duplicates should span across Visits.

*Exclude erroneous visit/deleted records from programming.

Report Scenarios:
A-Yes

Duplicated records

B-No

No duplicated record

C-No

Non-rand subject

Sorting:
Country, Site, Subject Number, Test, Start Date, result, visit, Seq

Parameter Selection:
Country, Site, Subject Number

Form.Item Names:
1. Subject Assignment.Country

2. Subject Assignment.Site Name

3. Subjects.Subject Number

4. OLAB.Visit Number

5. DOV.Date of Visit

6. OLAB.FORM IDX

7. OLAB.TEST NAME

8. Start Date Specimen Collected

9. Numeric Test Result & Test Unit/Character Test Result

* Column 9, for Numeric Test result, please concatenate both Numeric Test Result & Test Unit in one cell in output.
