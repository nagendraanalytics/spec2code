Report ID: RID139

Report Title:
Required Prestudy/On Study Local Lab OLAB Record Check

Description:
This report looks for required but missing OLAB local lab test result(s) required within a certain time period for each subject.

Column Heading:
1. Country

2. Site

3. Subject Number

4.Visit

5. Date of Visit

6. Test name

7. Specimen Collection Date

8. Error message = No Lab Test / outside timeframe

Logic:
Output is produced when a subject does not have at least one OLAB record in the same [Group] meet below criteria:

Logic 1: OLAB.Test Name = [OLAB Test Name]

AND

Logic 2: (OLAB.Numeric Test Result is not null OR OLAB.Character Test Result is not null

AND

Logic 3: OLAB.Start Date Specimen Collected >= [Visit Mnemonic].Date of Visit - [Lower window of  Days]

AND

Logic 4: OLAB.Start Date Specimen Collected <= [Visit Mnemonic].Date of Visit + [Upper window of  Days]

Note:

1.Please exclude erroneous visits and deleted records.

2.[Group]/[OLAB Test Name]/[Visit Mnemonic]/[Upper window of Days]/[Lower window of Days] is from supporting document.

3.Output is not expected as long as one of the test in one Group is recorded on a visit within required timeframe

Requires supporting document to be named OLAB001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each olab test

1.Group - Required, enter the same number for tests belongs to one group

2.OLAB Test Name - Required OLAB Test Name

3.Visit Mnemonic - Visit Mnemonic where OLAB Test is expected to locate

4.Lower window of days

5.Upper window of days

Example:

Group,OLAB Test Name,Visit Mnemonic,Lower window of days , Upper window of days;

1,Beta 2-Microglobulin,Visit 1,1,3

2,CD4,Visit 1,1,3

3,CD20 (%),Visit 2,1,3

4,Free T3,Visit 3,1,3

4,Total Triiodothyronine,Visit 1,3

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
This report lists randomized subjects who do not have a <enter lab test name parameter here> local lab record dated in the correct <prestudy/on study> timeframe.  The timeframe is defined as within <X> days prior to <Visit X> (inclusive).

Note:

Data in erroneous visits should not be considered.

Deleted records should not be considered.

Sorting:
Country, Site Number, Subject Number,Visit, Lab Test

Parameter Selection:
First Site, Last Site, First Subject, Last Subject, List of Subjects, Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
1. Subject Assignment Form.Site Country

2. Subject Assignment Form.Site Number

3. Subjects.Subject Number

4. Visit. Visit Mnemonic

5. Visits.DOV

6. Other Laboratory Form ~ Laboratory Test Itemset.Test Name

7. Other Laboratory Form.Start Date Specimen Collected

8. Hardcode.

   No Lab Test- there is no requried lab test including both missing lab test name or lab test name existing without result

   Outside timeframe-there is required lab test however, the lab is outside the timeframe.
