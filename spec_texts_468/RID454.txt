Report ID: RID454

Report Title:
Study Treatment radiation consistency

Description:
This report will check that radiation be given after the protocol surgery is performed.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Oncologic Surgery form

5. Oncologic Sugery form seq#

6. OS Date/Time Performed

7. STR visit

8. STR Seq

9. Start Date/time

10. Stop Date/Time

Logic:
Scenario 1:

Logic 1.1: OSOFL/OSOF. Date and Time Performed <> NULL

AND

Logic 1.2: OSOFL/OSOF. Date/Time Performed >  STR. Start Date/Time

Scenario 2:

Logic 2.1: OSOFL/OSOF. Date and Time Performed = NULL AND STR. Start Date/Time <> NULL

Notes

Note 1:  Please exclude deleted record and Erroneous Visit from programming

Note 2:  Please disregard time and only compare date

Note 3: For the Oncologic Surgery form prompt, please upload the applicable form per protocol and check logic 1.1 to 1.3 for the selected form in the prompt. If no form is selected, please check for the available form.

Note 4: For column 4 and 5, please use the Oncologic Surgery form prompt or the available form per protocol.

Note 5: For logic 2.1: please output if OSOFL/OSOF is not initialized.

Report Scenarios:
SCENARIO 1

SCENARIO D: YES

SCENARIO E: NO

OSOFL/OSOF. Date and Time Performed = NULL AND STR. Start Date/Time = NULL

Deleted records or erroneous visits
