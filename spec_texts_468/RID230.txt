Report ID: RID230

Report Title:
Forms before or equal to a cut-off date

Description:
This report will display all forms with dates before or equal to a cut-off date

Column Heading:
Table 1 - Common Forms

1. Country

2. Site

3. Subject Number

4. eCRF Name

5. Table

6. Seq

7. Item Name

8. Reference Date

9. Record Frozen Status

10. Record Locked Status

Table 2 - Visit-Based Forms

1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF Name

6. Table

7. Seq

8. Item Name

9. Reference Date

10. Record Frozen Status

11. Record Locked Status

Logic:
This report will be a listing of all records with date of supporting document before or equal to parameter (Cut-off date)

Note 1: If DS01. Date of Disposition is <> NULL then show output if the reference date is not completed or completed as anything different than a date. (Continuing/Ongoing).

Note 2: If item selected has the option of "Duration if Less Than 24 hrs", show an output as soon as this option is selected.

Note 3: Report will work for randomized and non-randomized patients.

Note 4: For multiple records in the same form that fills the condition, show all records in different outputs. (When reference date is in the main part of the form)

Note 5: For records in add-entry, only show an output if the maximum date in the add-entry section is before or equal to the parameter and only show the output with the latest date that is before or equal the parameter. (When reference date is in the add-entry section)

Note 6: For dates with unknown values or date fields with only some fields like year, compare only the data present in the eCRF (i.e. UNK/JAN/2025 with parameter as 31/Jan/2025 will show an output or UNK/UNK/2025 with the same parameter will show an output), if it is totally UNK, please show an output.

Note 7: Please show records based on "Frozen Status", "Table" and "Locked Status" parameters to show only the records selected.

Note 8: Report should not consider records deleted or in erroneous visits.

Requires supporting document to be named TQ056_supp_<xxxxxxx>.csv (in csv format) and will contain the following columns and associated content for all required forms

Note:

a. If the form has more than one date item, keep only the one you will use for reference to determine when the form could be frozen because record has finished, and no more information is expected on it. (Can be on main part or in add entry section), e.g. For lesion forms consider using the Date of current lesion evaluation in the add-entry section, for AE/CM forms consider using the stop dates in the main part, in HOSP the discharge date/time, etc...

b. Include ALL required forms in your study; Otherwise, no outputs will be generated for missing forms in supp doc.

1 row for each required field with the following columns:

1.FORM

2.DATE - Item Date of reference used to determine when the record is finished, and no more information would be added on it.

3. ADD ENTRY FLAG - Complete as Y for dates in add-entry section, complete as N for forms without add-entry section or if the item date selected is in the main part of the form.

4. COMMON FORM FLAG - Complete as Y for common forms, complete as N for visit-based forms

e.g.

FORM,DATE, ADD ENTRY FLAG,COMMON FORM FLAG

AE,End Date and Time,N,Y

LSNIR,Date of current lesion evaluation,Y,Y

CM,Stop Date and Time,N,Y

HOSP,Discharge Date/Time,N,Y
