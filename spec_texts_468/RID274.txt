Scenario 1: Logic 1.1: CIMG. Test Name/GEFCF. Test is NOT within supp document column ‘Test Name’ AND Logic 1.2: Information is entered in any item for this test AND Logic 1.3: CIMG. Date of Imaging/GEFCF. Date/Time of Measurement < minimum SM/SMAB/SMAU. Start Date/Time or STR. Start Date

Scenario 2:

 Logic 2.1: There are more than one GIMG records with CIMG. Date of Imaging <> NULL AND CIMG. Baseline Flag <> NULL

OR Logic 2.2: There are more than one GEFCF records with GEFCF. Date/Time of Measurement <> NULL AND GEFCF. Baseline Flag <> NULL

 Notes 1. For SM/SMAB/SMAU/STR forms, only check records that have the Please Indicate if this is the First Dose for this Label Description is checked

2. Disregard SM/SMAB/SMAU/STR deleted records

3. For Scenario 2: a. Please use External data Form column in supp document to evaluate logics (CIMG, logic 2.1 and GEFCF, logic 2.2) b. If NA was entered on the External data Form column in supp document, please use every logic c. If on External data Form column in supp document NA was entered, for column 9 please display form in the protocol.

Test Name = OVERALL RESPONE AND GEFCF. Result or Finding in Original Units Column 11 should show Column 9 should show Original Units

5. If more that one item was completed, please separate items on column 12 by commas

6. For scenario 2: Please leave column 12 blank and separate by commas column 9 and column 11

7. For scenario 1: Please exclude the following for column 12: Sequence Number, Visit Number, Planned Time Point Number, Site Id Or Number, Screen Id Or Number, Subject Id Or Number, Domain Abbreviation, Study Identifier, Test Short Name, Test, Category, Subcategory, Vendor Name, Visit Name, Visit Type
