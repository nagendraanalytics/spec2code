Report ID: RID380

Report Title:
Incorrect ORPI Responses

Description:
This report will display subjects with inconsistencies reported in ORPI between PCWG MODIFIED RECIST and PCWG Modified irRECIST

Column Heading:
1. Country

2. Site

3. Subject number

4. ORPI seq #1

5. ORPI Date Response Determined seq #1

6. ORPI Overall RECIST Response

7. ORPI seq #2

8. ORPI Date Response Determined seq #2

9. ORPI Overall RECIST/irRECIST Response

10. TBPR Date of Assessment

11. TBPR Response

12. Error message

Logic:
Scenario 1:

Logic 1: ORPI. Overall Response (PCWG-Modified RECIST) <> NULL

AND

Logic 2: In the same ORPI entry, ORPI. Overall Response (PCWG-Modified irRECIST) <> NULL

 OR

Logic 3: There is an ORPI. Overall Response (PCWG-Modified irRECIST) <> NULL with ORPI. Date Response Determined = ORPI. Date Response Determined in Logic 1.

Scenario 2a:

Logic 4: ORPI. Overall Response (PCWG-Modified RECIST) = Progressive Disease

AND

Logic 5: A new ORPI entry with PCWG MODIFIED RECIST section initialized. (A new entry means ORPI. Date Response Determined is greater than or equal to ORPI. Date Response Determine in Logic 4)

Scenario 2b:

Logic 6: ORPI. Overall Response (PCWG-Modified RECIST) = Progressive Disease and there is a SM/SMAU/SMAB.Start Date/Time greater than or equal to ORPI. Date Response Determined

AND

Logic 7: TBPR. The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression <> Yes with TBPR. Date of Assessment equal to ORPI. Date Response Determined in Logic 6.

Scenario 3:

Logic 8: ORPI. Overall Response (PCWG-Modified irRECIST) <> NULL.

AND

Logic 9: There is no ORPI. Overall Response (PCWG-Modified RECIST) = Progressive Disease with ORPI. Date Response Determined less than ORPI.Date Response Determined in Logic 8.

Note: Deleted records and erroneous visits should not be taken into account.

Report Scenarios:
A – Yes

Overall Response (PCWG-Modified RECIST) <> NULL and Overall Response (PCWG-Modified irRECIST) <> NULL

B – No

Overall Response (PCWG-Modified RECIST) <> NULL and Overall Response (PCWG-Modified irRECIST) = NULL or Overall Response (PCWG-Modified RECIST) = NULL and Overall Response (PCWG-Modified irRECIST) <> NULL

C – Yes

Overall Response (PCWG-Modified RECIST) = Progressive Disease and there is a new entry in ORPI with PCWG MODIFIED RECIST section initialized.

D – No

Overall Response (PCWG-Modified RECIST) <> Progressive Disease and there is a new entry in ORPI with PCWG MODIFIED RECIST section initialized.

E - Yes

ORPI.Date Response Determined = TBPR.Date of Assessment, ORPI.Overall Response (PCWG-Modified RECIST) = Progressive Disease, TBPR.The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression = No and there is a SM/SMAU/SMAB.Start Date/Time greater than or equal to ORPI. Date Response Determined

F – No

Overall Response (PCWG-Modified RECIST) = Progressive Disease and TBPR. The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression = Yes

G- Yes

Overall Response (PCWG-Modified irRECIST) <> NULL and there is not a previous ORPI entry with Overall Response (PCWG-Modified RECIST) = Progressive Disease

H- No

Overall Response (PCWG-Modified irRECIST) <> NULL and there is a previous ORPI entry with Overall Response (PCWG-Modified RECIST) = Progressive Disease

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, Site, Subject Number

Form.Item Names:
1. SA.Country

2. SA.Site

3. SA.Subject number

4. ORPI.Sponsor ID Number (Show blank for Scenario 3)

5. ORPI.Date Response Determined (Show blank for Scenario 3)

6. ORPI.Overall Response (PCWG-Modified RECIST) (Show blank for Scenario 3)

7. ORPI.Sponsor ID Number  (Show blank for Scenario 2b)

8. ORPI.Date Response Determined (Show blank for Scenario 2b)

9. Display ORPI. Overall Response (PCWG-Modified RECIST) for Scenario 2a and display ORPI. Overall Response (PCWG-Modified irRECIST) for Scenario 1 and 3 (Show blank for Scenario 2b)

10. TBPR.Date of Assessment (For Scenario 1, 2a and 3, please show this column in blank) (Show blank for Scenario 1, 2a and 3)

11. TBPR.The Investigator Believes the Benefit/Risk Assessment Favors Continued Treatment with Study Medication Beyond RECIST Disease Progression (For Scenario 1, 2a and 3, please show this column in blank) (Show blank for Scenario 1, 2a and 3)

12.  Display the Scenario that is fulfilled (Scenario 1, Scenario 2a, Scenario 2b or Scenario 3)
