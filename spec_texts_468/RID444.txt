Report ID: RID444

Report Title:
Incorrect Oncologic Radiation form associated with Symptomatic Skeletal Related Event

Description:
This report lists subjects who have incorrect form for Oncologic Radiation associated with SSRE.

Column Heading:
1. Country

2. Site

3. Subject Number

4. SSRE Visit

5. Start Date of SSRE

6. SR Subject Randomization Date of Assessment

7. Scenario

Logic:
Report should output subjects who meet the following criteria

Scenario 1

Associated Sponsor ID Number (from ORAD Form) <> blank and Start Date of SSRE > = to SR Date of assessment

Scenario 2:

Associated Sponsor ID Number (from ORAD2 Form) <> blank and Start Date of SSRE < to SR Date of assessment

Note 1: SR Date of Assessment should be obtained in SR form at cycle 1

Note 2: Erroneous visits and deleted records should not be considered in the programming and output.

Note 3: Associated Sponsor ID Number (from ORAD Form) and Associated Sponsor ID Number (from ORAD2 Form) are in SSRE form

Report Scenarios:
Scenario 1

A.Yes

If Associated Sponsor ID Number (from ORAD Form) was completed but Start Date of SSRE is on or after SR Date of assessment

B.No

If Associated Sponsor ID Number (from ORAD Form) was completed but Start Date of SSRE is before to SR Date of assessment

Scenario 2:

A.Yes

If Associated Sponsor ID Number (from ORAD2 Form) was completed but Start Date of SSRE is before to SR Date of assessment

B.No

If Associated Sponsor ID Number (from ORAD2 Form) was completed but Start Date of SSRE is on or after SR Date of Assessment

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N set by default to Y)

Form.Item Names:
1. SA. Site Country

2. SA. Site Mnemonic

3. SA. Subject Number

4. SSRE. Visit Mnemonic

5. SSRE Start Date of SSRE

6. SR Date of Assessment

7. If Scenario 1 is met, display “Scenario 1”, if Scenario 2 is met, display “Scenario 2”
