Report ID: AE001_AGG_STD

Report Title:
Count of subjects with AE action taken of discontinued versus subjects with Study Drug discontinuation due to AE

Description:
This report displays the number of randomized subjects with AEs with Action Taken for SM as "Discontinued", versus the number of randomized subjects where PMS1/DS02/DS01/PMST has reason for discontinuation entered as "Adverse Event".

Column Heading:
1. Country

2. Site

3. Number of Randomized Subjects per Treatment Phase

4. Number of Subjects with Action Taken with Study Medication as Discontinued

5. Form

6. Number of Forms as Discontinued due to AE

7. Rate of Subjects Discontinued due to AE

8. Treatment Phase

Logic:
The report is a listing and will output as follows:

Column 3: Display the Total Number of Subjects per site for the corresponding treatment phase with the "DATE OF VISIT" of "First Visitmnemonic of Treatment Phase" NOT NULL in the eCRF from "Group 1"

Column 4: Display the Total Number of subjects per site for the corresponding treatment phase with at least one AE record with the "OVERALL ACTION TAKEN" = "Discontinued" in the eCRF from "Group 4 "

Column 6: Display the Total Number of records per site for the corresponding treatment phase with the "STATUS" = "Adverse Event" in the eCRF from "Group 5"

Notes:

1-	Erroneous visits and deleted records are excluded from programming
2-	Report should be programmed for randomized subjects only
3-	STUDY PHASE SUPPORTING DOCUMENT NOTE:

	This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required, the order on which phases will appear on protocol
2. Treatment Phase: name of each study phase (Intial Treatment Phase, Neodjuvant Phase, Second Course Phase)
3. First Visitmnemonic of Treatment Phase: required, the first visit on which treatment is expected to be administered on each phase.

e.g.

Phase Order,Treatment Phase,First Visitmnemonic of Treatment Phase
1, Initial Treatment Phase, Cycle 1
2, Second Course Phase, Cycle 1 Course 2
3, Crossover Phase, Crossover Cycle 1

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

The report logic should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase
1,Initial Treatment Phase,Cycle 1
2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Date < Second Course Cycle 1
Second Course Phase: Second Course Cycle 1 <= Date

Date includes: "ONSET DATE" in eCRF from "Group 2", "DATE OF ASSESSMENT" in eCRF from "Group 3"

The forms DS01 and DS02 will be considered as part of the last treatment phase initiated for a subject, for example, if the trial has 2 treatment phases and for subject 1 the last treatment phase initiated was phase 1 then the DS01/DS02 will be considered as part of phase 1, if for subject 2 the last treatment phase initiated was phase 2 then the DS01/DS02 will be considered as part of phase 2.
