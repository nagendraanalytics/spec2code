Report ID: RID446

Report Title:
Current Disease Details and STR body site location reconciliation.

Description:
This report will show patients that have mismatch information of the body location on the Current Disease Details eCRF and STR forms, for reconciliation.

Column Heading:
1. Country

2. Site

3. Subject Number

4. STR Visit

5. STR seq#

6. STR Study period

7. STR Scheduled time

8. STR Location

Logic:
Logic 1.1: STR location <> NULL

AND

Logic 1.2: There is not Current Disease Details location = STR location

As explained in the notes section, this report may use a supporting document named ONC_STR_001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1) Disease Details Location - provide primary and metastases locations, exactly as in the <CODD> eCRF; each loacation requires a separate row;

2) STR Body Site Location of Administration - provide location in Body Site Location of Administration that should be matched with Disease Details Location; each loacation requires a separate row.

e.g.

Disease Details Location, STR Body Site Location of Administration

Lung, Left Lower Lobe,    Lung Left

Lung, Left Upper Lobe,    Lung Left

Para-aortic Lymph Nodes,    Lung Left

Lung, Right Lower Lobe,    Lung RIGHT

Lung, Right Upper Lobe,    Lung RIGHT

Mediastinum,    Mediastinum

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

3. If no supporting document is provided perform one-to-one reconciliation between Body Site Locations of Administration in STR and locations in Current Disease Details form selected in report parameter. The location names should match exactly, no case sensitive.

If a supporting document is provided, check if Body Site Locations of Administration in STR have a corresponding value in Current Disease Details form selected in report parameter. The corresponding values for STR Body Site Location of Administration column are provided in the Disease Details Location column.

If a supporting doc is provided, and there is a location in STR that is not listed in the supporting doc, the report should perform one-to-on reconciliation.

4. Erroneous visits and deleted records should not be considered in the programming and output.

5. If there are multiple Current Disease Details forms, check them all

6. For locations entered in [CDDG/CDDHN. Primary Location Other, CDDO/CDDU/CDDM/CODD/ CDDG/CDDHN/ODD. Location of Metastases Other, CDDB/DDRCC/ODD. Other Location of Metastases, CDDO/CDDU/CDDM/CODD/ODD. Other Location, ODD. Primary Location at Diagnosis Other] equals the location entered at STR. Body Site Location of Administration Other. No case sensitive for this comparison.

7. For the Current Disease Details form, please only check the forms selected in the prompt

8. The comparison will be done only using the locations entered in the STR form. This means that if the locations in the current disease form are not present in STR, NO outputs will be expected.

Report Scenarios:
SCENARIO A: YES

There is not a Location of metastases OR Location on Current Disease Details form = STR location

SCENARIO B: NO

STR location = NULL

SCENARIO C: NO

Do not output for deleted records or erroneous visit

SCENARIO D: NO

STR location matches with Current Disease Details location in [CDDG/CDDHN. Primary Location Other, CDDO/CDDU/CDDM/CODD/ CDDG/CDDHN/ODD. Location of Metastases Other, CDDB/DDRCC/ODD. Other Location of Metastases, CDDO/CDDU/CDDM/CODD/ODD. Other Location, ODD. Primary Location at Diagnosis Other]

SCENARIO E: NO

Current Disease Details location is present in the STR. Body Site Location of Administration Other item. Disregarding capital letters.
