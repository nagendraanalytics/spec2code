Report ID: RID315

Report Title:
Lesion Evaluation Study Period Reconciliation

Description:
This report will list subjects that have inconsistencies with the Study Period reported in lesion evaluation form.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Lesion Form

5. Seq#

6. Date of Lesion Evaluation Item Name

7. Date of Lesion Evaluation

8. Study Period

9. Lesion Present at [Initial Treatment Phase] Item name

10. Lesion Present at Initial Treatment Phase

11. DOV/PMS1 Date

12. Scenario

Logic:
<Criteria Form>.<Criteria Itemquestion> = <Criteria Value>

Logic 1:

DOV.Date of Visit/PMS1.Date of Assessment on the corresponding visit is not null

AND

LSN.Date of Initial Lesion Identification for This Trial (Scan/image/physical Exam) / Date of Assessment > DOV.Date of Visit/PMS1.Date of Assessment on the visit corresponding to the selected 'Study Period' (depending on the supp doc).

Logic 2:

LSN.Indicate if Lesion was Present at Initial Treatment Phase = Y

AND

the Lesion Number provided in 'Yes, Provide the Associated Lesion Number'/'Yes, Provide the Associated Sponsor ID Number' is not null

AND

LSN.Study Period <> First Study Period, as provided in the supporting doc

Requires supporting document to be named ONC_LSN_023_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Criteria Form - Form with criteria that report will use to distinguish groups of patients (e.g., SR/TRIG); enter NA if logic is applicable for all subjects

2. Criteria Itemquestion - Item within 'Criteria Form' that will allow to distinguish different groups of patients (e.g., Arm/Cohort/Stratification); enter NA if logic is applicable for all subjects

3. Criteria Value - Value for 'Criteria Item' (e.g., cohort A in item 'Cohort' on SR eCRF); enter NA if your study has the same requirement for all patients

4. Study Period Order (provide ‘1’ for the first study period, ‘2’ for the 2nd study period, etc.)

5. Study Period (as provided in the lesion evaluation form; make sure to provide study periods in chronological order)

6. Related Form (DOV or PMS1)

7. Visit (the 'cut-off' date for corresponding Study Period)

Example 1:

Criteria Form, Criteria Itemquestion, Criteria Value, Study Period Order, Study Period, Related Form, Visit

SR, Cohort, -3475, 1, Initial Treatment Phase, DOV, Cycle 1 Course 2

SR, Cohort, -3475, 2, Second Course, DOV, Cycle 2 Course 2

Example 2:

Criteria Form, Criteria Itemquestion, Criteria Value, Study Period Order, Study Period, Related Form, Visit

SR, Cohort, mFOLFOX6 + bevacizumab, 1, Initial Treatment Phase, PMS1, Discontinuation Visit

Note:

1: LSN eCRF data are going to be retrieved from the ‘LSN_supp_doc’ global supporting document.

2. Do not produce output for deleted ‘Lesion Evaluation Form’ entries

3. Do not produce output for DOV in erroneous visits (Logic 1, when DOV is provided in supporting doc)

4. For LSNEV/LSNRN, use 'Date of Assessment' for Logic 1. For other lesion evaluation forms, use 'Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam)' for Logic 1.

5. For Scenario 2, if the item name is 'Yes, Provide the Associated Lesion Number', check the Study Period in Lesion Evaluation Form with the corresponding Lesion Number; if the item name is 'Yes, Provide the Associated Sponsor ID Number', check the study Period in Lesion Evaluation Form with the corresponding Sponsor ID Number.

Report Scenarios:
Scenario A, Logic 1, Yes

‘Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam)’ in ‘Lesion Evaluation Form’ > DOV.Date of Visit/PMS1.Date of Assessment in the visit corresponding to the selected ‘Study Period’

Scenario B, Logic 1, No

‘Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam)’ in ‘Lesion Evaluation Form’ < DOV.Date of Visit/PMS1.Date of Assessment in the visit corresponding to the selected ‘Study Period’

Scenario C, Logic 1, No

‘Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam)’ in ‘Lesion Evaluation Form’ = DOV.Date of Visit/PMS1.Date of Assessment in the visit corresponding to the selected ‘Study Period’

Scenario D, Logic 1, No

‘Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam)’ in ‘Lesion Evaluation Form’ > DOV.Date of Visit in the visit corresponding to the selected ‘Study Period’ AND erroneous visit is checked

Scenario E, Logic 1 and 2, No

Lesion Evaluation Form is deleted

Scenario F, Logic 2, Yes

(Indicate if Lesion was Present at Initial Treatment Phase in ‘Lesion Evaluation Form’ = Y) AND (‘Study Period’ in ‘Lesion Evaluation Form’ provided in ‘Yes, Provide the Associated Sponsor ID Number’ <> INITIAL TREATMENT PHASE)

Scenario G, Logic 2, No

(Indicate if Lesion was Present at Initial Treatment Phase in ‘Lesion Evaluation Form’ = Y) AND (‘Study Period’ in ‘Lesion Evaluation Form’ provided in ‘Yes, Provide the Associated Sponsor ID Number’ = INITIAL TREATMENT PHASE)

Scenario H, Logic 2, No

(Indicate if Lesion was Present at Initial Treatment Phase in ‘Lesion Evaluation Form’ = N) AND (‘Study Period’ in ‘Lesion Evaluation Form’ provided in ‘Yes, Provide the Associated Sponsor ID Number’ <> INITIAL TREATMENT PHASE)

Sorting:
Country, Site Number, Subject Number, Lesion Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N set default to N), Supporting Doc Page (N/Y, Default as N), Lesion Evaluation forms (required, please separate by comma, i.e. LSNIR, LSNHM)

Form.Item Names:
1. SA. Country

2. SA. Site

3. SA. Subject number

4. LSN. Formmnemonic

5. LSN.Formidx(Itemsetidx)

6. LSN. Date of Lesion Evaluation Item Name

7. LSN. Date of Lesion Evaluation

8. LSN. Study Period

9. LSN. Present at Initial Treatment Phase Item name

10. LSN. Lesion Present at Initial Treatment Phase

11. DOV.Date of Visit or PMS1. Date of Assessment (depending on the supp doc)

12. Display 'Scenario 1' for Logic 1; 'Scenario 2' for Logic 2; 'Scenario 1 and 2' if both Logic 1 and Logic 2 are satisfied.
