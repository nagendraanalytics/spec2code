Report ID: RID006

Report Title:
Continuing Adverse Events With Status of Completed or Discontinued

Description:
This report displays subjects who have continuing AEs with a disposition status of Completed or Discontinued.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Term

6. AE LLT

7. Disposition Status

Logic:
This report lists subjects who have AEs with End Date indicating an ongoing AE and a disposition status of Completed or Discontinued in the Final Status visit.

The report will implement a radio button parameter for "Inclusion/Exclusion". The report will also list AE LLT terms from the study's database as a parameter selection. If "Include" parameter is checked, the report will only include selected AE LLT terms. If "Exclude" parameter is selected, the report will exclude the selected terms.

Report should not display subjects with any AE with outcome=Fatal or serious criteria=Death.

Report should not display subjects with date of death on the DEATH form completed.

Report should not display subjects with DS01 Discontinuation Reason=Death.

Report should not display deleted records.

Report Scenarios:
A-Yes

AE is ongoing but Disposition status is provided other than Death

B-No

AE is not ongoing

C-No

AE is ongoing but there is any AE or disposition data or Death data indicates this subject is dead

D-No

deleted records.

Sorting:
Country, Site, Subject Number, AE Seq

Parameter Selection:
Country, Site, Subject, Include/Exclude, AE LLT, Randomized Only, List of Subjects

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Adverse Events Form.Sequence Number

5. Adverse Events Form.AE Term

6. Adverse Events Form.AE LLT

7. Subject Disposition Form.Code ~ DS01DSTERMCMPRC
