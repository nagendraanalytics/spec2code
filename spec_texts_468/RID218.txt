Report ID: RID218

Report Title:
First Subject Review

Description:
This report displays subjects who are in scope of First Subject Review process

Column Heading:
1. Country

2. Site Number

3. Subject Number

4. Scenario

Logic:
Screnario 1:

If SA form item Screening Number ≠ null,

And Date of Visit of Screening visit ≠ null,

And within all subjects that have same site number, Date of Visit of Screening visit is the smallest

Will output

Note: If mutiple patients have same Date of Visit of Screening visit, output all patients

Screnario 2:

If SR form item Date of Assessment ≠ null,

And within all subjects that have same site number, SR form Date of Assessment is the smallest.

Will output

Note: If mutiple patients have same SR form Date of Assessment, output all patients

Note 2: If SR form is not available for the study, review SA form Treatment/Randomization Number ≠ null and  within all subjects that have same site number, SA form Treatment/Randomization Number with the earliest entry.

Will output

Screnario 3:

If DS01 form Date of Disposition ≠ null,

And DS01 form Select the Status of the Subject for the Study = Screen Failure

And within all subjects that have same site number, and DS01 form Select the Status of the Subject for the Study = Screen Failure, Date of Disposition is the smallest

Will output

Note: If mutiple patients have same DS01 form Date of Disposition, output all patients

Screnario 4:

If PMS1 form Date of Assessment≠ null,

And within all subjects that have same site number, PMS1 form Date of Assessment is the smallest.

Will output

Note: If mutiple patients have same PMS1 form Date of Assessment, output all patients

Note: If PSM1 is not present that scenario will not be considered

Screnario 5:

If DS01 form Date of Disposition ≠ null,

And within all subjects that have same site number, Date of Disposition is the smallest

Will output

Note: If mutiple patients have same DS01 form Date of Disposition, output all patients

Report Scenarios:
This report generates a listing of the first patient in each site who completed any of the following scenarios:

Scenario 1: First Patient screened in a site

Scenario 2: First Patient randomized/treated in a site

Scenario 3: First Patient discontinued in a site as a Screen failure

Scenario 4: First Patient Discontinued from study medication

Scenario 5: First Patient Discontinued from the study

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, Site Number, Subject Number

Form.Item Names:
1. SA Form. Site Country

2. SA Form. Site Mnemonic

3. SA Form. Subject Number

4. Scenario of logic (will output as First Patient screened in a site

/First Patient randomized/treated in a site/First Patient discontinued in a site as a Screen failure/First Patient Discontinued from study medication/First Patient Discontinued from the study)
