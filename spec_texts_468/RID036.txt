Report ID: RID036

Report Title:
Inform Lot Trace ID not in GCS

Description:
This report will display Lot Trace ID numbers which are present in the DISP/SMPB that are not present in the GCS file.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF Name

6. Lot Trace ID

Logic:
Merge the DISP/SMPB forms and the GCS file by Country, Site, Subject Number, Visit, eCRF Name and Lot Trace ID numbers and output those which are present in the  DISP/SMPB that are not in the GCS file

Note: Report is NOT case sensitive.

Sorting:
Country

Site

Subject Number

Visit

Lot Trace ID

Parameter Selection:
Country, Site, Subject Number, Randomized Only, Blinded eCRF Name(s): (Selection list with 'SMPB' and 'DISP', default as 'SMPB')

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subject Assignment.Subject Number

4. SMPB.Visitmnemonic/DISP.Visitmnemonic

5. SMPB. Form mnemonic/DISP. Form mnemonic

6. SMPB.Lot Trace ID/SMPB.LOT ID/DISP.Lot Number
