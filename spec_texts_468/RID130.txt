Report ID: RID130

Report Title:
Specimen Type consistency across visits by form and Lab ID

Description:
This report will review when a unique lab vendor ID has more than one Specimen Type used across all visits on each of the LNMT forms (CLB01, HLB01, OLB01).

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Visit Mnemonic

6. Lab Seq #

7. Laboratory ID

8. Specimen Type

Logic:
This report will output:

Separately review and output for each one of the LNMT forms (CLB01, HLB01, OLB01), if records with same Laboratory ID have more than one Specimen Type used across all visits

Note:

1. Specimen type comparison should be done by LAB ID, by subject, by form.

2. Report should not consider deleted records.

3. Report should not consider records in erroneous visits.

4. Report should not consider visits without Date of Visit.

5. Uninitialized laboratory forms should not be considered.

Report Scenarios:
1) Output=YES

Visit has DOV and is not erroneous AND laboratory form is initialized. CLB01 has same Laboratory ID, but there are more than one Specimen types within and across all visits

2) Output=YES

Visit has DOV and is not erroneous AND laboratory form is initialized. HLB01 has same Laboratory ID, but there are more than one Specimen types within and across all visits

3) Output=YES

Visit has DOV and is not erroneous AND laboratory form is initialized. OLB01 has same Laboratory ID, but there are more than one Specimen types within and across all visits

4) Output=NO

Visit has DOV and is not erroneous AND laboratory forms are initialized. For each form CLB01/HLB01/OLB01, have same Laboratory ID Only one Specimen Type within and across all visits

5) Output=NO

Visit has DOV and is not erroneous but laboratory forms are not initialized

6) Output=NO

Visit does not have DOV or it is erroneous

Sorting:
Country, Site Number, Subject Number, Form

Parameter Selection:
Country, Site Number, Subject Number, Form

Form.Item Names:
1. Subject Assignment. Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Form.Formmnemonic

5. DOV, Visit Mnemonic

6. CLB01/HLB01/OLB01, Lab seq #

7. CLB01/HLB01/OLB01, Laboratory ID

8. CLB01/HLB01/OLB01, Specimen Type
