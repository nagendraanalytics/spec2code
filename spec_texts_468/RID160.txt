Report ID: RID160

Report Title:
Positive pregnancy test

Description:
This report lists all subjects that have a positive pregnancy test but not have section current pregnancy outcome on PRG01 completed.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Sequence number

6. Specimen collect date

7. Test Name

8. Test Result

Logic:
Output the subjects when the subjects have one of tests match the test(s) from the information provide by user, and PRG01 is not initialized or PRG01 is initialized with blank "current pregnancy outcome" section.

*Comment on PRG01 will not be considered.

*Deleted records/erroneous visits data will not be considered in programming and logic.

* LABS, please use 'Specimen Material Name' as Specimen Type in programming.

* SLAB, please use 'Abbreviated Dictionary Term' in programming.

* SLAB, please use 'Abbreviated Unit Dictionary Term' for the unit in programming.

Requires supporting document to be named PRG001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

user should provide a list with six columns:

-Form Name: Local vs Central labs, to collect pregnancy test.

-Abbreviated Dictionary Term

-Specimen Type

- CONDSYMBOL : = or > or < or <> or >= or >=

- CONDRESULT : Condition result expected according to CONDSYMBOL

- CONDUNIT : Condition unit or NA

(Provide ‘Abbreviated Dictionary Term’, ‘Specimen Type’ and expected test result for each Lab test to consider the pregnancy test as positive (to confirm with Clinical))

e.g.

Form Name,Abbreviated Dictionary Term,Specimen Type,CONDSYMBOL,CONDRESULT,CONDUNIT

SLAB,Choriogonadotropin Beta,Serum,=,Positive,NA

SLAB,Choriogonadotropin Beta,Urine,=,Positive,NA

SLAB,Choriogonadotropin Beta,Serum,>=,5,IU/L

Report Scenarios:
A- Yes

there is a positive pregnancy test and PRG01 is not initialized

B-Yes

there is a positive pregnancy test and PRG01 is initialized with blank "current pregnancy outcome" section.

C-No

Negative pregnancy test

D-No

there is a positive pregnancy test and PRG01 is initialized with data on "current pregnancy outcome" section
