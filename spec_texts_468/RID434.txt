Report ID: RID434

Report Title:
Study medication switch reconciliation

Description:
This report will list  subjects that have entries for selected study medications at the same cycle or for whom the selected study medication was replaced with another, prohibited study medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit Mnemonic

5. SM Form

6. Sequence Number

7. Study Medication

8. SM Start Date/Time

9. Study Period

10. Scenario

Logic:
Logic 1

Study Period in SM/SMAU form = Study Period in SM/SMAU form for different Study Medications within the same Group provided in the supporting doc

Logic 2

Start Date in SM/SMAU for Study Medication with lower Order > Start Date/Time in SM/SMAU for Study Medication with higher Order for different Study Medications within the same Group provided in the supporting doc

Notes:

Note 1. Do not display output for deleted records or erroneous visits

Note 2. Display Logic 1 only if Scenario 1 is selected in prompts; display Logic 2 only if Scenario 2 is selected in prompts

Note 3. For Logic 2 produce output only for the Study Medication with lower Order within the same Group provided in the supporting doc

Note 4. Requires supporting document to be named ONC_SM_006_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

Group – enter 1, 2, 3 etc. to differentiate between different groups of prompts as indicated in the example below;

SM form – enter SM or SMAU, as applicable for Study Medication;

Study Medication – enter SM Label Description or SMAU Dose Number

Order – Enter NA for Scenario 1. For Scenario 2 enter 1, 2, 3, etc. Study Medication with higher order cannot be replaced with Study Medication with lower order.

Scenario – enter 1 for Scenario 1 or 2 for Scenario 2

For example, if:

- Carboplatin, Docetaxel and Paclitaxel can’t be administered at the same cycle

- 3475 and Enzalutamide can’t be administered at the same cycle

- Docetaxel can’t be replaced with Paclitaxel

Group, SM Form, Study Medication, Order, Scenario

1, SM, Carboplatin, NA,  1

1, SM, Docetaxel, NA, 1

1, SMAU, Paclitaxel, NA, 1

2, SMAU, -3475, NA, 1

2, SM, Enzalutamide, NA, 1

3, SM, Paclitaxel, 1,2

3, SM, Docetaxel, 2, 2

Note 4. If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, use the optional supporting doc study_med_match_supp_<xxxxxxx>.csv to define the mapping.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Optional supporting document should be named as study_med_match_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Label Description or Dose Number present in SM/SMAU/SMAB eCRFs.

1. eCRF – SM/SMAU/SMAB

2. Study Medication – Value of Study Medication

3. Matching Item – SM Label Description or SMAU/SMAB Dose Number

4. Matching Value – Value of SM Label Description or SMAU/SMAB Dose Number

e.g.

eCRF,Study Medication,Matching Item,Matching Value

SM,-1439,Label Description,-1439 100 mg

SM,Methadone,Label Description,Methadone Tablet 5 mg

SM,Methadone,Label Description,Methadone Tablet 10 mg

SMAB,3475/Placebo,Dose Number,3475/Placebo

SMAU,Carboplatin,Dose Number,Carboplatin

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 1

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 2

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 3

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Med Match Page".

Report Scenarios:
Scenario A, Logic 1, Output: Yes

Study Period in SM/SMAU form for ‘Study Medication A’ provided in supporting doc = Study Period in SM/SMAU form for ‘Study Medication B’ provided within the same group in supporting doc

Scenario B, Logic 1, Output: No

Study Period in SMAU form for ‘Study Medication A’ provided in supporting doc = Study Period in SMAU form for ‘Study Medication B’ provided within the same group in supporting doc, but SMAU is in erroneous visit

Scenario C, Logic 1, Output: No

Study Period in SM/SMAU form for ‘Study Medication A’ provided in supporting doc = Study Period in SM/SMAU form for ‘Study Medication B’ provided within the same group in supporting doc but SM/SMAU deleted

Scenario D, Logic 1, Output: No

Study Period in SM/SMAU form for ‘Study Medication A’ provided in supporting doc is different than Study Period in SM/SMAU form for ‘Study Medication B’ provided within the same group in supporting doc

Scenario E, Logic 2, Output: Yes

Start Date in SM/SMAU for Study Medication with lower Order > Start Date/Time in SM/SMAU for Study Medication with higher

Scenario F, Logic 2, Output: No

Start Date in SM/SMAU for Study Medication with higher Order = Start Date/Time in SM/SMAU for Study Medication with lower Order

Scenario G, Logic 2, Output: No

Start Date in SMAU for Study Medication with lower Order > Start Date/Time in SMAU for Study Medication with higher Order but SMAU is provided in erroneous visit

Scenario H, Logic 2, Output: No

Start Date in SM/SMAU for Study Medication with higher Order > Start Date/Time in SM/SMAU for Study Medication with lower Order but SM/SMAU deleted

Sorting:
Country, Site, Subject Number, SM/SMAU.Study Period

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Scenario 1 (Y/N, Default Y),  Scenario 2 (Y/N, Default Y), Supporting Doc Page (N/Y; Default as N), Study Med Match Page (N/Y, Default as N)

Form.Item Names:

5. Display SM or SMAU

6. Sequence number for SM or SMAU entry

7. SM/SMAU.Study Medication

8. SM/SMAU.Start Date/Time

9. SM/SMAU.Study Period

10. Display ‘Scenario 1’ for logic 1 and ‘Scenario 2’ for logic 2
