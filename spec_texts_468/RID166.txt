Report ID: RID166

Report Title:
Duplicate Randomization or Screening Numbers

Description:
This report will list subjects who, within a protocol, have duplicate Randomization numbers and/or Screening numbers.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Screening Number

5. Randomization Number

6. Duplicates

Logic:
The report should display output if subjects have identical Randomization Numbers. The report should also display output if subjects have identical Screening Numbers.

Report should not display deleted records.

Report Scenarios:
Refer to Test Case

Sorting:
For duplicate Randomization: Duplicates, Randomization Number, Subject Number

For duplicate Screening: Duplicates, Screening Number, Subject Number

Parameter Selection:
Country, Site

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment form.Site Mnemonic

3. Subjects.Subject Number

4. Subject Assignment form.Screening Number

5. Subject Assignment form.Treatment Randomization Number

6. Derive as follows:

For duplicate Randimization  display "Randomization Number Duplicate"

For duplicate Screening Number  display "Screening Number Duplicate"
