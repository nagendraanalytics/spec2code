Report ID:

EDC System / Language:

Description:
This report will display all subjects with incorrect reason for discontinuation selected in subject disposition

Column Heading:
1. Country
2. Site
3. Subject Number
4. DS01 Reason for Discontinuation

Logic:
Report will output the subjects who have invalid options selected for the DS01 Reason for Discontinuation.

Records with DS01 Subject Status = Completed or null should not be considered.

The Reason for Discontinuation prompt is mandatory and the user has to select the valid options for the trial. Records with options not according to what was selected in the prompt will be outputted.

Report Scenarios:
1) Output = YES
Subject with DS01 Reason for Discontinuation not in the values selected from the Reason for Discontinuation prompt

2) Output =NO
Subject with DS01 Reason for Discontinuation in the values selected from the Reason for Discontinuation prompt

3) Output =NO
Subject with DS01 Status = Completed or null

Sorting:
Country, Site, Subject Number

======================================================================
2. LOGIC UNDERSTANDING
======================================================================
This report flags subjects on the DS01 Subject Disposition form who selected a Reason for Discontinuation value that falls outside the set of valid options chosen via the study's Reason for Discontinuation prompt, while excluding any records where DS01 Subject Status is 'Completed' or null. The output lists Country, Site, Subject Number, and the invalid DS01 Reason for Discontinuation value, sorted by Country, Site, and Subject Number. The core logic is a validation/lookup comparison of an actual field value against a dynamically configured 'valid values' list, gated by a status-based exclusion filter.

1. This report works off the DS01 (Subject Disposition) form, specifically looking at the DS01 Reason for Discontinuation field for each subject.
2. First, exclude any DS01 records where DS01 Subject Status = 'Completed' or is null -- these records are not considered for this check at all, regardless of what Reason for Discontinuation value they have.
3. For the remaining records (Subject Status is neither Completed nor null), determine the set of 'valid' values for Reason for Discontinuation -- this is the set of options selected by the user in the Reason for Discontinuation prompt (a report parameter/filter configured for the trial).
4. Compare each remaining subject's DS01 Reason for Discontinuation value against this valid set. If the value is NOT in the values selected from the prompt, the record is flagged as having an invalid/incorrect reason for discontinuation.
5. Per Scenario 1, a subject whose DS01 Reason for Discontinuation is not among the prompt-selected values should be output (Output = YES).
6. Per Scenario 2, a subject whose DS01 Reason for Discontinuation IS among the prompt-selected values should NOT be output (Output = NO), since it's a valid, correctly selected reason.
7. Per Scenario 3, a subject with DS01 Status = Completed or null should NOT be output (Output = NO), reinforcing the exclusion from Step 2 regardless of the Reason for Discontinuation value.
8. The final output list includes Country, Site, Subject Number, and DS01 Reason for Discontinuation for each flagged subject, sorted by Country, then Site, then Subject Number.

4. GENERATED CODE

CQL -- Guardrails: passed

SELECT
  d.Country AS `Country`,
  d.Site AS `Site`,
  d.SubjectNumber AS `Subject Number`,
  d.ReasonForDisc AS `DS01 Reason for Discontinuation`
FROM
  (
    SELECT
      `@HDR`.`Site`.`Country` AS Country,
      `@HDR`.`Site`.`Number` AS Site,
      `@HDR`.`Subject`.`Name` AS SubjectNumber,
      DS01DSTERMDSCRC AS ReasonForDisc,
      DS01DSTERMCMPIT AS SubjStatus
    FROM `EDC`.`DS01FM`
    WHERE `@Form`.`Status` = 'submitted__v'
  ) d
WHERE
  (d.SubjStatus IS NOT NULL AND d.SubjStatus <> 'Completed')
  AND (d.ReasonForDisc IS NULL OR d.ReasonForDisc NOT IN (@ReasonForDiscontinuation))
ORDER BY
  d.Country,
  d.Site,
  d.SubjectNumber

Explanation:
I used the DS01FM Form (per the provided study metadata) with DS01DSTERMDSCRC as the "Reason for Discontinuation" item and DS01DSTERMCMPIT as the "Subject Status" item -- these are the closest matching items in the known metadata list for DS01, but their exact mapping to "Reason for Discontinuation" vs "Status" fields isn't explicitly confirmed in the metadata block, so please verify via DESCRIBE FORM before running. The report-level "Reason for Discontinuation prompt" is treated as a user-supplied runtime parameter (@ReasonForDiscontinuation) holding the valid/allowed values selected at runtime, per the spec's requirement that valid options be user-chosen rather than hardcoded; records are excluded when Subject Status is Completed or null (Scenario 3), and flagged when the reason is null or not among the prompt-selected values (Scenario 1/2). Deleted-record filtering was omitted since DS01FM has no DELETEDFM item listed in the known metadata.
