Report ID: RID015

Report Title:
AE Action vs. Protocol Milestone Status

Description:
This report displays subjects who have Overall action taken with Study medication in AE as Discontinued but Protocol Milestone status is not Discontinued per AE and viceversa. If there is a PMS1 completed as discontinued due to AE and there is no AE with Action Taken with study medication as Discontinued, the patient should be listed.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Term

6. AE Start

7. PMS1 Date

8. PMS1 Visit

9. Missing

Logic:
This report displays subjects who have a record in the Adverse Event form with an Overall action Taken with Study Medication of Discontinued and missing Protocol Milestone Status record with a "Status of Study Medication at the end of this trial segment" of Discontinued and a Reason of Adverse Event on a date greater or equal to the AE Start date. Also, this report should display patients with Protocol Milestone Status record with a "Status of Study Medication at the end of this trial segment" of Discontinued and a Reason of Adverse Event, however, there is no Adverse Event with an Overall action Taken with Study Medication of Discontinued.

The user should provide a list with three columns:

- visit: visitmnemonic where an AE may occur and the study medication may be discontinued.

- pms1f: PMS1 form with the "Status of Study Medication at the end of this trial segment" item that should be completed if the AE occurs at the given visit.

- pms1v: PMS1 visitmnemonic.

The AE records with Overall action Taken with Study Medication=Discontinued will be matched by the Start Date to the visit with the nearest DOV that is prior or equal to the AE event.

1) If there is no such visit, the Missing column will be blank.

2) If there is such visit, but it has not been defined in the supporting data provided by the user, the Missing column will be blank.

3) If there is such visit, and it has been defined in the supporting data provided by the user, this data will be used to determine the expected PMS1 form and visit, and the PMS1 data will be evaluated:

a) If the PMS1 Status of Study Medication at the end of this trial segment<>ADVERSE EVENTS then it will appear in the output.

B) If the PMS1 Status of Study Medication at the end of this trial segment=ADVERSE EVENTS and PMS1 Date of Assessment<AE Start Date then it will appear in the output.

C) If the PMS1 Status of Study Medication at the end of this trial segment=ADVERSE EVENTS and PMS1 Date of Assessment>=AE Start Date then it will not appear in the output.

D) If the PMS1 Status of Study Medication at the end of this trial segment=ADVERSE EVENTS and there is no AE with an Overall Action taken with Study Medication of Discontinued, then it will appear in the output.

Report should not consider deleted records or data in erroneous visits.

Requires supporting document to be named AE023_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

The user should provide a list with three columns:

- Visit: visitmnemonic where an AE may occur and the study medication may be discontinued.

- Pms1f: PMS1 form with the "Status of Study Medication at the end of this trial segment" item that should be completed if the AE occurs at the given visit.

- Pms1v: PMS1 visitmnemonic.

e.g.

Visit,PMS1f,PMS1v

Cycle 1,PMS1,Discontinuation Visit

Cycle 2,PMS1,Discontinuation Visit

Cycle 3,PMS1,Discontinuation Visit

Cycle 4,PMS1,Discontinuation Visit

Note 1: "The AE records with Overall action Taken with Study Medication=Discontinued will be matched by the Start Date to the visit with the nearest DOV that is prior or equal to the AE event." statement only applies for Scenario A,B and C. Please exclude Scenario D.

Note 2: Please consider AE Onset date as AE start date for the trials wherever is applicable.

Report Scenarios:
A- YES

AE Overall Action Taken with Study Medication = Discontinued and

PMS1 Status of Study Medication at the end of this trial segment <> ADVERSE EVENTS or is null at the appropriate visit

B- YES

AE Overall Action Taken with Study Medication = Discontinued and

PMS1 Status of Study Medication at the end of this trial segment = ADVERSE EVENTS at the appropriate visit and

PMS1 Date of Assessment < AE Start Date

C- NO

AE Overall Action Taken with Study Medication = Discontinued and

PMS1 Status of Study Medication at the end of this trial segment = ADVERSE EVENTS at the appropriate visit and

PMS1 Date of Assessment >= AE Start Date

D- YES

PMS1 Status of Study Medication at the end of this trial segment = ADVERSE EVENTS at the appropriate visit and

there is no AE Overall Action Taken with Study Medication = Discontinued

Sorting:
Country, Site, Subject Number, AE Seq

Parameter Selection:
Country, Site, Subject, List of Subjects, Randomized Only

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subject Assignment.Subject Number

4. Adverse Events Form.formidx. If there is no AE with action taken with SM as Discontinued, it should be empty.

5. Adverse Events Form.AE Term. If there is no AE with action taken with SM as Discontinued, it should be empty.

6. Adverse Events Form.Start Date. If there is no AE with action taken with SM as Discontinued, it should be empty.

7. Protocol Milestone Status Form.Date of Assessment

8. Protocol Milestone Status Form.Visitmnemonic

9. Derived: Missing PMS1 form or blank. When Logic D is satisfied, please display "Missing AE"
