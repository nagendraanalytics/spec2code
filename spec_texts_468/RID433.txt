Report ID: RID433

Report Title:
Radiation vs Study Medication dosing

Description:
This report identifies subjects that have selected study medication entries within X days before radiation/surgery treatment or did not restart selected study medication within Y weeks after radiation/surgery.

Column Heading:
1.Country

2.Site

3.Subject Number

4.Radiation Form

5.Radiation Form Seq

6.Date

7.SM Form

8.SM Form Seq

9.SM Visit

10.SM Start Date

11.SM Stop Date

12.Scenario

Logic:
Logic 1:

Logic 1a:

Radiation Date = (ORAD2.Start Date <> NULL OR OSOF.DATE OF SURGERY <> NULL)

AND

Logic 1b: SM/SMAU/SMAB. Stop Date/Time <> NULL AND Radiation Date - Window of days <= SM/SMAU/SMAB.Stop Date/Time <= Radiation Date

AND

Logic 1c: SM/SMAU/SMAB.Study Medication = Study Medication

Logic 2:

Logic 2a:

Radiation Date = (ORAD2.Start Date <> NULL OR OSOF.DATE OF SURGERY <> NULL)

AND

Logic 2b: (System Date) – (Radiation Date) > Number of weeks

AND

Logic 2c: There is no SM/SMAU/SMAB record with Start Date/Time > Radiation Date and before Radiation Date + Number of weeks

AND

Logic 2d: SM/SMAU/SMAB.Study Medication = Study Medication

Note 1: Please do not include deleted entries

Note 2: Please do not evaluate visits where ‘Erroneous Visit’ checkbox is selected.

Note 3: If any date is entered as UNK please consider the minimum day of the month and the maximum month of the year.

Note 4: For Radiation Date. If both the ORAD2 and [Oncology Surgery Follow-up Forms] Dates are present, please evaluate logic with both dates.

Note 5: Please disregard time if present in any forms.

Note 6: Requires supporting document to be named ONC_SM_005_supp_.csv and will contain the following columns and associated content:

1) Study Medication – Required, enter study medication name.

2) Window of days – Required, enter a number.

3) Number of weeks - Required, enter a number.

e.g.

Study Medication, Window of days, Number of weeks

3475/Placebo,30,1

Olaparib,20,2

Note 7: For Logic 2 do not display output if SM/SMAU/SMAB. Study Medication has 'Last Dose' checked

Note 8: For both logics consider only non-zero SM/SMAU/SMAB. Study Medication records (where Number of Units Taken <> 0 )

Note 9: The report will use master supporting document OSOF_supp_doc. This supporting document should be uploaded only once at TA level per the GDO Oncology TAST authorized members and will be used to facilitate programming of the report. Report builder will use all the columns provided in the excel spreadsheet to create the programming code. OSOF refers to the forms included in the OSOF_supp_doc.

Report Scenarios:
Scenario A – Output: Yes, There is a Study Medication entry in SM/SMAU/SMAB WITHIN X days prior a Radiation in ORAD2 or a Surgery in [Oncology Surgery Follow-up Forms]

Scenario B – Output: Yes, There is no Study Medication entry in SM/SMAU/SMAB WITHIN Y weeks after a Radiation in ORAD2 or a Surgery in [Oncology Surgery Follow-up Forms]

Scenario C – Output: No, There is no Study Medication entry in SM/SMAU/SMAB WITHIN X days prior a Radiation in ORAD2 or a Surgery in [Oncology Surgery Follow-up Forms]

Scenario D – Output: No, There is at least one Study Medication entry SM/SMAU/SMAB WITHIN Y weeks after a Radiation in ORAD2 or a Surgery in [Oncology Surgery Follow-up Forms]

Sorting:
Default

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N set default to N), Supporting Doc Page (N/Y, Default as N), OSOF Form (Text Box, default as ‘ALL’, separate each eCRF by comma)

Form.Item Names:
1. SA.Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. Please display the Form name of the Radiation Date used

5. Please display the Formidx of the Radiation Date used

6. Please display the Radiation Date used

7. SM/SMAU/SMAB.Form name

8. SM/SMAU/SMAB.Formidx

9. SM/SMAU/SMAB.Visit Mnemonic

10. SM/SMAU/SMAB.Start Date/Time

11. SM/SMAU/SMAB.Stop Date/Time

12. If Logic 1 is met, display ‘Scenario 1’; If Logic 2 is met, display ‘Scenario 2’ Note 1: If Scenario 2 is met, please display columns 7 to 11 as blank
