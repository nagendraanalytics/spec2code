Report ID: RID257

Report Title:
Missing efficacy assessment per protocol

Description:
This report will show output for missing cystoscopy

Column Heading:
1. Country

2. Site

3. Subject number

4. Timepoint Date

5. Expected Timeframe range

6. Display Message

Logic:
Definitions:

‘Start Item Date’ = date in the item provided in the supporting document “Start Item Date” field

‘Stop Item Date’ = date in the item provided in the supporting document “Stop Item Date” field

‘Timepoint’ = date calculated as explained in ‘Note 5’

‘Expected Timeframe’ = date range calculated as explained in ‘Note 5’

Scenario 1:

Screening DOV.Date of Visit date <> NULL

AND

SR.Date of Assessment <> NULL

AND

There is not at least 1 CTO entry with (CTO.Cystoscopy Date =< SR.Date of Assessment AND CTO Cystoscopy Date => DOV.Date of Visit)

Scenario 2:

 ‘Start Item Date’ <> NULL

AND

System Date – ‘Start Item Date’ > ‘Expected Timeframe’

AND

There is no CTO.Cystoscopy Date record within the ‘Expected Timeframe’

AND

(‘Stop item date’ from the Stop Item Date in Stop Form in Scenario 2 in supporting document = NULL

OR

(‘Stop item date’ from the Stop Item Date in Stop Form in Scenario 2 in supporting document <> NULL

AND

‘Stop item date’ from the Stop Item Date in Stop Form in Scenario 2 in supporting document >= ‘Timepoint’))

Scenario 3:

 ‘Start item date’ from the Stop Item Date in Stop Form in Scenario 3 in supporting document <> NULL

AND

‘Next Trial Segment’ = as provided in supporting document

AND

System Date – ‘Start item date’ > ‘Expected timeframe’

AND

There is no CTO.Cystoscopy Date record within the ‘Expected Timeframe’

AND

(‘Stop item date’ = NULL

OR

(‘Stop item date’ <> NULL

AND

‘Stop item date’ >= ‘Timepoint’))

Note 1: For all scenarios, display message “Scenario 1”, “Scenario 2” or “Scenario 3” accordingly

Note 2: If item in supporting document is completed as NA, please ignore this field.

Note 3: If Stop Week is entered as NA, then consider system date.

Note 4: Exclude deleted records.

Note 5:

Steps to calculate the ‘Timepoint’ and the 'Expected Timeframe':

A.      Calculate different timepoints by doing the following mathematical operation:

Timepoint 1: ‘Start Item Date’ + Start week

Timepoint 2: ‘Start Item Date’ + Start week + 1*Frequency

Timepoint 3: ‘Start Item Date’ + Start week + 2*Frequency

Timepoint N: ‘Start Item Date’ + Start week + (N-1)*Frequency

B.      Timepoints calculated on step A should be: ‘Start Item Date’ + Start week <= Timepoint N <= ‘Start Item Date’ + ‘Stop week’ OR ‘Stop Item Date’, whichever is first

C.      Expected Timeframe = From Timepoint N - 'Lower window of days' to Timepoint N + 'Upper window of days'

Example:

A.      Start Date Item = 01-Jan-2020

B.      Start week = 12

C.      Stop week = 108

D.      Frequency = 12

E.      Lower window of days = 14

F.      Upper window of days = 14

Timepoint 1 = 01-Jan-2020 + 12 weeks = 25-Mar-2020

Expected Timeframe 1 = From 11-Mar-2020 to 08-Apr-2020

Timepoint 2 = 01-Jan-2020 + 12 weeks + 12 weeks = 17-Jun-2020

Expected Timeframe 2 = From 3-Jun-2020 to 1-Jul-2020

Timepoint 3 = 01-Jan-2020 + 6 weeks + 12 weeks = 09-Sep- 2020

Expected Timeframe 3 = From 26-Aug-2020 to 23-Sep-2020

Note 6: For Scenario 1, COLUMN HEADINGS items ‘Timepoint Date’ display always as “Screening”, and ‘Expected Timeframe range’ leave blank

Note 7: If supporting doc is not provided, display the message as "ONC_CTO_001_JR_STD Supporting Document Not Present for This Trial"

Requires supporting document to be named ONC_CTO_001_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

Supporting document should have provided following fields:

Scenario - Required. Refers to the Scenarios 2 or 3 in RIG.

Lower Window of Days - Required. Number of lower window of days specified by the protocol (eg. +/- 14 days = 14 days as a Lower Window of Days)

Upper Window of Days - Required. Number of upper window of days specified by the protocol (eg. +/- 14 days = 14 days as a Upper Window of Days)

Frequency - Required. Frequency in weeks specified in the protocol. This value can differ within a scenario. If different interval while subject is in the study, it should be reflected as in example.

Start Form – Required. Form in which Start Item Date can be found

Start Item Date - Required. Date on the item used as a reference date to calculate CTO assessment expected timeframe.

Stop Form – Required. Form in which Stop Item Date can be found

Stop Item Date - Required. Date on the item used as a reference date after which CTO assessment is not expected.

Next Trial Segment - Required. Expected phase for Scenario 3 in which CTO assessment would be performed. If there is more than 1 option, please list them in separate records.

Start Week - Required. Week used for calculation expected CTO assessment (eg. if study have different intervals within one phase, 2 different start weeks for one scenario for both frequencies should be listed in separate entries as per example below) and first week in which CTO should be recorded.

Stop Week - Required. Week used as a reference date from the date 'Start Item Date' after which we don't expect CTO to be performed. If there is no Stop Week, please enter "NA".

Example 1:

2,14,14,12,SR.Date of Assessment,PMS1.Date of Assessment,NA,12,108

2,14,14,24,SR.Date of Assessment,PMS1.Date of Assessment,NA,108,260

3,14,14,12,PMS1.Date of Assessment,OEFU.Date of Assessment,CONTINUING INTO FOLLOW-UP PHASE,12,108

3,14,14,24,PMS1.Date of Assessment,OEFU.Date of Assessment,CONTINUING INTO FOLLOW-UP PHASE,108,260

Example 2:

2,14,14,12,SR.Date of Assessment,PMS1.Date of Assessment,NA,12,NA

3,14,14,12,PMS1.Date of Assessment,PMS1A.Date of Assessment,CONTINUING INTO FOLLOW-UP PHASE,0,NA

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
Scenario 1a, Output: Yes

Subject is randomized AND there is no CTO record with Cystoscopy Date equal or after Screening Visit DOV and equal or before SR Date of Assessment

Scenario 2a, Output: Yes

Subject is randomized AND there is no CTO record with Cystoscopy Date within ‘Expected Timeframe’ AND ‘Stop Item Date’ = NULL

Scenario 2b, Output: Yes

Subject is randomized AND there is no CTO record with Cystoscopy Date within ‘Expected Timeframe’ AND ‘Stop Item Date’ is <> NULL AND ‘Timepoint’ date is <= ‘Stop Item Date’

Scenario 2c, Output: No

Subject is randomized AND there is no CTO record with Cystoscopy Date within ‘Expected Timeframe AND ‘Stop Date Item’ is <> NULL AND ‘Timepoint’ date is > ‘Stop Item Date’

Scenario 3a, Output: Yes

Subject is randomized AND there is no CTO record with Cystoscopy Date within ‘Expected Timeframe’ AND ‘Next Trial Segment’ is = as provided in supporting document AND ‘Timepoint’ date is <= ‘Stop Item Date’

Scenario 3b, Output: No

Subject is randomized AND there is no CTO record with Cystoscopy Date within ‘Expected Timeframe’ AND ‘Next Trial Segment’ is = as provided in supporting document AND ‘Timepoint’ date is > ‘Stop Item Date’

Scenario 3c, Output: No

Subject is randomized AND there is no CTO record with Cystoscopy Date within ‘Expected Timeframe’ AND ‘Next Trial Segment’ is <> as provided in supporting document AND Timepoint date is <= ‘Stop Item Date’
