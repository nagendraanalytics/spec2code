Report ID: RID460

Report Title:
Missing required assessment within a specified window of lesion evaluation

Description:
This report will list subjects that there is no at least one assessment/test with the date/time within a specified window from a lesion evaluation.

Column Heading:
1.Country

2.Site

3.Subject Number

4.LSN ECRF

5.LSN Seq

6.Date of Lesion Evaluation

7.Scheduled Time

8.Target ECRF

9. Missing Test

Logic:
Logic 1.1: “Date of Current Lesion Evaluation (Scan/Image/Physical Exam)” from “ITEMQUESTION” column on LSN_supp_doc.csv is NOT NULL

AND

Logic 1.2: There is not at least one “Target eCRF” record that meets the following criteria:

Logic 1.3: "Target item" = “Test name”

AND

(Logic 1.4: Date of Assessment >= “Date of Current Lesion Evaluation (Scan/Image/Physical Exam)” – “Lower Window of Days”

AND

Logic 1.5: Date of Assessment =< ”Date of Current Lesion Evaluation (Scan/Image/Physical Exam)“ + ”Upper Window of Days“)

AND

Logic 1.6:  Scheduled Time= "Target eCRF Scheduled Time" (If NA in Supp Doc, please ignore Logic 1.6)

AND

Logic 1.7: System Date >= "Date of Current Lesion Evaluation (Scan/Image/Physical Exam)" + "Upper Window of Days"

Notes:

1-     The item "Date of Current Lesion Evaluation (Scan/Image/Physical Exam)" should be used from master LSN_supp_doc.csv.

2-     “Target eCRF”, "Target item" ,“Test name”, "Target eCRF Scheduled Time" , "Lower Window of Days" and "Upper Window of Days" are values from report-specific supporting document.

3-     'Date of Assessment' should be the values from 'Target eCRF date item' .

4-     Erroneous visits and deleted records are excluded from programming.

5-    "Target eCRF" can be a visit-based form or common form.

6-     Column 4 will display the LSN eCRF as provided in the ONC_TQ_003_supp_doc.csv

7-     Column 6 will display the date in format "DDMMMYYYY".

8-      Column 7 will display the scheduled time entered in LSN eCRF. If a same Date of Lesion Evaluation in different LSN entry and has different Scheduled Time, should display 2 rows.

Supporting Document Notes:

Requires supporting document to be named ONC_TQ_003_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Test that should be outputted by the report.

1. LSN eCRF: Required, enter the LSN Form Mnemonic applicable per protocol

2.Target eCRF: Required, enter Form name where required tests should be entered.

3.Target item: Required, enter Item name where required tests should be entered.

4. Test name: Required, enter the Test Name from the Target Form that should be outputted.

5.Target eCRF Scheduled Time: Define Scheduled time of Target eCRF. NA if Scheduled time no need to be checked.

6.Target eCRF date item:Required, enter Item name which date should be considered.

7. Lower Window of Days: Minimum window compared to LSN eCRF(Value is inclusive)

8. Upper Window of Days: Maximum window compared to LSN eCRF(Value is inclusive)

Eg: There should be a Scheduled ctDNA Analysis on SPECT and within +/- 14 days of each scheduled evaluation on LSNIR form:

LSNIR/SPECT/Testing to be Performed/ctDNA Analysis/Scheduled/Date and Time Specimen(s) Obtained/-14/14

 If supporting doc is not provided, display the message as "ONC_TQ_003_JR_STD Supporting Document Not Present for This Trial".

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

2-

This report also uses the master LSN_supp_doc.csv. This supporting document should be uploaded only once at TA level per the GDO Oncology TAST authorized members and will be used to facilitate programming of the report. Report builder will use all the columns provided in the excel spreadsheet to create the programming code.

Report Scenarios:
Report Scenarios: Scenario: 1

Output: Yes

There is a “Date of Current Lesion Evaluation (Scan/Image/Physical Exam)” from LSN eCRF and there is not at least one “Target eCRF” with: "Target item" = “Test”, and Scheduled Time= '"Target eCRF Scheduled Time", and with Date of Assessment within Lower Window of Days and Upper Window of Days.

Scenario: 2

Output: No

There is a “Date of Current Lesion Evaluation (Scan/Image/Physical Exam)” from LSN eCRF and there is one“Target eCRF” with: "Target item" = “Test”, and Scheduled Time= '"Target eCRF Scheduled Time", and with Date of Assessment within Lower Window of Days and Upper Window of Days.

Scenario: 3

Output : No

LSN eCRF is not initialized OR “Date of Lesion Evaluation” (in Evalution Entry)  is NULL

Scenario: 4

Output: Yes

LSN eCRF is initialized and Target eCRF is not initialized
