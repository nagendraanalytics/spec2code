Report ID: RID123

Report Title:
LECG Missing or Duplicate Scheduled Times

Description:
This report will output subjects that do not have records or have duplicate records for required LECG scheduled times.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF

6. Scheduled Time

7. Group

8. Seq

9. Issue

Logic:
This report outputs subjects with missing LECG scheduled times, and/or with duplicate LECG scheduled times at given visits. Only initialized visits where the LECG form is present should be considered.

Deleted records should not be considered.

Data at erroneous visits should not be considered.

Requires supporting document to be named LECG001_supp_PROTOCOL and will contain the following columns and associated content: 1 row with inidviduall GROUP number for required record with the following columns: 1.GROUP 2.VISIT ID 3.SCHEDULED TIME

Note: If rows have the same GROUP then only one of the records within this group (VISIT ID and SCHEDULED TIME) is required

Report Scenarios:
Scenario 1 -yes

This report will output subjects who do not have required records according to supporting document.

Scenario 2 -yes

This report will output subjects whor have duplicate records for required LECG scheduled times according to supporting document.

Sorting:
Country, Site, Subject Number, Group, Visit, eCRF, Scheduled Time, Issue, Seq

Parameter Selection:
Protocol Number, Country, Site, Subject, Randomized Only

Form.Item Names:
1. cv_safm .country

2. cv_safm.sitemnemonic

3. irv_cur_subject .subjectnumberstr

4. dov.visitmnemonic

5. dov.formmnemonic

6. supporting document. Schedule Time

7. GROUP based on supporting document

8. CV_LECGFM.formidx

9. Duplicate/Missing
