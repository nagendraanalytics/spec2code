Report ID: RID113

Report Title:
Existing results for NOT DONE records at GEFCF

Description:
This report displays all GEFCF records with ANY value at the results fields but also has a Status entered as "NOT DONE".

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. eCRF

6. Seq

7. Vendor Name

8. Visit Number

9. Visit Name

10. Visit Type

11. Date/Time of Measurement

12. Test Short Name

13. Test

Logic:
This report will retrieve the GEFCF records with Completion Status='NOT DONE', which corresponds to a Not Done Test, and Result or Finding in Original Units is not null.

AND

GEFCF records with Completion Status='NOT DONE' and Reason not performed = null.

AND

GEFCF records with Reason not performed <> null and Completion Status= null.

Note:

Report should not display deleted records.

Report Scenarios:
Output - Yes

Completion status is Not Done but test result presents

Output - No

Completion status is Not Done and test result is blank

Output-Yes

Completion Status is 'NOT DONE' but Reason not performed is blank.

Output-No

Completion Status is 'NOT DONE' and Reason not performed is complete.

Output-Yes

Reason not performed is complete but Completion Status is missing.

Output-No

Reason not performed is complete and Completion Status is complete.

Sorting:
Country, Site, Subject Number, eCRF, Seq, Vendor Name

Parameter Selection:
Country, Site, Subject Number, Randomized Only, Vendor, List of Subjects
