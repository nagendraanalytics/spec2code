Report ID: RID077

Report Title:
Incremental Encoding of Concomitant Medication Terms - Listing

Description:
This report is a listing of all encoded drug terms from the CM/APCM eCRF.

Column Heading:
1. Country

2. Site

3. Subject Number

4. eCRF

5. Seq

6. Medication Name

7. Standardized Medication Name

8. Encoded Drug Name

9. Broader Term

10. Medication Class

11. Medication Class Code

12. ATC1 Term

13. ATC2 Term

Logic:
The report should display output if verbatim terms from Prior and Concomitant Medication form (CM)/Associated Persons Concomitant Medications (APCM). Comparisons should be on non-null terms and should not be case-sensitive.

Incremental outputs can be run by last modified date on Standardized Medication Name.

Display row count in footer.

Report should not display deleted records.

If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
The report should display output if verbatim terms from Prior and Concomitant Medication form (CM)/Associated Persons Concomitant Medications (APCM).

Sorting:
Country, Site, Subject Number, Seq

Parameter Selection:
Country, Site, Subject Number, Randomized Only, Changed Data From, Changed Data To, List of Subjects
