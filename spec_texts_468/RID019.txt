Report ID: RID019

Report Title:
AE of Infusion Reaction with no matching SM Record

Description:
The report will output subjects when an AE PT term contains "infusion" and there is no SM Start Date between AE Onset Date and Date prior to acceptable timeframe of the AE Onset Date(inclusive).

Column Heading:
1 Country

2. Site Number

3. Subject Number

4. AE Seq

5. AE Term

6. AE Onset Date

Logic:
Output the subjects who meet the following criteria:

Logic 1: AE PT term contains "infusion" and AE Onset date <> null

and

Logic 2: There is no Start date and time (only consider date) on SMAU/SMAB/SM form between AE Onset Date and (AE Onset date - timeframe) (inclusive the margin dates)

Note 1: Deleted record or Erroneous visit will not be considered in programming or output.

Note 2: The timeframe parameter must be chose to continue to run the report.

Report Scenarios:
Scenario A- Yes

AE PT term contains "infusion" and AE Onset date <> null

and

There is no Start date and time (only consider date) on SMAU/SMAB/SM form between AE Onset Date and (AE Onset date - timeframe) (inclusive the margin dates)

Scenario B- No

AE PT term does not contain "infusion"

Scenario C-No

AE PT term contains "infusion" and AE Onset date <> null

and

There is a Start date and time (only consider date) on SMAU/SMAB/SM form between AE Onset Date and (AE Onset date - timeframe) (inclusive the margin dates)

Scenario D- Yes/No

Deleted Record or Erroneous visit

Sorting:
Country, Site Number and Subject Number

Parameter Selection:
Country, Site Number, Subject Number, timeframe ( 0, 1,2,3,4... ... days)

Form.Item Names:
1. Subject Assignment. Country

2. Subject Assignment. Site Number

3. Subject Assignment. Subject Number

4. AE. Formdix

5. AE. AE term

6. AE. Onset date
