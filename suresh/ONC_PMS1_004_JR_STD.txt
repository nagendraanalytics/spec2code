Report ID: ONC_PMS1_004_JR_STD
Title: Treatment discontinuation due to CP but PD reported on the Oncologic Response eCRF.

Forms / Items:
1. SA.Site Country
2. SA.Site Mnemonic
3. SA.Subject Number
4. PMS1/PMST.form
5. PMS1/PMST.Visit Mnemonic
6. PMS1/PMST.Date of Assessment
7. [ONCOLOGIC RESPONSE FORMS].Form Mnemonic
8. [ONCOLOGIC RESPONSE FORM]. Sponsor ID Number
9. [ONCOLOGIC RESPONSE FORM].Date Item Name
10. [ONCOLOGIC RESPONSE FORM]. Date

Description:
This report will output if pt. discontinued treatment due to Clinical Progression but there are Overall Response as Progressive Disease reported.

Logic:
LOGIC 1
[PMS1].Status of Study Medication at the End of This Trial Segment= "CLINICAL PROGRESSION" and there is at least one [ONCOLOGIC RESPONSE FORM]/ORAJ.OVERALL RESPONSE/RESPONSE/HEMATOLOGIC RESPONSE/OVERALL IRECIST RESPONSE/OVERALL RECIST RESPONSE/OVERALL IRRECIST RESPONSE/PET RESPONSE = "Progressive Disease" or "iCPD" or "irProgressive Disease" or "Yes" AND [ONCOLOGIC RESPONSE FORM].DATE RESPONSE DETERMINED < [PMS1].Date of Assessment
OR
[PMST]. Status of Subject at end of all Study Treatments= "Clinical Progression" and there is at least one [ONCOLOGIC RESPONSE FORM]/ORAJ.OVERALL RESPONSE/RESPONSE/HEMATOLOGIC RESPONSE/OVERALL IRECIST RESPONSE/OVERALL RECIST RESPONSE/OVERALL IRRECIST RESPONSE/PET RESPONSE = "Progressive Disease" or "iCPD" or "irProgressive Disease" or "Yes"AND [ONCOLOGIC RESPONSE FORM].DATE RESPONSE DETERMINED < [PMST]. Date of Assessment

Notes:
Note 1: [ONCOLOGIC RESPONSE FORMS] are defined in the RSP_supp_doc.csv as well as the items mentioned in the logic for RSP forms, except, for ORAJ
Note 2: Erroneous visit or deleted record will not be considered in the programming or output.
Note 3: If protocol have more than one [ONCOLOGIC RESPONSE FORMS] and at least one of the forms meets the criteria output is expected. If "RSP Form" parameter selection is leaving blank, report should work with the [ONCOLOGIC RESPONSE FORMS] that is present in the study and matches with the forms defined in the RSP_supp_doc.csv
Note 4: for logic please take into account the PMS form prompt
Note 5: If protocol have both forms (PMS1 and PMST) and those were selected in the prompt and at least one of the forms meets the criteria output is expected.
Note 6: The report logic should be checked within the same treatment phase defined in the supporting document.
For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1
2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:
Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1
Second Course Phase: Second Course Cycle 1 <= Form.Date
Form.Date include: [ONCOLOGIC RESPONSE FORM].DATE RESPONSE DETERMINED, [PMS1].Date of Assessment, [PMST].Date of Assessment
Note 7:  This is a required supporting document for all studies with one or more phases.
This supporting document is required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.
Required supporting document should be named as study_phase_supp <MK/Vxxxxxxx>.csv and will contain the following columns and associated content:
One row for each Treatment Phase
1. Phase Order: the order on which phases will appear on protocol
2. Treatment Phase: this information is the phase name given in the protocol (Initial Treatment Phase/Second Course Phase/Crossover/Neoadjuvant)
3. First Visitmnemonic of Treatment Phase: the first visit on which treatment is expected to be administered on each phase.
e.g.
1, Initial Treatment Phase, Cycle 1
2, Second Course Phase, Cycle 1 Course 2
3, Crossover Phase, Crossover Cycle 1
The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Prompts (runtime parameters):
Country, Site, Subject Number, List of Subjects, PMS form (multiple selection, PMS1 - PMST, default to PMS1), RSP Form (free textbox), Study Phase Page (N/Y, Default as N)

Column Headings:

8. Seq#
9. Item Name

Sorting:
Country, Site, Subject Number

Report Scenarios:
A output = No
PMS1 is Clinical Progression and there are NOT Responses of PD reported before PMS1 Date of Assessment.
OR
PMST is Clinical Progression and there are NOT Responses of PD reported before PMST Date of Assessment.
B output = Yes
PMS1 is Clinical Progression and there is/are Responses of PD reported before PMS1 Date of Assessment.
OR
PMST is Clinical Progression and there is/are Responses of PD reported before PMST Date of Assessment.
