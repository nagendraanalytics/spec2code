Report ID: RID295

Report Title:
Reconciliation for more than one Event reported in AOGVH with the same Location

Description:
This report will output when there is reported two different AOGVH records with the same Location (Site of GVHD) and GVHD Stage Dates as overlaps.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Site of GVDH

5. Seq #1

6. GVHD Stage Onset Date seq #1

7. GVHD Stage Stop Date seq #1

8. Seq #2

9. GVHD Stage Onset Date seq #2

10. GVHD Stage Stop Date seq #2

Logic:
Logic 1: There are two AOGVH entries with the same AOGVH.Site of GVHD

AND

Logic 2: Current minimum AOGVH.GVHD Stage Onset Date is within previous minimum AOGVH.GVHD Stage Onset Date and previous maximum AOGVH.GVHD Stage Stop Date

Note 1: Deleted records should not be taken into account.

Note 2: AOGVH.GVHD Stage Onset Date will be sorted from oldest to newest by site of GVHD

Note 3: Current records should be compared with all subsequent records by site of GVHD

Report Scenarios:
Scenario A Output = Yes

There are two or more sequences entered in AOGVH form with the same Site of GVHD and GVHD Stage Onset/GVHD Stage Stop dates present overlaps

Scenario B Output = No

There are not two or more sequences entered in AOGVH with the same Site of GVHD or AOGVH form is not initialized

Scenario C Output = No

There are two or more sequences entered in AOGVH form with the same Site of GVHD and GVHD Stage Onset/GVHD Stage Stop dates doesnt present overlaps

Parameter Selection:
Country,Site,Subject Number,List of Subject

Form.Item Names:
1. SA.country

2. SA.Site

3. SR.Subject number

4. AOGVH.Site of GVHD

5. Previous AOGVH.Sponsor ID Number

6. Previous minimum AOGVH.GVHD Stage Onset

7. Prevous maximum AOGVH.GVHD Stage Stop Date

8. Current AOGVH.Sponsor ID Number

9. Current  minimum AOGVH.GVHD Stage Onset

10. Current maximum AOGVH.GVHD Stage Stop Date
