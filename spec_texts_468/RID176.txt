Report ID: RID176

Report Title:
Missing Lot IDs based on BSA

Description:
This report shows patients with missing LOT IDs based on Body Surface Area.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. DOV

6. Date/Time of Assessment

7. Body Surface Area

8. SM seq.

9. Study Medication

10. Start Date/Time

11. Lot ID entered

Logic:
Logic 1

VS02 [Date/Time of Assessmen] = to SM [Start Date/Time]

AND

Logic 2

VS02 [Body Surface Area] is GREATER or EQUAL than [3.75 m2] AND SM [Lot ID 1 to Lot ID 6] = NULL OR Only one Lot ID in SM [Lot ID 1 to Lot ID 6]≠NULL’

Note 1: for Logic 1 Date/Time of Assessmen should be equal to Start Date/Time

Note 2: for Logic 2 output should be shown when Lot ID 1 to Lot ID 6, no Lot ID entered or only one Lot ID

Note 3: The report should not display deleted records.

Note 4: The report should not display records in erroneous visits.

Report Scenarios:
-Yes

Body Surface Area is greater or equal than 3.75 m2 AND Lot ID 1 to Lot ID 6, no Lot ID entered or only one Lot ID entered’

-No

All  scenarios other than the first scenario.

Sorting:
Country, Site, Subject Number, VS02 Date/Time of Assessmen, Body Surface Area, SM Sequence Number, Start Date/Time

Parameter Selection:
Country, Site, Subject, Body Surface Area

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Visit Mnemonic

5. DOV

6. VS02. Date/Time of Assessment

7. VS02. Body Surface Area

8. SM. Formidx or blank

9. SM. Study Medication

10. SM. Start Date/Time

11. SM. Lot ID 1 to Lot ID 6 if anyone is completed
