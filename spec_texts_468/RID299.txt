Report ID: RID299

Report Title:
New lesions reconciliation

Description:
This report will list lesions with a Date of Assessment after 1st dose and Lesion Category is not New or vice versa.

Column Heading:
1. Country

2. Site

3. Subject number

4. Visit Mnemonic

5. Date of Visit

6. Form Mnemonic

7. Seq #

8. Study Period

9. Date of Initial Identification

10. Tumor Identification

11. Merged or Split

12. Scenario

Logic:
Logic 1.1: LSN eCRF: TUMOR IDENTIFICATION is not New/New Lesion Since Last Evaluation/ New Bone Lesion/New Soft Tissue Lesion Since Last Evaluation

AND

Logic 1.2: LSN eCRF INDICATE IF LESION MERGED OR SPLIT is null

AND

Logic 1.3: “LSN eCRF DATE OF INITIAL IDENTIFICATION” is after DOV.Date of first Visit for the same treatment phase

AND

Logic 1.4: LSN eCRF: STUDY PERIOD = to “Study Period” from the supporting document.

OR

Logic 2.1: LSN eCRF: TUMOR IDENTIFICATION is New/New Lesion Since Last Evaluation/ New Bone Lesion/New Soft Tissue Lesion Since Last Evaluation

AND

Logic 2.2: LSN eCRF INDICATE IF LESION MERGED OR SPLIT is null

AND

Logic 2.3 LSN eCRF DATE OF INITIAL IDENTIFICATION is on or before DOV.Date of first Visit.

AND

Logic 2.4: LSN eCRF: STUDY PERIOD = to “Study Period” from supporting document.

OR

Logic 3.1: LSN eCRF: TUMOR IDENTIFICATION is New/New Lesion Since Last Evaluation/ New Bone Lesion/New Soft Tissue Lesion Since Last Evaluation

AND

Logic 3.2 LSN eCRF INDICATE IF LESION MERGED OR SPLIT is not null

AND

Logic 3.3: LSN eCRF DATE OF INITIAL IDENTIFICATION is after DOV.Date of first Visit.

AND

Logic 3.4: LSN eCRF: STUDY PERIOD = to “Study Period” from supporting document.

Note 1: Erroneous Visit and Delete records should not be taken into account.

Note 2: For LSNIR: New can be found in the form as: New Non-Target, New Target

Note 3: When “Indicate If Lesion Merged or Split” is not present for the trial then the report will not consider the item.

Note 4: For studies without item Study Period report will ignore logic 1.4, 2.4 and logic 3.4

Note 5: For studies only have one treatment phase report will ignore logic 1.4, 2.4 and logic 3.4

Note 6: This report uses master supporting document named LSN_supp_doc.csv; LSN eCRF: TUMOR IDENTIFICATION, STUDY PERIOD, INDICATE IF LESION MERGED OR SPLIT and DATE OF INITIAL IDENTIFICATION should be retrieved from LSN global supp doc column C

Note 7: For multiple treatment phase trials, the report logic should be checked within the same treatment phase. Treatment phase is identified refer to item "Study Period". For the study do not have item "Study Period", use the minimum Lesion Date with LSN eCRF: TUMOR IDENTIFICATION not like 'New%' AND LSN eCRF INDICATE IF LESION MERGED OR SPLIT is null.

Note 8:

For subject that only enter one treatment phase, check the logic directly without separate treatment phase.

Note 9:

Please note that limited by the logic itself, report can only cover below scenarios:

1)	The study has “Study Period”

2)	The study doesn’t have “Study Period”, and subject only entered in 1 treatment phase

3)	The study doesn’t have “Study Period”, and subject entered in more than 1 treatment phase, and record of target/not-target record is correct

For scenario: the study doesn’t have ‘study period’, and subject entered in more than 1 phase, and the yellow marked target/not-target record is incorrect (which should be new), there would be false/missing output.

Note 10:

Requires supporting document to be named ONC_LSN_001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Study Period study treatment for Lesion Evaluation eCRF:

1. Phase Order – Required, the value should match with the required study phase supporting document

2. Lesion Evaluation Form – Required, enter LSNEV, LSNBC, LSRIR, LSNPC, LSNHM, LSNPI, LSNIR, LSNRN, LOEL, LSNA

3. Study Period – Required for multiple treatment phase trials and LSN form with "Study Period" is available, enter the study period according to the options available in the LSN form. For the study do not have item "Study Period" or one treatment phase trials, enter 'NA'.

e.g.

Phase Order 	Lesion Evaluation    		Study Period

             1                          LSNEV                       Initial Treatment phase

             2                          LSNEV                       Second Course Treatment Phase

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

The supporting document is required for all trials if treatment phase is applied to logic, even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required, the order on which phases will appear on protocol

2. Treatment Phase: name of each study phase (Intial Treatment Phase, Neodjuvant Phase, Second Course Phase)

3. First Visitmnemonic of Treatment Phase: required, the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Report Scenarios:
SCENARIO A – No - Lesion is not New and Date of lesion is on or before the Date of Visit of the first visit for the specified Study Period select.

SCENARIO B - Yes - Lesion is not New and Date of lesion is after the Date of Visit of the first visit for the specified Study Period.

SCENARIO C - No - Lesion is New and Date of lesion is after the Date of Visit of the first visit for the specified Study Period.

SCENARIO D - Yes - Lesion is New and Date of lesion is on or before the Date of Visit of the first visit for the specified Study Period.

SCENARIO E – No - Lesion is not New and Lesion is Merged or Split  and Date of lesion is after the Date of Visit of the first visit for the specified Study Period.

SCENARIO F – Yes - Lesion is New and Lesion is Merged or Split  and Date of lesion is after the Date of Visit of the first visit for the specified Study Period.

Sorting:
(Defaulted to Country, Site Number and Subject Number if not specified): Country, Site Number, Subject number, List of Subjects, Visit Mnemonic of first dose

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Supporting Doc Page (N/Y, Default as N), Study Phase Page (N/Y, Default as N), Randomized Only (Y/N set default to N)
