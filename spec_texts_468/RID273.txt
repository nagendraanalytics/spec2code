Report ID: RID273

Report Title:
Dates inconsistencies in GEFCF for Tumor Tissue and/or Biomarker vendor information

Description:
This report will output inconsistencies present within dates reported in GEFCF for Tumor Tissue and/or Biomarker information.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. Visit Name

6. GEFCF Seq

7. GEFCF Specimen ID

8. GEFCF Category

9. GEFCF Subcategory

10. GEFCF Test

11. GEFCF Test Date

12. GEFCF Method of  test or Examination

13. SUPQUAL

14. SUPQUAL - B

Logic:
Logic 1: For each subject number and each GEFCF Visit Name check for each unique specimen ID (if present) the following logic; if any of this logic is not met, then output:

Logic 1.1. Date/Time of Measurement <= Result or Finding in Original Units for GEFCF Test 1

AND

Logic 1.2. Result or Finding in Original Units for GEFCF Test 1 <= Result or Finding in Original Units for GEFCF Test 2

AND

Logic 1.3. Result or Finding in Original Units for GEFCF Test 2 <= Result or Finding in Original Units for GEFCF Test 3

AND

Logic 1.4. Result or Finding in Original Units for GEFCF Test 3 <= Result or Finding in Original Units for GEFCF Test 4

AND

Logic 1.5. Result or Finding in Original Units for GEFCF Test 4 <= Result or Finding in Original Units for GEFCF Test 5

Note 1: By default, GEFCF Test 1 = ‘Date/Time Specimen Placed In Formalin’ OR ‘Date/Time Specimen Placed in Fixative’ unless other specified in supporting doc

Note 2: By default, GEFCF Test 2= ‘Date/Time Tissue Removed From Formalin’ OR ‘Date/Time Specimen Removed From Formalin’ unless other specified in supporting doc

Note 3: By default, GEFCF Test 3 = ‘Slide Cut Date’ unless other specified in supporting doc

Note 4: By default, GEFCF Test 4 = ‘Slide Stain Date’ unless other specified in supporting doc

Note 5: By default, GEFCF Test 5 = ‘Date of test’ unless other specified in supporting doc

Note 6: For some specimen ID when one or more tests are not present then the report must skip that test and continue checking the following test to ensure all tests provided for that specimen ID were done in the correct chronological order.

Example 1: For the specimen ID A123456 only GEFCF Test 5 is present; then check:

Date/Time of Measurement <= Result or Finding in Original Units for GEFCF Test 5

Example 2: For the specimen ID B123456 only GEFCF Test 2 and GEFCF Test 4 are present; then check:

Date/Time of Measurement <= Result or Finding in Original Units for GEFCF Test 2

AND

Result or Finding in Original Units for GEFCF Test 2 <= Result or Finding in Original Units for GEFCF Test 4

Example 3: For the specimen ID C123456 only GEFCF Test 1 and GEFCF Test 5 are present; then check:

Date/Time of Measurement <= Result or Finding in Original Units for GEFCF Test 1

AND

Result or Finding in Original Units for GEFCF Test 1 <= Result or Finding in Original Units for GEFCF Test 5

Note 7: When a discrepancy is found then output all tests for that specific specimen ID and not only those which are incorrect.

Example 4:

Date/Time of Measurement = 01-Jan-2020

Result or Finding in Original Units for GEFCF Test 1 = 02-Jan-2020

Result or Finding in Original Units for GEFCF Test 2 = 03-Jan-2020

Result or Finding in Original Units for GEFCF Test 3 = 04-Jan-2020

Result or Finding in Original Units for GEFCF Test 4 = 05-Jan-2020

Result or Finding in Original Units for GEFCF Test 5 = 04-Jan-2020 - This test looks like it was done before GEFCF Test 4 which is not correct therefore output Date/Time of Measurement, GEFCF Test 1, GEFCF Test 2, GEFCF Test 3, GEFCF Test 4, GEFCF Test 5.

Note 8: If Specimen ID is not present, then the report should check consistency across all test for each unique GEFCF visit name.

Note 9 : Remove the GEFCF seq for Date/Time of Measurement but keep the GEFCF seq for the other tests.

Note 10: Change the date format, make the date format uniform for all tests.

Note 11: For Date/Time of Measurement SUPQUAL and SUPQUAL – B should not be displayed.

Requires optional supporting document to be named ONC_EVD_010_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each GEFCF Test done in chronological order, if for your study there are only 4 GEFCF Test then there is no need to create empty rows to match with this example.

GEFCF Test Number GEFCF Test                                      SUPQUAL                             SUPQUALB

GEFCF Test 1  Date/Time Specimen Placed In Formalin	SUPQUAL3		SUPQUAL4

GEFCF Test 2  Date/Time Tissue Removed From Formalin	SUPQUAL3		SUPQUAL4

GEFCF Test 3  Slide Cut Date			SUPQUAL3		SUPQUAL4

GEFCF Test 4  Slide Stain Date			SUPQUAL5		SUPQUAL6

GEFCF Test 5  Date of test				NA			NA

Note 12: SUPQUAL and SUPQUALB are optional values, please enter ‘NA’ when the items are not needed. If LCDM does not provide supp document, then report should be run with values by default from Note 1 – 5 and Columns 9 and 10 should be blank

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
Scenario 1 Output = No

For each subject number on each unique GEFCF Visit Name and each unique Specimen ID the Result or Finding in Original Units for the tests present in supporting document are entered as per defined order

Scenario 2 Output = Yes

A-	For each subject number on each unique GEFCF Visit Name and each unique Specimen ID the Result or Finding in Original Units for the GEFCF Test present in supporting document are not entered as per defined order

B-	For each subject number on each unique GEFCF Visit Name and each unique Specimen ID the Result or Finding in Original Units for at least one GEFCF Test present in supporting document is not entered as per defined order

Sorting:
Country, Site Number, Subject Number, Visit Name, Specimen ID, GEFCF Test Name (Always display Date/Time of Measurement at the top and thereafter sort data using the same order used in GEFCF Test Number from supporting document)

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only, Include GEFCF Seq (N/Y, Default as Y ), Vendor (free textbox, case insensitive), Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
1. GEFCF. Site Country

2. GEFCF. Site Mnemonic

3. SA. Screening Number

4. GEFCF. Subject Number

5. GEFCF. Visit Name

6. GEFCF. GEFCF Seq

7. GEFCF. Specimen ID (If present, otherwise blank)

8. GEFCF. Category

9. GEFCF. Subcategory

10. GEFCF. Date/Time of Measurement or GEFCF Test according to the supporting document

11. GEFCF. Result or Finding in Original Units for GEFCF Test in format "dd-mmm-yyyy hh:mm" (if time is not present show only the date)

12. GEFCF. Method of  test or Examination

13. SUPQUAL. Display the value for the SUPQUAL provided in supporting doc if present. Example: SUPQUAL = SUPQUAL1; and SUPQUAL1 in GEFCF = RETEST then display ‘RETEST’

14. SUPQUALB. Display the value for the SUPQUAL provided in supporting doc if present. Example: SUPQUALB = SUPQUAL2; and SUPQUAL2 in GEFCF = ACCEPTABLE then display ‘ACCEPTABLE’
