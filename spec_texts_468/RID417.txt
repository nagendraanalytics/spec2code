Report ID: RID417

Report Title:
New Lesion Reconciliation Between Response and Evaluation Forms

Description:
This report will list subjects who have inconsistencies reported between New Lesions in Lesion Evaluation form and New Lesions item in Oncologic Response form.

Column Heading:
1.Country

2.Site

3.Subject Number

4.Response form

5.Sequence

6.Date Response Determined

7.Lesion Evaluation form

8.Seq#

9.Lesion Evaluation Date of assessment

10. Scenario

Logic:
(Scenario 1:

Logic 1.1: RSP eCRF.”NEW LESIONS SINCE LAST EVALUATION” is “Yes” OR RSP eCRF.”NEW SOFT TISSUE LESIONS SINCE LAST EVALUATION” is “Yes” OR RSP eCRF.”NEW IRRECIST LESIONS SINCE LAST EVALUATION” is “Yes”

AND

(Logic 1.2: There is NO (Lesion Evaluation Form with LSN eCRF.”DATE OF INITIAL IDENTIFICATION” equal to RSP eCRF.”DATE RESPONSE DETERMINED” of Response Form of logic 1.1 AND with LSN eCRF.”TUMOR IDENTIFICATION” completed as NEW)

AND

Logic 1.3: There is NO (LSNEV with LSN eCRF.”DATE OF LESION EVALUATION” equal to RSP eCRF.”DATE RESPONSE DETERMINED” of Response Form of logic 1.1 AND with LSN eCRF.”IS THE LESION FDG-AVID ON THE PET SCAN” completed as “Yes” for the first time in all the entries of the same lesion ) ) )

(Scenario 2:

Logic 2.1: LSN eCRF.”TUMOR IDENTIFICATION” contains NEW

AND

Logic 2.2: There is NO (Response Form with (RSP eCRF.”NEW LESIONS SINCE LAST EVALUATION” as “Yes” OR RSP eCRF.”NEW SOFT TISSUE LESIONS SINCE LAST EVALUATION” as “Yes” OR RSP eCRF.”NEW IRRECIST LESIONS SINCE LAST EVALUATION” as “Yes”) AND with RSP eCRF.”DATE RESPONSE DETERMINED” equal to LSN eCRF.”DATE OF INITIAL IDENTIFICATION” of Lesion Evaluation Form of logic 2.1) )

Notes:

1.	RSP eCRF.”NEW SOFT TISSUE LESIONS SINCE LAST EVALUATION”, RSP eCRF.”NEW IRRECIST LESIONS SINCE LAST EVALUATION” or RSP eCRF.“ NEW LESIONS SINCE LAST EVALUATION” are not present in all forms, each form may have different items.

2.	For logics 1.2 and 2.1 NEW includes any option in LSN eCRF.”TUMOR IDENTIFICATION” where the word new is present such as for example: “New Target Extra Nodal”.

3.	 Please obtain the items below from the supporting document:

o	Response Form.

o	Lesion Evaluation Form.

4.	 Requires supporting document to be named ONC_RSP_007_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

Please complete 1 row for each pair of response and lesion evaluations forms to be compared.

1.	Response Form

2.	Lesion Evaluation Form

For example:

Response Form, Lesion Evaluation Form

ORIR, LSNIR

ORIR, LSNEV

ORPC, LSNPC

The report should check both scenarios between each pair of forms present in the supporting document.

5.	 For Scenario 1 display columns 7, 8, 9 in blank. For scenario 2 display columns 4, 5, 6 in blank

6.	 There should be an output when the form is not initialized or deleted

7.	 If supporting document for a study is not present in the database, then display message "ONC_RSP_007_JR_STD Supporting Document Not Present for This Trial".

8.	 RSP eCRF.”NEW SOFT TISSUE LESIONS SINCE LAST EVALUATION”, RSP eCRF.”NEW IRRECIST LESIONS SINCE LAST EVALUATION”, RSP eCRF.”NEW LESIONS SINCE LAST EVALUATION”, RSP eCRF.”DATE RESPONSE DETERMINED” are going to be retrieved from the ‘RSP_supp_doc’ global supporting document column C.

9.	 LSN eCRF.”TUMOR IDENTIFICATION”, LSN eCRF.”DATE OF LESION EVALUATION”,  LSN eCRF. “IS THE LESION FDG-AVID ON THE PET SCAN” and LSN eCRF.”DATE OF INITIAL IDENTIFICATION” are going to be retrieved from the ‘LSN_supp_doc’ global supporting document column C.

10.	The logic 1.3 only applies for LSNEV form that has LSN eCRF.”IS THE LESION FDG-AVID ON THE PET SCAN” item, if not or if the Lesion Evaluation Form is different the report will simply ignore logic 1.3

Report Scenarios:
Scenario 1: Output YES: The new lesion item is “Yes” on the response form and there is not a new lesion record in the lesion evaluation form for the same date or there is not the first FDG-avid lesion in LSNEV for the same date.

Scenario 2: Output YES: There is a new lesion on lesion evaluation form and response form on the same date does not have new lesion item as “Yes”.

Scenario 3: Output NO: New lesion item is “Yes” in the response form but there is at least one lesion record on the same date for a new lesion or there is the first FDG-avid lesion in LSNEV for the same date.

Scenario 4: Output NO: There is a new lesion on lesion evaluation form and response form on the same date has new lesion item as “Yes”.

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N) Supporting Doc Page (N/Y, Default as N)

8. Lesion Evaluation Form. Sponsor ID Number

9. Lesion Evaluation Form.LSN eCRF.”DATE OF INITIAL IDENTIFICATION”

10.Display Scenario 1 or Scenario 2 depending on which scenario is met
