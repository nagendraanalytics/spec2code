Report ID: RID023

Report Title:
AE Action taken with SM reconciliation to SM Start Date

Description:
Action taken with Study Medication was indicated however, AE Onset Date is prior to minimum Study Medication Start Date

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Term

6. Study Medication

7. AE Action

8. AE Onset Date

9. SM(A) Visit

10. Min Start Date

11. Issue

Logic:
This report is to check,

Scenario 1- Discontinued due to AE prior to SM Start Date

AE onset date < Study Medication [X] minimum start date AND AE action taken for Study Medication [X]=Discontinued.

Scenario 2- Interruption due to AE  prior to SM start date

AE onset date < Study Medication [X] minimum start date AND AE action taken for Study Medication [X]=Interrupted.

Scenario 3- Reduced due to AE  prior to SM start date

AE onset date < Study Medication [X] minimum start date AND AE action taken for Study Medication [X]= Reduced.

Scenario 4- Increased due to AE  prior to SM start date

AE onset date < Study Medication [X] minimum start date AND AE action taken for Study Medication [X]= Increased.

User can select the scenarios that apply to their study, and remove any scenarios that do not apply.

* Compare both Date and Time in AE and SM(A) form.

* SMA form (SMAU, SMAB), 'Study medication' should be derived from SMPU/SMPB form by using 'Dose Number+ Visit Number' between SMAU/SMAB and SMPU/SMPB. It will not use 'Study Medication' item from SMA directly.

* SM form, use Study Medication item from SMA directly.

*When AE onset date=SM minimum start date, if time portion for only AE Onset or SM start date  is UNK, then output. If both time portion are UNK, then don't display in output.

* Please don't include deleted and erroneous data into programming.

Report Scenarios:
Report Scenarios: A-Yes

AE onset date < Study Medication [X] minimum start date AND AE action taken for Study Medication [X]=Discontinued/Interrupted/Reduced/Increased

B-No

AE onset date < Study Medication [X] minimum start date AND AE action taken for Study Medication [X]<>Discontinued/Interrupted/Reduced/Increased

C-No

AE onset date >=Study Medication [X] minimum start date AND AE action taken for Study Medication [X]=Discontinued/Interrupted/Reduced/Increased
