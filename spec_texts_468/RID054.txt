Report ID: RID054

Report Title:
Erroneous Visit Checked But Deletable Data Exists

Description:
This report displays subjects who have Erroneous Visit box checked with deletable data present within the visit.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. DOV

6. Form/Itemset

7. Seq #

Logic:
This report that shows when Erroneous visit box is checked but deletable data is present within the visit.

Deleted records are not shown.

The hole SMPB form is shown if not deleted.

Report Scenarios:
Scenario1-N: Erroneous Visit=No, and there is deletable data within visit;

Scenario2-Y: Erroneous Visit=Yes, and there is deletable data within visit;

Scenario3-N: Erroneous Visit=Yes, and there is deletable data in Common Form;

Scenario4-N: Erroneous Visit=Yes, and there is NO deletable data within visit;

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, Site, Subject Number, List of Subjects

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Visits.Visit Mnemonic

5. Visits.DOV

6. Forms.Form Mnemonic or Forms.Form Mnemonic/"Itemset"

7. Forms.Formidx or Forms.Formidx (Forms.Itemsetidx)
