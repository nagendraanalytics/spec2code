Logic:
Scenario 1: Run Control with Category CONTROL CELL LINE and Run Control with Category CONTROL TISSUE SLIDES inconsistency

Logic 1:

(GEFCF.TEST = ‘PDL1 Outcome’ AND GEFCF.ORRES <> null)

AND

(At least one GEFCF.TEST = ‘Run Control’ AND GEFCF.CATEGORY =’ CONTROL CELL LINE’ AND GEFCF.ORRES = ‘FAIL’

OR

At least one GEFCF.TEST = ‘Run Control’ AND GEFCF.CATEGORY =’ CONTROL TISSUE SLIDES’ AND GEFCF.ORRES = ‘FAIL’ )

Error Message:if meet logic 1 then display as "Scenario 1"

Scenario 2: Estimated Number of Tumor Cells inconsistency

Logic 2:

(GEFCF.TEST = ‘PDL1 Outcome’ AND GEFCF.ORRES <>  null)

AND

(At least one GEFCF.TEST = ‘Estimated Number of Tumor Cells’ AND GEFCF.ORRES = ‘<100’ )

Error Message:if meet logic 2 then display as "Scenario 2"

Scenario 3:  (NCR) Assessment

Logic 3:

(GEFCF.TEST = ‘PDL1 Outcome’ AND GEFCF.ORRES <>  null)

AND

(At least one GEFCF.TEST = ‘Is the NCR Control Acceptable’ AND GEFCF.ORRES = ‘N’ )

Error Message:if meet logic 3 then display as "Scenario 3"

Scenario  4: Background inconsistency

Logic 4:

(GEFCF.TEST = ‘PDL1 Outcome’ AND GEFCF.ORRES <>  null)

AND

(At least one GEFCF.TEST = ‘Background’ AND GEFCF. ORRES = ‘NOT ACCEPTABLE’ )

Error Message:if meet logic 4 then display as "Scenario 4"

Scenario  5: PD-L1 result missing

Logic 5:

(GEFCF.TEST = ‘PDL1 Outcome’ AND GEFCF.ORRES = null)

AND (

(ALL GEFCF.TEST = ‘Run Control’ AND GEFCF.CATEGORY =’ CONTROL CELL LINE’ AND GEFCF.ORRES = ‘PASS’ )

AND

(ALL GEFCF.TEST = ‘Run Control’ AND GEFCF.CATEGORY =’ CONTROL TISSUE SLIDES’ AND GEFCF.ORRES = ‘PASS’ )

AND

(ALL GEFCF.TEST = ‘Estimated Number of Tumor Cells’ AND GEFCF.ORRES = ‘>=100’)

AND

(ALL GEFCF.TEST = ‘Is the NCR Control Acceptable’ AND GEFCF.ORRES = ‘Y’)

AND

(ALL GEFCF.TEST = ‘Background’ AND GEFCF.ORRES = ‘ACCEPTABLE’))

Error Message:if meet logic 5 then display as "Scenario 5"

Scenario 6: Duplicate PD-L1

Logic 6:

There are more than one record with GEFCF.TEST = ‘PDL1 Outcome’ AND same SUPQUALA

Error Message:if meet logic 6 then display as "Scenario 6"

Scenario 7: Combined Positive Score (raw CPS) inconsistency

Logic 7:

(GEFCF.TEST = ‘Combined Positive Score’ with an integer GEFCF.ORRES < 0 or GEFCF.ORRES >100)

OR

(GEFCF.TEST = ‘Combined Positive Score’ with a decimal GEFCF.ORRES < 0 or GEFCF.ORRES >1)

Error Message:if meet logic 7 then display as "Scenario 7"

Scenario 8: PD-L1 Expression Level VS CPS inconsistency

Logic 8:

(GEFCF.TEST = ‘Combined Positive Score’/ ‘Tumor Proportion Score’  and there is GEFCF.ORRES = Value in supp doc)

AND

(GEFCF.TEST = ‘PDL1 Outcome’ and there is no GEFCF.ORRES = supp. PD-L1 Expression Level)

Error Message: If Logic 8 is filled and "Is the cancer NSCLC?" parameter is selected as No, then display " Scenario 8:PD-L1 Expression Level mismatch with CPS value" if parameter is Yes display "Scenario 8:PD-L1 Expression Level mismatch with TPS value".

Requires supporting document to be named ONC_EVD_016_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Test - Enter ' Tumor Proportion Score' for only Trial NSCLC  and ‘Combined positive Score' for all other Trials

2. Symbol1 - (=, <, >, <=, >=, <>)

3. Value1

4. Connector - AND/OR, or leave blank if not needed

5. Symbol2 - (=, <, >, <=, >=, <>), or leave blank if Connector is blank

6. Value2 - leave blank if Connector is blank

7. PD-L1 Expression Level

e.g.

Test,Symbol1,Value1,Connector,Symbol2,Value2,PD-L1 Expression Level

Combined Positive Score,<,1,,,,CPS <1

Combined Positive Score,>=,1,AND,<=,9,CPS >=1 to <=9

Combined Positive Score,>=,10,,,,CPS >=10

Tumor Proportion Score,<,1,,,,TPS <1%

Tumor Proportion Score,>=,1,,,,TPS >=1%

Note:

1. Report should not consider deleted records.

2.For Scenarios 7 and 8: If ORRES is empty and completion status is NOT DONE, report should not display any output.

3. If Blinding flag='B' for test, then the following fields should display 'xxxx': Result or Findings in Original Units (ORRES),Original Units,,Standard Units

4.Common classification of CPS value ranges associated with specific tumors:

CPS (All Solid Tumors, TNBC, Bladder, Head and Neck, Esophageal, Gastric, Breast, Ovarian, Cervical, and Endometrial)

<1 vs ≥ 1

<10 vs ≥ 10

<1,   ≥ 1 to ≤ 9,  ≥ 10

<50 vs ≥ 50 (only used in the Head and Neck indication)

< 20 vs ≥ 20 (only used in the Head and Neck indication)

All other exploratory solid tumors will only collect the raw score, no cut off, and should not be more than 100

5.Common classification of TPS value ranges:

TPS (specific for NSCLC)

<1%

≥ 1% to ≤ 49%

≥ 50%

<1% vs ≥ 1%

<50% vs ≥ 50%

6: For Logic 8, if Protocol Number is ‘NSCLC’ then GEFCF.TEST = ‘Tumor Proportion Score’ ;

If Protocol Number is all other Protocol Number, then GEFCF.TEST = ‘Combined Positive Score’

7.Mutiple CPS/TPS value ranges can be provied to the supporting document

8. SUPQUALA and SUPQUALB are parameters completed by user as numbers, if SUPQUALA/SUPQUALB is completed as 'X' it would refer to column GEFCFSUPPQUALXIT / SupqualX / SuppqualX.

Report Scenarios:
Scenario 1: Run Control with Category Control Cell line and Run Control with Category Control Tissue inconsistency

This report will output when there is a "Fail" response for Run Control with Category Control Cell line Or Run Control with Category Control Tissue and there is a PD-L1 result available.

Scenario 2:  Estimated Number of Tumor Cells inconsistency

This report will output when the Estimated Number of Tumor Cells is <100 and there is a PD-L1 result available.

Scenario 3: (NCR) Assessment

This report will output when Is the NCR Control Acceptable is N and there is a PD-L1 result available.

Scenario 4: Background assessment inconsistency

This report will output when Background assessment is NOT ACCEPTABLE and there is a PD-L1 result available.

Scenario 5: PD-L1 result missing

This report will output when  all Run Control with Category Control Cell line and Run Control with Category Control Tissue have "pass" responses and Estimated Number of Tumor Cells is >=100 and Is the NCR Control Acceptable is Y and Background assesment is ACCEPTABLE but there is no PD-L1 result.

Scenario 6: Duplicate PD-L1

This report will output when there are duplicate PD-L1 test result for the same read category (Initial/Repeat).

Scenario 7: Combined Positive Score (raw CPS) inconsistency

Output is produced if Combined Positive Score is NOT a integer between 0-100 or not a decimal between 0-1

Scenario 8: PD-L1 Expression Level  VS CPS inconsistency /TPS inconsistency（NSCLC specific)

This report will output when there is a discrepancy  when the value in Combined positive Score (CPS)/Tumor Proportion Score (TPS) does not match PD-L1 expression Level.
