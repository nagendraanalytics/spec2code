Description:
This report displays subjects who have matching CM Standardized Medication Name and overlapping Start and Stop dates for all medications taken within 14 days of an SAE/ECI Onset Date. CM Term could be either Standardized Medication Name, Encoded Drug Name or Medication Class as selected from the Parameter Selection screen. The report checks for overlaps in a list of medications selected from the Parameter Selection screen.

Column Heading:
1. Country
2. Site
3. Subject Number
4. Standardized Medication Name or Encoded Drug Name or Medication Class
5. CM 1 Seq
6. CM 1 TDD
7. CM 1 Start Date
8. CM 1 Stop Date
9. CM 1 Freq
10. CM 1 Dose Form
11. CM 1 Route
12. CM 1 Reason for Therapy
13. CM 2 Seq
14. CM 2 TDD
15. CM 2 Start Date
16. CM 2 Stop Date
17. CM 2 Freq
18. CM 2 Dose Form
19. CM 2 Route
20. CM 2 Reason for Therapy
21. SAE/ECI Seq
22. SAE/ECI Onset Date

Logic:
1. The report should display subjects with identical CM Terms having overlapping start and stop dates. Each pair of overlapping CM record should be on one line.

CM Term should be a radio button parameter with the following values: Standardized Medication Name, Encoded Drug Name and Medication Class. If Standardized Medication Name is selected, the report will display subjects with identical Standardized Medication Name and overlapping start and stop dates.

Lists of Standardized Medication Name, Encoded Drug Name and Medication Class from the study's database should be available as parameter selections.

An "Include/Exclude" radio button parameter should be available to allow the selected medication names to be Included or Excluded from the above check.

2. The report should display subjects with identical CM terms having overlapping start and stop dates for all medications taken within +/- 14 days of an SAE Onset Date. Each pair of overlapping CM records should be on one line. A parameter selection checkbox named "CM taken within +/- 14 days of SAE/ECI" should be available for user to select this check. Only if selected, these two columns are to be shown: SAE/ECI Seq and SAE/ECI Onset Date.

The report should specifically check if:

• CM start date is within +/- 14 days of SAE/ECI onset date

• CM start date is more than 14 days prior to SAE/ECI onset date and

CM stop date is selected as Continuing or CM stop date is > -14 days of SAE/ECI onset date.

An AE record is considered an SAE if any of the 8 serious AE criteria is marked Yes or ECI is marked Y.

3. The following Optional Conditions should be available to restrict the output as needed.

- Frequency - PRN: the overlapping pair has frequencies equal to or different from PRN

- Dose Form: equal or different within the overlapping pair

- Route of Administration: equal or different within the overlapping pair

- Reason for Therapy: include the exact Reason for Therapy for the overlapping pair.

Report should not display deleted records. If "Randomized only" parameter selection checkbox is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
Refer to logic

Sorting:
Country,Site,Subject Number,Sorting Variable (Standardized Medication Name or Encoded Drug Name or Medication Class),CM 1 Seq,CM 2 Seq

2. LOGIC UNDERSTANDING
======================================================================
This report identifies pairs of CM records per subject that share the same value of a user-selected CM Term (Standardized Medication Name, Encoded Drug Name, or Medication Class) and have overlapping Start/Stop date ranges, displaying each qualifying pair as one row. An Include/Exclude medication-list parameter, an optional +/-14-day SAE/ECI onset-date window check (with its own start/stop date sub-logic and SAE/ECI definition based on 8 seriousness criteria or ECI=Y), and optional filters (PRN frequency, Dose Form, Route, Reason for Therapy) further refine which pairs are shown. Deleted records are always excluded, an optional 'Randomized only' filter can restrict to randomized subjects, and results are sorted by Country, Site, Subject, the CM Term sorting variable, and CM 1/CM 2 Seq.

1. Identify pairs of CM records within the same subject that have an identical CM Term value, where CM Term is whichever field the user selected via the radio button parameter: Standardized Medication Name, Encoded Drug Name, or Medication Class.
2. For each pair of records with identical CM Term, check whether their Start Date and Stop Date ranges overlap in time. Only pairs with overlapping date ranges are candidates for display.
3. Each qualifying overlapping pair of CM records is displayed as one line/row in the report, with columns for 'CM 1' fields (Seq, TDD, Start Date, Stop Date, Freq, Dose Form, Route, Reason for Therapy) and 'CM 2' fields for the same attributes, representing the two records in the pair.
4. The lists of Standardized Medication Name, Encoded Drug Name, and Medication Class values available for parameter selection are populated dynamically from the study's database (not hardcoded).
5. An Include/Exclude radio button parameter modifies step 1: if 'Include' is selected, only CM records matching the medication names chosen in the parameter selection are considered for the overlap check; if 'Exclude' is selected, those selected medication names are omitted from consideration and the remaining records are checked.
6. Separately/additionally, when the 'CM taken within +/- 14 days of SAE/ECI' checkbox parameter is selected, the report restricts the overlap check (identical CM Term + overlapping dates) to medications taken within 14 days of an SAE/ECI Onset Date.
7. The +/-14 day window check has two sub-conditions for a CM record to qualify: (a) the CM start date falls within +/- 14 days of the SAE/ECI onset date, OR (b) the CM start date is more than 14 days prior to the onset date AND the CM stop date is marked 'Continuing' or the CM stop date is greater than -14 days relative to the onset date (i.e., the medication is still ongoing into or past the -14 day boundary).
8. When this SAE/ECI-window checkbox is selected, the report additionally displays the SAE/ECI Seq and SAE/ECI Onset Date columns; these columns are hidden/omitted when the checkbox is not selected.
9. An AE record qualifies as an 'SAE' for purposes of this onset-date check if any of the 8 serious AE criteria fields is marked 'Yes', OR if the ECI field is marked 'Y' - either condition is sufficient to treat the AE's onset date as an SAE/ECI Onset Date for the window comparison.
10. Three Optional Condition filters can further restrict which overlapping pairs are displayed: Frequency-PRN (filter pairs where frequencies are equal to or different from PRN), Dose Form (filter pairs where dose form is equal or different between the two records), and Route of Administration (filter pairs where route is equal or different between the two records).
11. An additional Optional Condition, Reason for Therapy, restricts output to only those overlapping pairs where Reason for Therapy matches an exact value selected by the user (not merely equal/different between the pair, but matching a specific selected value). (inferred)
12. Regardless of other filters, deleted CM records are always excluded from consideration before any matching/overlap logic is applied.
13. If the 'Randomized only' parameter checkbox is checked, the report further restricts output to only subjects whose Randomization Number is not null; if unchecked, all subjects (randomized or not) are eligible.
14. The final output is sorted by Country, Site, Subject Number, then by the Sorting Variable (whichever CM Term field was selected), then by CM 1 Seq and CM 2 Seq to order the pairs consistently within a subject.

SELECT
  c1.Country AS `Country`,
  c1.Site AS `Site`,
  c1.SubjectNumber AS `Subject Number`,
  c1.CMTermValue AS `Standardized Medication Name or Encoded Drug Name or Medication Class`,
  c1.CMSeq AS `CM 1 Seq`,
  c1.CMTDD AS `CM 1 TDD`,
  c1.CMStartDate AS `CM 1 Start Date`,
  c1.CMStopDate AS `CM 1 Stop Date`,
  c1.CMFreq AS `CM 1 Freq`,
  c1.CMDoseForm AS `CM 1 Dose Form`,
  c1.CMRoute AS `CM 1 Route`,
  c1.CMReason AS `CM 1 Reason for Therapy`,
  c2.CMSeq AS `CM 2 Seq`,
  c2.CMTDD AS `CM 2 TDD`,
  c2.CMStartDate AS `CM 2 Start Date`,
  c2.CMStopDate AS `CM 2 Stop Date`,
  c2.CMFreq AS `CM 2 Freq`,
  c2.CMDoseForm AS `CM 2 Dose Form`,
  c2.CMRoute AS `CM 2 Route`,
  c2.CMReason AS `CM 2 Reason for Therapy`,
  sae.SAESeq AS `SAE/ECI Seq`,
  sae.SAEOnsetDate AS `SAE/ECI Onset Date`
FROM
  (
    SELECT
      `@HDR`.`Subject`.`ID` AS SubjID,
      `@HDR`.`Site`.`Country` AS Country,
      `@HDR`.`Site`.`Number` AS Site,
      `@HDR`.`Subject`.`Name` AS SubjectNumber,
      (CASE
         WHEN @CMTermParam = 'Encoded Drug Name' THEN CODEDTERM(CMTRTIT, 'PT')
         WHEN @CMTermParam = 'Medication Class' THEN CMCATIT
         ELSE CMSCATIT
       END) AS CMTermValue,
      CMSPIDIT AS CMSeq,
      CMDOSTOTTB AS CMTDD,
      RAWDATE(CMSTDTCIT) AS CMStartDate,
      RAWDATE(CMENDTCIT) AS CMStopDate,
      CMDOSFRQADMIT AS CMFreq,
      CMDOSFRMIT AS CMDoseForm,
      CMROUTEIT AS CMRoute,
      CMCMINDIT AS CMReason
    FROM `EDC`.`CMFM`
    WHERE `@Form`.`Status` = 'submitted__v'
      AND (DELETEDFM = 'N' OR DELETEDFM IS NULL)
      AND (
        @IncludeExclude = 'Exclude'
        AND CMSCATIT NOT IN (@SelectedMedList)
        OR
        @IncludeExclude = 'Include'
        AND CMSCATIT IN (@SelectedMedList)
      )
      AND (@RandomizedOnly = 0 OR EXISTS (
            SELECT 1 FROM `EDC`.`RNTFM` r
            WHERE r.`@HDR`.`Subject`.`ID` = `@HDR`.`Subject`.`ID`
              AND r.RNTDMARMNRSIT IS NOT NULL
          ))
      AND (@FreqPRN = 'Any' OR (@FreqPRN = 'Equal' AND CMDOSFRQADMIT = 'PRN') OR (@FreqPRN = 'Different' AND CMDOSFRQADMIT <> 'PRN'))
      AND (@ReasonForTherapy IS NULL OR CMCMINDIT = @ReasonForTherapy)
  ) c1
  JOIN
  (
    SELECT
      `@HDR`.`Subject`.`ID` AS SubjID,
      (CASE
         WHEN @CMTermParam = 'Encoded Drug Name' THEN CODEDTERM(CMTRTIT, 'PT')
         WHEN @CMTermParam = 'Medication Class' THEN CMCATIT
         ELSE CMSCATIT
       END) AS CMTermValue,
      CMSPIDIT AS CMSeq,
      CMDOSTOTTB AS CMTDD,
      RAWDATE(CMSTDTCIT) AS CMStartDate,
      RAWDATE(CMENDTCIT) AS CMStopDate,
      CMDOSFRQADMIT AS CMFreq,
      CMDOSFRMIT AS CMDoseForm,
      CMROUTEIT AS CMRoute,
      CMCMINDIT AS CMReason
    FROM `EDC`.`CMFM`
    WHERE `@Form`.`Status` = 'submitted__v'
      AND (DELETEDFM = 'N' OR DELETEDFM IS NULL)
      AND (
        @IncludeExclude = 'Exclude'
        AND CMSCATIT NOT IN (@SelectedMedList)
        OR
        @IncludeExclude = 'Include'
        AND CMSCATIT IN (@SelectedMedList)
      )
      AND (@FreqPRN = 'Any' OR (@FreqPRN = 'Equal' AND CMDOSFRQADMIT = 'PRN') OR (@FreqPRN = 'Different' AND CMDOSFRQADMIT <> 'PRN'))
      AND (@ReasonForTherapy IS NULL OR CMCMINDIT = @ReasonForTherapy)
  ) c2
  ON c1.SubjID = c2.SubjID
  AND c1.CMSeq < c2.CMSeq
  AND c1.CMTermValue = c2.CMTermValue
  AND c1.CMStartDate <= IFNULL(c2.CMStopDate, c1.CMStartDate)
  AND c2.CMStartDate <= IFNULL(c1.CMStopDate, c2.CMStartDate)
  AND (@DoseFormCheck = 'Any' OR (@DoseFormCheck = 'Equal' AND c1.CMDoseForm = c2.CMDoseForm) OR (@DoseFormCheck = 'Different' AND c1.CMDoseForm <> c2.CMDoseForm))
  AND (@RouteCheck = 'Any' OR (@RouteCheck = 'Equal' AND c1.CMRoute = c2.CMRoute) OR (@RouteCheck = 'Different' AND c1.CMRoute <> c2.CMRoute))
  LEFT JOIN
  (
    SELECT
      `@HDR`.`Subject`.`ID` AS SubjID,
      SAEIFESPIDIT AS SAESeq,
      RAWDATE(SAEIFESTDTCIT) AS SAEOnsetDate
    FROM `EDC`.`SAEIFM`
    WHERE `@Form`.`Status` = 'submitted__v'
      AND (DELETEDFM = 'N' OR DELETEDFM IS NULL)
      AND (
        SAEIFESCANCB = 'Y' OR SAEIFESCONGCB = 'Y' OR SAEIFESDISABCB = 'Y'
        OR SAEIFESDTHCB = 'Y' OR SAEIFESHOSPCB = 'Y' OR SAEIFESLIFECB = 'Y'
        OR SAEIFESMIECB = 'Y' OR SAEIFESODCB = 'Y'
      )
  ) sae
  ON sae.SubjID = c1.SubjID
  AND (
    @WithinSAEWindow = 0
    OR (
      (RAWDATE(c1.CMStartDate) BETWEEN SUBDATE(sae.SAEOnsetDate, INTERVAL 14 DAY) AND DATE_ADD(sae.SAEOnsetDate, INTERVAL 14 DAY))
      OR (
        RAWDATE(c1.CMStartDate) < SUBDATE(sae.SAEOnsetDate, INTERVAL 14 DAY)
        AND (c1.CMStopDate IS NULL OR RAWDATE(c1.CMStopDate) > SUBDATE(sae.SAEOnsetDate, INTERVAL -14 DAY))
      )
    )
  )
WHERE
  (@WithinSAEWindow = 0 OR sae.SubjID IS NOT NULL)
ORDER BY
  c1.Country, c1.Site, c1.SubjectNumber, c1.CMTermValue, c1.CMSeq, c2.CMSeq
