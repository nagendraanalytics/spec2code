Report ID: RID251

Report Title:
Tumor Location entries

Description:
Report output subject with Tumor Location inconsistency in Add entry section per requirements

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Lesion Type

6. Lesion Presence

7. Scenario

Logic:
Scenario 1a: Error Message: Scenario 1a

Output if HDD/CDD eCRFS Primary Lesion Question is Yes and In add entry section there is no entry with Is this a Primary or Metastatic Location? Item as Primary Tumor Location

Scenario 1b: Error Message: Scenario 1b

Output if HDD/CDD eCRFS Primary Lesion Question is No and In add entry section there is entry with Is this a Primary or Metastatic Location? Item as Primary Tumor Location

Scenario 2a: Error Message: Scenario 2a

Output if HDD/CDD eCRFS Any Metastases Lesion Question is Yes and In add entry section there is no entry with Is this a Primary or Metastatic Location? Item as Metastases Location

Scenario 2b: Error Message: Scenario 2b

Output if HDD/CDD eCRFS Any Metastases Lesion Question is No and In add entry section there is entry with Is this a Primary or Metastatic Location? Item as Metastases Location

Scenario 3a: Error Message: Scenario 3a

Output if CDD eCRFS Liver Lesion Question is Yes and In add entry section there is no entry with Is this a Primary or Metastatic Location? = Metastases Location and Tumor Location = Liver

Scenario 3b: Error Message: Scenario 3b

Output if CDD eCRFS Liver Lesion Question is No and In add entry section there is entry with Is this a Primary or Metastatic Location? = Metastases Location and Tumor Location = Liver

Scenario 4: Error Message: Scenario 4

Output if CDD eCRFS Liver Lesion Question is Yes AND  HDD/CDD eCRFS Any Metastases Lesion Question  is No

Scenario 5: Error Message: Scenario 5

Output if Primary Lesion Question  AND Any Metastases Lesion Question is both NO

Note 1: Disregard erroneous visit and deleted rows

Note 2: Lesion Presence/ Form Item: use ‘NA’ if Primary Lesion Question or Any Metastases Lesion Question or Liver Metastases Lesion Question are not present for particular form

Note 3: Report uses Global Supporting Document HDD_Supp_Doc, it contains the SAS names for the items used across reports in the Historic Oncologic Disease Details eCRFs.

Note 4: Report uses Global Supporting Document CDD_Supp_Doc, it contains the SAS names for the items used across reports in the Current Oncologic Disease Details eCRFs.

Note 5: Primary Lesion Question refers to: ‘ARE THERE ANY PRIMARY LESIONS PRESENT’, ‘ARE THERE ANY PRIMARY LESIONS PRESENT?’, ‘IS THE PRIMARY MELANOMA PRESENT?’, ‘IS THE PRIMARY MERKEL CELL CARCINOMA LESION PRESENT?’, ‘WERE THERE ANY PRIMARY LESIONS PRESENT?’ in the ITEMQUESTION column of the HDD_Supp_Doc and CDD_Supp_Doc.

Note 6: Any Metastases Lesion Question refers to: ‘ARE THERE ANY METASTASES PRESENT’, ‘WERE THERE ANY METASTASES PRESENT?’ in the ITEMQUESTION column of the HDD_Supp_Doc and CDD_Supp_Doc

Note 7: Liver Metastases Lesion Question refers to: ARE THERE ANY LIVER METASTASES PRESENT in the ITEMQUESTION column of the CDD_Supp_Doc

Note 8: Tumor Location refers to: TUMOR LOCATION, OTHER TUMOR LOCATION, LOCATION OF METASTASES

Report Scenarios:
Yes: Display output that satisfy the logic

No: Do not display output that do not satisfy the logic

Form.Item Names:
1. HDD/CDD.SITECOUNTRY

2. HDD/CDD.SITEMNEMONIC

3. HDD/CDD.SUBJECTID

4. HDD/CDD.FORMMNEMONIC

5. Hardcoded: Primary/Metastases/Liver

6. Derived Primary Lesion Question OR Any Metastases Lesion Question OR Liver Metastases Lesion Question separated with ‘/’ (e.g. Yes/No/Yes)

7. Error Message
