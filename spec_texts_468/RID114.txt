Report ID: RID114

Report Title:
Duplicate SME Records

Description:
This report lists all subjects with duplicate SME records

Column Heading:
1. Country

2. Site

3. Subject Number

4. Formindex

5. Vendor

6. Label Description

7. Start Date/Time

8. Body site location of administration

Logic:
The report should output SME records where Vendor Name, Label Description, Start Date and Time，Body site location of administration AND All items EXCEPT for the selected items from supporting document " SME items to exclude" are equal.

allows user to select items that can be equal or different within the record and should not be used to consider duplicates

Note 1: Requires supporting document to be named  EVD039_supp_<xxxxxxx>.csv and  will allow user to select items that can be equal or different within the record and should not be used to consider duplicates, this supporting document will contain 1 column with the items the user wants to exclude from the duplicate comparation of records.

Note 2: Report should not display deleted records.

Note 3: If item (Exclude the item selected on parameter) = Null across all compared records, output should be displayed for reference.

Report Scenarios:
: 1) Output=Yes

Subject has duplicate SME records with same Start Date/Time AND Vendor Name AND Label Description AND Body site location of administration AND it is not present in “SME items to exclude “ supporting document.

Output all duplicate records.

2) Output=No

Subject has SME records with any of Start Date/Time OR Vendor Name OR Label Description OR Body site location of administration OR  is present in “SME items to exclude “ supporting document

3) Output=No

Subject has SME records with different Start Date/Time AND Vendor Name AND Label Description AND Body site location of administration AND is present in “SME items to exclude “ supporting document.
