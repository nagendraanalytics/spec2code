Report ID: RID291

Report Title:
AE sequence number reconciliation

Description:
This report ensures that the Associated Sequence number on OAGVH and AOGVH matches.

Column Heading:
1. Country

2. Site

3. Subject Number

4. GVH Form

5. GVH Form seq#

6. GVH Form Date of Assessment

7. Missing AE Seq#

Logic:
LOGIC

Logic 1.1: If OAGVH.OAGVHCFAESEQ1 OR OAGVH.OAGVHCFAESEQ2 has no matching AE seq within the AOGVH Associated AE Sequence Number (From AE Form) item

OR

Logic 1.2: If AOGVH.AOGVHCFAESEQ1 OR AOGVH.AOGVHCFAESEQ2 has no matching AE seq within the OAGVH Associated AE Sequence Number (From AE Form) item

Note:

1. Please do not take into account deleted records

2. Please check this information for all AOGVH/OAGVH entries.

Report Scenarios:

IF AOGVH Associated AE Sequence Number (From AE Form) item=NULL AND OAGVH Associated AE Sequence Number (From AE Form) item=NULL

B- NO

If AOGVH.AOGVHCFAESEQ1=OAGVH.OAGVHCFAESEQ1 AND AOGVH.AOGVHCFAESEQ2= OAGVH.OAGVHCFAESEQ2

C- NO

AOGVH.AOGVHCFAESEQ1=OAGVH.OAGVHCFAESEQ2 AND AOGVH.AOGVHCFAESEQ2= OAGVH.OAGVHCFAESEQ1

D- NO

AOGVH.AOGVHCFAESEQ1=OAGVH.OAGVHCFAESEQ1 AND AOGVH.AOGVHCFAESEQ2=NULL AND OAGVH.OAGVHCFAESEQ=NULL

E- NO

H- YES

IF AOGVH Associated AE Sequence Number (From AE Form) item=NULL AND OAGVH Associated AE Sequence Number (From AE Form) item<>NULL

AOGVH.AOGVHCFAESEQ2=OAGVH.OAGVHCFAESEQ1 AND AOGVH.AOGVHCFAESEQ1<> OAGVH.OAGVHCFAESEQ2

M- YES

AOGVH.AOGVHCFAESEQ2=OAGVH.OAGVHCFAESEQ2 AND AOGVH.AOGVHCFAESEQ1<> OAGVH.OAGVHCFAESEQ1

AOGVH.AOGVHCFAESEQ1=OAGVH.OAGVHCFAESEQ2 AND AOGVH.AOGVHCFAESEQ2<>NULL AND OAGVH.OAGVHCFAESEQ1=NULL

AOGVH.AOGVHCFAESEQ2=OAGVH.OAGVHCFAESEQ1 AND AOGVH.AOGVHCFAESEQ1<>NULL AND OAGVH.OAGVHCFAESEQ2=NULL

Sorting:
Country, Site, Subject Number, GVH Form seq#

Parameter Selection:
Country, Site, Subject Number, List of Subjects

Form.Item Names:
1. SA. Country

2. SA. Site mnemonic

3. Subject Number

4. If logic 1.1 is met display ‘AOGVH’ OR if logic 1.2 is met display ‘OAGVH’

5. If logic 1.1 is met display the AOGVH seq# (AOGVH.AOGVHCFSPID) where AE seq# is present OR if logic 1.2 is met display the OAGVH seq# (OAGVH.OAGVHCFSPID) where AE seq# is present

6. If logic 1.1 is met display the AOGVH Date of Assessment (AOGVH.AOGVHCFDTC) where AE seq# is present OR if logic 1.2 is met display the OAGVH Date of Assessment (OAGVH.OAGVHCFDTC) where AE seq# is present.

7. Display the Missing AE seq# (OAGVH.OAGVHCFAESEQ1 OR OAGVH.OAGVHCFAESEQ2 OR AOGVH.AOGVHCFAESEQ1 OR AOGVH.AOGVHCFAESEQ2). If more than one AE is missing, please separate AE seq# with a comma (,).
