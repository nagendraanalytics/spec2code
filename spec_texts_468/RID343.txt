Report ID: RID343

Report Title:
Study Medication Last Dose Date vs Start Date of Oncologic Regimen

Description:
This report lists subjects who have a Start Date of Regimen that is prior or equal to the Start Date of Last Dose of Study Medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit Mnemonic

5. SM Form

6. SM Seq

7. Last Dose Date

8. New Treatment Seq

9. New Treatment Seq

10. eCRF Name

Logic:
Logic 1: SM/SM04/SMAB/SMAU/STR. Please Indicate if this is the Last Dose for the table is selected.

AND

Logic 2: OSOF/OSOFL/ORAD2/ODBF/ODBCF/ODBHF/ODBNF.Start Date of Regimen OR minimum ODBF/ODBCF/ODBHF/ODBNF.Start Date of Medication <=  STR/SM/SM04/SMAB/SMAU. MAX Start Date/Time of Logic 1

Note 1: Deleted records and erroneous visits should not be taken into account.

Note 2: Report should check minimum OSOF/OSOFL/ORAD2/ODBF/ODBCF/ODBHF/ODBNF.Start Date of Medication within formidx.

Note 3:  For ODBF/ODBCF/ODBHF/ODBNF, if "Start Date of Regimen" exists, then use "Start Date of Regimen"; if not, use "Start Date of Medication". For ORAD2, use Start Date of Medication,". For OSOF/OSOFL, use Date of Assessment /Date Performed/ Date and Time Performed/Date of Surgery  per study design.

Note 4: Please ignore time for logic2, use "Imputed Start Date of Regimen" or "Imputed Start Date of Medication"  for ODBF/ODBCF/ODBHF/ODBNF/ORAD2/OSOF/OSOFL

Note 5: Hardcode ORAD2.Start Date as below: Month UNK: Jan Day UNK: 01

Note 6: Hardcode OSOF.Date and Time Performed  as below: Month UNK: Jan Day UNK: 01

Report Scenarios:
A – Yes

Start Date of Regimen/Start Date/Date and Time Performed/Date of Surgery for any Oncologic treatment is prior or equal to the MAX Start Date of Last Dose of Study Medication.

B – No

Start Date of Regimen/Start Date/Date and Time Performed/Date of Surgery for any Oncologic treatment is greater than the MAX Start Date of Last Dose of Study Medication.

Sorting:
1. Country 2. Site 3. Subject number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, eCRF Name(s)
