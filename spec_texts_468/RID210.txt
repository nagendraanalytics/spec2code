Report ID: RID210

Report Title:
Other Specify Review Listing

Description:
This report outputs other specify content to ensure there is no duplicity in other specify fields as compared to corresponding radio buttons, drop downs, or selection lists.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF

6. Seq

7. Item

8. Other Specify

Logic:
This is a listing of the values entered by the sites in "Other, specify" fields in the forms and items indicated by the requestor.

Data in erroneous visits should not be considered.

Deleted records should not be considered.

Requires supporting document to be named TQ022 _supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Form mnemonic. If a form has two or more  ‘Other fields items’ then each row should contain one ‘Other field item’ along with same Form Mnemonic.

1)Form – Form mnemonic, Not Null

2)Items – Item Question from respective form mnemonic, Not Null

E.g:

Form Items

LECG Scheduled Time

ULAB Normal Range/Indicator

CIM Scheduled Time

PRG02 Type of Delivery/Termination

ODB Frequency of Administration

TSIF Reason Specimen Not Collected and/or Not Sent

TSIF Anatomic Location of Tumor Tissue Collection

TSIF Fixative Type

TSIF Section Thickness (um)

Report Scenarios:
1. Output=YES

Field has the "Other, specifiy" item or similar completed.

Record is not deleted.

Record is not in an erroneous visit.

2. Output=NO

Field does not have the "Other, specifiy" item or similar completed OR

Record is deleted OR

Record is in an erroneous visit OR

Field has not been specified by the requestor.

Sorting:
Country, Site, Subject Number, visitorder, Visit, eCRF, Seq, Item

Parameter Selection:
Country, Site, Subject, Randomized Only, List of Subjects, eCRF

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Visits.Visitmnemonic

5. Forms.Formmnemonic

6. Forms.formidx and (Add-entry.itemsetidx), if applicable

7. Forms.Itemquestion
