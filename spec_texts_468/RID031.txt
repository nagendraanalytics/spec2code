Report ID: RID031

Report Title:
Overlapping APCM Start and Stop Dates

Description:
This report displays subjects who have matching APCM Standardized Medication Name and overlapping Start and Stop dates for all medications taken within 14 days of an SAE/ECI Onset Date.

APCM Term could be either Standardized Medication Name, Encoded Drug Name or Medication Class as selected from the Parameter Selection screen.

The report checks for overlaps in a list of medications selected from the Parameter Selection screen.

Logic:
1. The report should display subjects with identical APCM Terms having overlapping start and stop dates. Each pair of overlapping APCM record should be on one line.

APCM Term should be a radio button parameter with the following values: Standardized Medication Name, Encoded Drug Name and Medication Class. If Standardized Medication Name is selected, the report will display subjects with identical Standardized Medication Name and overlapping start and stop dates.

2. The report should display subjects with identical APCM terms having overlapping start and stop dates for all medications taken within +/- 14 days of an SAE Onset Date. Each pair of overlapping APCM records should be on one line. A parameter selection checkbox named "APCM taken within +/- 14 days of SAE/ECI" should be available for user to select this check. Only if selected, these two columns are to be shown: SAE/ECI Seq and SAE/ECI Onset Date.

The report should specifically check if:

• APCM start date is within +/- 14 days of SAE/ECI onset date

• APCM start date is more than 14 days prior to SAE/ECI onset date and

APCM stop date is selected as Continuing or APCM stop date is > -14 days of SAE/ECI onset date.

An APAE record is considered an SAE if any of the 8 serious AE criteria is marked Yes or ECI is marked Y.

3. The following Optional Conditions should be available to restrict the output as needed.

- Frequency - PRN: the overlapping pair has frequencies equal to or different from PRN

- Dose Form: equal or different within the overlapping pair

- Route of Administration: equal or different within the overlapping pair

- Reason for Therapy: include the exact Reason for Therapy for the overlapping pair.

Report should not display deleted records. If "Randomized only" parameter selection checkbox  is checked, the report should

only output subjects with Randomization number that is not null.
