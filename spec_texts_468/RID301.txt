Report ID: RID301

Report Title:
Duplicate lesions and assessments

Description:
This report will output when the lesion number entered in Indicate if Lesion Merged or Split is duplicated within the same record or when the selected merged or split lesion number is being assessed twice

Column Heading:
1. Country

2. Site Mnemonic

3. Subject Number

4. Lesion evaluation form

5. Seq #

6. Lesion Number

7. Date of Baseline Lesion Evaluation

8. Indicate if Lesion Merged or Split

9. Date of Current Lesion Evaluation

10.  Scenario

Logic:
Logic 1

Logic 1.1 Lesion Number entered in LSN. ‘Indicate if Lesion Merged or Split’ is entered more than once within the same LSN record

Logic 2

Logic 2.1 LSN record 1 ‘Indicate if Lesion Merged or Split’ <> NULL

AND

Logic 2.2 LSN record 1 ‘Indicate if Lesion Merged or Split’ = LSN record 2 ‘Lesion Number’

AND

Logic 2.3 LSN record 1 ‘Date’ = LSN record 2 ‘Date’

Note 1: Deleted record will not be considered in the programming or output.

Note 2: Example of Logic 2. Lesion Number TN1 has the item ‘Indicate if Lesion Merged or Split’ = TN2 AND (TN1. Date of Current Lesion Evaluation (Scan Image Physical Exam) = TN2. Date of Current Lesion Evaluation (Scan Image Physical Exam))

Note 3: Note 2: The report will use master supporting document LSN_supp_doc. These supporting documents should be uploaded only once at TA level per the GDO Oncology TAST authorized members and will be used to facilitate programming of the report. Report builder will use all the columns provided in the excel spreadsheet to create the programming code. LSN refers to the forms included in the LSN_supp_doc.

Note 4: When Logic 1 is satisfied column 9 will be blank

Note 5: When Logic 1 is satisfied column 10 will display ‘Scenario 1’. When Logic 2 is satisfied column 10 will display ‘Scenario 2’

Note 6: Column 7 will display the value of LSN. Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) OR LSN. Date of Assessment in format "DDMMMYYYY

Note 7: When logic 2 is satisfied Column 9 will display the value of LSN. Date of Current Lesion Evaluation (Scan Image Physical Exam) OR LSN. Date of Lesion Evaluation in format "DDMMMYYYY"

Note 8: In the Logic 2.3 ‘Date’ refers to LSN. Date of Current Lesion Evaluation (Scan Image Physical Exam) OR LSN. Date of Lesion Evaluation

Note 9: The report will not be case sensitive. Example: TN1 or tn1 or Tn1 or tN1 should be considered as the same value between the item 'Indicate if Lesion Merged or Split' and 'Lesion Number'.

Report Scenarios:
Scenario 1:

A – Yes: If Lesion number <> null AND Lesion number is the same more than once within the form.

B - No: If Lesion number <> null AND Lesion number is different within the form.

Scenario 2:

C – Yes: Indicate if Lesion Merged or Split <> null AND Date of Current Lesion Evaluation from LSN record 1 is the same as Date of Current Lesion Evaluation from LSN record 2

D – No: Indicate if Lesion Merged or Split <> null AND Date of Current Lesion Evaluation from LSN record 1 is the different as Date of Current Lesion Evaluation from LSN record 2

Sorting:
Country, Site, Subject Number, Lesion evaluation form, Seq #, Scenario

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N, default as N)

Form.Item Names:
1. SA.Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. LSN. Form Mnemonic

5. LSN.formidx

6. LSN.Lesion number

7. As specified by Note 6

8. LSN.Indicate if Lesion Merged or Split (should be blank for original lesion)

9. As specified by Note 4 and by Note 7

10. As specified by Note 5
