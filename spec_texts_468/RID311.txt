Report ID: RID311

Report Title:
Indicate if Lesion was Present at indicated phase reconciliation

Description:
This report will output when the indicate if Lesion was Present at indicated phase per protocol is completed incorrectly.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Lesion form

5. Lesion number

6. Date of lesion

7. Indicate if Lesion was Present at Initial Treatment Phase

8. Study period

Logic:
Please output:

LOGIC 1 When the Lesion form “Indicate if Lesion was Present at initial treatment” <> NULL

AND

LOGIC 2

Logic 2: Lesion form. Date of lesion > 'Last Visit' DOV

OR

LOGIC 3

Lesion form. Date of lesion < 'Window of days' before to 'First Visit' DOV

Note:

1. Deleted records or erroneous visits will be excluded.

2. Lesion evaluation forms = Pulled from Global Supp doc LSN_Supp_Doc depending on the form present in the study and on the selected form within the prompt.

3. For the parameters the First visit DOV and Last visit DOV refer to the first visit and last visit prompts.

4. for the 4th column if more than one lesion evaluation form is present in the protocol please check the logic for all the selected forms within the prompt.

5. Date of lesion refers to:

LSNBC/LSNEC/LSNHM/LSNIR/LSNLG/LSNPC/LSNPI/LSRIR/LOEL/LSNEV/LSNRN: Date of initial Identification pulled from LSN_Supp_Doc

6. For column 7, display YES if item is checked. If not, display NO

7. For column 6, please take into account note 5.

8. If Last Visit checked in the prompt is erroneous, previous non-erroneous visit should be checked for logic.

9. If first visit is checked as erroneous always output if checkbox is selected in lesion form.

Report Scenarios:
A = No

Date of lesion = Null OR Lesion form was deleted

B = No

When the First visit or Last Visit is marked as erroneous

C= No

Date of lesion < Last Visit DOV OR Date of lesion > First Visit DOV

D = No

When the item “Indicate if Lesion was Present at indicated phase reconciliation” for the given Lesion Form = Null

E = Yes

Date of lesion < ‘Window of days’ from First visit DOV AND Date of lesion > Last visit DOV AND  “Indicate if Lesion was Present at indicated phase reconciliation” for the given Lesion Form is <> NULL

Sorting:
Country, Site, Subject Number, Study Period

Parameter Selection:
Country, Site, Subject Number, Window of days (set default as 28), First visit (please list all visits of the protocol, required), Last visit (please list all visits of the protocol, required), Lesion form

Form.Item Names:
1. SA. Country

2. SA. Site Mnemonic

3. SA. Subject Number

4. Lesion evaluation form (Pulled from Global Supp doc LSN_Supp_Doc depending on the form present in the study)

5. Lesion evaluation form. Lesion number or Sponsor ID Number if present (Pulled from Global Supp doc LSN_Supp_Doc depending on the form present in the study)

6. Date of initial Identification pulled from LSN_Supp_Doc

7. Indicate if Lesion was Present at Initial Treatment Phase (Pulled from Global Supp doc LSN_Supp_Doc depending on the form present in the study)

8. Study period (Pulled from Global Supp doc LSN_Supp_Doc depending on the form present in the study)
