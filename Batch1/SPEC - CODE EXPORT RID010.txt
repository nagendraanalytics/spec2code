Description:
This report lists subjects with gaps or overlaps in Toxicity Grade Dates, with AE Onset Date not equal to the earliest Toxicity Grade Onset Date OR with AE End Date that is not equal to the latest Toxicity Grade Stop Date.

Column Heading:
1. Country
2. Site
3. Subject Number
4. AE Seq
5. AE Term
6. AE Onset Date
7. AE End Date
8. Tox Grade Onset Date
9. Tox Grade Stop Date
10. Error Message

Logic:
This report lists subjects with the following conditions:

1) Add entry Toxicity Grade Date overlaps. Output an error message that says "Overlap with Tox Grade Onset dd-mon-yyyy and Tox Stop dd-mon-yyyy"

2) Add entry Toxicity Grade Date gaps. Output an error message that says "Gap with previous Tox Grade Onset dd-mon-yyyy and Tox Stop dd-mon-yyyy"

3) AE Onset Date does not equal the minimum date of Toxicity Grade Onset Date in the add entry section of the same AE. Output an error message that says "AE Onset not earliest Tox Grade Onset"

4a) AE End Date does not equal the maximum date of Toxicity Grade Stop Date in the add entry section of the same AE. Output an error message that says "AE End not latest Tox Grade Stop"

4b) AE End Date is ongoing but there is no blank Toxicity Grade Stop Date in the add entry section of the same AE. Output an error message that says "AE End not latest Tox Grade Stop"

4c) AE End Date has a date but there is a blank Toxicity Grade Stop Date in the add entry section of the same AE. Output an error message that says "AE End not latest Tox Grade Stop"

5) AE Term is completed but Add-entry section is blank, either because it's not initialized or because all the records are completed with UNK/ND/NA. Output an error message that says "Add entry missing"

Report should not display deleted records.

Add-entry records with both dates as UNK/ND/NA are not be considered for scenarios 1 to 4 when there are other records with data entered.

If "Randomized only" parameter selection checkbox is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
Test Case Workbook

Sorting:
Country, Site, Subject, AE Seq

2. LOGIC UNDERSTANDING
======================================================================
This report cross-checks each AE record's Onset/End dates against the date range covered by its nested 'add entry' Toxicity Grade Onset/Stop Date records, flagging gaps, overlaps, mismatched earliest/latest dates, and inconsistent ongoing/blank-stop-date logic, plus flagging AEs entirely missing their add-entry toxicity data. Placeholder UNK/ND/NA-only add-entry records are ignored when real data exists elsewhere, deleted records are excluded, and an optional parameter can restrict output to randomized subjects only. Several nuances -- like how ties in dates are handled or whether 'deleted' applies at add-entry level -- are inferred rather than explicit in the spec.

1. For a given AE record, examine all its 'add entry' Toxicity Grade Onset Date / Toxicity Grade Stop Date pairs and check whether any two add-entry date ranges overlap each other. If so, output the error 'Overlap with Tox Grade Onset dd-mon-yyyy and Tox Stop dd-mon-yyyy' using the specific overlapping dates.
2. Similarly, check whether there is a gap between the Stop Date of one add-entry record and the Onset Date of the next add-entry record (i.e., they are not contiguous) for the same AE. If so, output the error 'Gap with previous Tox Grade Onset dd-mon-yyyy and Tox Stop dd-mon-yyyy' using the specific dates involved.
3. Compare the AE Onset Date to the minimum (earliest) Toxicity Grade Onset Date among all add-entry records for that same AE. If they are not equal, output 'AE Onset not earliest Tox Grade Onset'.
4. Compare the AE End Date to the maximum (latest) Toxicity Grade Stop Date among all add-entry records for that same AE. If they are not equal, output 'AE End not latest Tox Grade Stop' (scenario 4a).
5. As a variant of the AE End check: if AE End Date indicates the AE is ongoing (no end date) but none of the add-entry records for that AE has a blank Toxicity Grade Stop Date, this is inconsistent -- output 'AE End not latest Tox Grade Stop' (scenario 4b).
6. As another variant: if AE End Date has an actual completed date but there exists an add-entry record with a blank Toxicity Grade Stop Date for that same AE, this is inconsistent -- output 'AE End not latest Tox Grade Stop' (scenario 4c).
7. Before applying scenarios 1-4, exclude any add-entry record where BOTH Toxicity Grade Onset Date and Toxicity Grade Stop Date are UNK/ND/NA, but only in cases where other add-entry records for that same AE contain actual entered data -- meaning these placeholder-only records are ignored as noise when real data exists elsewhere.
8. Separately, check whether the AE Term is completed (i.e., the AE record itself is filled in) but the entire add-entry section for that AE is blank -- either because no add-entry records were ever created, or because all existing add-entry records only contain UNK/ND/NA in both date fields. In that case, output 'Add entry missing' (scenario 5) instead of running scenarios 1-4 for that AE.
9. Exclude any deleted records (whether at the AE level or the add-entry level, inferred) from all of the above checks and from the report output entirely. (inferred)
10. If the 'Randomized only' parameter checkbox is selected when running the report, filter the final output to only include subjects whose Randomization Number is not null; otherwise include all subjects regardless of randomization status.
11. Present all resulting error rows sorted by Country, Site, Subject, AE Seq, with each row showing Country, Site, Subject Number, AE Seq, AE Term, AE Onset Date, AE End Date, Tox Grade Onset Date, Tox Grade Stop Date, and the specific Error Message generated from steps 1-8.
