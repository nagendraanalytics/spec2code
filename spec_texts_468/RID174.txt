Report Title:
Study Medication Gaps and Overlaps

Description:
This report lists subjects who have gaps or overlaps in their study medication records

Column Heading:

2. Site

3. Subject Number

4. Previous Visit

5. Previous Form

12. Previous Stop Date/Time

13. Current Visit

14. Current Form

15. Current Seq

16. Current Study Period

17. Current Scheduled Time

18. Current Study Medication

19. Current Label Description/Dose Number

20. Current Start Date/Time

21. Current Stop Date/Time

22. Current Reason for Dose Variation

23. Gap or Overlap

24. Difference in Days/Mins

Logic:
<Criteria Form1>.<Criteria Itemquestion1> = <Criteria Value1>  AND

<Criteria Form2>.<Criteria Itemquestion2> = <Criteria Value2> AND

<Criteria Form3>.<Criteria Itemquestion3> = <Criteria Value3> AND

List subjects who have gaps or overlaps in two consecutive study medication records in SM/SMAU/SMAB forms available in a study.

Logic1: Current Start Date/Time – Previous Stop Date/Time > gap provided in the supporting document

or

Logic2: Current Start Date/Time – Previous Stop Date/Time <= overlap provided in the supporting document

Notes:

Note 1: Please exclude deleted records and erroneous visits from programming.

Note 2: Supporting document is required, if it is not provided, display the message as "SM001_JR_STD Supporting Document Not Present for This Trial".

Note 3: If Criteria(s) are provided as 'NA' in the supporting doc (columns 2-4), check gap or overlap for all subjects.

Note 4: The Gap or Overlap is checked for each group provided by supporting doc, within SM form and/or study medication and/or Label Description and/or Dose Number and/or study period and/or Scheduled time. If 'NA' is provided to variable, it checks gap or overlap for each variable globally, and ignore this variable. If 'ALL' is provided to variable, it checks gap or overlap for each variable individually, and group by this variable.

Note 5: The Gap or Overlap is calculated based on date only or date and time, and display output per nbr and unit of gap or overlap provided by supporting doc. If date only is considered, please use day as unit, while when considering date and time, please use min as unit.

Note 6a: IF SM Label Description and SMAU/SMAB Dose Number are exactly matched within forms For SM/SMAU/SMAB Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number directly.

Note 6b: If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_<xxxxxxx>.csv to define the mapping.

Note 7a: If Stop Date/Time is missing, use Start Date/Time for calculation.

Note 7b: For gaps and overlaps, please display the output if the logic is met even if the remaining date is missing. (For example: SM record 2 Current Start Date/Time – SM Record 1 Previous Stop Date/Time > gap provided in the supporting document AND SM Record 2 Current Stop Date/Time is missing)

Requires Supporting Document to be named SM001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Group - Unique key for group of SM records, NOT NULL. Criteria Form1/2/3, Criteria Itemquestion1/2/3, Criteria Value1/2/3, gap_overlap, date_only, nbr and unit must be unique in each group

2. Criteria Form1 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA

3. Criteria Itemquestion1 - Arm/Cohort/Stratification Itemquestion1. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion1 is not applicable for the protocol, enter NA

4. Criteria Value1 - Arm/Cohort/Stratification Value. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the itemValue1 is not applicable for the protocol, enter NA

5. Criteria Form2 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

6. Criteria Itemquestion2 - Arm/Cohort/Stratification Itemquestion2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion2 is not applicable for the protocol, or is not needed enter NA

7. Criteria Value2 - Arm/Cohort/Stratification Value2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value2 is not applicable for the protocol, enter NA

8. Criteria Form3 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

9. Criteria Itemquestion3 - Arm/Cohort/Stratification Itemquestion3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion3 is not applicable for the protocol, or is not needed enter NA

10. Criteria Value3 - Arm/Cohort/Stratification Value3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value3 is not applicable for the protocol, enter NA

11. SM Form - SM/SMAU/SMAB, specified as 'NA' if gap/overlap is checked globally in each group, specified as 'ALL' if gap/overlap is checked individually in each group

12. Study Medication - Value for specific SM/SMAU/SMAB Study Medication, specified as 'NA' if gap/overlap is checked globally in each group, specified as 'ALL' if gap/overlap is checked individually in each group

13. Label Description - Value for specific SM Label Description, specified as 'NA' if gap/overlap is checked globally in each group, specified as 'ALL' if gap/overlap is checked individually in each group

14. Dose Number - Value for specific SMAU/SMAB Dose Number, specified as 'NA' if gap/overlap is checked globally in each group, specified as 'ALL' if gap/overlap is checked individually in each group

15. Study Period - Value for specific SM/SMAU/SMAB Study Period, specified as 'NA' if gap/overlap is checked globally in each group, specified as 'ALL' if gap/overlap is checked individually in each group

16. Scheduled Time - Value for specific SM/SMAU/SMAB Scheduled Time, If the Scheduled Time is not applicable for the protocol, enter NA

17. gap_overlap - gap/overlap, unique value in each group

18. date_only - yes/no, unique value in each group

19. nbr - number, unique value in each group

20. unit - day/hr/min, unit day for date_only, if date_only= no enter either min or hr, unique value in each group
