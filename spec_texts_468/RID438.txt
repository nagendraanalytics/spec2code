Report ID: RID438

Report Title:
Lenvatinib dose increase

Description:
Output is produced when Lenvatinib dose increase.

Column Heading:
1. Country

2. Site Mnemonic

3. Subject Number

4. Immediate Previous SM sequence

5. Immediate Previous SM Start Date/Time

6. Immediate Previous SM Dose amount

7. Current SM sequence

8. Current SM Start Date/Time

9. Current SM Dose Amount

Logic:
(Logic 1.1 Current SM.Start date/time <> null

Note: Sort by Start Date

AND

Logic 1.2 SM.Dose amount = any of Dose Reduction values per Supporting Document)

AND

(Logic 2.1 Immediate previous SM.Start/date time <>null

AND

Logic 2.2 SM.Dose amount in Immediate previous SM from logic 2.1 = any of Dose Reduction values per Supporting Document

And 2.3 Current SM. Start/date time from logic 1.1 > Immediate previous SM.Start/date time from logic 2.1)

AND

Logic 3

Logic 3.1 SM.Dose amount from logic 1.2 > SM.Dose amount in Immediate previous SM from logic 2.2

Note 1: Exclude deleted from programming.

Note 2: Do not output when SM.Dose Amount (from logic 1.2) is <> 0 AND Immediate previous SM.Dose Amount (from logic 2.2) is 0.

Note 3: Do not output when SM.Dose Amount (from logic 1.2) is = 0 AND Immediate previous SM.Dose Amount (from logic 2.2) is <> 0.

Note 4: Please consider to output when i.e SM.Dose Amount (from logic 1.2)  is the greatest Dose Reduction value from Supp Document AND Immediate previous SM. Dose Amount (from logic 2.2) is less than that dose amount.

Note 5: Please consider not to create output when the dose amount of both dates are the same i.e SM.Dose Amount is 14 (from logic 1.2) AND Immediate previous SM. Dose Amount (from logic 2.2) is 14.

Note 6: Please consider not to create output when SM.Dose Amount (from logic 1.2) is less than the Immediate previous SM. Dose Amount (from logic 2.2).

Note 7: Display date as DD-MMM-YYY format (e.g 01-Jan-2018).

Note 8: Requires supporting document to be named ONC_SM010_supp_<xxxxxxx>.csv and will contain the following columns and associated content: 1 row for each variation of Dose Reduction.

1. Group - Unique key for group of required value for Dose Reduction, NOT NULL.

2. Criteria Form - Unique value in each group, specified as per each protocol and should reflect the appropriate form used to the stratification of the subjects. Specified as ‘NA’ if no criteria form is expected for any subject.

3. Criteria Itemquestion - Unique value in each group, specified as per each protocol and should reflect the cohort or arm that subject was randomized in. Specified as ‘NA’ if same cohort or arm with no different value in day window is check for all subjects.

4. Criteria Value - Unique value in each group, specified as per each protocol and should reflect the study medication assigned for subjects regarding stratification form and cohort or arm.  Specified as NA if same medication and frequency is check for all subjects.

5. Formmnemonic - Unique value in each group

6. Dose Reduction - Dose to be administered when a dose modification is done e.g. 20 mg, 12 mg, 8 mg, 4 mg etc.

E.g.

Group,Criteria Form,Criteria Itemquestion,Criteria Value,Formmnemonic,Dose Reduction

1,NA,NA,NA,SM,8

2,NA,NA,NA,SM,4

3,SR,Arm,Arm 1,SM,12

Report Scenarios:
Output YES:

Current SM Dose amount is greater than the immediate previous SM Dose amount.

Output NO:

Current SM Dose amount is lower than the immediate previous SM Dose amount.

Sorting:
Country, Site, Subject, eCRF

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, default as N), Supporting Document (N/Y, Default as N) (If supporting doc is needed for the report)

Form.Item Names:
1. Subject Assignment. Country

2. Subject Assignment. Site Mnemonic

3. Subject Assignment. Subject Number

4. SM.display form index number from logic 2.1

5. SM.display Start Date/Time from logic 2.1

6. SM.display Dose Amount from logic 2.2

7. SM.display form index number from logic 1.1

8. SM.display Start Date/Time from logic 1.1

9. SM.display Dose Amount from logic 1.2
