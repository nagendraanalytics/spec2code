Report ID: RID087

Report Title:
Duplicate CECG Records

Description:
This report lists all patients with duplicate ECG records based on the parameters selected from the CECG items.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. Vendor

6. Visit Number

7. Collection Date and Time

8. Form Index

9. Seq

Logic:
Report Logic: The report should output CECG records where Site, Subject ID or Number, Vendor Name AND All items EXCEPT for the selected items from parameter " CECG items to exclude" are equal.

Note:

1. Report should not display deleted records.

2. If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.                                                                                                                                                                                                                                                                                                  3. Collection Date and Time field is formatted according to the ISO standard. An example for 12-Jul-2007 at noon is: 2007-07-12T12:00:00 (yyyy-mm-ddThh:mm:ss). However, not all time parts are always present.

4. Visit numbers are formatted as a number without any leading zeros.

5. If item selected on parameter " CECG items to exclude "=Null, that should be also considered as duplicate value. Per default, the report should consider items in Data Type such as Study Identifier, Site ID or Number, Screen ID or Number or Subject ID or Number to exclude duplicates.

Report Scenarios:
Output – Yes

There are two records on CECG with all items equal (The items on “CECG items to exclude” can be equal or different, should be ignored)

Output – No

There are two records on CECG but at least one of the items NOT present in “CECG items to exclude” is different.
