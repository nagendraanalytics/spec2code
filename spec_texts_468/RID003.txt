Report ID: RID003

Report Title:
Reconciliation of Subject Status associated to COVID-19 and disposition forms

Description:
This report lists the discontinuation reason details in the subject/study medication status forms, to identify missing associations or inconsistencies to COVID-19 in ACDC form.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit Mnemonic

5. Form name

6. Reason for Discontinuation Details

7. ACDC Question

Logic:
Logic 1: Disposition Form.Reason details item (provided in the supp doc) <> NULL

AND

Logic 2: ACDC Question (provided in the supp doc) <> Yes

Note 1: The report should generate an output for every form that meets the logic

Note 2: Only output when Disposition Form.Date of Assessment is > 1-Dec-2019

Note 3: For this report, only use all columns in the supporting document.

Requires supporting document to be named ACDC003_supp_<xxxxxxx>.csv. It will contain the following columns and associated content:

1) Form – Each form where discontinuation is indicated

2) Date of Assessment – Date of Assessment item for each form

3) Visit Mnemonic – Visit where each form is triggered per T&E

4) Reason details item – Reason details item for each form

5) ACDC Question- Each question paired with the corresponding form.

Eg.

Form, Date of Assessment, Visit Mnemonic, Reason details item

OEDRA, Date of Assessment, Follow-up Day 30, Reason for Discontinuation from This Trial Segment Details (see note immediately above), Was the Discontinued Status of Subject at the End of the Imaging/Efficacy Assessments Recorded on the OEDRA Form Associated With COVID-19?

Report Scenarios:
Output Yes: Disposition Form.Date of Assessment > 1-Dec-2019 AND Disposition Form.Reason details item <> NULL AND ACDC Question = No

Output Yes: Disposition Form.Date of Assessment > 1-Dec-2019 AND Disposition Form. Reason details item <> NULL AND ACDC Question = Unknown

Output Yes: Disposition Form.Date of Assessment > 1-Dec-2019 AND Disposition Form.Reason details item <> NULL AND ACDC Question = NULL

Output No: Disposition Form.Date of Assessment < 1-Dec-2019 AND Disposition Form.Reason details item = NULL AND ACDC Question = NULL

Output No: Disposition Form.Date of Assessment > 1-Dec-2019 AND Disposition Form. Reason details item <> NULL AND ACDC Question = Yes

Sorting:
Default

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N set default to N)

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subject Assignment.Subject Number

4. Visitmnemonic from Supporting Document

5. Display eCRF name (DS01/OEDRA/PMS1/PMS1A/PMST)

6. Display Reason for Discontinuation Details (DS01.Reason for Study Discontinuation Details (see note immediately above) OR OEDRA/PMS1/PMS1A/PMST.Reason for Discontinuation from This Trial Segment Details (see note immediately above))

7. Display ACDC Question value
