Report ID: RID440

Report Title:
Missing SSC Baseline Assessment

Description:
This report will list subjects who are missing the baseline Specimen Sample Collection Invoice for Specified Sample Description.

Column Heading:
1.	Country

2.	Site

3.	Subject Number

4.	Date of Randomization

5.	Sponsor ID Number

6.	Date and time Specimen Obtained

7.	Error Message

Logic:
SR date of Assessment <> NULL

AND

There’s no SSC Sample Description Completed as the Selected Sample Description in the prompt

With Date and time Specimen Obtained within X days within prior to SR date of Assessment

Note 1: X should be obtained from window of days prompt

Report Scenarios:
Scenario A, Output = Yes

Output is produced for subjects who do not have at least one Date/Time Specimen Obtained for Specified Sample Description (Specified by prompt) that occurs within (window specified by prompt) days prior to the Date of Randomization.

Scenario B, Output = No

If there’s at least one record in SSC with Date/Time Specimen Obtained for Specified Sample Description:  (Specified by prompt) within (window specified by prompt) days within prior to the Date of Randomization.

Scenario C, Output = No

Exclude deleted records

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, Site, Subject Number, Randomized Only, Sample Description, Window of Days

Form.Item Names:
1.	SA. Country

2.	SA. Site

3.	SA. Subject Number

4.	SR. Date of Assessment

5.	SSC. Sponsor ID Number

6.	SSC. Date and time Specimen Obtained

7.	When there’s a missing Entry Display: Missing Sample

When it’s outside the allowed window established by prompt Display: Outside allowed Window.
