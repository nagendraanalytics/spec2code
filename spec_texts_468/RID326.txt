Report ID: RID326

Report Title:
Enlargement Reconciliation

Description:
This report will output if Further Enlargement from Nadir is selected, but in there is no an initial timepoint in which the lesion was Enlargement from Nadir for the items Non-Target Lesion Status & New Non-Target Lesion Status.

Column Heading:
1.Country

2.Site

3.Subject Number

4.Form

5.Sequence

6.Date of Current Lesion Evaluation (Scan/Image/Physical Exam)

Logic:
Logic 1.1:

LSN.Status = "Further Enlargement from Nadir"

AND

Logic 1.2:

There is NO entry with

LSN.Status = "Enlargement from Nadir"

AND

LSN.Date from logic 1.2 < LSN.Date from logic 1.1

Logic 2.1:

LSN.Status = "Further Enlargement from Nadir"

AND

Logic 2.2:

There is an entry with

LSN.Status = "Enlargement from Nadir"

AND

LSN.Date from logic 2.2 < LSN.Date from logic 2.1

AND

Logic 2.3:

There is an entry with LSN.Status = "Present"

AND

LSN.Date from logic 2.3 < LSN.Date from logic 2.1

AND

LSN.Date from logic 2.3 > LSN.Date from logic 2.2

Notes:

1.	The report should ignore the deleted records.

2.	Compare within the same Lesion Number LSNIR.Associated Lesion Number.

3.	To show an output, items from logic 1.1 and 1.2 must be the same(Compare within the same Lesion Number.

For example, if in logic 1.1 further enlargement from nadir is selected in Non-Target Lesion Status item, for logic 1.2 the report only should search entries with Non-Target Lesion Status item completed.

4.	LSN.Date refers to LSN eCRF.”DATE OF LESION EVALUATION” from global supporting document LSN_supp_doc.

5.	LSN.Status refers to LSN eCRF.”NON TARGET LESION STATUS” and LSN eCRF.“NEW NON-TARGET LESION STATUS” from global supporting document LSN_supp_doc.

Report Scenarios:
Scenario 1: Output YES: “Further Enlargement From Nadir” option is selected in the Non-target lesion status item, and there IS NOT an entry with prior date and “Enlargement From Nadir” option selected in the add-entry section for the same lesion in the same item.

Scenario 2: Output YES: “Further Enlargement From Nadir” option is selected in the New Non-target lesion status item, and there IS NOT an entry with prior date and “Enlargement From Nadir” option selected in the add-entry section for the same lesion in the same item.

Scenario 3: Output NO: “Further Enlargement From Nadir” option is selected in the Non-target lesion status item, and there IS an entry with prior date and “Enlargement From Nadir” option selected in the add-entry section for the same lesion in the same item.

Scenario 4: Output NO: “Further Enlargement From Nadir” option is selected in the New Non-target lesion status item, and there IS an entry with prior date and “Enlargement From Nadir” option selected in the add-entry section for the same lesion in the same item.

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, default as N)

Form.Item Names:
1. SA.Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. LSNIR

5. LSNIR. Sponsor ID Number

6. LSNIR. Date of Current Lesion Evaluation (Scan/Image/Physical Exam)
