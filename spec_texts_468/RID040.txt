Report ID: RID040

Report Title:
Overlapping CM Start and Stop Dates

Description:
This report displays subjects who have matching CM Standardized Medication Name and overlapping Start and Stop dates for all medications taken within 14 days of an SAE/ECI Onset Date.

CM Term could be either Standardized Medication Name, Encoded Drug Name or Medication Class as selected from the Parameter Selection screen.

The report checks for overlaps in a list of medications selected from the Parameter Selection screen.

Logic:
1. The report should display subjects with identical CM Terms having overlapping start and stop dates. Each pair of overlapping CM record should be on one line.

CM Term should be a radio button parameter with the following values: Standardized Medication Name, Encoded Drug Name and Medication Class. If Standardized Medication Name is selected, the report will display subjects with identical Standardized Medication Name and overlapping start and stop dates.

Lists of Standardized Medication Name, Encoded Drug Name and Medication Class from the study's database should be available as parameter selections.

An "Include/Exclude" radio button parameter should be available to allow the selected medication names to be Included or Excluded  from the above check.

2. The report should display subjects with identical CM terms having overlapping start and stop dates for all medications taken within +/- 14 days of an SAE Onset Date. Each pair of overlapping CM records should be on one line. A parameter selection checkbox named "CM taken within +/- 14 days of SAE/ECI" should be available for user to select this check. Only if selected, these two columns are to be shown: SAE/ECI Seq and SAE/ECI Onset Date.

The report should specifically check if:

• CM start date is within +/- 14 days of SAE/ECI onset date

• CM start date is more than 14 days prior to SAE/ECI onset date and

CM stop date is selected as Continuing or CM stop date is > -14 days of SAE/ECI onset date.

An AE record is considered an SAE if any of the 8 serious AE criteria is marked Yes or ECI is marked Y.

3. The following Optional Conditions should be available to restrict the output as needed.

- Frequency - PRN: the overlapping pair has frequencies equal to or different from PRN

- Dose Form: equal or different within the overlapping pair

- Route of Administration: equal or different within the overlapping pair

- Reason for Therapy: include the exact Reason for Therapy for the overlapping pair.

Report should not display deleted records. If "Randomized only" parameter selection checkbox  is checked, the report should

only output subjects with Randomization number that is not null.
