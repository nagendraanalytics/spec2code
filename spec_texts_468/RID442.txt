Report ID: RID442

Report Title:
Symptomatic Skeletal Related Event Start Date Reconciliation

Description:
This report lists subjects who have SSRE whose Symptomatic Skeletal Related Event Start Date is after ORAD/ORAD2/OS/OSOF/OSCN date which is associated by Sequence Number in SSRE form.

Column Heading:
1.	Country

2.	Site

3.	Subject Number

4.	SSRE seq#

5.	SSRE Date

6.	SSRE, associated sponsor ID Number

7.	Form Mnemonic

8.	Seq#

9.	Date of assessment

10.           SSRE Visit

Logic:
IF SSRE. Start date is > ORAD/ORAD2/OS/OSOF/OSCN “start date of the associated sequence”

Notes:

1.1	Deleted records and Erroneous visits should not be considered for programming

1.2	If one of the forms (ORAD ORAD2, OSCN, OSOF or OS) are not initiated outputs should not appear.

1.3	For sequence association on SSRE use each item for the corresponding form as:

A.	Associated Sponsor ID Number (from ORAD form) related to Skeletal Symptoms

B.	Associated Sponsor ID Number (from ORAD2 form) related to Skeletal Symptoms

C.	Associated Sponsor ID Number (from OSCN form) related to Unscheduled imaging

D.	Associated Sponsor ID Number (from OSOF form) related to Surgical intervention for Bone Metastases

E.	Associated Sponsor ID Number (from OS form) related to Surgical intervention for Bone Metastases

1.5 Please use “start date of the associated sequence” as:

1.5.1 For ORAD use Start Date

1.5.2 For ORAD2 use Start Date

1.5.3 For OSCN use the Scan date

1.5.4 For OSOF use the Date and Time Performed

1.5.5 For OS use the Date and Time Performed

1.6 When UNK is selected as the day or month in ORAD/ORAD2, use the first day of the month OR the first month of the year

Report Scenarios:
Scenario A: (Output its expected)

 YES

If a subject SSRE Start Date is after ORAD/ORAD2, OS/OSOF, OSCN Scan/Start Date which is associated by Sequence Number in SSRE form.

OR

Scenario B: (Output is not expected)

NO

 If the subject SSRE Date is before ORAD/ORAD2, OS/OSOF, OSCN Scan/Start date which is associated by Sequence Number in SSRE form.

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N), Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
1.	SA. Site Country

2.	SA. Site Mnemonic

3.	SA. Subject Number

4.	SSRE Seq#

5.	SSRE, start date of SSRE (Take into account Note 1.4)

6.	SSRE, Associated Sponsor ID Number (from OS, OSOF, OSCN, ORAD, ORAD2)

7.	ORAD, ORAD2, OS, OSOF, OSCN.

8.	ORAD, ORAD2, OS, OSOF, OSCN Seq #

9.	ORAD, ORAD2, OS, OSOF, OSCN. Date of assessment (Take into account Note 1.5)

10.          SSRE.Visit Mnemonic

Note: Form item No 6, if there is more than one Associated Sponsor ID Number that meet the logic of Output = Yes show them in the same output separated by a comma
