Report ID: RID126

Report Title:
Mismatch in units between Local Lab and Site Level Local Lab NR

Description:
This report outputs subjects who have a local lab (CLAB, HLAB, OLAB) test unit that does not match the corresponding site level local lab normal range (SLCNR, SLHNR, SLONR) test unit for the same lab, test and specimen type (where applicable).

Column Heading:
1. Country

2. Site

3. Subject Number

4. Local Lab eCRF

5. Visit

6. Local Lab Seq

7. Laboratory Name

8. Specimen Type

9. Test Name

10. LL Test Unit

11. SLLNR Test Unit

Logic:
Match each site, test, specimen type (for CLAB and OLAB only) and laboratory name on the local lab (CLAB, HLAB, OLAB) eCRF with site, test, specimen type (for CLAB and OLAB only) and laboratory name on the site level local lab normal range (SLCNR, SLHNR, SLONR) eCRF. Each HLAB and CLAB test is a field on the local lab eCRF, with the field name specifying the test.

Report should display subjects who have mismatches in test units for matching site, test, specimen type (CLAB and OLAB)  and laboratory name.  Comparison should not be case sensitive.

The following units need to be standardized to avoid mismatches between forms:

- 'GM' to 'G'

- 'GRAM' to 'G'

- 'MOLE' to 'MOL'

- 'MICRO' to U'

- 'MILLI' to 'M'

- 'UG/L' to 'NG/ML'

Do not include deleted records.

Do not include data from erroneous visits.

Report Scenarios:
Yes:Which satisfies logic, have mismatch in test units

No: Which doesn't satisfies logic, does not have mismatch in test units.
