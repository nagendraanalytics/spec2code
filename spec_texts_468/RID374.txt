Report ID: RID374

Report Title:
Missing iUPD Overall iRECIST response after initial RECIST PD if subject continue with treatment or incorrect RECIST response

Description:
This report will display subjects who continue with treatment after Overall RECIST response of Progressive Disease in ORIR and there is not iUPD Overall iRECIST response in the same ORIR entry or if RECIST response was provided after Overall iRECIST response was provided or if the Overall iRECIST response is iUPD and Overall RECIST response is not completed or is not PD on the same entry or if the Overall iRECIST response is completed but there is not a previous progressive disease reported.

Column Heading:
1. Country

2. Site

3. Subject Number

4. ORIR Seq #

5. Date of Procedure for Overall Response (Scan/Image/Physical Exam)

6. Overall RECIST Response

7. Overall iRECIST Response

8. SM Visit

9. SM eCRF

10. SM Seq #

11. Stop Date/Time

12. Scenario

Logic:
Logic 1:

Logic 1.1: There is an ORIR record completed with the following criteria: (ORIR."DATE RESPONSE DETERMINED" NOT NULL AND ORIR."OVERALL RECIST RESPONSE" = "Progressive Disease" AND (ORIR."OVERALL IRECIST RESPONSE" NOT "iUPD" OR ORIR."OVERALL IRECIST RESPONSE" = NULL))

AND

Logic 1.2: There is at least one record SM/STR/SMAU/SMAB with "STOP DATE" >= ORIR."DATE RESPONSE DETERMINED" from record in Logic 1.1

Logic 2:

Logic 2.1: There is an ORIR record completed with the following criteria: (ORIR."DATE RESPONSE DETERMINED" NOT NULL AND ORIR."OVERALL RECIST RESPONSE" = "Progressive Disease")

AND

Logic 2.2: There is another ORIR record completed with the following criteria: (ORIR."OVERALL RECIST RESPONSE " NOT NULL AND ORIR."DATE RESPONSE DETERMINED" > ORIR."DATE RESPONSE DETERMINED" from Logic 2.1)

Logic 3:

Logic 3.1: Output when Overall RECIST response is not completed as PD in the same entry when Overall IRECIST is iUPD for the first time

OR

Logic 3.2: Output when Overall RECIST response is not completed in the same entry when Overall IRECIST is iUPD for the first time

Logic 4:

Logic 4.1: There is an ORIR record completed with the following criteria: (ORIR."DATE RESPONSE DETERMINED" NOT NULL AND ORIR."OVERALL IRECIST RESPONSE" NOT "iUPD")

AND

Logic 4.2: There is NOT at least one ORIR record completed with the following criteria: (ORIR."OVERALL RECIST RESPONSE" = "Progressive Disease" AND ORIR."OVERALL IRECIST RESPONSE" = "iUPD" AND ORIR."DATE RESPONSE DETERMINED" < ORIR."DATE RESPONSE DETERMINED" from Logic 4.1)

Notes:

1-	Erroneous visits and deleted records are excluded from programming

2-	This report uses the master RSP_supp_doc.csv and SM_supp_doc.csv and these files will be used to obtain the data needed to create the programming. The spec uses items that can be found in the column "ITEMQUESTION" to standardize the different "ORIGINAL ITEMQUESTION" variations

3-	"DATE RESPONSE DETERMINED", "OVERALL IRECIST RESPONSE" and "OVERALL RECIST RESPONSE" are items from RSP_supp_doc.csv

4-	"STOP DATE" is an item from SM_supp_doc.csv

5-	For Logic 2, Logic 3 and Logic 4 columns 8 – 11 should be blank

6-	Include the date only and exclude the time from comparison

7-	For Logic 1.2 check only for the minimum study medication record to display columns 8-11

8-	For STR and SM if "STOP DATE" is blank, then assume the date as system date

9-             For scenario 3 & 4, disregard output if ORIR."OVERALL IRECIST RESPONSE" is blank

Supporting Document Notes:

1-	Requires supporting document that should be named as study_phase_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: the order on which phases will appear on protocol

2. Treatment Phase: this information is the phase name given in the protocol (Initial Treatment Phase/Second Course Phase/Crossover/Neoadjuvant)

3. First Visitmnemonic of Treatment Phase: the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

2-	The report logic should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: ORIR."DATE RESPONSE DETERMINED", SM/STR/SMAU/SMAB."STOP DATE"

3-	The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

4-	This is a required supporting document for all studies with one or more phases.

5-	This supporting document is required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Report Scenarios:
A - No

There is no Overall RECIST response = Progressive Disease

B – No

There is an Overall RECIST response = Progressive Disease AND There is no Study Medication record with Start Date >= Date of Procedure for Overall Response (Scan/Image/Physical Exam) to ORIR record in Logic 1 when Study Medication and ORIR records in the same treatment phase.

C – No

There is an Overall RECIST response = Progressive Disease AND There is a Study Medication record with Start Date >= Date of Procedure for Overall Response (Scan/Image/Physical Exam) to ORIR record in Logic 1 when Study Medication and ORIR records in the same treatment phase. AND The Overall iRECIST Response of ORIR record in Logic 1 = iUPD

D – Yes

There is an Overall RECIST response = Progressive Disease AND There is a Study Medication record with Start Date >= Date of Procedure for Overall Response (Scan/Image/Physical Exam) to ORIR record in Logic 1 when Study Medication and ORIR records in the same treatment phase. AND The Overall iRECIST Response of ORIR record in Logic 1 <> iUPD

SCENARIO 2

E – No

There is an Overall RECIST response = Progressive Disease AND There is no other Overall RECIST response <> NULL with Date of Procedure for Overall Response (Scan/Image/Physical Exam) > Date of Procedure for Overall Response (Scan/Image/Physical Exam) of Logic 1 when ORIR records in the same treatment phase.

F – Yes There is an Overall RECIST response = Progressive Disease AND There is another Overall RECIST response <> NULL with Date of Procedure for Overall Response (Scan/Image/Physical Exam) > Date of Procedure for Overall Response (Scan/Image/Physical Exam) of Logic 1 when ORIR records in the same treatment phase
