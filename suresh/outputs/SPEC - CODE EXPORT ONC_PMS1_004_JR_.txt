Report ID:
ONC_PMS1_004_JR_STD

EDC System / Language:
veeva / CQL

Description:
This report identifies subjects who discontinued/had a treatment-phase-defining PMS (Post-Med/Study status, e.g. PMS1 or PMST "Disease Status") form assessment recorded as reason "Clinical Progression", but who also have an Oncologic Response eCRF (ORAJ / Overall Response form) record reporting Progressive Disease (or equivalent PD terms) with a response date that PRECEDES the PMS clinical-progression assessment date within the same treatment phase window. It flags a data inconsistency: site recorded discontinuation as "Clinical Progression" on the PMS form even though an earlier Oncologic Response assessment already showed Progressive Disease. Source clinical data comes from a CDM/Oracle-based clinical database (subject demographics/status, date-of-visit/DOV control records, PMS1/PMST disease-status forms, and the Oncologic Response (ORAJ) eCRF form), with study-specific and global supporting documents (CSV files) driving dynamic column/alias mapping and treatment-phase (visit window) definitions. Output is an Excel report (via ODS TAGSETS.EXCELXP) listing each qualifying subject/visit combination, optionally with a supporting "Study Phase" reference page.

Column Heading:
Country | Site | Subject Number | PMS Form | PMS Visit | PMS Date | eCRF | Seq# | Item Name | Item Date
(When phase supp page shown: Phase Order | Treatment Phase | First Visitmnemonic of Treatment Phase)

Logic:
1. Source data: subject/site info (irv_cur_subject + cv_safm), visit/date-of-visit control (cv_dovfm) used to exclude visits flagged with a DOV error, PMS1/PMST disease-status eCRF forms (cv_pms1fm / cv_pmstfm) representing discontinuation-reason assessments, and the Oncologic Response eCRF (cv_orajfm) representing tumor response assessments. Dynamic form/item metadata (aliases, column names, deleted-form/item flags, formindex) is resolved at runtime from a global supporting CSV (RSP_supp_doc.csv) cross-referenced against the study's live data dictionary (cv_datadictionary), because item/column names vary by study build.
2. Filtering/matching logic:
   - PMS1/PMST records are filtered to those where the disease-status term (PMS1DSTERMSMDCRC_PMS1DSTER_1 or PMSTTERMSUBDCRC_PMSTDSATER_1) = 'CLINICAL PROGRESSION' (case-insensitive) and the assessment date is not null, joined to DOV excluding rows with a DOV error flag.
   - Oncologic Response (ORAJ) records are filtered to responses not marked as a deleted form, then further restricted (onc_resp) to records where the response value is one of 'PROGRESSIVE DISEASE','ICPD','IRPROGRESSIVE DISEASE','YES' and response date is not null.
   - Both PMS and Response records are assigned to a "treatment phase" window per subject by joining to a subject-level ordered list of treatment-phase start dates (subj_tp), derived from a study-specific "study phase" supporting CSV mapped to DOV visit dates; each record's date must fall between a phase's start date and the next phase's start date (or "now"/1960 default bounds for first/last phase).
   - The two phase-tagged datasets (pms_tp/pms_supp and rsp_tp/rsp_supp) are joined on subjectid where the Oncologic Response date (rsp_dt) is strictly LESS THAN the PMS/PMST clinical-progression assessment date (date_of_assessment) — i.e., the PD response was recorded earlier than (before) the clinical-progression discontinuation reason was entered, representing the discrepancy being flagged.
   - Final subject/site attributes are merged in from the subject table.
   - Records are additionally restricted to the PMS form(s) selected via macro parameter (&MVAR1, derived from &fname parameter which can be PMS1, PMST, or a user-specified list) and formmnemonic filter (&mvar2) applied to the Oncologic Response dataset via a parameter (&rform).
3. If no PMS1/PMST form exists for the trial (cnt=0), a message row is output instead ("&MVAR1 Form is not available for selected trial"). If the study-phase supporting CSV file does not exist for the protocol, a message page is generated instead of running the report ("Supporting Document Not Present for This Trial"). If the treatment-phase dataset (subj_tp) has 0 observations, empty placeholder datasets are created and no matching is performed (effectively no output rows).
4. Final duplicate-record removal by country/site/subject (proc sort noduprecs).

Report Scenarios:
1. Normal case: Study has PMS1 and/or PMST form and a valid study-phase supporting document — full comparison logic runs, producing rows for subjects with PD response occurring before a recorded Clinical Progression discontinuation.
2. No PMS1/PMST form present for the selected trial (cnt=0 from IRV_STUDYVERSION_FORMS lookup) — output a message page stating the form is not available.
3. Study-phase supporting document (CSV) not found for the protocol — output a message page stating the supporting document is missing and to contact the RaM programmer.
4. Treatment-phase dataset (subj_tp) has zero records — empty placeholder final datasets are produced (no findings reported), no join/comparison performed.
5. No records meet the discrepancy test condition (final has 0 obs) — report outputs a "No records meet the test condition" placeholder row instead of the standard report grid.
6. Optional supplementary "Study Phase" reference page produced when macro parameter &aform = 'Y', listing Phase Order, Treatment Phase name, and First Visitmnemonic of each phase from the supporting doc.
7. Study contains both PMS1 and PMST forms simultaneously — code unions PMS1FM and PMSTFM query results (per Version 4 fix note) and resolves the correct view names dynamically via database data-dictionary lookup rather than assuming a single form.

Sorting:
Final report sorted by Country, Site Number, Subject Number, with duplicate records removed (PROC SORT ... NODUPRECS). Supporting phase-lookup logic requires subject-level records sorted by subjectid descending date (tpdtstr) then by subjectid ascending date (tpdtstr) for LAG-based phase window derivation (RETAIN/lag-implied ordering, not an explicit final output sort).

SELECT
  PMS_RSP.Country AS `Country`,
  PMS_RSP.Site AS `Site`,
  PMS_RSP.SubjectNumber AS `Subject Number`,
  PMS_RSP.PmsForm AS `PMS Form`,
  PMS_RSP.PmsVisit AS `PMS Visit`,
  DATE_FORMAT(PMS_RSP.PmsDateRaw, '%d%b%Y') AS `PMS Date`,
  PMS_RSP.RspForm AS `eCRF`,
  PMS_RSP.RspSeq AS `Seq#`,
  PMS_RSP.RspItemName AS `Item Name`,
  DATE_FORMAT(PMS_RSP.RspDateRaw, '%d%b%Y') AS `Item Date`
FROM
(

-- PMS1 clinical-progression assessments, joined to DOV (excluding erroneous visits) for phase/visit context
SELECT
    `@HDR`.`Subject`.`ID` AS SubjectID,
    `@HDR`.`Site`.`Country` AS Country,
    `@HDR`.`Site`.`Number` AS Site,
    `@HDR`.`Subject`.`Name` AS SubjectNumber,
    `@Form`.`Name` AS PmsForm,
    `@HDR`.`Event`.`Name` AS PmsVisit,
    RAWDATE(PMS1FM.PMS1DSDTCIT) AS PmsDateRaw,
    'ORAJ' AS RspForm,
    ORAJFM.ORAJSPIDIT AS RspSeq,
    ORAJFM.ORAJTESTIT AS RspItemName,
    RAWDATE(ORAJFM.ORAJDTCIT) AS RspDateRaw
  FROM `EDC`.`PMS1FM` PMS1FM
  INNER JOIN `EDC`.`DOVFM` DOVFM
    ON `@HDR`.`Subject`.`ID` = `@HDR`.`Subject`.`ID`
  INNER JOIN `EDC`.`ORAJFM` ORAJFM
    ON `@HDR`.`Subject`.`ID` = `@HDR`.`Subject`.`ID`
  WHERE `@Form`.`Status` = 'submitted__v'
    AND (DOVFM.DOVSERRORVIT = 'N' OR DOVFM.DOVSERRORVIT IS NULL)
    AND (ORAJFM.DELETEDFM = 'N' OR ORAJFM.DELETEDFM IS NULL)
    AND UPPER(TRIM(PMS1FM.PMS1DSTERMSMDCRC)) = 'CLINICAL PROGRESSION'
    AND PMS1FM.PMS1DSDTCIT IS NOT NULL
    AND ORAJFM.ORAJORRESIT IN ('PROGRESSIVE DISEASE', 'ICPD', 'IRPROGRESSIVE DISEASE', 'YES')
    AND ORAJFM.ORAJDTCIT IS NOT NULL
    AND RAWDATE(ORAJFM.ORAJDTCIT) < RAWDATE(PMS1FM.PMS1DSDTCIT)

  UNION ALL

-- PMST clinical-progression assessments, joined to DOV (excluding erroneous visits) for phase/visit context
SELECT
    `@HDR`.`Subject`.`ID` AS SubjectID,
    `@HDR`.`Site`.`Country` AS Country,
    `@HDR`.`Site`.`Number` AS Site,
    `@HDR`.`Subject`.`Name` AS SubjectNumber,
    `@Form`.`Name` AS PmsForm,
    `@HDR`.`Event`.`Name` AS PmsVisit,
    RAWDATE(PMSTFM.PMSTDSDTCIT) AS PmsDateRaw,
    'ORAJ' AS RspForm,
    ORAJFM2.ORAJSPIDIT AS RspSeq,
    ORAJFM2.ORAJTESTIT AS RspItemName,
    RAWDATE(ORAJFM2.ORAJDTCIT) AS RspDateRaw
  FROM `EDC`.`PMSTFM` PMSTFM
  INNER JOIN `EDC`.`DOVFM` DOVFM2
    ON `@HDR`.`Subject`.`ID` = `@HDR`.`Subject`.`ID`
  INNER JOIN `EDC`.`ORAJFM` ORAJFM2
    ON `@HDR`.`Subject`.`ID` = `@HDR`.`Subject`.`ID`
  WHERE `@Form`.`Status` = 'submitted__v'
    AND (DOVFM2.DOVSERRORVIT = 'N' OR DOVFM2.DOVSERRORVIT IS NULL)
    AND (ORAJFM2.DELETEDFM = 'N' OR ORAJFM2.DELETEDFM IS NULL)
    AND UPPER(TRIM(PMSTFM.PMSTTERMSUBDCRC)) = 'CLINICAL PROGRESSION'
    AND PMSTFM.PMSTDSDTCIT IS NOT NULL
    AND ORAJFM2.ORAJORRESIT IN ('PROGRESSIVE DISEASE', 'ICPD', 'IRPROGRESSIVE DISEASE', 'YES')
    AND ORAJFM2.ORAJDTCIT IS NOT NULL
    AND RAWDATE(ORAJFM2.ORAJDTCIT) < RAWDATE(PMSTFM.PMSTDSDTCIT)
) PMS_RSP
ORDER BY
  `Country`, `Site`, `Subject Number`
