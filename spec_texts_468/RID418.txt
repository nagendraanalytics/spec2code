Report ID: RID418

Report Title:
Study Medication First Dose Date vs Date Response Determined

Description:
This report lists subjects who have a Date Response Determined that is prior to Start Date of First Dose of Study Medication.

Column Heading:
1. Country

2. Site

3. Subject number

4. SM Form

5. SM Visit

6. SM Seq

7. MIN First Dose Start date Time

8. Response Form

9. Seq#

10. Date Response Determined

Logic:
Logic 1: SM_Form.Date of First Dose <> NULL

AND

Logic 2: RSP_Form.Date <= SM_Form.Date of First Dose

Note:

Note 1: This report uses the master RSP_supp_doc.csv. This supporting document should be uploaded only once at TA level per the GDO Oncology TAST authorized members and will be used to facilitate programming of the report. Report builder will use all the columns provided in the excel spreadsheet to create the programming code.

Note 2: Please exclude deleted records and erroneous visits from programming

Note 3: SM_Form include SM/SMAU/SMAB/STR/SM01

For Note 4: SM_Form.Date of First Dose definition:

For SM/SMAB/SMAU/STR use the MIN ‘START DATE/TIME’, check records with first dose checked.

For SM01 use ‘START DATE AND TIME FIRST DOSE ADMINISTERED/RECEIVED’.

Note 5: RSP_Form.Date definition：Item “DATE RESPONSE DETERMINED” from master RSP_supp_doc.csv

Note 6: Using "Response form" parameter to determine which Response forms need to be checked, if none is entered use all Response forms present in the study

Note 7: Using "Study Medication form" parameter to determine which Study Medication forms need to be checked,if more than one Study medication form is entered, use the minimum date among all the date of first dose

Note 8: Using "Protocol Requirement" parameter to determine if include "=" in date comparision

Report Scenarios:
Scenario A/Yes:

Response form date is "Less Than Date of First Dose" OR "Less Than or Equal to Date First Dose" according to parameter

Scenario B/No:

Response form date is After Date of first dose OR After or equal to date of first dose according to parameter.

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only, Response Form (text box, if multiple options entered should be separated by comma), Study Medication eCRF (text box, if multiple options entered should be separated by comma), Protocol Requirement (select list, Less Than Date of First Dose/Less Than or Equal to Date of First Dose, default as Less Than Date of First Dose)

Form.Item Names:
1. SA form. Country

2. SA form. Site

3. SA form. Subject number

4. Display it as SM or SMAU or SMAB or SM01 or STR

5. Display SMAU or SMAB or SM01 Visit Mnemonic, for SM and STR leave this column blank.

6.Display STR or SM or SMAU or SMAB form, Seq#, Form SM01 leave this column blank.

7. SM or SMAU or SMAB form  Start date and time, STR "Start Date/Time" , SM01 Start Date and Time First Dose Administered/Received.

8. Display Response form from logic 2

9. Response form. Seq#

10. Response form Date according to Note 4
