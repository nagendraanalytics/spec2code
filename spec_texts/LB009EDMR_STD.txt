Report ID: LB009EDMR_STD

Report Title:
Trends Listing of Hematology and Chemistry Central Lab Data Sorted By Lab Test

Description:
This report gives a trends listing of Hematology and Chemistry Central Lab Data Sorted By Lab Test including High/Low flags.  The numeric results are sorted in ascending order within each lab test.  The user has the option to run this report for all values, or for out of range values only.

Column Heading:
1. Test Name

2. Results

3. Test Unit

4. NR Flag

5. Normal Range

6. Subject Number

7.Collection Date/Time

8. Visit

9. Country

10. Site
