Report ID: RID241

Report Title:
Malignant Neoplasm Progression vs PMS1/PMST Status

Description:
This report will display discrepancies between the AEs with action taken with study medication of discontinued and the reason selected for discontinuation in PMS1/PMST or when the dates are not consistent.

Logic:
Logic 1:

Logic 1.1 There is a PMS1/PMST record with ‘Status of Study Medication’ <> ‘PD’

AND

Logic 1.2 Identify the maximum SMAB/SMAU/STR/SM ‘Study Medication’ and/or ‘Study Treatment’ on or before PMS1/PMST Date of Assessment from Logic 1.1

AND

Logic 1.3 There is an AE with LLT Term = ‘Malignant Neoplasm Progression’ and with ‘Onset Date’ on or before record identified on Logic 1.2

AND

Logic 1.4 AE from Logic 1.3. Action with Taken with ‘Study Medication’ or/and Action Taken with ‘Study Treatment’ = ‘Discontinued’

AND

Logic 1.5 ‘Study Medication’ or/and ‘Study Treatment’ from Logic 1.4 matches with ‘Study Medication’ or/and ‘Study Treatment’ from record on Logic 1.2

Logic 2:

Logic 2.1 There is a PMS1/PMST record with ‘Status of Study Medication’ <> ‘Adverse Event’

AND

Logic 2.2 Identify the maximum Stop Date and Time SMAB/SMAU/STR/SM ‘Study Medication’ and/or ‘Study Treatment’ on or before PMS1/PMST Date of Assessment from Logic 2.1

AND

Logic 2.3 There is an AE with LLT Term <> ‘Malignant Neoplasm Progression’ and with ‘Onset Date’ on or before record identified on Logic 2.1

AND

Logic 2.4 AE from Logic 2.3. Action with Taken with ‘Study Medication’ or/and Action Taken with ‘Study Treatment’ = ‘Discontinued’

AND

Logic 2.5 ‘Study Medication’ or/and ‘Study Treatment’ from Logic 2.4 matches with ‘Study Medication’ or/and ‘Study Treatment’ from record on Logic 2.2

Logic 3:

Logic 3.1 There is a SM/SMAU/SMAB/STR ‘Study Medication’ and/or ‘Study Treatment’ with ‘last dose indicator’ selected

AND

Logic 3.2 Identify the minimum PMS1/PMST record that is on or after the record identified in Logic 3.1

AND

Logic 3.3 There is an AE with ‘Onset Date’ after PMS1/PMST from Logic 3.2 with Action Taken with ‘Study Medication’ and/or Action Taken with ‘Study Treatment’ = ‘Discontinued’

AND

Logic 3.4 ‘Study Medication’ and/or ‘Study Treatment’ from Logic 3.3 matches with ‘Study Medication’ and/or ‘Study Treatment’ on Logic 3.1

Note : For Logic 3.1 ‘last dose indicator’ refers to the item ‘Please Indicate if this is the Last Dose for this Label Description’

Logic 4:

Logic 4.1 There is a PMS1/PMST with ‘Status of Study Medication’ = ‘Adverse Event’

AND

Logic 4.2 Identify the maximum SMAB/SMAU/STR/SM ‘Study Medication’ and/or ‘Study Treatment’ on or before PMS1/PMST Date of Assessment from Logic 4.1

AND

Logic 4.3 There is no AE with ‘End Date’ On/After max SM record on Logic 4.2 and with ‘Onset Date’ On/Before PMS1/PMST. Date of assessment From logic 4.1 with Action taken with ‘Study Medication’ and/or Action taken with ‘Study Treatment’ matching ‘Study Medication’ and/or ‘Study Treatment’ from Logic 4.2 = ‘Discontinued’

Note 1: Disregard special characters when matching study medications (e.g., 'Study Medication' 3475 or -3475 are considered the same. 'Study Medication' 3475/Placebo or -3475/Placebo are considered the same).

Note 2: 'Status of Study Medication' refers to PMS1/PMST 'Status of Study Medication at the End of This Trial Segment' or 'Status of the subject at end of all Study Treatments'

Note 3: 'PD' refers to 'Progressive Disease' or 'Clinical Progression' or 'Radiographic Progression'

Note 4: For Logic 1.2 the maximum refers to the maximum 'Start Date/Time' across all records.

Note 5: For studies with multiple study medications, match AE Action Taken with Study Medication [x] with Study Medication [x] on SM/SMAU/SMAB.

Note 6: For studies with single study medication compare the ‘Overall Action Taken with Study Medication [x] with Study Medication [x] on SM/SMAU/SMAB.

Note 7: Please exclude erroneous visits and deleted records and records completed entirely as Unknown, Not Applicable or Not Done.

Note 8: Report should be run for randomized subjects only.

Note 9: Do not output if the eCRF PMS1/PMST is not initialized.

Note 10: Only consider date.

This report can also use the optional Study medication supporting document.

It is only required in the following cases:

- SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Optional supporting document should be named as study_med_match_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Label Description or Dose Number present in SM/SMAU/SMAB eCRFs.

1. eCRF – SM/SMAU/SMAB

2. Study Medication – Value of Study Medication

3. Matching Item – SM Label Description or SMAU/SMAB Dose Number

4. Matching Value – Value of SM Label Description or SMAU/SMAB Dose Number

e.g.

eCRF,Study Medication,Matching Item,Matching Value

SM,-1439,Label Description,-1439 100 mg

SM,Methadone,Label Description,Methadone Tablet 5 mg

SM,Methadone,Label Description,Methadone Tablet 10 mg

SMAB,3475/Placebo,Dose Number,3475/Placebo

SMAU,Carboplatin,Dose Number,Carboplatin

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 1

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 2

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 3

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Med Match Page".

Note 11: The report logic should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: PMS1.Date of Assessment, PMST.Date of Assessment, AE.Onset Date and Time, SMAB/SMAU/STR/SM.Start Date, SMAB/SMAU/STR/SM.Start Date/Time

Note 12:  This is a required supporting document for all studies with one or more phases.

This supporting document is required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Required supporting document should be named as study_phase_supp <xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: the order on which phases will appear on protocol

2. Treatment Phase: this information is the phase name given in the protocol (Initial Treatment Phase/Second Course Phase/Crossover/Neoadjuvant)

3. First Visitmnemonic of Treatment Phase: the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Report Scenarios:
Scenario 1/Yes:

AE is Malignant Neoplasm Progression with overall action taken with Study Medication as Discontinued, but PMS1/PMST is not discontinued per "Progressive Disease" or "Clinical Progression" or "Radiographic Progression".

Scenario 2/Yes

AE is not Malignant Neoplasm Progression with overall action taken with Study Medication as Discontinued, but PMS1/PMST is not discontinued per AE.

Scenario 3/Yes

AE with overall action taken with Study Medication as Discontinued but PMS1/PMST Date of Assessment is less than AE Start Date.

Scenario 4/Yes

Status of Study medication at PMS1/PMST is "Adverse Event", but there is no AE on or Before with overall action taken of "Discontinued" with any Study Medication.
