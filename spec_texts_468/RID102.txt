Report ID: RID102

Report Title:
SME Record with Missing Values

Description:
This report displays all SME records with null values in required fields.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Vendor Name

5. Seq #

6. Label Description

7. Start Date/Time

8. Missing Item

Logic:
Output when any of the item selected through supporting document that is missing in a SME record.

Please ignore deleted record. (Deleted Form = N)

Note 1: if Please be aware that some of the studies will have both Scheduled Time Name and Scheduled Time Number, while some other studies will not have these two items, instead there is an item called Scheduled Time, in this case, please ignore Scheduled Time Number even if it is selected through supp doc, and please treat Scheduled Time as Scheduled time name.

Note 2: Please note that some studies will not have item Test Short Name provided in eCRF and some will have this item, in this case if Test Short Name is entered as NA in supp doc and item Test Short Name is not present for trial report should not consider Test Short Name.

Requires supporting document to be named EVD024_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1) Vendorname - unique vendor name, specified as 'NA' if it is checked for all vendors.

2) Test Short Name - fill with test short name per PSA, NA if not applicable

3) Category - unique category name, NA if not applicable

4) Completion status - filled as “NULL” if the test can be missing , NA if not applicable

5-N) ITEMQUESTION1, 2, ..., (N) - filled with all columns that per PSA required to be completed

E.g:

Vendorname, Test Short Name, Category, Completion status, ITEMQUESTION1, ITEMQUESTION2, ITEMQUESTION3..., ITEMQUESTION(N)

CRFH,QUESTAT,EQ-5D-5L,NULL,Result or Finding in Original Units,Character Result/Finding in Std Format ,Domain Abbreviation

CRFH,EQ5D0201,EQ-5D-5L,NULL,Result or Finding in Original Units,Character Result/Finding in Std Format ,EVAL,EVLINX,Domain Abbreviation

Report Scenarios:
A/Y Required Item selected in parameter selection is missing

B/N Required Item selected in parameter selection is not missing

C/N deleted record

Sorting:
Country, Site, Subject Number, Seq #

Parameter Selection:
Country(ies), Site(s), Subject(s), Required Items, List of Subjects

Form.Item Names:
1. SA. Site Country

2. SA. Site Mnemonic

3. Subjects.Subject Number

4. SME. Vendor Name

5. SME. Form Index ID

6. SME. Label Description

7. SME. Start Date/Time

8. Hard code to the name of the missing item.
