Report ID: RID097

Report Title:
Missing eCOA Records

Description:
This report lists subjects that have DOV that is not null  but there are missing external eCOA records before the current maximum DOV

Column Heading:
Table 1:

1. Country

2. Site

3. Subject Number

4. Vendor

5. Category

6. Starting Time Point

7. Max Visit

8. Max DOV

9. Previous eCOA Date

10. Subsequent eCOA Date

11. Missing # of Days

Table 2:

1. Country

2. Site

3. Subject Number

4. Vendor

5. Category

6. Starting Time Point

7. Max Visit

8. Max DOV

9. Date/Time of Measurement

10. Missing # of records

11. Required number of record

Logic:
Table 1: Title = Missing eCOA Daily Records

For each subject, Vendor Name=required vendor, Category=required category, there does NOT EXIST at least 1 corresponding GEFCF records which have GEFCF. Date Time of Measurement on every day during the time span ('user provided starting time point per protocol' and 'current Maximum DOV'),

Note on output: If a Previous or Subsequent eCOA Date is equal to either the starting or stopping time point, then it's fine for the Previous or Subsequent eCOA Date to be blank (since there is no actual Date Time of Measurement to display).

* If GEFCF. Date Time of Measurement includes the time (e.g. ‘2012-02-02T09:33:00’) then use only the Date for the calculation.

* Report should not consider deleted GEFCF records / DOV records where Erroneous Visit checkbox is checked (is not null).

End of Table 1

Table 2: Title = Missing Multiple times eCOA Records within a day

For each subject,

Vendor Name=Required vendor and Category= Required Category, AND (there are less than ’X’ number of corresponding GEFCF records which have same GEFCF. Date Time of Measurement on every day) during the time span ('user provided  starting time point per protocol' and 'current Maximum DOV').

'X' need be provided by user.

* If GEFCF. Date Time of Measurement includes the time (e.g. ‘2012-02-02T09:33:00’) then use only the Date to calculate the records number on same date.

* Report should not consider deleted GEFCF records / DOV records where Erroneous Visit checkbox is checked (is not null).

* Column 9, if all the X record is missing for a single day, please hardcode the missing Date in this column; if less than X records for a single day, please display the missing Date in this column.

End of Table 2
