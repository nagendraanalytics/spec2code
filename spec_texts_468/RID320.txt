Report ID: RID320

Report Title:
Missing Lesion Evaluation - Adjuvant

Description:
This report will output when the LSNAJ eCRF is missing based on ORAJ entries and also when all ORAJ recurrences have been completed as "no" but there are entries in LSNAJ.

Column Heading:
1. Country

2. Site

3. Subject Number

4. ORAJ Seq

5. ORAJ Date

6. LSNAJ Seq

7. LSNAJ Date

8. Recurrence Location Relative to Primary Tumor

9. OSOF date

10. Scenario

Logic:
If Parameter :Recurrence Location Relative to Primary Tumor (N/Y, default as Y) = Y

Scenario 1.a

[

 Scenario 1.1:

LSNAJ Date <> Null AND LSNAJ. Recurrence Location Relative to Primary Tumor is completed <> Null AND there is NO ORAJ.Date of Assessment (Scan/Image/Physical Exam) with ORAJ. Disease Recurrence Indicator = yes with the same date of LSNAJ Date.

OR

Scenario 1.2:

LSNAJ Date <> Null AND LSNAJ. Recurrence Location Relative to Primary Tumor is completed <> Null AND there is a ORAJ.Date of Assessment (Scan/Image/Physical Exam) with ORAJ. Disease Recurrence Indicator = no with the same date of LSNAJ Date.

]

Scenario 1.b

[

 Scenario 1.1:

LSNAJ Date <> Null AND LSNAJ. Recurrence Location Relative to Primary Tumor is = Null AND there is NO ORAJ.Date of Assessment (Scan/Image/Physical Exam) with ORAJ with the same date of LSNAJ Date.

]

Scenario 2:

ORAJ.Disease Recurrence Indicator as Yes AND ORAJ.Date of Assessment (Scan/Image/Physical Exam) >= DOV [Adjuvant Phase Initial Visit] AND there is NO LSNAJ. Recurrence Location Relative to Primary Tumor completed on same date of ORAJ.Date of Current Lesion Evaluation (Scan/Image/Physical Exam).

Scenario 3:

ORAJ.Disease Recurrence Indicator as Yes AND ORAJ.Date of Assessment (Scan/Image/Physical Exam) >= OSOF.[OSOF Date item prompt] AND  OSOF.Post Op Result is "Complete Resection" AND there is NO LSNAJ. Recurrence Location Relative to Primary Tumor completed on the same date of ORAJ.Date of Current Lesion Evaluation (Scan/Image/Physical Exam)

]

If “N”, it will follow the logic(which NOT contain the item to be reviewed: Recurrence Location Relative to Primary Tumor ):

Scenario 1.a

[Scenario 1.1:

LSNAJ Date <> Null AND there is NO ORAJ.Date of Assessment (Scan/Image/Physical Exam) with ORAJ. Disease Recurrence Indicator = yes with the same date of LSNAJ Date.

OR

Scenario 1.2:

LSNAJ Date <> Null AND there is a ORAJ.Date of Assessment (Scan/Image/Physical Exam) with ORAJ. Disease Recurrence Indicator = no with the same date of LSNAJ Date.

]

Scenario 2:

ORAJ.Disease Recurrence Indicator as Yes AND ORAJ.Date of Assessment (Scan/Image/Physical Exam) >= DOV [Adjuvant Phase Initial Visit] AND there is NO LSNAJ Date = ORAJ.Date of Current Lesion Evaluation (Scan/Image/Physical Exam))..

Scenario 3:

ORAJ.Disease Recurrence Indicator as Yes AND ORAJ.Date of Assessment (Scan/Image/Physical Exam) >= OSOF.[OSOF Date item prompt] AND  OSOF.Post Op Result is "Complete Resection" AND there is NO LSNAJ Date = ORAJ.Date of Current Lesion Evaluation (Scan/Image/Physical Exam)).

]

Note 1: Deleted records should not be taken into account.

Note 2: For Column Headings below, if there is any missing data, please leave it blank (Output in Excel cell).

Note 3: LSNAJ Date in logic is taken from parameter selection: Date of Initial Identification (Scan/Image/Physical Exam) or Date of Current Lesion Evaluation (Scan/Image/Physical Exam), default as Date of Initial Identification (Scan/Image/Physical Exam)

Note 4: For column ‘OSOF Date Item’, the date values will only be populated for Scenario 3 and for Scenarios 1 and 2 will be left blank.

Note 5. If  Recurrence Location Relative to Primary Tumor is not present in the eCRF, the report should only take into account the completion of LSNAJ, understood as LSNAJ. Date of Initial Identification (date taken per Note 3)

Note 6. The completion date for Recurrence Location Relative to Primary Tumor should  follow and use the date described in the Note 3.

Report Scenarios:
Scenario 1.a.

Output Yes:

Output is produced when LSNAJ.Recurrence Location Relative to Primary Tumor is completed, but there is no ORAJ entry with Disease Recurrence Indicator completed as “yes” with the same date.

Output Yes:

when LSNAJ. Recurrence Location Relative to Primary Tumor is completed, and there is an ORAJ entry with Disease Recurrence Indicator completed as “no” with the same date.

Output No:

when LSNAJ. Recurrence Location Relative to Primary Tumor is completed, and there is an ORAJ entry with Disease Recurrence Indicator completed as “yes” with the same date.

Scenario 1.b.

Output Yes:

Output is produced when LSNAJ.Date is completed AND LSNAJ.Recurrence Location Relative to Primary Tumor is NOT completed, but there is no ORAJ entry with the same date.

Output No:

Output is produced when LSNAJ.Date is completed AND LSNAJ.Recurrence Location Relative to Primary Tumor is NOT completed, but there is an ORAJ entry with the same date.

Scenario 2

Output Yes:

Output is produced when Disease Recurrence Indicator is entered as Yes in ORAJ, with a Date of Assessment (Scan/Image/Physical Exam) on or after [Adjuvant Phase Initial Visit prompt] DOV (Date of Visit), but there is no LSNAJ. Recurrence Location Relative to Primary Tumor record completed on the same date as ORAJ.

Output No:

When Disease Recurrence Indicator entered in ORAJ is completed as No

Output No:

When the Disease Recurrence Indicator Present in ORAJ is completed as Yes and ORAJ Date of Assessment (Scan/Image/Physical Exam) is Not on or after the DOV of [Adjuvant Phase Initial Visit prompt] DOV (Date of Visit).

Scenario 3

Output Yes:

Output is produced when Disease Recurrence Indicator is entered as Yes in ORAJ, with a ORAJ Date of Assessment (Scan/Image/Physical Exam) on or after date present in selected OSOF.[OSOF Date item prompt], with OSOF.Post Op Result as "Complete Resection", but there is no LSNAJ. Recurrence Location Relative to Primary Tumor record completed on the same date as ORAJ.

Output No:

When Disease Recurrence Indicator entered in ORAJ is completed as No

Output No:

When the Disease Recurrence Indicator Present in ORAJ is completed as Yes and ORAJ Date of Assessment (Scan/Image/Physical Exam) is before the date present in selected OSOF.[OSOF Date item prompt]

Output No:

When the Disease Recurrence Indicator is entered as Yes in ORAJ, with a ORAJ Date of Assessment (Scan/Image/Physical Exam) on or after date present in selected OSOF.[OSOF Date item prompt], but OSOF.Post Op Result is different than "Complete Resection"

Output No:

When the Disease Recurrence Indicator is entered as Yes in ORAJ, with a ORAJ Date of Assessment (Scan/Image/Physical Exam) on or after date present in selected OSOF.[OSOF Date item prompt], with OSOF.Post Op Result as "Complete Resection", but there is a LSNAJ. Recurrence Location Relative to Primary Tumor record completed on the same date as ORAJ.

Sorting:
Country, Site, Subject Number, Scenario

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized only, Scenarios (free text, multiple numeric entries separated by comma, default as ALL), Adjuvant Phase Initial Visit (free text (Visitmnemonic), required, default as Null), Take into account Physical Examination for LSNAJ (N/Y, default as N), LSNAJ Date (Date of Initial Identification (Scan/Image/Physical Exam) / Date of Current Lesion Evaluation (Scan/Image/Physical Exam), default as Date of Initial Identification (Scan/Image/Physical Exam)),  OSOF Date item(Date of Surgery/Date Performed/Date of Assessment, default as "Date of Surgery"), Only required if the Scenario 3 is included in the 'Scenarios' prompt, Recurrence Location Relative to Primary Tumor (N/Y, default as Y)

Form.Item Names:
1. SA.Country

2. SA.Site

3. SA.Subject Number

4. ORAJ.Sponsor ID Number

5. ORAJ.Date of Assessment (Scan/Image/Physical Exam)

6. LSNAJ.Sponsor ID Number

7. LSNAJ.Date of Current Lesion Evaluation (Scan/Image/Physical Exam) or LSNAJ.Date of Initial Identification (Scan/Image/Physical Exam)

8.LSNAJ.Recurrence Location Relative to Primary Tumor record

9. Date present in selected OSOF.[OSOF Date item prompt].  Show this date only when the Scenario 3 is selected in paramethers

10. IF Logic scenario 1.a is used, then display “Scenario 1.a” OR

     IF Logic scenario 1.b is used, then display “Scenario 1.b” OR

    IF Logic scenario 2 is used, then display “Scenario 2”.  OR

    IF Logic scenario 3 is used, then display “Scenario 3”
