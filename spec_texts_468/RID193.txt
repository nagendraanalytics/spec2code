Report ID: RID193

Report Title:
Study Medication Status Completed Vs expected Study medication study period

Description:
Report will look for inconsistencies between Study Medication Status when entered as Completed for selected Study Medication entered in the expected Study Period.

Column Heading:
################

Logic:
<Criteria Form 1>,<Criteria Itemquestion 1> = <Criteria Value 1> AND

<Criteria Form 2>,<Criteria Itemquestion 2> = <Criteria Value 2> AND

<Criteria Form 3>,<Criteria Itemquestion 3> = <Criteria Value 3>

AND

SCENARIO 1

Logic 1:

SM_Table.SM Status <> Completed

AND

Logic2:

SM_Table.Study Period <> null

AND

Logic3:

SM_Table.Study Period <> Expected Study period for one specific study medication

SCENARIO 2

Logic 1:

SM_Table.SM Status <> NULL and SM_Table.SM Status <> Completed

AND

Logic2:

SM_Table.Study Period= Expected Study period for one specific study medication

Note: The following instruction only applies for SM form

Study period:

If SM Form=SM AND SM.Scheduled time is present in SM form THEN Study period = “<SM. Study Period> <SM.Scheduled time>”

If SM Form=SM AND If SM.Scheduled time is not present in SM form THEN Study period = SM.Study Period

If SM Form<>SM, Study period = SM_Table.Study Period

AND

Expected Study period

Expected SM for one specific study medication= Expected Study Period according to supporting document (for SM/SMAU/SMAB) AND Expected Scheduled time according to supporting document (for SM/SMAU/SMAB.)

If Scheduled time = “NA”, should be only Expected Study Period according to supporting document

Note:

1. Please exclude deleted record and erroneous visit from programming.

2. SM_Table could be SM, SMAU and SMAB form.

3. SM Status could be Label Description Status or Study medication status.

4. If user provides two Treatment Phases (Initial Treatment Phase and Second course Phase) and First Visit for each phase (Cycle 1 and Second course Cycle 1), then the report should check for SM Start Date/Time between Cycle 1 DOV (inclusive) and Second course Cycle 1 (exclusive), and for SM Form Start Date/Time after Second course Cycle 1 (inclusive).

5. If Treatment phase and First visit of corresponding phase are all entered as NA in required supp doc, then no need to compare SM date and DOV.

6. If DOV of next Treatment Phase First Visit is not initialized, SM/SMAB/SMAU record should be regarded as First Phase.

7a: If SM Label Description and SMAU/SMAB Dose Number are exactly matched within forms For SM/SMAU/SMAB Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number directly.

7b: If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_<xxxxxxx>.csv to define the mapping.

8: Check that Criteria Form 1, Criteria Item question 1, and Criteria Value 1, Criteria Form 2, Criteria Item question 2, and Criteria Value 2, Criteria Form 3, Criteria Item question 3, and Criteria Value 3 matches data on InForm for each scenario logic according to the supporting doc provided.

9: If Scheduled time is present in SM form, please consider the Study period of the SM form as “<SM. Study Period> <SM.Scheduled time>”. For example: if SM.Scheduled time is present, and SM. Study Period= Cycle 1, and SM.Scheduled time = Day 1,  then the Study period  should be “<SM. Study Period> <SM.Scheduled time>”= Cycle 1 Day 1. If SM.Scheduled time is not present at SM, then the Study period  should be “<SM. Study Period>”
