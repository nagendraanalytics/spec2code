Report ID: RID170

Report Title:
Missing SCI or Form Variation Scheduled Time vs. First Dose for this Study Medication checked in SM Form.

Description:
Report lists data from SCI or Form Variation whose ANTI-<-3475; -5180> ANTIBODIES Scheduled Time does not match what is specified in the protocol.

Column Heading:
Table 1: Logic 1

1.Country

2.Site

3.Subject Number

4.Label Description

5.Visit Mnemonic

6.Missing Scheduled Time

Logic:
Logic 1:

Logic 1.1: There is at least one non-deleted SM record that meets the following criteria:

(

Logic 1.2: SM.Label Description = "Label Description" from Supporting Document

AND

Logic 1.3: SM.Please Indicate if this is the First Dose for this Study Medication is checked

)

AND

Logic 1.4: DOV.Date of Visit from visit "Visit Mnemonic" from supporting document is NOT NULL

AND

Logic 1.5: System date > (DOV.Date of Visit – 1 day + "Days per SoA" from supporting document + "Window of Days" from supporting document + prompt "Data Entry Window")

AND

(

Logic 1.6: There is NOT at least one non-deleted “SCI form” record from supporting document that meets the following criteria:

(

Logic 1.7: SCI form.Scheduled Time = “Scheduled Time” from Supporting document

AND

Logic 1.8: SCI form.Specimen Label = “Specimen Label” from Supporting document

AND

Logic 1.9: SCI form.Date Specimen(s) Obtained = (DOV.Date of Visit – 1 day + "Days per SoA" (+/- "Window of Days"))

)

OR

Logic 1.10: “SCI form” is not initialized or all the records in the “SCI form” are deleted records

)

Clarification Notes Applicable for Logic 1:

-"Data Entry Window" is a prompt that represents the number of days that the sites have for entering the data. This prompt will be modified by the CDM any time if needed (e.g., during non-accelerated timelines is 14 days, during accelerated timelines can be 5 days, 1 day or even 0 days). The programming code should be flexible enough to meet such flexibility

-Consider only the date portion in any date/time field, time portion should be disregarded

-Erroneous visits should be excluded from programming

-The programming code will be executed for all the following combination of variables:

Requires Supporting Document to be named SCI007_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1.Label Description: Type in the name of the study medication as appear in the SM eCRF.

2.Visit Mnemonic: Type in the name of the visit as appear in T&E

3.Days per SoA: Type in the number of days according to SoA in protocol

4.Window of Days: Type in the window of days according to SoA in protocol

5.SCI form: Type in the form variation. (SCI or SCIA or SCIB)

6.Scheduled Time: Type in the scheduled time as appear in the eCRF.

7.Specimen Label: Type in the name of the specimen label as appear in the eCRF

E.g.:

Label Description, Visit Mnemonic, Days per SOA, Window of Days, SCI form, Scheduled Time, Specimen Label

-3475A, Cycle 1 Day 1, 42, 1, SCI, POSTDOSE, ANTI--3475 ANTIBODIES

-3475, Cycle 3 Day 1, 42, 1, SCI, POSTDOSE, ANTI--3475 ANTIBODIES

3475A, Cycle 1 Day 1, 42, 1, SCIA, POSTDOSE, ANTI--5180 ANTIBODIES

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Layout Notes:
