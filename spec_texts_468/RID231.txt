Report ID: RID231

Report Title:
Missing additional ULAB tests per protocol requirement

Description:
The report displays subjects who have a specified urinalysis tests with abnormal results but the required additional assessment(s) are missing.

Column Heading:
1. Country

2. Site

3.  Subject Number

4.  Visit

5. Date Specimen Collected

6. ULAB seq #

7. Main form test

8. Main form test result

9. Add entry test

10. Add entry test result

11. Missing test

12. Scenario

Logic:
Condition ULAB test meets ULAB test result condition per supporting document for the specific Group, visitmnemonic, criteria form, criteria value and criteria itemquestion.

AND

There is no ULAB.Lab Test or SLAB.Laboratory Test (depending on prompts selected SLAB:Y or SLAB:N) with ULAB.Lab Test Result or SLAB.Numeric Test Result (depending on prompts selected SLAB:Y or SLAB:N) IN [Required ULAB tests]

AND

ULAB.Enter date specimen collected for Condition ULAB test + min window of days <=ULAB.Enter date specimen collected or SLAB. Enter date/time specimen collected  <= ULAB.Enter date specimen collected for Condition ULAB test + Max window of days

Note1: Report has 3 scenarios based on the same logic. Conditions for each scenario are defined in the supporting document

Note 2: Report should not take into account Deleted records or erroneous visits

Note3: Condition ULAB test AND Required ULAB Test should be considered for both main form AND add entry form

Note4: SLAB [Y/N], Y is selected means if there's required ULAB test entered in SLAB form is acceptable, then no output.

            N means if there's required ULAB test not in ULAB form, then output.(as SLAB recording is not acceptable).

Note5: prompts: Visit Expected to check: Within visit / Across visit, means test will be checked within visit or cross visit or under any visit

Note6: If one test from the group is provided as expected per condition in the supp doc, rest of the test from the same group should NOT be outputted as missing.

Note 7: Please consider results provided in ULAB (main part or add entry) if TEST NAME match test name from supp doc

Note 8: Please display Scenario from supporting document as per logic met

Requires supporting document to be named ULAB001_supp_XXXXXXX (in csv format) and will contain the following columns and associated content:

1) Group # - Unique number to identify group of tests NOT NULL

2) Criteria Form - Unique value in each group, specified as 'NA' if it is checked for all subjects

3) Criteria Itemquestion - Unique value in each group, specified as 'NA' if it is checked for all subjects

4) Criteria Value - Unique value in each group, specified as 'NA' if it is checked for all subjects

5) Visitmnemonic - Unique value in each group, specified as 'NA' if it is checked for all visits

6) Condition ULAB test - NOT NULL

7) Condition ULAB test operator - NOT NULL. =, <, >, >= or <=

8)Condition ULAB test result - NOT NULL

9) Required ULAB test - NOT NULL. Test required if condition test result is recorded

10) Min window of days - minimum difference of days between condition test and required test

11) Max window of days - Maximum difference of days between condition test and required test

12) Scenario

Report Scenarios:
Scenario 1: There is an ULAB test record (specified in supporting document in column Condition ULAB Test) with result which meets criteria given in the supporting document (Condition ULAB test operator ; Condition ULAB test result ), but there is no ULAB/SLAB (depends on prompts selected SLAB:Y or SLAB:N) record done in the expected timeframe (defined in supporting document) for the required tests (defined in supporting document Required ULAB test).

Note: Please note that one test from the group defined in the supporting document is enough to satisfy this scenario.

Scenario 2: Lab Test result (defined in the supporting document) is equal to or greater than value from supp doc (Condition ULAB Test Result) but an entry for required Lab test within expected timeframe is missing in ULAB/SLAB (depends on prompts selected SLAB:Y or SLAB:N).

Note: If SLAB: Y Output = YES if there is no SLAB/ULAB record for the expected test done within timeframe

Scenario 3: Urine protein test result is equal to or greater than Value from supp doc (Condition ULAB Test Result) but another ULAB done within expected timeframe (defined in supporting document) is missing

Sorting:
