Report ID: RID280

Report Title:
Inconsistencies in MMR Results

Description:
This report displays inconsistencies between MMR overall result and sample tests.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. Vendor

6. Visit Name

7. Date/Time of Measurement

8. Test Short Name 1

9. Test 1

10. Kit ID 1/Specimen ID 1

11. Result or Findings in Original Units 1

12. Initial/Repeat Read 1

13. Vendor Comments 1

14. Test Short Name 2

15. Test 2

16. Kit ID 2/Specimen ID 2

17. Category 2

18. Result or Findings in Original Units 2

19. Initial/Repeat Read 2

20. Vendor Comments 2

21. Blinding Flag

22. Error Message

Logic:
Output when:

Scenario 1:

Logic 1.1:  GEFCF.Test Short Name = MMRPINTP AND GEFCF.Result or Finding in Original Units = PROFICIENT or DEFICIENT

AND

Logic 1.2: GEFCF.Test Short Name = INPOSCON AND GEFCF.Category = MLH1 OR MSH2 OR MSH6 OR PMS2 AND GEFCF.Result or Finding in Original Units = NOT ACCEPTABLE

Scenario 2:

Logic 2.1:  GEFCF.Test Short Name = MMRPINTP AND GEFCF.Result or Finding in Original Units = PROFICIENT or DEFICIENT

AND

Logic 2.2:  GEFCF.Test Short Name = SLIDEQLT AND GEFCF.Result or Finding in Original Units = NOT ACCEPTABLE

Scenario 3:

Logic 3.1:  GEFCF.Test Short Name = MMRPINTP AND GEFCF.Result or Finding in Original Units = PROFICIENT or DEFICIENT

AND

Logic 3.2:  GEFCF.Test Short Name = NCRCOACC AND GEFCF.Result or Finding in Original Units = NOT ACCEPTABLE

Scenario 4:

Logic 4.1:  GEFCF.Test Short Name = MMRPINTP AND GEFCF.Result or Finding in Original Units = PROFICIENT or DEFICIENT

AND

Logic 4.2:  GEFCF.Test Short Name = SLDSTAIN AND GEFCF.Category = MLH1 OR MSH2 OR MSH6 OR PMS2 AND GEFCF.Result or Finding in Original Units = NOT ACCEPTABLE

Scenario 5:

Logic 5.1:  GEFCF.Test Short Name = MMRPINTP AND GEFCF.Result or Finding in Original Units = PROFICIENT or DEFICIENT

AND

Logic 5.2: GEFCF.SUPPQUALA = INITIAL READ

AND

Logic 5.3: There is at least one record for the same patient as:

GEFCF.Test Short Name = PMS2 OR MSH6 OR MSH2 OR MLH1 with GEFCF.SUPQUALA <> INITIAL READ

Scenario 6:

Logic 6.1:  There is more than one record as GEFCF.Test Short Name = MMRPINTP AND SUPQUALA = INITIAL READ within the same Kit ID/Specimen ID (Use Specimen ID if Kit ID is empty)

Scenario 7:

Logic 7.1:  GEFCF.Test Short Name = MMRPINTP AND GEFCF.Result or Finding in Original Units = PROFICIENT or DEFICIENT

AND there is a record that fills the condition below for the same patient:

Logic 7.2:  GEFCF.Test Short Name = BACKGRND AND GEFCF.Category = MLH1 OR MSH2 OR MSH6 OR PMS2 AND GEFCF.Result or Finding in Original Units = NOT ACCEPTABLE

Note: 1. If Blinding Flag='B' for the test, then the following fields should display 'xxxx': Result or Findings in Original Units.

2. SUPQUALA and SUPQUALB are parameters completed by user as numbers, if SUPQUALA/SUPQUALB is completed as 'X' it would refer to column GEFCFSUPPQUALXIT/SupqualX / SuppqualX.

3. SUPQUALA is mandatory, SUPQUALB is optional, If SUPQUALA is not entered report should ask for it, if SUPQUALB is not provided columns 13 and 20 should be null for all outputs.

Report Scenarios:
Scenario 1:

Yes - MMR overall result is either Proficient or Deficient and the Internal Positive Control is Not Acceptable

No - MMR overall result <> Proficient or Deficient

No - Internal Positive Control <> Not Acceptable

Scenario 2:

Yes - MMR overall result is either Proficient or Deficient and the Slide Quality is Not Acceptable

No - MMR overall result <> Proficient or Deficient

No - Slide Quality <> Not Acceptable

Scenario 3:

Yes - MMR overall result is either Proficient or Deficient and the NCR Control is Not Acceptable

No - MMR overall result <> Proficient or Deficient

No - NCR Control <> Not Acceptable

Scenario 4:

Yes - MMR overall result is either Proficient or Deficient and the Slide Staining is Not Acceptable

No - MMR overall result <> Proficient or Deficient

No - Slide Staining <> Not Acceptable

Scenario 5:

Yes - MMR overall result is either Proficient or Deficient AND SUPQUALA = INITIAL READ and there is any test (PMS2, MSH6, MSH2, MLH1) with SUPQUALA <> INITIAL READ.

No - MMR overall result <> Proficient or Deficient for Initial Read.

No - MMR overall result = Proficient or Deficient for Initial Read and there are no repeating reads.

Scenario 6:

Yes – There are more than one MMR overall result with SUPQUALA = INITIAL READ for the same Kit ID/Specimen ID

No – There are more than one MMR overall result with SUPQUALA = INITIAL READ but not for the same Kit ID/Specimen ID

No - There is one MMR overall result with SUPQUALA = INITIAL READ.

No - There are more than one MMR overall result, but SUPQUALA is different.

Scenario 7:

Yes - MMR overall result is either Proficient or Deficient and the Background is Not Acceptable.

No - MMR overall result <> Proficient or Deficient

No – Background <> N or Not Acceptable
