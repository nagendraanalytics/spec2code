Report ID: RID370

Report Title:
New Non-Target Worsening reconciliation

Description:
This report will output if worsening of New Non-Target lesions is entered incorrectly.

Column Heading:
1. Country

2. Site

3. Subject Number

4. LSNIR Seq#

5. Date of Lesion Evaluation

6. ORIR Seq #

7. Date of Procedure for Overall Response (Scan/Image/Physical Exam)

8. New Lesion (Non-Target) Worsening

9. First New Lesion/No prior New Lesion

10. Scenario

Logic:
Scenario 1:

Logic 1.1: ORIR. New Lesion (Non-Target) Worsening <> Null

AND

Logic 1.2: There is no LSNIR record with (LSNIR.Tumor Identification = New Non-Target Extra Nodal OR New Non-Target Nodal OR New Non-Target in any prior entry done considering Date of Current Lesion Evaluation (Scan/Image/Physical Exam)).

AND

Logic 1.3. LSNIR.Study Period = ORIR.Study Period = to “Treatment Phase” from the supporting document.

Scenario 2:

Logic 2.1: LSNIR.Date of Current Lesion Evaluation (Scan/Image/Physical Exam) = ORIR. Date of Procedure for Overall Response (Scan/Image/Physical Exam)

AND

Logic 2.2: LSNIR.Tumor Identification = New Non-Target Extra Nodal OR New Non-Target Nodal OR New Non-Target

AND

Logic 2.3: LSNIR.New Non-Target Lesion Status <> Worsening OR Enlargement From Nadir OR Further Enlargement From Nadir

AND

Logic 2.4:

ORIR.New Lesion (Non-Target) Worsening = Yes

AND

Logic 2.5. LSNIR.Study Period = ORIR.Study Period = to “Treatment Phase” from the supporting document.

AND

Logic 2.6: There is no LSNIR record with (New Non-Target Lesion Status = Worsening OR Enlargement From Nadir OR Further Enlargement From Nadir) at this timepoint

Scenario 3:

Logic 3.1: ORIR.New Lesion (Non-Target) Worsening = NULL

AND

Logic 3.2: There is a LSNIR record with (LSNIR.Tumor Identification = New Non-Target Extra Nodal OR New Non-Target Nodal OR New Non-Target in any previous LSNIR record considering Date of Current Lesion Evaluation (Scan/Image/Physical Exam)).

AND

Logic 3.3. LSNIR.Study Period = ORIR.Study Period = to “Treatment Phase” from the supporting document

Scenario 4:

Logic 4.1: LSNIR.Date of Current Lesion Evaluation (Scan/Image/Physical Exam) = ORIR. Date of Procedure for Overall Response (Scan/Image/Physical Exam)

AND

Logic 4.2: LSNIR.Tumor Identification = New Non-Target Extra Nodal OR New Non-Target Nodal OR New Non-Target

AND

Logic 4.3: LSNIR.New Non-Target Lesion Status = Worsening OR Enlargement From Nadir OR Further Enlargement From Nadir

AND

Logic 4.4: ORIR.New Lesion (Non-Target) Worsening = No

AND

Logic 4.5. LSNIR.Study Period = ORIR.Study Period = to “Treatment Phase” from the supporting document

Notes :

Note 1: Report should not display deleted records.

Note 2: For LSNIR, for all scenarios, only consider records that have the item “Was the Lesion Evaluable?” = “Yes”

Note 3: If Scenario 1 is met because LSNIR form initial date is equal to date of current lesion evaluation Column Headings "9. First New Lesion/No prior New Lesion" should be completed as "First New Lesion"; otherwise, Column Heading "9. First New Lesion/No prior New Lesion" should be completed as "No Prior New Lesions".

Note 4: Scenario 2, 4 must be displayed by the report when it is satisfied and scenario 1 is not met.

Note 5: For multiple treatment phase trials, the report logic should be checked within the same treatment phase. Treatment phase is identified with item "Study Period".

Note 6: For subject that has only one treatment phase, check the logic directly without separate treatment phase.

Note 7: The Study Phase Supporting Document is required for all trials if treatment phase is applied to logic, even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Requires supporting document to be named study_phase_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Phase Order: the order on which phases will appear on protocol

2. Treatment Phase: this information is the phase name given in the protocol (Initial Treatment Phase/Second Course Phase/Crossover/Neoadjuvant)

3. First Visitmnemonic of Treatment Phase: the first visit on which treatment is expected to be administered on each phase.

e.g.

Phase Order, Treatment Phase,First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

3,Crossover Phase,Crossover Cycle 1

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Report Scenarios:
Scenario 1

Scenario 1 Output Yes:

New Lesion (Non-Target) Worsening is completed

but there is not at least one LSNIR record with tumor identification as New Non-Target Extra Nodal or New Non-Target Nodal or New Non-Target in the LSNIR evaluation which is before ORIR.Date of Procedure for Overall Response

Scenario 1 Output No:

New Lesion (Non-Target) Worsening is not completed,

and Tumor Identification is New Non-Target Extra Nodal or New Non-Target Nodal or New Non-Target compared to any prior entry.

Scenario 2

Scenario 2 Output Yes:

New Lesion (Non-Target) Worsening is Yes

and Tumor Identification is New Non-Target Extra Nodal or New Non-Target Nodal or New Non-Target but New Non-Target Lesion Status is not Worsening OR Enlargement From Nadir OR Further Enlargement From Nadir

Scenario 2 Output No:

New Lesion (Non-Target) Worsening is Yes

and Tumor Identification is New Non-Target Extra Nodal or New Non-Target Nodal or New Non-Target but there is at least oneNew Non-Target Lesion Status is Worsening OR Enlargement From Nadir OR Further Enlargement From Nadir

Scenario 3

Scenario 3 Output Yes:

New Lesion (Non-Target) Worsening is not completed,

but there is at least one previous LSNIR record with Tumor Identification as New Non-Target Extra Nodal or New Non-Target Nodal or New Non-Target

Scenario 4

Scenario 4 Output Yes:

New Lesion (Non-Target) Worsening is No

and Tumor Identification is New Non-Target Extra Nodal or New Non-Target Nodal or New Non-Target but New Non-Target Lesion Status is Worsening OR Enlargement From Nadir OR Further Enlargement From Nadir

Scenario 4 Output No:

New Lesion (Non-Target) Worsening is No

and Tumor Identification is New Non-Target Extra Nodal or New Non-Target Nodal or New Non-Target but New Non-Target Lesion Status is not Worsening OR Enlargement From Nadir OR Further Enlargement From Nadir

Sorting:
Country, Site, Subject Number, Date of Procedure for Overall Response (Scan/Image/Physical Exam) (ORIR) OR 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam) (LSNIR). If some rows of output have both ORIR date and LSNIR date, consider sort by LSNIR date first then ORIR date

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, default as N), Study Phase Page (N/Y, Default as N)

Form.Item Names:
1. SA .Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. LSNIR. Associated Lesion number (if there are more than one Lesion number for each Tumor Identification, display them all and joined by commas)

5. LSNIR. Date of Current Lesion Evaluation (Scan/Image/Physical Exam).

6. Oncologic Response - Solid Tumor - RECIST/iRECIST. Sponsor ID Number

7. Oncologic Response - Solid Tumor - RECIST/iRECIST.Date of Procedure for Overall Response (Scan/Image/Physical Exam)

8. Oncologic Response - Solid Tumor - RECIST/iRECIST.New Lesion (Non-Target) Worsening. If item is blank, display the column blank.

9. For Scenario 1, complete this column as explained in Note 3 of Logic; for Scenario 2, 3 and 4, leave this column blank.

10. Show “Scenario 1” if output meets Logic Scenario 1 and "Scenario 2" if output meets Logic Scenario 2", Show “Scenario 3” if output meets Logic Scenario 3, Show “Scenario 4” if output meets Logic Scenario 4.
