Report ID: RID215

Report Title:
Supporting documents listing

Description:
This report displays supporting documents uploaded to JR servers

Column Heading:
The report will show the headers used in each supporting document

Logic:
Logic:

Report will list supporting documents of “Report ID” present in JR servers separated by tab for a specific “Protocol”.

Note 1: “Report ID”  and “Protocol” are parameters. If “Report ID” parameter is blank, then output supporting documents of ALL reports present in JR servers separated by tab for a specific “Protocol”, including study_phase  and study_med_match  supporting document.

Note 2: If supporting document for a “Report ID” is not present in the database, then display message "Report ID_JR_STD Supporting Document Not Present for This Trial".

Note 3: If no supporting document is found for a specific “Protocol”, then display message "No Supporting Document Present for This Trial".

Note 4: “Master” prompt will be used to output master supporting documents by TAST. When using this prompt, "Protocol" and "Report ID" should be blank.

Note 5: The report will output a "Summary page" with the uploading timestamp that CDM will use for tracking purposes. This page will show the "Report ID" and the timestamp when the supporting document was uploaded to JR servers

Report Scenarios:
As specified in logic section

Sorting:
The report will output the supporting document sorted in the same way it was uploaded to JR servers.

Parameter Selection:
Protocol (text box, required, case insensitive, format /vxxxxyyy where xxxx refers to the compound while yyy refers to the protocol number, e.g., 3475123, v920123), Report ID (text box, optional, case insensitive, multiple value separated by comma. Enter Report ID without “JR_STD” suffix. e.g. ONC_LSN_003), Master (enter the name of master supporting document)

Form.Item Names:
The report will show the content used in each supporting document
