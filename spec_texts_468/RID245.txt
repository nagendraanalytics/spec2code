Report ID: RID245

Report Title:
Valid CM Sequence number for ANL

Description:
Output will be produced when the value entered in the item "Associated CM Sequence Number (From Concomitant Medication form)" does not corresponds to an analgesic medication or the value entered corresponds to a deleted CM sequence.

Column Heading:
1. Country

2. Site

3. Subject Number

4. ANL sequence number

5. ANL Medication Name

6. Associated CM Sequence Number

7. CM Medication Name

8. Medication Class

9. Scenario

Logic:
Logic 1:

ANL.Associated CM Sequence Number (From Concomitant Medication form)<>Null AND ANL.Associated CM Sequence Number (From Concomitant Medication form)= CM. Sequence Number AND CM.Medication Class Code<> “Class Code”

Logic 2:

ANL.Associated CM Sequence Number (From Concomitant Medication form)<>Null ANL.Associated CM Sequence Number (From Concomitant Medication form)= CM. Sequence Number AND ANL. Prescribed Pain Medication Name <> CM. Medication Name

Note 1: This only applies for Logic 1: For Class Code, please check for the following Medication Class Codes: (N02AA, N02AB, N02AC, N02AD, N02AE, N02AF, N02AG, N02AJ, N02AX, N01AH,N02BF, M01AE, N02BE, M01BX, M01AH, M01AB, M03BX, N02BA, H02AB, M01AX, N03AX, N02BB, R05DA, N07BC, V03AX, A03DC, N05AH, N01BB, N05BA, M01AC, N02BG, N06AA, N05CB, M02AA, N06AX, M03BC, N02AA, P02CX, R07AX, M01AG, M03BA, M03BB). If CM Medication Class Code matches at least one of the codes listed, do not show output

Note 2: Erroneous visits and deleted records are excluded from programming.

Note 3: Blank value should also output for scenario 1 and scenario 2.

Report Scenarios:
A –Yes

The entered value in ""Associated CM Sequence Number (From Concomitant Medication form)"" does not match a medication with Medication Class Code of Analgesic in CM form.

B- No

The entered value in ""Associated CM Sequence Number (From Concomitant Medication form)"" match a medication with Medication Class Code of Analgesic in CM form.

C –Yes

The Prescribed Pain Medication Name in ANL does not match with the Medication Name in CM

D –No

The Prescribed Pain Medication Name in ANL match with the Medication Name in CM

Sorting:
Site, Subject Number, ANL sequence number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects,Randomized Only (Y/N)

Form.Item Names:
1. SA. Country

2. SA. Site

3. SA. Subject Number

4. ANL. Formidx

5. ANL. Prescribed Pain Medication Name

6. ANL. Associated CM Sequence Number (From Concomitant Medication form)

7. CM. Medication Name

8. CM.Medication Class Code

9. Display 'Scenario 1' if Logic 1 is met, 'Scenario 2' if Logic 2 is met

*Note: For Column 7 CM Medication Name display the medication name of the CM with the same sequence number as the ANL. Associated CM Sequence Number
