Report ID: RID020

Report Title:
Reconciliation between AE Action Taken and Study medication

Description:
This report displays adverse events based on dosing, PMS1 Date of Assessment and AEs Start and End Dates to determine the AE Action Taken with the Study Medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Term

6. AE Onset Date

7. AE End Date

8. AE Action Taken

9. Study Medication

10. SM form

11. SM Sequence

12. Label Description/Dose Number

13. SM Start Date

14. SM Stop Date

15. Last Dose Checked for SM Stop Date

16. Phase Start Visit

17. Phase End Visit

18. Phase End Form

19. Phase End Date

20. Error Message

Logic:
This report outputs AE records in the following scenarios:

Logic 1) AE Action Taken with Study Medication(x) <> Not Applicable and there is no Study Medication record at all.

Error Message: Scenario 1

Logic 2) AE Action Taken with Study Medication(x) <> Not Applicable and AE End Date and Time < Minimum Study Medication Start Date and Time

Error Message: Scenario 2

Logic 3) AE Action Taken with Study Medication(x) = Not Applicable AND AE Onset Date and Time >= Minimum Study Medication Start Date and Time AND meets one of below logic:

a. If Condition provided within supporting document <> NA AND meet CONDRESULT then AE Onset Date <= CONDDATE

b. If Condition provided within supporting document = NA or Condition provided within supporting document is not met then AE Onset Date <= Max SM/SMAB/SMAU/STR.Stop Date/Time

Error Message: Scenario 3

Logic 4) AE Action Taken with Study Medication(x) <> Not Applicable AND meets one of below logic:

a. If Condition provided within supporting document <> NA AND CONDFORM <> SM/SMAB/SMAU/STR AND meet CONDRESULT then AE Onset Date > CONDDATE

b. If Condition provided within supporting document <> NA AND CONDFORM = SM/SMAB/SMAU/STR AND meet CONDRESULT AND SM/SMAB/SMAU/STR. Visit Mnemonic <> "Max Dose Visit" then AE Onset Date > CONDDATE + window of days

c. If Condition provided within supporting document <> NA AND CONDFORM = SM/SMAB/SMAU/STR AND meet CONDRESULT AND SM/SMAB/SMAU/STR. Visit Mnemonic = "Max Dose Visit" then AE Onset Date > CONDDATE

d. If Condition provided within supporting document = NA or Condition provided within supporting document is not met then AE Onset Date > Max SM/SMAB/SMAU/STR.Stop Date/Time + window of days

Error Message: Scenario 4

For Scenario 2, 3 and 4, report requires supporting document to be named AE030_supp_<XXXXXXX>.csv and will contain the following columns and associated content:

1. Treatment Phase - Consecutive numbers entered for every study treatment phase/period (i.e. Adjuvant phase and adjuvant phase will be treatment phase 1 and 2, or just enter as 1 for one phase)

2. Study Medication

3. SM Form - eCRF used on study, specify as NA for SM01/SM02/SM03/SM04 SM eCRFs

4. Min Dose Visit - Minimum visit where dose is expected for each phase

5. Max Dose Visit - Maximum visit where dose is expected for each phase

6. Window of Days for AE- Window of days for washout period for each phase

7. CONDFORM - Conditional form to be used (PMST/PMS1/NATS/NAPS/SM/SMAB/SMPB/STR/TACE) or NA

8. CONDITEM - Conditional item question within the form or NA

9. CONDSYMBOL - = or <> or NA

10. CONDRESULT - Condition result expected according to CONDFORM and CONDITEM or NA

11. CONDDATE - Condition Date item question according to CONDFORM or NA

12. Criteria Form - Specified as 'NA' if logic is applicable for all subjects

13. Criteria Itemquestion - Specified as 'NA' if logic is applicable for all subjects

14. Criteria Value - Specified as 'NA' if logic is applicable for all subjects

e.g.

Treatment Phase,Study Medication,SM Form,Min Dose Visit,Max Dose Visit,Window of Days for AE,CONDFORM,CONDITEM,CONDSYMBOL,CONDRESULT,CONDDATE,Criteria Form,Criteria Itemquestion,Criteria Value

1,1234,SM,Cycle 1 Adjuvant,Cycle 4 Adjuvant,34, SM,Label Description Status,<>,NULL,Stop Date/Time,SR,Arm,Arm 1

1,-3475/Placebo,SMAB,Cycle 1,Cycle 17,30,SMAB,Study Medication Status,<>,NULL,Stop Date/Time,SR,Stratification,Stratum 1

2,-3475/Placebo,SMAB,Cycle 1 Course 2,Cycle 17 Course 2,30,NATS,Study Treatment Not Received,=,Adjuvant Treatment,Date of Assessment,SR,Stratification,Stratum 1

1,5678,SM,Cycle 1 Neoadjuvant,Cycle 17 Neoadjuvant,28,PMS1,Trial Segment Reference,=,End of Neoadjuvant Treatment,Date of Assessment,NA,NA,NA

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Note 1: Items 7 to 11 need to be included when an specific condition is needed for the report to produce an output for scenarios 3 and 4. Report will only output when the value of CONDITEM in CONDFORM is compared with CONDRESULT is satisfied.

Note 1a: If items 7 to 11 are completed as NA, report will use the Maximum dose of Study Medication plus washout period (Window of Days for AE).

Note 1b: if items 7 to 11 are provided, report will use the date provided on the CONDDATE column when the conditions are met.

Note 2: Please exclude deleted records and erroneous visits from programming.

Note 3: UNK Time should be considered as 00:00.

Note 4: When Time component is missing in one of the eCRFs, please output time as 00:00:00.

Note 5a: For studies with single study medication, Overall Action Taken is checked and the match on Study Medication is not performed.

Note 5b: For studies with multiple study medications, match Study Medication [x] on AE with Study Medication [x] on SM related forms.

Note 6a: IF SM Label Description and SMAU/SMAB Dose Number are exactly matched within forms For SM/SMAU/SMAB Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number directly.

Note 6b: If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_<XXXXXXX>.csv to define the mapping.

Note 7: If more than one condition is provided the hierarchy for programming should be: PMST;PMS1;NATS;NAPS;SM/SMAB/SMPB/STR

Note 8: Just non-zero dose is considered, which means Number of Units Taken in SM related forms is greater than 0.

Note 9: If Criteria(s) are provided as 'NA' in the supporting doc (columns 12-14), check gap or overlap for all subjects.

Note 10: The following AE entries are excluded from ALL logics:

- Any AE entry with the item "Serious Criteria (check all that apply)" NOT "None"

- Any AE entry with the item "Is the AE an Event of Clinical Interest?" = "Yes"

Note 11: The report uses the following treatment phases definition applicable to Scenario 2, 3 and 4 and for SM and AE form

Treatment phase for SM form:

TX phase 1: First Visit of TX phase 1 <= SM Form.Start Date/Time < First Visit of TX phase 2 if exists

TX phase 2: First Visit of TX phase 2 <= SM Form.Start Date/Time < First Visit of TX phase 3 if exists

Treatment phase for AE form:

1. Only Overall Action Taken item exists:

a. Only one TX phase:

No treatment phase definition will be implemented for AE form

b. Multiple TX phases:

TX phase 1: AE.Onset Date and Time < First Visit of TX phase 2

TX phase 2: First Visit of TX phase 2 <= AE.Onset Date and Time < First Visit of TX phase 3 if exists

2. Individual Action Taken items exist:

a. For corresponding SM having just one TX phase:

No treatment phase definition will be implemented for AE form

b. For corresponding SM having multiple TX phases:

First TX phase: AE.Onset Date and Time < First Visit of its own TX phase 2

Second TX phase: First Visit of its own TX phase 2 <= AE.Onset Date and Time < First Visit of its own TX phase 3 if exists

Note 12: For Scenario 3 and 4 and condition b/c:

- If the SM form is visit-based, then use the visit mnemonic where the SM record is located for comparison

- If the SM form is a common form, then the report will compare the CONDDATE with the maximum DOV entered to define which condition is met, for example:

If DOV from "Max Dose Visit" is not initialized or "Erroneous visit" is checked, then condition b is met

If DOV from "Max Dose Visit" is initialized and "Erroneous visit" is NOT checked and CONDDATE < DOV.Date of Visit then condition b is met

If DOV from "Max Dose Visit" is initialized and "Erroneous visit" is NOT checked and CONDDATE >= DOV.Date of Visit then condition c is met

This report can also use the optional Study medication supporting document.

It is only required in the following cases:

- SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Optional supporting document should be named as study_med_match_supp_<XXXXXXX>.csv and will contain the following columns and associated content:

1 row for each Label Description or Dose Number present in SM/SMAU/SMAB eCRFs.

1. eCRF – SM/SMAU/SMAB

2. Study Medication – Value of Study Medication

3. Matching Item – SM Label Description or SMAU/SMAB Dose Number

4. Matching Value – Value of SM Label Description or SMAU/SMAB Dose Number

e.g.

eCRF,Study Medication,Matching Item,Matching Value

SM,-1439,Label Description,-1439 100 mg

SM,Methadone,Label Description,Methadone Tablet 5 mg

SM,Methadone,Label Description,Methadone Tablet 10 mg

SMAB,3475/Placebo,Dose Number,3475/Placebo

SMAU,Carboplatin,Dose Number,Carboplatin

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 1

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 2

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 3

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Med Match Page".

Report Scenarios:
Scenario 1) Output = YES

AE Action Taken with Study Medication(x) <> Not Applicable and there is no Study Medication record at all OR AE Action Taken with Study Medication(x) <> Not Applicable and AE End Date and Time < Minimum Study Medication Start Date and Time.

Scenario 2) Output = YES

AE Action Taken with Study Medication(x) = Not Applicable AND AE Onset Date and Time >= Minimum Study Medication Start Date and Time AND <= DOV of Max Dose Visit + window of days AND Date of Visit of condition provided within supporting document is present.

Scenario 3) Output=YES

AE Action Taken with Study Medication(x) <> Not Applicable and AE Onset Date > DOV of Max Dose Visit + Window of days AND Date of Visit of condition provided within supporting document is present

Scenario 4) Output = NO

AE Action Taken with Study Medication(x) = Not Applicable and AE started and ended prior to any study medication intake or after Max dose visit + Window of Days

Scenario 5) Output = NO

AE Action Taken with Study Medication(x) <> Not Applicable and AE started during dosing and prior to Max dose visit + Window of Days

Scenario 6) Output = NO

Records in erroneous visits and deleted record.
