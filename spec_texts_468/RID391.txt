Report ID: RID391

Report Title:
Missing Scheduled Scan

Description:
This report will list subjects who are missing a scheduled scan on OSCN for every protocol-defined timepoint

Column Heading:
1.    Country

2.    Site

3.    Subject Number

4.    Starting Point

5.    Starting Point Date

6.    Type of Image

7.    Anatomical Location

8.    Expected Timeframe

Logic:
Scenario 1:

Logic 1.1 Screening DOV.Date of Visit date <> NULL

AND

Logic 1.2 SR.Date of Assessment <> NULL

AND

Logic 1.3 There is not at least 1 OSCN that OSCN.Scan Date =< SR.Date of Assessment

with OSCN.Type of Image = ‘Type of Image’ as specified in supporting document within a ‘Group’ for selected ‘Criteria Value’ in ‘Criteria Form’

AND

with OSCN. Anatomical Location = ‘Anatomical Location’ as specified in supporting document within a ‘Group’ for selected ‘Criteria Value’ in ‘Criteria Form’

Scenario 2:

Logic 2.1 System date > 'Upper Value of Expected Timeframe'

AND

Logic 2.2 There is no OSCN. Scan Date within the 'Expected Timeframe' for each OSCN ‘Type of Image’ within a ‘Group’ for selected ‘Criteria Value’ specified in supporting document OR There is no OSCN. Anatomical Location within the 'Expected Timeframe' for each OSCN ‘Anatomical Location’ within a ‘Group’ for selected ‘Criteria Value’ specified in supporting document

AND

(Logic 2.3 There is not at least one record on the 'Oncologic Treatment' form with ODBX.Date <> NULL

OR 'Expected Timepoint' is before the minimum ODBX.Date entered across all records present in the form

AND

Logic 2.4 There is not at least one record on the 'Oncologic Radiation' form with ORAD2.Start Date <> NULL AND ORAD2.Reason <> Palliative

OR 'Expected Timepoint' is before the minimum ORAD2.Start Date entered across all records present in the form)

AND

Logic 2.5 There is not at least one record on the 'Oncologic Surgery' form with OSOFX.Date <> NULL

OR 'Expected Timepoint' is before the minimum OSOFX.Date entered across all records present in the form)

AND

(

Logic 2.6 PMS1 is not completed

OR

There is no

(

Logic 2.7 PMS1.Select the Status of the Subject for the Next Trial Segment IS as ‘Next Trial Segment from PMS1’ in supporting document

AND

Logic 2.8 ’End of Response eCRF’ from Supporting Document in which Date of Assessment < 'Expected Timepoint'

)

OR

Logic 2.9 PMS1.Select the Status of the Subject for the Next Trial Segment IS NOT as ‘Next Trial Segment from PMS1’ in supporting document and PMS1.Date of Assessment < ‘Expected Timepoint’

)

AND

(

Logic 2.10 The subsequent treatment phase 'First Visitmnemonic of Treatment Phase' DOV.Date of Visit  is NULL

AND

Logic 2.11 'the upper limit date of the Expected Timeframe'< DOV.Date of Visit of the subsequent treatment phase 'First Visitmnemonic of Treatment Phase' OR SR.Date of Assessment

)

Notes:

1- ‘Criteria Form’, ‘Criteria Item’, ‘Criteria Value’, ‘Phase Order’, ‘Minimal start timepoint’, ‘Group’, ‘Type of Image’, ‘Anatomical Location’, ‘Frequency’, ‘Lower Window of Days’, ‘Upper Window of Days’, ‘Next Trial Segment from PMS1’, ‘End of Response eCRF’, ‘Start Week’, ‘Stop Week’, 'Oncologic Treatment', 'Oncologic Radiation', and 'Oncologic Surgery’ are values from supporting document. ‘Expected Timepoint’ and ‘Expected Timeframe’ are values created by calculation.

2-      ODBX.Date = Imputed Start Date of Regimen/Imputed Start Date of Medication. Use by default 'Imputed Start Date of Regimen'. For newer trials where 'Imputed Start Date of Regimen' is not available use 'Imputed Start Date of Medication'. ODBX forms are included in global supporting document ODBF_supp_doc.

3-      ORAD2.Reason <> Palliative refers to the item 'Reason for Radiation' <> 'Palliative Treatment or Symptom Control' OR 'Palliative Treatment or Symptom Control of Metastatic Disease' for older studies and 'Treatment Category' <> 'Palliative' for newer studies.

4-     OSOFX.Date = Date of Surgery in global supporting document OSOF_supp_doc

5-     Report will work for randomized patients only

6-     Erroneous visits and deleted records will not be considered for programming

7-     When ORAD2.Date or OSOFX.Date are entered as UNK, consider the value as 01 for the day and Jan for the month. Example. UNK/UNK/2020 will be considered as 01/Jan/2020.

8-     If 'Oncologic Treatment' from supporting document is entered as NA, then the report will ignore Logic 2.3

9-     If 'Oncologic Radiation' from supporting document is entered as NA, then the report will ignore Logic 2.4

10-     If 'Oncologic Surgery' from supporting document is entered as NA, then the report will ignore Logic 2.5

11-     If a date is displayed in the output the report will display it in format 'DDMMMYYYY'

12-     For column 8 the report will display the expected timeframe in format 'DDMMMYYYY to DDMMMYYYY' e.g., '01JAN2020 to 15JAN2020'

13-     For column 6 the report will display the result of 'Start week' + N*Frequency. Where N starts at 0 and increments by 1 for each expected timeframe.

14-     For Scenario 2 the 'stop week' can be entered as NA if per protocol imaging assessments should be performed until disease progression, death, withdrawal, the end of the study etc and does not truly mention a real 'stop week'. For these cases the report will consider 'stop week' as system date and will continue output missing lesion evaluations until PMS1A/OEDRA Date of Assessment is less than 'Expected Timeframe' according to the Logic 2.8.

15-     'Expected Timeframe' and ‘Expected Timepoint’ will be calculated using the items ‘Minimal start timepoint', 'Start week', 'Stop week', 'Frequency', 'Lower window of days', 'Upper window of days'.

Steps to calculate the 'Expected Timeframe':

A.      Calculate different timepoints by doing the following mathematical operation:

‘Expected Timepoint’ 1: First Visitmnemonic of Treatment Phase OR SR.Date of assessment + Start week

‘Expected Timepoint’ 2: First Visitmnemonic of Treatment Phase OR SR.Date of assessment  + Start week + 1*Frequency

‘Expected Timepoint’ 3: First Visitmnemonic of Treatment Phase OR SR.Date of assessment + Start week + 2*Frequency

‘Expected Timepoint’ N: First Visitmnemonic of Treatment Phase OR SR.Date of assessment + Start week + (N-1)*Frequency

B.      ‘Expected Timepoint’ calculated on step A should be: First Visitmnemonic of Treatment Phase OR SR.Date of assessment + Start week <= Timepoint N <= First Visitmnemonic of Treatment Phase OR SR.Date of assessment + Stop week

C.      ‘Expected Timeframe’ = From ‘Expected Timepoint’ N - 'Lower window of days' to ‘Expected Timepoint’ N + 'Upper window of days'

16 – For Logic 2, if Expected Timeframe of treatment phase X overlaps with start date of treatment phase X+1 then no output should be produced for treatment phase X. For example: if phase 2 starts on 14Feb2018, ‘45 week’ check for phase 1 is on 10FEB2018 and acceptable timeframe is 03FEB2018~17FEB2018 (lower and upper window is 7 days) then no output is produced for ‘45 week’.

17-     If supporting doc is not provided, display the message as "ONC_OSCN_003_JR_STD Supporting Document Not Present for This Trial"

Requires supporting document to be named ONC_OSCN_003_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Criteria Form – eCRF in which Criteria Item can be found. Item is optional and if not used, please enter NA.

2. Criteria Item – item that value would differentiate scan schedule, eg. Cohort 1 would have scan frequency every 12 weeks and Cohort 2 would have scan frequency 16 weeks. Item is optional and if not used, please enter NA.

3. Criteria Value – value of the Criteria item. Item is optional and if not used, please enter NA.

4. Phase Order – Enter the number corresponding to the order in which each treatment phase occurs e.g. if your study has Initial Treatment Phase and Second Course Treatment Phase, then, Initial Treatment Phase should be 1 and Second Course Treatment Phase should be 2. This value should match with the 'Phase Order' column from global study phase supporting document. Item is required.

5.      Minimal start timepoint – DOV.Date of Visit OR Date of Assessment of SR. Enter ‘DOV’ if study wants to use the Minimal start timepoint as DOV of visit from study_phase_supp or ‘SR’ if minimal start point for first treatment phase should be set as Date of assessment from SR eCRF.

6. Group – item used to group the Type of Image if there is more than one type of image that can be performed. Item is required.

7. Type of Image –Enter expected type of image that is consistent with pulldown list in the OSCN Type of Image item (eg. MRI, CT Scan). Item is required.

8. Anatomical Location – Enter expected anatomical location consistent with options available on this item on OSCN eCRF (i.e. Abdomen, Whole Body, Brain etc.). If not applicable for your study complete as ‘NA’.

9. Frequency - Enter the number of weeks when each lesion should be assessed from start week e.g., 'The imaging assessment should be performed at Week 6 (42 ± 7 days), Week 12 (84 ± 7 days) and Week 18 (126 ± 7 days) from the date of randomization', then enter 6. If the frequency changes during the same treatment phase a new row is expected with a new frequency e.g., 'Subsequent tumor imaging should be performed every 9 weeks (63 days ±7 days) until week 45', then enter 9. The value should always be in weeks. Item is required.

10. Lower window of days – Enter the amount of days corresponding to the window applicable for each imaging timepoint e.g., 'imaging scans will occur every 6 weeks +/- 7', then enter 7. Item is required.

11. Upper window of days – Enter the amount of days corresponding to the window applicable for each imaging timepoint e.g., 'imaging scans will occur every 3 weeks +/- 7', then enter 7. Item is required.

12. Next Trial Segment from PMS1 – value from the item PMS1.Select the Status of the Subject for the Next Trial Segment. Please enter the value after which scan schedule would be continued (eg. Continuing into Safety Follow-Up Phase).

13. End of Response CRF – represents PMS1A or OEDRA, which Date of Assessment is always a cutoff date for the scan schedule in Logic 2.8.

14. Start Week - enter the week when the first lesion evaluation should occur from first visit applicable to each frequency e.g., 'The imaging assessment should be performed at Week 6 (42 ± 7 days), Week 12 (84 ± 7 days) and Week 18 (126 ± 7 days) from the date of randomization.', then enter 6. If the frequency changes during the same treatment phase then a new row is expected with a new start week e.g., 'Subsequent tumor imaging should be performed every 9 weeks (63 days ±7 days) until week 45' then enter 27 (last stop week + new frequency 18+9 = 27) as the new start week. The value should always be in weeks.

15. Stop Week - Enter the stop week when the last lesion evaluation should occur applicable to each frequency e.g., 'The imaging assessment should be performed at Week 6 (42 ± 7 days), Week 12 (84 ± 7 days) and Week 18 (126 ± 7 days) from the date of randomization.', then enter 18. If the frequency changes during the same treatment phase then a new row is expected with a new stop week e.g., 'Subsequent tumor imaging should be performed every 9 weeks (63 days ±7 days) until week 45' then enter 45 as the new stop week. Do NOT overlap start and stop week between multiple rows. If there is no 'stop week' simply enter as 'NA' and the report will output missing lesion evaluations until PMS1A/OEDRA is completed e.g., 'The first on study imaging assessment should be performed at 12 weeks (84 days ±7 days) after the restart of treatment. Subsequent tumor imaging should be performed every 12 weeks (84 days ±7 days) or more frequently if clinically indicated' then enter 'NA' as the stop week. The value should always be in weeks.

16. 'Oncologic Treatment': Complete with the form that contains Oncologic Medication treatments administered during FU phase eg. ODBF. Complete with NA if imaging can continue during new medication regimen

17. 'Oncologic Radiation': Complete with the form that contains Oncologic Radiation treatments administered during FU phase eg. ORAD2. Complete with NA if imaging can continue during new radiation regimen

18. 'Oncologic Surgery': Complete with the form that contains Oncologic Surgical treatments administered during FU phase eg. OSOF. Complete with NA if imaging can continue after surgical intervention.

Criteria Form, Criteria Item, Criteria Value, Phase Order, Minimal start timepoint, Group, ‘Type of Image’, ‘Frequency’, ‘Lower Window of Days’, ‘Upper Window of Days’, ‘Next Trial Segment from PMS1’, ‘End of Response eCRF’, ‘Start Week’ and ‘Stop Week’, 'Oncologic Treatment', 'Oncologic Radiation', and 'Oncologic Surgery’ are values from supporting document. ‘Expected Timepoint’ and ‘Expected Timeframe’ are values created by calculation.

18-     The supporting document is required for all trials if treatment phase is applied to logic, even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required,the order on which phases will appear on protocol

2. Treatment Phase: name of each study phase (Intial Treatment Phase, Neodjuvant Phase, Secon Course Phase)

3. First Visitmnemonic of Treatment Phase: required,the first visit on which treatment is expected to be administered on each phase.

19-     The report logic should be checked within the same treatment phase defined in the study phase supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

20- For Scenario 1, Columns ‘Starting Point’, ‘Starting Point Date’, ‘Week’ should not be displayed (please leave them blank). For ‘Expected Timeframe’ for this scenario, please display ‘Screening assessment’ instead of the one calculated in Note 14.

21- If for a particular location, if anyone type of image is present in inform but if it is not present between the expected timeframe then report should produce an output. If for a location, if all type of images are missing in inform which is given in the supp doc, then all the type of images should be displayed in the output.

There is at least one OSCN.Scan Date for Type of Image and/or Location within a Group specified in supporting document for each expected timeframe according to the start/stop week and frequency from date of randomization OR cycle 1 of each treatment phase and for each OSCN record that belong to each treatment phase

C.      Patient is not randomized
