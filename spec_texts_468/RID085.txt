Report ID: RID085

Report Title:
Duplicate LABS Records

Description:
This report lists all subjects with duplicate LABS records.

Column Heading:
Column Headings

1. Country

2. Site

3. Screening Number

4. Subject Number

5. Vendor

6. Visit ID or Number

7. Vendor Visit Type

8. Lab Test ID

9. Lab Test Name

10. Lab Collection Date/Time

11. Specimen ID

12. Accession Number

13. Results

14. Seq

Logic:
The report should output LABS records where LABS.Site ID or Number, LABS.Subject ID or Number, Test AND AND All items EXCEPT for the selected items from parameter " LABS items to exclude" are equal

. Parameter "LABS items to exclude " allows user to select items that can be equal or different within the record and should not be used to consider duplicates. This parameter can contain the following items:

1.*Transmission Source ID

2.*Visit ID or Number

3.*Visit Name

4.*Visit Type

5.*Accession ID or Number

6.*Record Extension Type

7.*Actual Collection Date and Time

1. Report should not display deleted records.

2. If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization

number that is not null.

3. If Blinding flag='B' for LABS then the following fields should display 'xxxx': Results.                                                                                                                                                                                                                                                                                           4. Collection Date and Time field is formatted according to the ISO standard. An example for 12-Jul-2007 at noon is: 2007-07-12T12:00:00 (yyyy-mm-ddThh:mm:ss). However, not all time parts are always present.

4. If item selected on parameter " LABS items to exclude "=Null, that should be also considered as duplicate value. Per default, the report should consider items in Data Type such as Study Identifier, Site ID or Number, Screen ID or Number or Subject ID or Number to exclude duplicates.

Report Scenarios:
Report Scenarios A)

Output=Yes

Output= No

If LABS.Site ID or Number, LABS.Subject ID or Number, test <> AND is  present in selected items on parameter " LABS items to exclude "
