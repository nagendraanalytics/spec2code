2. LOGIC UNDERSTANDING
======================================================================
This spec identifies discrepancies in scheduled times across three paired-form comparisons: LSN-vs-RSP/ORAJ (Logic 1/Scenario 1), OSCN-vs-RSP/ORAJ (Logic 2/Scenario 2), and LSN-vs-OSCN (Logic 3/Scenario 3), where each comparison flags a subject when two forms share the same clinical assessment date but have mismatched scheduled times. Scenario 2 and 3 are conditionally suppressed per Note 4 if OSCN Scheduled Time isn't collected in the study, and deleted records are excluded throughout (Note 1). A key ambiguity is the ORAJ form referenced in Logic 1 and 2, which is not explicitly defined or reflected in the Column Headings, requiring clarification before coding.

1. Logic 1 (Scenario 1) has two OR'd sub-conditions, each requiring BOTH a scheduled-time mismatch AND a date match to trigger. Sub-condition A (Logic 1.1 AND 1.2): LSN.'Scheduled time' does NOT equal RSP.'Scheduled time' (Logic 1.1), AND at the same time 'Date of Lesion Evaluation' equals RSP.'Date Response Determined' (Logic 1.2) - meaning the LSN and RSP records represent the same clinical assessment date but were scheduled at different times, which is the discrepancy being flagged.
2. Logic 1 sub-condition B (Logic 1.3 AND 1.4): as an alternative (OR) to sub-condition A, LSN.'Scheduled time' does NOT equal ORAJ.Scheduled Time (Logic 1.3), AND 'Date of Lesion Evaluation' equals ORAJ.Date of Assessment (Scan/Image/Physical Exam) (Logic 1.4) - same pattern as sub-condition A but comparing LSN against ORAJ instead of RSP, again meaning same-date but different scheduled-time is a discrepancy.
3. If either sub-condition A or sub-condition B of Logic 1 is true, the overall Logic 1 is satisfied and the record is flagged as 'Scenario 1'.
4. Logic 2 (Scenario 2) mirrors the structure of Logic 1, but compares OSCN (Oncologic Scan) records instead of LSN records. Sub-condition A (Logic 2.1 AND 2.2): OSCN.Scheduled Time does NOT equal RSP.'Scheduled Time' (Logic 2.1) AND OSCN.Scan Date equals RSP.'Date Response Determined' (Logic 2.2) - i.e., same assessment date but different scheduled times between the Scan and RSP records.
5. Logic 2 sub-condition B (Logic 2.3 AND 2.4): as an alternative (OR), OSCN.Scheduled Time does NOT equal ORAJ.Scheduled Time (Logic 2.3) AND OSCN.Scan Date equals ORAJ.Date of Assessment (Scan/Image/Physical Exam) (Logic 2.4) - same pattern comparing OSCN against ORAJ instead of RSP.
6. If either sub-condition A or B of Logic 2 is true, Logic 2 is satisfied and the record is flagged as 'Scenario 2'. Per Note 4, Logic 2 (and Scenario 2) should only be evaluated if OSCN 'Scheduled Time' is actually collected/present in the study.
7. Logic 3 (Scenario 3) is a single AND-combined condition (no OR branches), all three sub-conditions must be true together: (3.1) LSN.Date of Initial Identification equals LSN.Date of Lesion Evaluation time - meaning the lesion was first identified on the same date as its evaluation; AND (3.2) LSN.'Scheduled time' does NOT equal OSCN.'Scheduled' time; AND (3.3) LSN.Date of Initial Identification equals OSCN.Scan Date - meaning the lesion's initial identification date lines up with the scan date, but the scheduled times between LSN and OSCN differ.
8. If all three sub-conditions of Logic 3 are true, the record is flagged as 'Scenario 3'. Per Note 4, this scenario is only evaluated if OSCN 'Scheduled Time' is present in the study - otherwise it's skipped entirely.
9. Across all three Logic blocks, deleted records must be excluded first (Note 1) before any of the above date/time comparisons are made, since a deleted LSN, OSCN, RSP, or ORAJ record should not be used in the matching logic.
10. For each subject/record combination where any of Logic 1, Logic 2, or Logic 3 is satisfied, the report displays the corresponding Scenario label ('Scenario 1', 'Scenario 2', or 'Scenario 3') along with the LSN, Scan, and RSP form/date/scheduled-time details as listed in the Column Headings, and marks it as discrepant ('Yes'); the Report Scenarios section indicates 'No' is shown when the logic is not satisfied - though it's inferred this means non-flagged combinations are either excluded from the listing or shown with a 'No' indicator, since the report's Description states it 'will list subjects that have discrepancies', suggesting only 'Yes' rows are typically included.
