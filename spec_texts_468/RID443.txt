Report ID: RID443

Report Title:
Symptomatic Skeletal Related Event versus Adverse Event Reconciliation

Description:
This report lists subjects who have SSRE whose Skeletal Related Event Start Date is before AE Onset Date or after AE End Date which is associated by AE Sequence Number in SSRE form.

Column Heading:
1. Country

2. Site

3. Subject Number

4. SSRE Sequence

5. SSRE Start Date

6. SSRE Associated sequence number

7. AE Onset Date

8. AE End Date

9. Scenario

Logic:
Logic 1

There is a record in SSRE form with the item SSRE.Associated AE Sequence Number (from AE Form) Related to New Symptomatic Bone Fracture <> Null

AND

SSRE form with the item SSRE.Associated AE Sequence Number (from AE Form) Related to New Symptomatic Bone Fracture = AE.Formidx

AND

SSRE.Start Date of SSRE < AE.Onset Date and Time of associated AE.

Note 1:For Error Message please display : Scenario 1.

Note 2: Disregard deleted rows in SSRE.

Note 3: If the associated AE is deleted please displays in Error Message: Associated AE Erased

Logic 2

There is a record in SSRE form with the item SSRE.Associated AE Sequence Number (from AE Form) Related to New Symptomatic Bone Fracture <> Null

AND

SSRE form with the item SSRE.Associated AE Sequence Number (from AE Form) Related to New Symptomatic Bone Fracture = AE.Formidx

AND

SSRE.Start Date of SSRE > AE.End Date and time of associated AE.

Note 4:For Error Message please display : Scenario 2.

Note 5: Disregard deleted rows in SSRE.

Note 6: If the associated AE is deleted please displays in Error Message: Associated AE Erased

Report Scenarios:
Output = Yes

Which satisfies logic

Output = No

Which doesn’t satisfy logic

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N)

Form.Item Names:
1. SA. Country

2. SA. Site

3. SA. Subject Number

4. SSRE. Sponsor ID Number

5. SSRE. Start Date of SSRE

6. SSRE. Associated AE Sequence Number (from AE Form) Related to New Symptomatic Bone Fracture

7. AE. Onset date and Time

8. AE. End date and time

9. Error Message: If applies logic 1 please display “Scenario 1” If applies logic 2 please display “Scenario 2”
