Report ID: RID393

Report Title:
Lesion Evaluation and Oncologic Response after Surgical visit date

Description:
This report will list subjects with data entered in Lesion Evaluation and Oncologic Response forms that are after Surgical visit date

Column Heading:
1. Country

2. Site

3. Subject number

4. Surgery form

5. Surgery sponsor ID #

6. Surgery date

7. Post Op result

8. Lesion evaluation form

9. Lesion evaluation sponsor ID #

10. Lesion evaluation date

11. Response form

12. Response sponsor ID #

13. Response date

14. Scenario

Logic:
Logic 1

Oncologic Surgery Form.Post Op Result = Post Op Result, as provided in supporting doc

AND

Lesion evaluation form. Lesion evaluation date item

> Oncologic surgery form. Oncologic surgery date item

Logic 2

Oncologic Surgery Form.Post Op Result = Post Op Result, as provided in supporting doc

AND

Oncologic response form. Oncologic response date item

 > Oncologic Surgery Form. Oncologic surgery date item

Requires supporting document to be named ONC_OSOF_001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

Lesion evaluation form – Enter the lesion evaluation form that should be used before the surgery visit, depending on study design;

Lesion evaluation date item – Provide the name of the item in the lesion evaluation form, that should be compared with the date of surgery;

Oncologic response form – Enter the response form that should be used before the surgery visit, depending on study design;

Oncologic response date item - Provide the name of the item in the response form, that should be compared with the date of surgery;

Oncologic surgery form – Enter the surgery form used in the surgery visit, depending on study design;

Oncologic surgery date item - provide the name of the item in the surgery form, that should be compared with the dates in Lesion evaluation form and Oncologic response form;

Post Op Result – list all values in Oncologic surgery form, for which output should be present; each value is to be entered in a separate row.

For example:

Lesion evaluation form, Lesion evaluation date item, Oncologic response form, Oncologic response date item, Oncologic surgery form, Oncologic surgery date item, Post Op Result

LSNEV, Date of Assessment, ORST, Date Response Determined, STOS, Date of Surgery, Complete Resection-R0

LSNEV, Date of Assessment, ORST, Date Response Determined, STOS, Date of Surgery, Incomplete Resection-R1

Note 1: Do not produce output for deleted entries

Note 2: If the Day is UNK, use the 1st day of the month; if time is UNK use ‘23:59’.

Report Scenarios:
Scenario A – Output: Yes

Oncologic Surgery Form.Post Op Result = Post Op Result, as provided in supporting doc

AND

Lesion evaluation form. Lesion evaluation date item > Oncologic Surgery Form. Oncologic surgery date item

Scenario B – Output: No

Oncologic Surgery Form.Post Op Result = Post Op Result, as provided in supporting doc

AND

(Lesion evaluation form. Lesion evaluation date item < Oncologic Surgery Form. Oncologic surgery date item  OR Lesion evaluation form. Lesion evaluation date item = Oncologic Surgery Form. Oncologic surgery date item )

Scenario C – Output: No

Oncologic Surgery Form.Post Op Result <> Post Op Result, as provided in supporting doc

Scenario D – Output: Yes

Oncologic Surgery Form.Post Op Result = Post Op Result, as provided in supporting doc

AND

Oncologic response form. Oncologic response date item > Oncologic Surgery Form. Oncologic surgery date item

Scenario E – Output: No

Oncologic Surgery Form.Post Op Result = Post Op Result, as provided in supporting doc

AND

(Oncologic response form. Oncologic response date item < Oncologic Surgery Form. Oncologic surgery date item  OR Oncologic response form. Oncologic response date item = Oncologic Surgery Form. Oncologic surgery date item )

Sorting:
Country, Site, Subject Number, Oncology Surgery Form.Sponsor ID Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, default as N), Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Oncologic surgery form, as provided in the supporting doc

5. Oncologic surgery form.Sponsor ID Number.

6. Oncologic surgery form.Oncologic surgery date item

7. Oncologic surgery form.Post Op Result

8. Lesion evaluation form, as provided in the supporting doc

9. Lesion evaluation form.Sponsor ID Number (leave blank for Logic 2)

10. Lesion evaluation form.Lesion evaluation date item  (leave blank for Logic 2)

11. Oncologic response form, as provided in the supporting doc

12. Oncologic response form.Sponsor ID Number (leave blank for Logic 1)

13. Oncologic response form.Oncologic response date item (leave blank for Logic 1)

14. Display ‘Scenario 1’ for Logic 1, display ‘Scenario 2’ for Logic 2
