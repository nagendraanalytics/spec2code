Report ID: ONC_LSN_011_JR_STD
Title: Schedule time reconciliation between Lesion evaluation, oncologic response and Oncologic scan

Forms / Items:
1. SA. Country

8. OSCN. Form Mnemonic
9. OSCN. Sponsor ID Number
10. OSCN. Scan Date
11. OSCN. Scheduled Time
12. RSP/ORAJ. Form Mnemonic
13. RSP/ORAJ. Sponsor ID Number
14.RSP/ORAJ. Date Response Determined
15. RSP/ORAJ. Scheduled Time
16. Display 'Scenario 1' for Logic 1, 'Scenario 2' for Logic 2,  Scenario 3' for Logic 3.

Description:
This report will list subjects that have discrepancies between Lesion evaluation "schedule time" and its corresponding oncologic response "schedule time" and Oncologic scan "schedule time".

Logic:
Logic 1:
(Logic 1.1: LSN. "Scheduled time" <> RSP. "Scheduled time"
AND
Logic 1.2: "Date of Lesion Evaluation" =  RSP."Date Response Determined"
)

OR

(Logic 1.3 LSN. "Scheduled time" <> ORAJ. Scheduled Time
AND
Logic 1.4: "Date of Lesion Evaluation" = ORAJ.Date of Assessment (Scan/Image/Physical Exam)
)

Logic 2:
(Logic 2.1: OSCN. Scheduled Time <> RSP. "Scheduled Time"
AND
Logic 2.2: OSCN. Scan Date = RSP."Date Response Determined"
)

OR

(Logic 2.3: OSCN. Scheduled Time <> ORAJ. Scheduled Time
AND
Logic 2.4: OSCN. Scan Date = ORAJ.Date of Assessment (Scan/Image/Physical Exam)
)

Logic 3:
Logic 3.1: LSN.Date of Initial Identification = LSN.Date of Lesion Evaluation time
AND
Logic 3.2: LSN."Scheduled time" <> OSCN. "Scheduled"
AND
Logic 3.3: LSN.Date of Initial Identification = OSCN.Scan Date

Notes:
Note 1: Exclude deleted records.
Note 2: The report will use master supporting documents LSN_supp_doc and RSP_supp_doc. These supporting documents should be uploaded only once at TA level per the GDO Oncology TAST authorized members and will be used to facilitate programming of the report. Report builder will use all the columns provided in the excel spreadsheet to create the programming code.
Note 3: The distribution of items are as follows:
- "Date of Lesion Evaluation", "Date of Initial Identification ", LSN. "Scheduled Time" belong to LSN_supp_doc
- "Date Response Determined", RSP. "Scheduled Time" belongs to RSP_supp_doc
Note 4: If OSCN 'Scheduled Time' is not present in the study, please do not consider Scenario 2 and Scenario 3 and run only Scenario 1.
