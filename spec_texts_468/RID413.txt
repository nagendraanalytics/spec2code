Report ID: RID413

Report Title:
Missing Oncologic Response or Lesion evaluation

Description:
This report will list subjects who are missing Oncologic Response that should be assessed every time Lesion Evaluation is done, except at baseline. AND subjects who are missing Lesion evaluations corresponding to an Oncologic response except after a lesion merged or split.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Lesion Form

5. Lesion Seq

6. Lesion Date

7. Response Form

8. Response Seq

9. Response Date

10. Scenario

Logic:
Scenario 1:

(

'LSN eCRF'.'TUMOR IDENTIFICATION' <> (New / New Lesion Since Last Evaluation / New Non-Target Extra Nodal / New Non-Target Nodal / New Target Extra Nodal / New Target Nodal)

AND

'LSN eCRF'.'DATE OF LESION EVALUATION'<> 'LSN eCRF'.'DATE OF INITIAL IDENTIFICATION'

AND

'LSN eCRF'.'INDICATE IF LESION MERGED OR SPLIT' = BLANK

AND

There is no 'RSP eCRF'.'DATE RESPONSE DETERMINED'= 'LSN eCRF'.'DATE OF LESION EVALUATION'

)

OR

(

'LSN eCRF'.'TUMOR IDENTIFICATION' <> (New / New Lesion Since Last Evaluation / New Non-Target Extra Nodal / New Non-Target Nodal / New Target Extra Nodal / New Target Nodal)

AND

'LSN eCRF'.'DATE OF LESION EVALUATION' <> NULL

AND

'LSN eCRF'.'INDICATE IF LESION MERGED OR SPLIT' <> BLANK

AND

There is no 'RSP eCRF'.'DATE RESPONSE DETERMINED' = 'LSN eCRF'.'DATE OF LESION EVALUATION'

)

OR

(

'LSN eCRF'.'TUMOR IDENTIFICATION' = (New / New Lesion Since Last Evaluation / New Non-Target Extra Nodal / New Non-Target Nodal / New Target Extra Nodal / New Target Nodal)

AND

'LSN eCRF'.'DATE OF LESION EVALUATION' <> NULL

AND

There is no 'RSP eCRF'.'DATE RESPONSE DETERMINED'= 'LSN eCRF'.'DATE OF LESION EVALUATION'

)

Scenario 2:

'RSP eCRF'.'DATE RESPONSE DETERMINED'<> NULL

AND

There is not a corresponding 'DATE OF LESION EVALUATION' on each 'LSN eCRF'.'LESION NUMBER' where 'LSN eCRF'.'DATE OF INITIAL IDENTIFICATION' <= 'RSP eCRF'.'DATE RESPONSE DETERMINED'

Note 1: Please exclude deleted record from programming.

Note 2: If supporting doc is not provided, display the message as "ONC_RSP_003_JR_STD Supporting Document Not Present for This Trial".

Note 3: Do not show output for Scenario 2 if 'LSN eCRF' 'LESION NUMBER'  is present in other lesion evaluation entry on the Merged (Provide Associated Lesion Number) or Split (Provide Associated Lesion Number) associated boxes AND missing 'LSN eCRF'.'DATE OF LESION EVALUATION' is after 'LSN eCRF'.'DATE OF LESION EVALUATION'of the other lesion evaluation entry.

Note 4: Condense all outputs of the same date in one row. For Scenario 2, show Lesion Date column in blank.

Requires supporting document to be named ONC_RSP_003_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Group – If the lesion evaluation form is to be compared with only one response form then each pair of lesion evaluation forms and response forms should have a unique group. If one lesion evaluation form can be compared with more than one response forms, then all forms should be under the same group (see example below)

2. LSN eCRF – Enter the form mnemonic from the corresponding lesion evaluation form

3. RSP eCRF – Enter the form mnemonic from the corresponding response form

4. Treatment Phase – (Be very careful with this column), enter either No or Yes. Type in “No” if the study meets at least one of the following conditions 1- The study does not follow the standard DEG guidelines about rebaseline (e.g. 3475407 or 3475585) where the re-baseline can be skipped between different treatment phases due to specific subject conditions 2- The trial only has one treatment phase and NO rebaseline is done at all. Type in “Yes” if the study follows the standard DEG guidelines about rebaseline for ALL subjects with no exception at all and the study has multiple treatment phases (see example below)

e.g.

Example when the LSN form is to be compared only with one RSP form (each pair have its unique group) and the study does NOT follow the standard DEG guidelines about rebaseline or the study has only one treatment phase and no rebaseline is performed at all

Group,LSN eCRF, RSP eCRF, Treatment Phase

1,LSNIR, ORIR, No

2,LSNEV, ORST, No

Example when the LSN form is to be compared with multiple RSP form (all forms are under the same group) and the study follows the standard DEG guidelines about rebaseline and have multiple treatment phases (such as first course, second course, crossover, among others)

Group,LSN eCRF, RSP eCRF, Treatment Phase

1,LSNIR, ORIR, Yes

1,LSNIR, ORPC, Yes

Note 5: Expected relations between lesion evaluation and response forms will appear with a unique Group umber. If two or more lesion evaluation forms or response forms could be done interchangeably, i.e. completing only one of them is enough, then all those rows need to have the same Group number.

Note 6: Required supporting document should be named as study_phase_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase:

1. Phase Order: the order on which phases will appear on protocol

2. Treatment Phase: this information can be taken from PMS1/PMS1A/OEDRA Trial Segment Reference

3. First Visitmnemonic of Treatment Phase: the first visit on which treatment is expected to be administered on each phase.

e.g.

Phase Order,Treatment Phase,First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Cycle 1 Course 2

3,Crossover Phase,Crossover Cycle 1

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

The supporting document is required for all trials if treatment phase is applied to logic even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Note 7: The report logic should be checked within the same treatment phase defined in the supporting document.

Note 8: The study_phase supporting document will NOT be applied to Scenario 1 and it will be only applied to Scenario 2 if Treatment Phase column from supporting document = “Yes” as noted below:

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

If Treatment Phase from supporting document = “Yes”

The treatment phase will be identified as following:

1) For NON-LSN form:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include:, 'RSP eCRF'.'DATE RESPONSE DETERMINED'

2) For LSN form:

When 'TUMOR IDENTIFICATION' does not contain 'New' and 'INDICATE IF LESION MERGED OR SPLIT' is NULL

Initial Treatment Phase: Form.Date <= Cycle 1

Second Course Phase: Cycle 1 < Form.Date <= Second Course Cycle 1

When 'TUMOR IDENTIFICATION' contain 'New' OR ('TUMOR IDENTIFICATION' does not contain 'New' AND 'INDICATE IF LESION MERGED OR SPLIT' is NOT NULL)

Initial Treatment Phase: Cycle 1 < Form.Date <= Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 < Form.Date

Form.Date include: 'LSN eCRF'.'DATE OF INITIAL IDENTIFICATION'

If Treatment Phase from supporting document = “No”: Do not apply study phase supporting document.

Note 9: The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization". The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page" and "Study Phase Page".

Note 10: This report uses the LSN and RSP master supporting documents

Report Scenarios:
Scenario 1, Output: Yes

Subject is missing an Oncologic Response that corresponds to a Lesion Evaluation date, and Lesion Evaluation is not the baseline.

Scenario 1, Output: No

Subject is missing an Oncologic Response that corresponds to a Lesion Evaluation date, but Lesion Evaluation is the baseline.

Scenario 1, Output: No

Subject has an Oncologic Response that corresponds to a Lesion Evaluation date.

Scenario 2, Output: Yes

Subject is missing a Lesion Evaluation that corresponds to the Oncologic Response, and Lesion has not merged or split.

Scenario 2, Output: No

Subject is missing a Lesion Evaluation that corresponds to the Oncologic Response, but Lesion has merged or split.

Scenario 2, Output: No

Subject has a Lesion Evaluation that corresponds to the Oncologic Response.

Sorting:

10. Display “Scenario 1” or “Scenario 2” depending on the logic that is met
