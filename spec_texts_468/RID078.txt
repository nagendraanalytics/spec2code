Report ID: RID078

Report Title:
Missing MedDRA Derivations

Description:
This report displays a listing of all MedDRA terms where: 1) LLT is not null, but PT or SOC is null; or 2) LLT is null, but PT or SOC is not null.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF

6. Seq

7. Verbatim Term

8. LLT

9. PT

10. SOC

Logic:
The report should display output if

1) the LLT is not null but the PT or SOC is null; or

2) the LLT is null but the PT or SOC is not null.

The forms to be evaluated should be provided by the requestor.

Display row count in footer. Report should not display deleted records.

If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
Refer to Test Case Work book

Sorting:
Country, Site, Subject Number, Visit, eCRF, Seq

Parameter Selection:
Country, Site, Subject Number, Randomized Only, Visit, eCRF, List of Subjects

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Forms.Visit Mnemonic

5. Forms.Form Mnemonic

6. Forms.Form Index

7. Forms.Term

8. Forms.LLT

9. Forms.PT

10. Forms.SOC
