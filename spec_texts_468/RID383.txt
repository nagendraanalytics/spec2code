Report ID: RID383

Report Title:
Overall Response vs Lesion Evaluation measurements

Description:
This listing contains details about the type of lesions reported under Lesion Category item on LSNEV/LSNEI (Target/Index, Non-target/Non-Index, and New) and the corresponding Overall Response recorded in ORST.

- For the Target/Index lesions, the listing will show the Target/Index Lesion

Measurement for each lesion and the Summatory of the diameters (SOD) for the all the lesions evaluated on the same date. If the item "Was the Lesion Evaluable?" is selected as No, the lesion will appears as Not evaluable.

- For the Non-target/Non-index lesions, the listing will show the total number of lesions for each Non-Target/Non-index lesion status  (Baseline/Present, Absent, Worsening/Increasing, Not evaluable)  evaluated on the same date.

- For the New lesions, the listing will show the total number on each evaluation.

Note: SOD = sum of longest diameters (extra nodal/Dimension 1) or short axis (nodal/Dimension 2) of all Target/Index lesions

SOD is calculated as Sum of ‘Target Lesion Measurement’ /Index Lesion Measurement, Longest Diameter/Dimension 1 and Short Axis/Dimension 2 depending on what is in the trial and of all records of Evaluation Entry of LSN. “TUMOR IDENTIFICATION” =’Target /Index’ or Target Nodal or Target Extra Nodal and LSN. “LESION TYPE”= ‘Nodal’ or ‘Extra-Nodal’ (Only consider if present) and have same Date of Evaluation. SOD should only display for logic 3 and 6 when Lesion Category is “Target/Index”.

Display the whole addition expression like “1.5+2.5=4.0”, not only “4.0”.

14. % Change from Baseline is calculated as [(SOD from current Timepoint - SOD from Baseline)/SOD from Baseline] *100%. Baseline SOD corresponds to the SOD of the Baseline assessment, i.e., evaluation done prior first Dose. If SOD from Baseline is equal to 0, ignore calculation and display "Baseline is zero".

15. % Change from Nadir is Calculated as [(SOD from current Timepoint - SOD from Nadir)/SOD from Nadir] *100%. Nadir SOD corresponds to the smallest SOD of all prior lesion evaluations of current Timepoint. If SOD from Nadir is equal to 0, ignore calculation and display "Nadir is zero".

16. Non-Target/Non-index Lesion Status/Total number should display as below format:

 “N/A(baseline) =<total number>”, “Absent=<total number>”, “Present=<total number>”, “Worsening/Increasing =<total number>”, “Not Evaluable=<total number>” in sequence. If there are multiple status, display them all in this column and joined by semicolon.

Total number is calculated as the total record number of Evaluation Entry of LSN form which “TUMOR IDENTIFICATION” =’Non-Target/Non-index’ and have same LSN.“DATE OF LESION EVALUATION”.  This column should only display for logic 3 and 6 when LSN.“TUMOR IDENTIFICATION” is “Non-Target/Non-index” or Non-Target Nodal or Non-Target Extra Nodal.

17. New Lesion/Total Number is calculated as the total record number of LSN which “TUMOR IDENTIFICATION” is ‘New’. This column should only display for logic 3 and 6 when which “TUMOR IDENTIFICATION” is “New”.

Note: If the protocol has the LSN.”IS THE LESION FDG-AVID ON THE PET SCAN” item, consider as ‘New’ if the item value passes from NO in one timepoint and YES in the following. If the item LSN.”IS THE LESION FDG-AVID ON THE PET SCAN” is not present or if the Lesion Evaluation Form is different the report, please simply ignore this note.

18. LSN form, Evaluation Entry section. “WAS THE LESION EVALUABLE?”  This column should only display when logic7 is met and meanwhile keep item 10~1213-15 # as blank.

19. If ORST RSP Form. “OVERALL RESPONSE” <> Null display "Progressive Disease" if calculated % Change from Nadir in column 15 is >= 20% AND difference in SOD column 13 and SOD of  Nadir is >=5.
