Report ID: RID232

Report Title:
Reconciliation of the ULAB Test Result and Normal Range/Indicator

Description:
The report is checking the mismatch between ULAB test result and the selection for Normal Range/Indicator.

Column Heading:
1.Country

2.Site

3.Subject Number

4.Visit

5.ULAB Seq

6.Enter date specimen collected

7.Lab Test

8.Lab Test Result

9.Nomal Range/Indicator

10.Lower Limit of Normal

11.Upper Limit of Normal

12.Unit

13.Scenario

Logic:
Logic 1

Error Message=Scenario 1

ULAB is initiated

AND

Lab Test is completed

AND

'Abnormal Character Result' is selected for Normal Range/Indicator

AND

Result is a numeric result

Logic 2

Error Message=Scenario 2

ULAB is initiated

AND

Lab Test is completed

AND

'Numeric Result' is selected for Normal Range/Indicator

AND

Result is a non-numeric result

Note:

1.non-numeric result means the result contains characters like qualitative result (negative, positive, +, -) or range result(6 - 9, 6 to 9, >100).

2.Exclude the Erroneous Visits and Deleted records.

3.For Scenerio 1, Column 'Lower Limit of Normal','Upper Limit of Normal','Unit' will be blank.

Report Scenarios:
Scenario 1: ULAB result is numeric, but the Abnormal Character Result is selected for item Normal Range/Indicator.

Scenario 2: ULAB result is non-numeric, but the Numeric Result is selected for item Normal Range/Indicator.
