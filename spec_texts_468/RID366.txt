Report ID: RID366

Report Title:
Sum of Diameters reconciliation

Description:
This report will output if the value entered on the Sum of Diameters for Target and New Target Lesions do not match with the information entered in the Lesion Evaluation form.

Column Heading:
1.Country

2. Site

3. Subject Number

4. Lesion Sequence Number

5. Date of Lesion Evaluation

6. Sum of Target Lesion Longest Diameter and Short Axis

7. ORIR Sequence Number

8. ORIR Date

9. Target Lesion Sum of Diameters - ORIR

10. Sum of New Target Lesion Longest Diameter and Short Axis

11. New Target Lesion Sum of Diameters – ORIR

12. Study Phase

13. Scenario

Logic:
Scenario 1.

[Logic 1.1: LSNIR. Tumor Identification = Target Nodal or Target Extra Nodal

AND

Logic 1.2: ORIR. Lesion Sum of Diameters - Current (For lesions Identified at Baseline) <> calculation of the sum of all Target Lesions Longest Diameter (Extra Nodal Lesion) and Short Axis (Nodal Lesion) in LSNIR form in all records within [ +/- X] days from ORIR. Date of Procedure for Overall Response (Scan Image Physical Exam) and with the same Study Period.)]

OR

(Logic 1.3: There are NO lesions with LSNIR. Tumor Identification as Target Nodal or Target Extra Nodal within [+/- X] days from ORIR. Date of Procedure for Overall Response (Scan Image Physical Exam) and with the same Study Period

AND

Logic 1.4: ORIR. Lesion Sum of Diameters - Current (For lesions Identified at Baseline) <> NULL)

Scenario 2

[Logic 2.1: LSNIR. Tumor Identification = New Target Nodal or New Target Extra Nodal

AND

Logic 2.2: ORIR. New Lesion (Target) Sum of Diameters – Current <> calculation of the sum of all New Target lesions Longest Diameter (Extra Nodal Lesion) and Short Axis (Nodal Lesion) in LSNIR form in all records within [+/- X] days from ORIR. Date of Procedure for Overall Response (Scan Image Physical Exam) and with the same Study Period.)]

OR

(Logic 2.3: There are NO lesions with Tumor Identification as New Target Nodal or New Target Extra Nodal within [+/- X] days from ORIR. Date of Procedure for Overall Response (Scan Image Physical Exam) and with the same Study Period.

AND

Logic 2.4: ORIR. New Lesion (Target) Sum of Diameters – Current <> NULL)

Scenario 3.

[(Logic 3.1: LSNIR. Tumor Identification is Target Nodal or Target Extra Nodal

AND

Logic 3.2: there is at least one target lesion within [+/- X] days from ORIR. Date of Procedure for Overall Response (Scan Image Physical Exam) with  LSNIR. Was the Lesion Evaluable? = No)

AND

Logic 3.3: ORIR. Target Lesion Sum of Diameters - Current (For lesions Identified at Baseline) for this timepoint and with the same Study Period <> NULL]

OR

[(Logic 3.4: LSNIR. Tumor Identification = New Target Nodal or New Target Extra Nodal

AND

Logic 3.5: There is at least one New target lesion within [+/- X] days from ORIR. Date of Procedure for Overall Response (Scan Image Physical Exam) with  LSNIR. Was the Lesion Evaluable? = No)

AND

Logic 3.6: ORIR. New Lesion (Target) Sum of Diameters - Current (For lesions Identified at Baseline) for this timepoint and with the same Study Phase <> NULL]

Note 1. Non-Target lesions should not be taken into consideration for scenario 1.

Note 2. New Non-Target lesions should not be taken into consideration for scenario 2.

Note 3: The same timepoint means that all evaluation on LSNIR done within [X] days from Date of Procedure for Overall Response (Scan/Image/Physical Exam) on ORIR form with the same Study Period should be counted as one.

Note 4: Please exclude deleted records and erroneous visits from programming.

Note 5: For all scenarios, please consider LSNIR and ORIR from the same Study Period (LSNIR.Study Period = ORIR.Study Period).

Note 6: For Logic 1 and Logic 2, do not produce output if at least one of the lesion from the same timepoint (LSNIR date +/- x days from ORIR date) has Was the Lesion Evaluable? item in LSNIR completed as NO and Lesion Sum of Diameters - Current (For lesions Identified at Baseline) or New Lesion (Target) Sum of Diameters -Current in ORIR form the same timepoint and with the same Study Phase is blank. In such case only scenario 3 is applicable.

Note 7. For Logic 1 and Logic 2, if lesion evaluation is provided to LSNIR for the same Study Period and in expected window from ORIR date, and Sum of Diameters item on ORIR form for this timepoint is not completed, the output is not expected.

Note 8. If Dates of Currect Lesion Evaluation on LSNIR eCRF is different for one time point, output is expected in one row; and LSNIR date should be provided using coma e.g.14-Mar-22,08-Mar-22

Report Scenarios:
Scenario 1 Output Yes:

For the same date of assessment and for the same Study Phase, the Target Lesion Sum of Diameters - Current (For lesions Identified at Baseline) is different than calculation of the sum of all Target Lesions Longest Diameter (Extra Nodal Lesion) and Short Axis (Nodal Lesion) present in LSNIR within the same timepoint.

Scenario 1 No Output:

For the same date of assessment and for the same Study Phase, the Target Lesion Sum of Diameters - Current (For lesions Identified at Baseline) is equal to the sum of all Target Lesions Longest Diameter (Extra Nodal Lesion) and Short Axis (Nodal Lesion) present in LSNIR within the same timepoint.

Scenario 2 Output Yes:

For the same date of assessment and for the same Study Phase, the New Lesion (Target) Sum of Diameters - Current is different than calculation of the sum of all New Target lesions Longest Diameter (Extra Nodal Lesion) and Short Axis (Nodal Lesion) present in LSNIR within the same timepoint.

Scenario 2 No Output:

For the same date of assessment and for the same Study Phase, the New Lesion (Target) Sum of Diameters - Current is equal to calculation of the sum of all New Target lesions Longest Diameter (Extra Nodal Lesion) and Short Axis (Nodal Lesion) present in LSNIR within the same timepoint.

Scenario 3 Output Yes:

For the same date of assessment and for the same Study Phase, the Target Lesion Sum of Diameters - Current (For lesions Identified at Baseline) is NOT BLANK and any of the Target Lesions present in LSNIR is not evaluable OR New Lesion (Target) Sum of Diameters - Current is NOT BLANK and any of the New Target Lesions present in LSNIR is not evaluable.

Scenario 3 Output No:

For the same date of assessment and for the same Study Phase, the Target Lesion Sum of Diameters - Current (For lesions Identified at Baseline) is BLANK and any of the Target Lesions present in LSNIR is not evaluable OR New Lesion (Target) Sum of Diameters - Current is BLANK and any of the New Target Lesions present in LSNIR is not evaluable

Parameter Selection:
Country, Site Number, Subject Number, Randomized Only, List of Subjects; Window of Days (Free textbox, Only numeric values allowed, default to 7)

Form.Item Names:
1. Country

2. Site

3. Subject Number

4. LSNIR. Associated Lesion Number (for all Target lesions (Including New)

5. LSNIR. Date of Current Lesion Evaluation (Scan/Image/Physical Exam) (for all Target lesions (Including New)

6. Display the value of LSNIR tumor Identification Target Extra Nodal and Target Nodal. that is calculated as (Longest Diameter (extra Nodal Lesion) plus Short Axis (Nodal Lesion)) if item is in blank, display the sum result.

7. ORIR. Sponsor ID number

8. ORIR. Date of Procedure for Overall Response (Scan/Image/Physical Exam)

9. ORIR. Target Lesion Sum of Diameters - Current (For lesions Identified at Baseline)

10. Display the value of LSNIR tumor identification New Target Extra Nodal and New Target Nodal. that is calculated as (Longest Diameter (extra Nodal Lesion) plus Short Axis (Nodal Lesion)) if item is in blank, display the sum result.

11. ORIR. New Lesion (Target) Sum of Diameters -Current

12. ORIR. Study Period

13. Display the value “Scenario 1” if Logic 1 applies, display the value “Scenario 2” if Logic 2 applies, display “Scenario 3” if Logic 3 applies.
