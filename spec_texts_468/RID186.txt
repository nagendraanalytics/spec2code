Report ID: RID186

Report Title:
Subject with Last Dose of Study Medication missing

Description:
This report will display subjects  who do NOT have a Last Dose of Study Medication checked when applicable.

Column Heading:
1.	Country

2.	Site

3.	Subject Number

4.	PMS1/PMST Visit

5.	PMS1/PMST Status

6.	PMS1/PMST Trial Segment Reference

7.	PMS1/PMST Date

8.	DS01 Status

9.            SM Form

10.	Study Medication

11.	First dose start date/time

12.	First dose stop date/time

Logic:
Logic 1:

If DS01.'Select the Status of the Subject for the Study'=completed

 OR (DS01 item 'Select the Status of the Subject for the Study'=Discontinued AND the reason <>Screen Failure)

 AND any first dose record in SMAU/SM01/SM/SMAB/STR has no corresponding

 last dose record in SMAU/SM04/SM/SMAB/STR for the same study medication.

Logic 2:

PMS1 variation form under defined visit(s) with item 'Status of Study Medication at the End of This Trial Segment'<>Null

OR PMST form under defined visit(s) with item 'Status of Subject at end of all Study Treatments'<>Null

 AND

There is no SMAU/SM01/SM/SMAB/STR Start Date > Max PMS1/PMST Date of Assessment

AND

              (

Logic 2A

If all SM discontinued together,   then output all study medications (all SM that in Supporting document in “Scenario” column  = A),  when any first dose record in SMAU/SM01/SM/SMAB/STR has no corresponding last dose record in SMAU/SM04/SM/SMAB/STR for the same study medication.

 OR

 Logic2B

If all SM not discontinued together, then output (each SM individually that in Supporting document in “Scenario” column  = B) when PMS1/variation/PMST form item 'Trial Segment Reference'= “Value in supporting document” AND any first dose record for study medication in SMAU/SM01/SM/SMAB/STR has no corresponding last dose record in SMAU/SM04/SM/SMAB/STR for the same study medication.

   )

)

Note 1: The first dose record in SMAU/ SM/SMAB/STR is defined as any record with item 'Please indicate if this is the first dose for this label description' <>null. The first dose record in SM01 is defined as any record in SM01 form.

Note 2: The last dose record in SMAU/ SM/SMAB/STR is defined as any record with item 'Please indicate if this is the last dose for this label description' <>null. The last dose record in SM04 is defined as any record in SM04 form.

Note 3: For Logic 2, If there is any SM record with Start Date > Max PMS1/PMST Date of Assessment in  SMAU/SM01/SM/SMAB/STR, then no output should be display for the corresponding SM. Other SM should not be affected.

E.g. PMS1/PMST Trial segment= A  --> Study med =B and/or  study med =C and/or Study med =E

            PMS1/PMST Trial segment= D --> Study med =E and/or Study med=G and/or Study med =F

E should not be output when PMS1/PMST completed with Trial segment= A since E continuing during another treatment phase. But B&C should be output;

Note 4: Exclude erroneous visit and deleted record when programming.

Note 5: The optional supporting document is only required in the following cases:

If scenario 2 applies requires supporting document to be named SM018_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

If no supporting document is provided only run Logic 1

For example:

SM, Axitinib, PMS1, Discontinuation visit, End of Treatment, A

SM, Paclitaxel, PMS1, Cycle 17, End of Treatment, A

SMAU, 3475, PMS1, Discontinuation visit, End of Treatment, A

SM, Sunitinib, PMST,  Discontinuation visit, End of Treatment, B

SM, Cisplatin, PMS1,  Cycle 6, End of Cisplatin treatment, B

Note 6: Supporting document  study_med_match_supp_<xxxxxxx>.csv can be used to identify Study medication

Note 7: only one output is required for each study medication
