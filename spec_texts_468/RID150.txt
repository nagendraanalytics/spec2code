Report ID: RID150

Report Title:
Missing, Duplicate or Incorrect PK Scheduled Time

Description:
This report will list subjects whose PK Scheduled Time does not match what is specified in the protocol. This report will also list subjects that have duplicate or missing Scheduled Times.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Date of Visit

6. eCRF

7. Analyte

8. Scheduled Time

9. Specimen ID

10. Seq

11. Issue

Logic:
<Criteria Form1>.<Criteria Itemquestion1> = <Criteria Value1>  AND

<Criteria Form2>.<Criteria Itemquestion2> = <Criteria Value2> AND

<Criteria Form3>.<Criteria Itemquestion3> = <Criteria Value3> AND

This report lists missing, duplicate or incorrect PK Scheduled Times by visit, form and analyte as defined in the supporting document.

Output the Missing, Incorrect or Duplicate Scheduled Time according to the Visit and Criteria form/itemquestion/Value provided in the supporting document.

If the Scheduled Times selected by the user or expected per eCRF and analyte at a given visit have not been entered on the PK eCRF, then issue='Missing'.

If the Scheduled Times selected by the user or expected appear more than once per Analyte 'Specimen ID duplicates' prompt is selected as 'No' then issue='Duplicate'

If the Scheduled Times selected by the user or expected appear more than once per Analyte, with the same Specimen ID and 'Specimen ID duplicates' prompt selected as 'yes' then issue='Duplicate'

If the Scheduled Times selected by the user or expected appear more than once per Analyte, 'Specimen ID duplicates' prompt selected as 'yes' and Specimen ID not duplicated then do not issue='Duplicate'

If there are Scheduled Times entered on the PK eCRF different from the Scheduled Times selected by the user or expected per eCRF and analyte at a given visit, then issue='Incorrect'

If there are Scheduled Times entered on the PK eCRF but the visit has not been initialized, then issue='Incorrect'

Notes:

1) Erroneous visits should not be included.

2) For Scenario "Incorrect", Unscheduled assessments can be disregarded when submitting the report spec

3) For Scenario "Incorrect", when Form and Visit are not provided by user in supporting document and Form is entered with Scheduled Time<>Unscheduled, please output as Incorrect

4) Do not consider deleted Items for Missing scheduled time per visit scenario.

5) If item Visit Initialized in Supp Doc is entered as Y, do not output Missing Scenario when form is not initialized, or only deleted items are present in the form.

6) Display missing analyte and scheduled time as per supporting document for "Missing Scenario".

Report Scenarios:
Scenario 1: Error message:  "Missing"

Output if the expected Scheduled Times and analyte at a given visit have not been entered on the PK eCRF.

* If selected no output if PK eCRF is not initiated for a given visit

Scenario 2 Error message:  "Incorrect"

Output if there are Scheduled times entered on the PK eCRF different from the Scheduled Times expected per supporting document for analyte at a given visit

Scenario 3   Error message:  "Duplicated"

Output if the expected Scheduled Times appear more than once per Analyte.
