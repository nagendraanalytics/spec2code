Report ID: BDR002_STD (m)

Report Title:
NSAE New/Modified Data (manual version)

Description:
This report lists all patients with new or modified Non-Serious Adverse Experience data in the AE module.  Report can be limited by date and time stamps of changed data so that incremental reports can be run.  This will enable teams to perform review in accordance with GDP AE Reporting.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Sequence Number

5. Field Changed

6. New or Changed AE

7. New or Changed Date/Time

8. Old Data Value

9. New Data Value

10. AE Term

11. AE Onset Date

12. Overall Toxicity

13. Serious AE

Logic:
This report outputs 1 row per each new record.  When data within the report are changed, the entire record would output with the changed information.  If more than 1 datapoint changes within the report period, there will be a separate record for each change.   The report looks at new and changed information within the period specified on the prompt page.

Non-Serious AE is any AE where all  serious AE criteria are null  and Adverse Events.AEAECLINTRC ~ Is the AE an Event of Clinical Interest = No or is null

New or Changed Fields to be included:

Adverse Events.AE Term,

Adverse Events.AEAESERHOSPCB ~ Inpatient hospitalization or prolongation of hospitalization ~ Serious Criteria,

Adverse Events.AEAESERCANCB ~ Cancer ~ Serious Criteria,

Adverse Events.AEAESERLIFECB ~ Immediately life threatening ~ Serious Criteria,

Adverse Events.AEAESERDISABCB ~ Persistent or significant disability incapacity ~ Serious Criteria,

Adverse Events.AEAESERCONGCB ~ Congenital anomaly birth defect ~ Serious Criteria ,

Adverse Events.AEAESERODCB ~ Overdose ~ Serious Criteria,

Adverse Events.AEAESERSIMECB ~ Other important medical event ~ Serious Criteria,

Adverse Events.AEAESERDTHCB ~ DeathEvent reported in autopsy as cause of death ~ Serious Criteria,

Adverse Events.AEAECLINTRC ~ Is the AE an Event of Clinical Interest

New or Changed AE - Display "New" the first time a record is submitted.  Display "Changed" anytime that a datapoint is added or changed to the record after initial submission

The latest transaction date time should be included in the header as the Last DB Refresh.
