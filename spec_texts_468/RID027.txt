Report ID: RID027

Report Title:
Same AE LLT with consecutive dates entered in different records

Description:
Report will output AEs that have the same LLT term with consecutive days that were reported in different records

Column Heading:
1. Country

2. Site

3. Subject Number

4. Seq1

5. AE Term1

6. LLT1

7. Onset Date1

8. End Date1

9. Seq2

10. AE Term2

11. LLT2

12. Onset Date2

13. End Date2

Logic:
This report outputs AEs that have the same LLT and the Onset Date of one of the AEs is one day after the End Date of the other AE.

Consider:

Onset Date2 = End Date1 + 1

The time component is not considered.

The comparisons are done in pairs.

Deleted records are not considered.

Note: The same LLT term regardless of ''worsened/worsening of/aggravated/exacerbated/exacerbation of/exacerbation'', only consider clinical condition term.

If the AE is ongoing and does not have an end date show null value. Do not auto fill with time when AE end date without collect time.

Report Scenarios:
1) Output=YES

AE seq x LLT = AE seq y LLT and

AE seq x end date + 1 = AE seq y start date

2) Output=NO

AE seq x LLT = AE seq y LLT and

AE seq x end date + 1 <> AE seq y start date

3) Output=NO

AE seq x LLT <> AE seq y LLT

4) Output=NO

Deleted records

5) Output=YES

AE seq x LLT (cough) <> AE seq y LLT (Worsening cough)

AE seq x end date + 1 = AE seq y start date

Sorting:
Country, Site, Subject Number, Seq1, Seq2

Parameter Selection:
Country, Site, Subject Number, List of Subjects, Randomized only
