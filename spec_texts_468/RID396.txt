Report Title:
Post Allogeneic Transplant Disease Status reconciliation

Description:
This report will list subjects with inconsistencies between PATDS, SCTF, SFU, VST and DEATH forms.

Scenario 3

If SFU and DEATH form missing, then “Dead form(s) missing” = DEATH/SFU

If SFU form is missing, then “Dead form(s) missing” = SFU

If DEATH form is missing, then “Dead form(s) missing” = DEATH

Note 5: For STCF Visit: if protocol has STCF form as visit based please display visit mnemonic; if form is Common then Display "Common Form"

Report Scenarios:
Scenario 1 Output = Yes

This scenario displays subjects who has reported Allogeneic Stem Cell Transplant in SCTF form, dead has been entered on VST,DEATH or SFU but PATDS form is missing.

Scenario 2 Output = Yes

This scenario displays subjects who have information in PADTS form entered, dead has been reported on DEATH,SFU or VST but there is not any entry of Allogeneic Stem Cell Transplant in SCTF form.

Scenario 3 Output = Yes

This scenario displays subjects who have information in PADTS, patient has Allogenic transplant but Dead has not been reported on DEATH or DEATH AND SFU.
