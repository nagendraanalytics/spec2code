Report ID: RID408

Report Title:
Missing RNT for subjects randomized but never treated

Description:
This report will show subjects who were randomized but did not have at least one study medication record and RNT was not completed

Column Heading:
1. Country

2. Site

3. Subject Number

4. Date of Randomization

Logic:
1.1 SR Date of Assessment <> NULL AND

1.2 ALL SMAB/SM Study Medication AND STR Study Treatment=NULL AND

1.3 RNT Date of Assessement=NULL  or Not initialized

Notes:

1. Forms for Logic 1.2, then only review forms present in the study

2. Optional supporting document to be named ONC_RNT_001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each ARM whose subjects do not receive medication

1) Criteria From-Unique value in each group, specified as 'NA' if gap/overlap is checked for all subjects - TRIG, SR, SA, TRIG

2) Criteria item question - Unique value in each group, specified as 'NA' if gap/overlap is checked for all subjects-Arm, Stratification, Cohort

3) Criteria Value-Unique in each group, specified as 'NA' if gap/overlap is checked for all subjects - Arm 1, Arm 2, Arm3

Example:

Criteria Form. Criteria, Item question, Criteria Value

SR,Arm,Arm 1

SR, Arm, Arm 2

TRIGA, Cohort, Arm 3

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

3. Please consider RNT  form even if it is not initialized

4. If supp doc is present, please only output for patient that met the criteria

5. For Scenario B and C, please refer to Note 1

Report Scenarios:
Scenario A: Yes

1. Subject is randomized

2. SMAB/SM/STR is blank

3. RNT is Blank  or Not initialized

Scenario B: No

Output will not be produced if subject was randomized and there is at least one study medication record <SMAB/SM/STR>

Scenario C: No

Output will not be produced if the patient is not randomized

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Supporting Doc Page (N/Y, default as N)

Form.Item Names:
1. SA. Country

2. SA. Site Mnemonic

3. SA. Subject Number

4. SR. Date of Assessment
