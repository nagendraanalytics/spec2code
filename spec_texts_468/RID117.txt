Report ID: RID117

Report Title:
External Data Site Reconciliation

Description:
This report will output subjects with mismatching between Site reported in Vendor and Site reported in InForm.

Column Heading:
Country, Site Number, Screening number, Subject Number, Vendor, Site ID or number, Screening ID or Number, Subject ID or Number

Logic:
Output is produced if site number entered on "Site ID or Number" is not matching "Site" reported on GEFCF but with the same screening number

Note: Deleted records are not considered.

Report Scenarios:
This report will output subjects with mismatching between Site reported in Vendor and Site reported in InForm.

Sorting:
Country, Site Number, Screening number, Subject Number, Vendor, Site ID or number, Screening ID or Number, Subject ID or Number

Form.Item Names:
Subject Assignment.Site Country

Subject Assignment.Site Mnemonic

Subject Assignment. Screening number

Subject Assignment. Subject Number

GENERIC EXTERNAL FINDINGS Form.Vendor Name

GENERIC EXTERNAL FINDINGS Form., Site ID or number

GENERIC EXTERNAL FINDINGS Form.Screening ID or Number

GENERIC EXTERNAL FINDINGS Form.Subject ID or Number
