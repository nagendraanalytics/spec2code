Report ID: RID055

Report Title:
Erroneous Visit Listing

Description:
This report lists all visits where erroneous visit checkbox is checked for identifying Erroneous visit. Visit which contains SR will not be listed for randomized patients.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Screening Number

5. Visit

6. DOV

7. DS01 Status

Logic:
This report lists all visits where erroneous visit checkbox is checked for identifying Erroneous visit.

If SR.Date of Assessment <> NULL For randomized patient: exclude SR visit.

SR visit= Visit which contains SR form. It is provided as a mandatory prompt in the report.

Report Scenarios:
1) Output=No

Erroneous visit check box is not checked on a DOV form. including when the item of "Erroneous Visit" is marked with comment bubble.

Only for randomized patients: Erroneous visit check box is checked on the DOV of the Visit which contains the SR form (SR visit).

2) Output=Yes

Erroneous visit check box is checked on a DOV form.

Sorting:
Country, Site, Subject Number, DOV, visitorder

Parameter Selection:
Country, Site, Subject, List of Subjects, SR Visit

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Subject Assignment.Screening Number

5. Visits.Visit Mnemonic

6. Visits.DOV

7. Subject Disposition Form.Select the Status of the Subject for the Study
