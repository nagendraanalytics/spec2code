Report ID: RID058

Report Title:
Consistency between Protocol Milestone status and Post End of treatment visits

Description:
This report lists subjects that have completed item "Select the Status of the Subject for the Next Trial Segment" in Status forms and the expected visit has not been entered or is out of the expected window or the option selected does not match with Post End of treatment visits initialized.

This report also displays subjects who are missing a Post End of treatment visit or not within the specified time after the last dose of study medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Trial Segment Reference

6. Next Trial Segment

7. Count Days From

8. Date Selected

9. Expected Visit Mnemonic

10. Expected Visit DOV

11. Days elapsed from date selected

12. Scenario

Logic:
Scenario 1:

Logic 1.1 There is a "Form" record with Trial Segment Reference = "Trial Segment Reference"

AND

Logic 1.2 Select the Status of the Subject for the Next Trial Segment = "Next trial segment"

AND

[Logic 1.3 The "Expected visit" DOV Date of visit = NULL

OR

Logic 1.4 The "Expected visit" DOV Erroneous visit box is checked]

AND

Logic 1.5 system date – "Count days from" => "Upper number of days" + "Data entry window"

Scenario 2

Logic 2.1 There is a "Form" record with Trial Segment Reference = "Trial Segment Reference"

AND

Logic 2.2 Select the Status of the Subject for the Next Trial Segment = "Next trial segment"

AND

Logic 2.3 "Expected visit" DOV Date of visit <> NULL

AND

[Logic 2.4 "Expected visit" DOV Date of visit – "Count days from" < "Lower number of days"

OR

Logic 2.5 "Expected visit" DOV Date of visit – "Count days from" > "Upper number of days"]

Scenario 3

Logic 3.1 "Expected visit" DOV Date of visit <> NULL

AND

Logic 3.2 There is no at least one "Form" with Trial Segment Reference = "Trial Segment Reference" and Select the Status of the Subject for the Next Trial Segment = "Next trial segment"

Scenario 4

Logic  4.1 There is a "SM Form" record with Last Dose Checked

AND

[Logic 4.2 The "Expected visit" DOV Date of visit = NULL

OR

Logic  4.3 The "Expected visit" DOV Erroneous visit box is checked]

AND

Logic 4.4 system date – "Count days from" => "Upper number of days" + "Data entry window"

Logic 5.1 There is a "SM Form" record with Last Dose Checked

AND

Logic 5.2 "Expected visit" DOV Date of visit <> NULL

AND

[Logic 5.3 "Expected visit" DOV Date of visit – "Count days from" < "Lower number of days"

OR

Logic 5.4 "Expected visit" DOV Date of visit – "Count days from" > "Upper number of days"]

Note 1: Erroneous visit or deleted records will not be considered in the programming or output except for logic 1.4 and logic 4.3 where erroneous visit box should be considered

Note 2: Form, Trial Segment Reference, Next trial segment, Expected visit, Count days from, Upper number of days, Lower Number of days are values from supporting document

Note 3: Please check below clarification for "Count days from" in supporting document

Enter either of 3 values: Last dose/Date of Assessment/Date of Visit

For Date of Visit: report use the "Date of Visit" of "Visit Mnemonic" in supporting doc to perform calculation in logic 1.5, logic 2.2 and logic 2.3.

For Last dose: report use the maximum SM04/SMAB/SMAU/STR/SM, the maximum is calculated within SM04/SMAB/SMAU/STR/SM records with the item Stop Date and Time/Stop Date and Time Last Dose Administered/Received/Stop Date/Time

on or before to "Form" Date of Assessment with Trial Segment Reference = "Trial Segment Reference" and Select the Status of the Subject for the Next Trial Segment = "Next trial segment".

But for scenario 4 and scenario 5, only consider Last dose: report use the maximum SM04/SMAB/SMAU/STR/SM, the maximum is calculated within SM04/SMAB/SMAU/STR/SM records with the item Stop Date and Time/Stop Date and Time Last Dose Administered/Received/Stop Date/Time

If more than one study medication form is present in the study, then use the maximum last dose date across all of them.

For Date of Assessment: report use the Date of Assessment in "Form" with Trial Segment Reference = "Trial Segment Reference" and Select the Status of the Subject for the Next Trial Segment = "Next trial segment" from supporting document.

Note 4: Only use date for calculation in this report, disregard time

Note 5: If supporting doc is not provided, display the message as "DOV007A_JR_STD Supporting Document Not Present for This Trial".

Requires supporting document to be named DOV007A_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each group of Scenario to be reviewed according to protocol design

1.            Group - Required for Scenario 3 this is a unique value that can be used between two or more records when there is a need to check the "Expected visit" vs the "Next Trial Segment" in two different forms example, PMS1 and OEFU. For Scenario 1 and 2 just simply enter NA.

2.	Expected visit - Required for Scenario 1,2,3,4,5, Enter Visit mnemonic

3.	Form - Required for Scenario 1,2,3, Enter PMST/PMS1/OEFU/PMS1A;for scenario 4 and 5, Enter SM/SMAB.

4.	Trial Segment Reference - Required for Scenario 1,2,3, Enter value list of Trial Segment Reference of corresponding Form;for scenario 4 and 5, enter NA.

5.	Next trial segment - Required for Scenario 1,2,3, Enter value of Trial Segment Reference of corresponding Form;for scenario 4 and 5, enter NA.

6.	Count days from - Required for Scenario 1,2, Enter Last dose/Date of Assessment/Date of Visit; Enter 'NA' for Scenario 3;for scenario 4 and 5, Enter Last dose.

7.	Visit mnemonic - Required only if Count days from is equal to Date of Visit, Enter Visit Mnemonic related to Discontinuation visit as per T&E, eg: "Discontinuation", "Discontinuation Visit", "End of Treatment" or any additional mnemonic variation; Enter 'NA' for Scenario 3 or Count of days is equal to Last dose or Date of Assessment

8.	Lower number of days - Enter 'NA' for Scenario 1,3, 4; At least one of Lower number of days and Upper number of days need to be provided for Scenario 2 and 5, enter 'NA' if it is not needed.

9.	Upper number of days - Required for Scenario 1 and 4; At least one of Lower number of days and Upper number of days need to be provided for Scenario 2 and 5, enter 'NA' if it is not needed; Enter 'NA' for Scenario 3

10.	Scenario - Required, Enter 1/2/3/4/5

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
Scenario 1:

Output: Yes - There is a "Form" record completed and the expected “Expected Visit” visit DOV has not been entered and the amount of days allowed plus the data entry window has elapsed since "Form".Date

Output: Yes - There is a "Form" record completed and the expected “Expected Visit” visit DOV has been completed, but is entered as Erroneous Visit, and the amount of days allowed plus the data entry window has elapsed since "Form".Date

Output: No - There is a "Form" record completed and the expected “Follow Up” visit DOV has been entered and “Follow Up” visit is NOT set as Erroneous

Scenario 2:

Output: Yes - There is a "Form" record completed and the "Expected visit" DOV minus “Form”.Date is LESS than the “Lower number of days” allowed per supporting document

Output: Yes - There is a "Form" record completed and the "Expected visit" DOV minus “Form”.Date is GREATER than the “Upper number of days” allowed per supporting document

Output: No -There is a "Form" record completed and The "Expected visit" DOV minus “Form”.Date is GREATER than the “Lower number of days” and “LESS” than the “Upper number of days” allowed per supporting document

Scenario 3:

Output: Yes - DOV from "Expected visit" is entered and there is NO at least one "Form" completed indicating that subject moved to the "Expected visit" phase

Output: No - DOV from "Expected visit" is entered and there is at least one "Form" completed indicating that subject moved to the "Expected visit" phase

Output: No - DOV from "Expected visit" is NOT entered and there is at least one "Form" completed indicating that subject moved to the "Expected visit" phase

Scenario 4:

Output: Yes - SM last dose checked and the expected “Expected Visit” visit DOV has not been entered and the amount of days allowed plus the data entry window has elapsed since Max SM Last dose Date

Output: No - The expected “Expected Visit” visit DOV has been entered and “Follow Up” visit is NOT set as Erroneous.

Scenario 5:

Output: Yes - SM last dose checked and the expected “Expected Visit” visit DOV minus Max SM Last dose Date is LESS than the “Lower number of days” allowed per supporting document

Output: Yes - SM last dose checked and the expected “Expected Visit” visit DOV minus Max SM Last dose Date is GREATER than the “Upper number of days” allowed per supporting document Output

Output: No -SM last dose checked and The "Expected visit" DOV minus Max SM Last dose Date is GREATER than the “Lower number of days” and “LESS” than the “Upper number of days” allowed per supporting document

Output: No – Deleted records and Erroneous Visits
