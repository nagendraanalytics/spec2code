Report ID: RID138

Report Title:
Excluded Conditions reported on MH

Description:
The report will list if any of the Specified MH terms (Based on LLT term) was recorded in MH form for Randomized Subjects within a specific window from date of randomization

Column Heading:
1.Country

2.Site

3.Subject Number

4.MH seq#

5.MH History term

6.MH LLT term

7. MH Year diagnosed

Logic:
Logic1: MH.LLT =  <LLT Term>

AND

Logic2: <Criteria form>. <Criteria Itemquestion> = <Criteria Value>

AND

Logic3: (Year part of <Criteria form>.<Criteria Datequestion> - <Window>) <= MH.Year diagnosed

Notes

1. “Criteria form”, “Criteria Itemquestion”, “Criteria Value”, “Criteria Datequestion”, “LLT Term”, and “Window” are parameters that will be present in the MH005_supp_<xxxxxxx>.csv supporting document

2. The report should only output subjects with Randomization number that is not null

3. This report will output if any of the Specified MH terms (Based on LLT term) was recorded in MH form for Randomized Subjects within a specific window from date of randomization

4. If the parameter <Window> (specified in the supporting document) is entered as “NA”, window of year should be considered as “99999”. In other words, ALL MH.LLT present in the supporting document should be considered and outputed.

5. For Logic3, only the “year” section of the <Criteria form>.<Criteria date question> should be considered

6. Report should not consider erroneous visits and deleted records

7. Requires supporting document to be named MH005_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1.	Criteria Form - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA

2.	Criteria Itemquestion - Arm/Cohort/Stratification Itemquestion. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA

3.	Criteria Value - Arm/Cohort/Stratification Value. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA

4. 	Criteria Datequestion – Date question present in the Criteria Form. If not applicable, enter NA. If Datequestion is NA, LLT term will be an output

5.	LLT Term: LLT Medical History term prohibited per protocol (can be consulted with Manual Encoding Lead).

6.	Window: Number of Years from date of randomization, in which the MH term is not allowed. If MH is not allowed regardless the time elapsed prior to randomization, enter NA

Example

Criteria Form, Criteria Itemquestion, Criteria Value, Criteria Datequestion, LLT Term, Window

SR, Arm, -3475, Date of Assessment, hypersensitivity reaction, NA

TRIG, Arm, Docetaxel, Date of Assessment, Vasculitis, 1

NA, NA, NA, NA, Pleural effusion, 2

Note:

-  The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

-  The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting Doc Page".

If supporting doc is not provided, display the message as "MH005_JR_STD Supporting Document Not Present for This Trial".

Report Scenarios:
Scenario A: Output Yes.

MH.LLT = a value in column 5 ( LLT Term)  as specified in supporting document MH005_supp_<xxxxxxx>.csv patients

AND

MH.Year diagnosed is within X years prior to date of randomization.

Scenario B: Output No.

MH.LLT <> a value in column 5 ( LLT Term)  as specified in supporting document MH005_supp_<xxxxxxx>.csv patients

Scenario C: Output No.

MH.LLT =  a value in column 5( LLT Term)  as specified in supporting document MH005_supp_<xxxxxxx>.csv patients

AND

MH.Year diagnosed Is NOT is within X years prior to date of randomization.

Scenario D: Output No.

Screen failures (not randomized) subjects

Scenario E: Output No.

Erroneous Visits and Deleted records

Sorting:
Country, Site, Subject, MH Seq

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Supporting doc Page (N/Y, default as N)

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. MH form. Sequence Number

5. MH form. Medical History Term

6. MH form. LLT term

7. MH form.Year diagnosed
