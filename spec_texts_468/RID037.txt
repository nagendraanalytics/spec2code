Report ID: RID037

Report Title:
Incorrect lot number format for specific group of subjects.

Description:
This report will output entries with incorrect lot number format for specific subjects.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF

6. Seq

7. Study Medication

8. Lot ID Item Name

9. Lot ID value

10. Dose Amount Value

11. Error message

Logic:
This report displays subjects who have DISP/SM/SMPU Lot ID not according to what has been selected in the supporting document or Lot Number is missing based on the list of Sites that are centrally sourced (BNR005_Supp1).

1. Missing lot ID check: - This scenario only to be used when "Check missing lot ID" in parameter is selected as Y.

Check if lot ID item specified in prompt is blank in DISP/SM/SMPU eCRF. Output will be showed with error message as "Missing lot ID"

Note:

Note 1. Zero doses are considered. [DISP.Amount of Study Medication Dispensed = 0.0/SM.Dose Amount = 0.0/SMPU.Volume Prepared = 0.0, then no output for Missing Lot ID is expected.

2. Incorrect lot ID format check:

The expected DISP/SM/SMPU Lot ID format could be:

- Length, e.g. 7

- Letters+Digits, e.g. XXXX000000

- Letters, e.g. XXXXXXXX

- Digits, e.g. 00000000

Output will be showed with error message as "Incorrect lot ID format".

Notes:

Note 2. Leading or trailing spaces are not considered

Note 3: Letter cases are not considered.

Note 4: Deleted records should not be considered.

Note 5: Erroneous visits should not be considered.

This report requires 1 supporting document, and the naming conventions is as below.

‘BNR005_supp_<xxxxxxx>.csv’

1. Group - numbers that identify the different groups of Lot ID.

Expected unique Lot ID per form will appear with a unique Group number.

2. Country - SA.Country If applies for all countries, enter NA.

3. Site - SA.Site Mnemonic. If applies for all sites, enter NA.

4. SM Form – DISP/SM/SMPU, specified as 'NA' if Format is the same for all Study Medications.

5. Study Medication - Value for specific DISP/SM/SMPU Study Medication, specified as 'NA' if Format is the same for all Study Medications.

6. Length - include the appropriate length of the Lot ID. The Length is required for Valid Format 1.

7. # of Letters - only complete if the appropriate number of letters is known. This item needs to be in synch with item 6. Complete as NA it is not applicable for the expected format

8. # of Digits - only complete if the appropriate number of digits is known. This item needs to be in synch with item 6. Complete as NA it is not applicable for the expected format

9. Starting with - only complete in case of just one common starting letter/s and/or digit/s per group of subjects. This item needs to be in synch with items 7 and 8. Complete as NA it is not applicable for the expected format

e.g.

Group,Country,Site,SM Form,Study Medication,Length,# of Letters,# of Digit,Starting with

1,USA,9998,SM,-3475,7,1,6,T

1,USA,9998,SM,-3475,7,1,6,S

1,USA,9998,SM,Lenvatinib,7,1,6,NA

1,USA,9998,SM,Oxaliplatin,NA,6,NA

2,USA,9997,SM,-3475,7,1,6,S

2,USA,9997,SM,Lenvatinib,7,1,6,NA

Report Scenarios:
1) Output=YES

The Lot ID does not match the expected format as selected on the supporting document.

2) Output=NO

The Lot ID matches the expected format as selected on the supporting document.

3) Output=YES

The Lot ID is missing for specified group of subjects according to parameter entered.

4) Output=NO

The Lot ID is not missing for specified group of subjects according to parameter entered.

5) Output=NO

Erroneous visits or Deleted records

Sorting:
Country, Site, Subject Number
