Report ID: RID352

Report Title:
Missing Oncologic Surgery for Adjuvant and Neoadjuvant therapy

Description:
This report will produce output for subjects that have Adjuvant or Neoadjuvant selected as reason for therapy in ODB form and OS is missing.

Column Heading:
1)       Country

2)       Site

3)       Subject Number

4)       ODB seq

5)       Reason for therapy

Logic:
Scenario 1: Scenario 1:ODB. Reason for Therapy = (Adjuvant OR Neo-Adjuvant) AND OS. Date of Surgery = NULL

Note:

-For deleted ODB records output should not appear. i.e: If there is an ODB completed with reason for therapy as Adjuvant or Neo-Adjuvant, but ODB record has been deleted there should not be an output.

- For deleted OS records output should appear. i.e: If there is an ODB completed with reason for therapy as Adjuvant or Neo- Adjuvant and there is OS record but has been deleted, there should be and output.

-For erroneous visit no output should appear.

-If there are several ODB entries and no OS entry, there should be an output for each of the ODB entries where reason for therapy is Adjuvant or Neo Adjuvant.

- If there is an ODB completed with reason for therapy as Adjuvant or Neo-Adjuvant and Date of Surgery in OS is provided partially as UNK, output should not appear

Report Scenarios:
Scenario 1:

Output - Yes

Output is generated if Reason for Therapy has been selected as Adjuvant or Neoadjuvant in Oncologic Drugs and Biologics form and Oncology Surgery information is missing

Output - No

Output is not expected when Reason for Therapy has been selected as Adjuvant or Neoadjuvant in Oncologic Drugs and Biologics form and Oncology Surgery information is completed.

Form.Item Names:
1) SA.Country

2) SA.Site

3) SA.Subject Number

4) ODB. FORMIDX

5) ODB. Reason for therapy
