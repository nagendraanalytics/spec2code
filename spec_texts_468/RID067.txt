Report ID: RID067

Report Title:
Procedure/Lab test is Listed as an Adverse Event

Description:

4. Form Name

5. Seq

Report should display Adverse Event terms on AE/SAEI/SAEP/APAE form

where SOC = 'Surgical and medical procedures'

OR

Report should not display deleted records.

If ""Randomized only"" parameter selection checkbox is checked, the report should only output subjects with Randomization number that is not null.

this report should not be case-sensitive

Note: Report should run for AE if other mandatory forms are not present in study and error message should be removed.
