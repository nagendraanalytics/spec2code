Report ID: RID288

Report Title:
OAGVH/CGVHD Dates VS. AE Dates

Description:
This report lists subjects with no matching dates between OAGVH/CGVHD Grade Onset/Stop date and AE Toxicity Grade Onset/end date.

Column Heading:
1. Country

2. Site

3. Subject Number

4. GVHD form

5. GVHD seq

6. GVHD Start date

7. GVHD Stop date

8. Associated AE

9. AE Onset Date

10. AE End Date

11. Scenario

Logic:
Scenario 1:

Logic 1: there is an associated AE on OAGVH/CGVHD Associated AE Sequence Number

AND

Logic 2: the earliest onset date in OAGVH/CGVHD date does not equal onset date of the AE from logic 1.

Scenario 2:

Logic 3: there is an associated AE on OAGVH/CGVHD Associated AE Sequence Number

AND

Logic 4: the latest end date between OAGVH/CGVHD date does not equal the end date of the AE from logic 3.

Note 1: when there is an AE end date and time as ongoing then OAGVH/CGVHD end date should be Ongoing.

Note 2: please disregard the time.

Note 3: for OAGVH use the earliest onset date from "GVHD Grade Onset Date" and use the latest End date from "GVHD Grade Stop Date". For CGVHD use onset date "Chronic GVHD Grade Start Date", End date "Chronic GVHD Grade Stop Date".

Note 4: please exclude deleted records and erroneous visits from programming.

Note 5: please use OAGVH/CGVHD independently. if there is an associated AE in OAGVH, then check dates using AE and OAGVH. if there is an associated AE in CGVHD, then check dates using AE and CGVHD.

Note 6: when AE End Date is selected as ‘Duration if less than 24 hrs’ please use the latest AE Toxicity Grade Stop Date as the AE stop date

Note 7: when the OAGVH/CGVHD form only has one text box of AE, use the AE onset date and AE end date. when the OAGVH/CGVHD form has two text box for Associated AE, use the earliest onset date of both AEs and the latest onset date of both AEs.

Report Scenarios:
Scenario 1, output yes:

OAGVH/CGVHD Grade Onset Date does not equal Onset Date for the associated AE.

Scenario 2, output yes:

2a) associated AE End Date and Time does not equal the maximum date of OAGVH/CGVHD Grade Stop Date.

2b) associated AE End date and Time is “ongoing" but there is no "Ongoing" OAGVH/CGVHD Grade Stop Date.

2c) associated AE End Date and time has an End date but there is a "ongoing" OAGVH/CGVHD  Grade Stop Date.

Scenario 3, output no:

associated AE Onset Date and Time equal the OAGVH/CGVHD Grade Onset Date AND AE End Date and Time equal the maximum date of OAGVH/CGVHD Grade Stop Date.

Scenario 4 output no:

associated AE Onset Date and Time equal the minimum GVHD Grade Onset Date AND AE is ongoing AND OAGVH/CGVHD Grade Stop Date is "Ongoing" .

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, Site Number, Subject Number, Randomized only, List of subjects

Form.Item Names:
1. SA.Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. OAGVH/CGVHD

5. OAGVH/CGVHD. Sponsor ID Number

6. OAGVH/CGVHD. onset date as mentioned on note 3

7. OAGVH/CGVHD. end date as mentioned on note 3

8. OAGVH/CGVHD. Associated AE Sequence Number, if there are two AEs, display them separated by commas.

9. AE. Onset Date and Time, show only the date. If there are two AEs, display the earliest date.

10. AE. End Date and Time, show only the date.If there are two AEs, display the latest date. if AE end date is ‘Duration if less than 24 hrs’, display the latest AE Toxicity Grade Stop Date

11. Display "Scenario 1" for logic 1 and 2, display "Scenario 2" for logic 3 and 4
