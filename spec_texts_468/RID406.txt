Report ID: RID406

Report Title:
Oncologic Surgery or Radiation completed but no PROC provided

Description:
This report will display subjects who completed Oncologic Surgery or Radiation during 30 days prior from the onset of an SAE/ECI but PROC information is not provided

Column Heading:
FOR TAB 1:

1.Country

2. Site

3. Subject Number

4. Surgery form

5. Sequence

6. Surgery term

7. Date of Surgery

8. AE Sequence

9. AE Term

10. AE Onset Date and Time

FOR TAB 2:

1.Country

2. Site

3. Subject Number

4. Radiation form

5. Sequence

6. Radiation Start Date

7. Radiation Stop Date

8. AE Sequence

9. AE Term

10. AE Onset Date and Time

Logic:
Logic 1 (For tab 1)

Logic 1.1 Date of Surgery <> null

AND

Logic 1.2  AE.Onset Date and Time  <> null

AND

{Logic 1.3 AE.Serious Criteria <> null

OR

Logic 1.4 AE.Is the AE an Event of Clinical Interest? <> null}

AND

Logic 1.5 Date of Surgery is within 30 days prior SAE/ECI Onset Date

AND

There is not at least one PROC record meet below criteria:

{Logic 1.6 PROC.LLT term = OS/OSOF eCRF.LLT

OR

Logic 1.7 PROC.LLT term = Radical cystectomy.

OR

Logic 1.8 PROC.LLT term = Associated PROC LLT term per supp document.}

AND

Logic 1.9 PROC.Procedure Start date=Date of Surgery

Logic 2 (for tab 2)

Logic 2.1 Radiation Start Date <> null

AND

Logic 2.2 AE. Onset Date and Time <> null

AND

{Logic 2.3 AE.Serious Criteria <> null

OR

Logic 2.4 AE.Is the AE an Event of Clinical Interest? <> null }

AND

Logic 2.5 Radiation Start Date is within 30 days prior SAE/ECI Onset Date

AND

There is not at least one PROC record meet below criteria:

Logic 2.6 Radiation Start Date = PROC.Procedure Start date

OR

Logic 2.7 Radiation Stop Date <> null

AND

Logic 2.8 AE. Onset Date and Time   <> null

AND

{Logic 2.9 AE.Serious Criteria <> null

OR

Logic 2.10 AE.Is the AE an Event of Clinical Interest? <> null}

AND

Logic 2.11 Radiation Stop Date is within 30 days prior SAE/ECI Onset Date

AND

There is not at least one PROC record meet below criteria:

Logic 2.12 Radiation Stop date = PROC.Procedure Stop date

Note 1: Please consider  SAE/ECI Onset date as AE.Start Date  for any AE record with either:

- Serious Criteria <> Null AND Serious Criteria <> None OR

- Is the AE an Event of Clinical Interest? = Yes

Note 2: For Logic 1.1 and 1.5 “Date of Surgery” refers to OS.Date of Surgery, OSOF eCRF.DATE OF SURGERY, SPLO.Date of Surgery, SPLX.Date of Surgery and SPPX.Date of Surgery.

Note 3: Logic 1.7 is applicable for OSOC eCRF

Note 4: Logic 1.8 is applicable for SPLO, SPLX and SPPX eCRFs.

Note 5: For logic 1.8 Study defined LLT term refers to the LLT in PROC eCRF to be associated with SPLO, SPLX and SPPX eCRFs

Note 6: For logic 2.6 Radiation start date refers to ORAD.Start date and ORAD2.Start date

Note 7: For logic 2.12 Radiation stop date refers to ORAD.Stop date and ORAD2.Stop date

Note 8: Please exclude deleted records

Note 9: The report will use master supporting document OSOF_supp_doc. This supporting document should be uploaded only once at TA level per the GDO Oncology TAST authorized members and will be used to facilitate programming of the report. Report builder will use all the columns provided in the excel spreadsheet to create the programming code. OSOF refers to the forms included in the OSOF_supp_doc.

Note 10. If trial has implemented SPLO, SPLX and/or SPPX requires an optional supporting document to be named ONC_PROC_001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

Group, Surgery eCRF, Associated PROC LLT term  

1 Group: Unique key for each surgery eCRF

2 Surgery eCRF: Surgery eCRF to be considered in the report 

3 Associated PROC LLT term:  LLT term expected in PROC eCRF according to each surgery eCRF (SPLO, SPLX, SPPX)

Report Scenarios:
Scenario 1 Output Yes:

• There is an OS/[Oncology Surgery Follow-up Forms] entry with Date of surgery within 30 days prior from SAE/ECI Onset Date and there is not at least a PROC entry with following conditions:

o Procedure start date is the same as the OS/[Oncology Surgery Follow-up Forms] Date of surgery

o LLT term in PROC is the same as LLT term in OS/[Oncology Surgery Follow-up Forms].

• There is an SPLO/SPLX/SPPX entry with Date of surgery within 30 days prior from SAE/ECI Onset Date and there is not at least a PROC entry with following conditions:

o Procedure start date is the same as the SPLO/SPLX/SPPX Date of surgery

o LLT term in PROC is the same as the associated LLT term for SPLO/SPLX/SPPX eCRFs

• There is an ORAD2 entry with start date or stop date within 30 days prior from SAE/ECI Onset Date and there is not at least a PROC entry with following conditions

o Start Date or Stop date in ORAD2 is the same as PROC

Scenario 2 Output No:

• There is an OS/[Oncology Surgery Follow-up Forms] entry with Date of surgery within 30 days prior from SAE/ECI Onset Date and there is at least a PROC entry with following conditions:

o Procedure start date is the same as the OS/[Oncology Surgery Follow-up Forms] Date of surgery

o LLT term in PROC is the same as LLT term in OS/[Oncology Surgery Follow-up Forms].

• There is an SPLO/SPLX/SPPX entry with Date of surgery within 30 days prior from SAE/ECI Onset Date and there is at least a PROC entry with following conditions:

o Procedure start date is the same as the SPLO/SPLX/SPPX Date of surgery

o LLT term in PROC is the same as the associated LLT term for SPLO/SPLX/SPPX eCRFs

• There is an ORAD2 entry with start date or stop date within 30 days prior from SAE/ECI Onset Date and there is at least a PROC entry with following conditions

o Start Date or Stop date in ORAD2 is the same as PROC
