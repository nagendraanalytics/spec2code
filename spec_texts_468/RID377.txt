Report ID: RID377

Report Title:
Overall Response vs Lesion Evaluation measurements

Description:
This listing contains details about the type of lesions reported under Lesion Identification/ Tumor identification item on LSNPC (Target, Non-target, and New) and the corresponding Overall PCWG2-modified RECIST Response recorded in ORPC.

- For the Target lesions (Target Nodal or Target Extra nodal) the listing will show the Target Lesion Measurement for each lesion and the Sum of the diameters (SOD) for all the lesions evaluated on the same date. If the item "Was the Lesion Evaluable?" is selected as No, the lesion expected response will appear as Not evaluable.

 - For the Non-target lesions (Non-Target Nodal or Non-Target Extra nodal), the listing will show the total number of lesions for each Non-Target lesion status evaluated on the same date (Absent, Present, Enlargement). If the item "Was the Lesion Evaluable?" is selected as No, the lesion expected response will appear as Not evaluable.

- For the New lesions (New Soft Tissue Lesion Since Last Evaluation or New Bone Lesion), the listing will show the total number of lesions for each New Lesion status (Absent, Present, Enlargement) evaluated on the same date.

- For the Bone Lesion, the listing will show the total number of lesions for each Bone Lesion Status (Absent, Present) evaluated on the same date.

- For the Target lesions, the report will show also the variation from Baseline and Nadir on each evaluation date to easily calculate the Response.

% change from Baseline:

[(SOD from current Timepoint / Baseline SOD) - 1] x 100

% from Nadir:

[(SOD from current time point – Nadir SOD) / Nadir SOD] x 100%.

Nadir: Is the smallest SOD since Baseline.

Note: SOD = sum of longest diameters for extra nodal or short axis  for nodal of all Target lesions.

Note: To be used with PCWG2-modified RECIST and Overall Response

Logic:
Report will output the subjects who meet following criteria.

Logic 1: ORPC.Date Response Determined AND ORPC.Overall Response is not Null

AND

Logic 2:

LSNPC.Lesion identification = 'Target Nodal, Target Extra Nodal, non-Target Nodal, non-Target Extra Nodal, New Soft Tissue Lesion Since Last Evaluation, New Bone Lesion or Bone Lesion'

AND

Logic 3: ORPC. Date Response Determined – x days <= LSNPC. Evaluation Entry with Date of Lesion Evaluation

AND

Logic 4: LSNPC.Date of Lesion Evaluation >= ORPC. Date Response Determined + x days

AND

Logic 5: LSNPC. Was the Lesion Evaluable? <> 'No'

Note1: Deleted data should be excluded from programming.

Note2: “x” is the Allowed Window entered as parameter.

Report Scenarios:
A- Yes List Overall Response of ORPC and its corresponding LSNPC (Target Nodal, Target Extra Nodal, non-Target Nodal, non-Target Extra Nodal, New Soft Tissue Lesion Since Last Evaluation, New Bone Lesion, and Bone Lesion)

B- Yes List Overall Response of ORPC which has no corresponding LSNPC or LSNPC which has  no corresponding ORPC

C- Yes LSNPC cannot evaluate

D- No Deleted record
