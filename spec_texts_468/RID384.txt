Report ID: RID384

Report Title:
Biopsies entries in Oncology Surgery forms

Description:
This report will list subjects where biopsies have been entered in the Oncology Surgery forms

Column Heading:
1. Country

2. Site

3. Subject number

4. eCRF

5. Oncology Surgery Seq

6. Oncology Surgery Term

7. Oncology Surgery LLT

8. Scenario

Logic:
Logic 1:

SURGERY eCRF.LLT begins with the word "Biopsy" or contains the word "biopsy"

AND

SURGERY eCRF.POST OP RESULT <> "Complete Resection"

AND

SURGERY eCRF.DATE OF SURGERY < Survival Reference Date Hardcode = Scenario 1

Logic 2:

SURGERY eCRF.LLT begins with the word "Biopsy" or contains the word "biopsy"

AND

SURGERY eCRF.POST OP RESULT = "Complete Resection"

AND

SURGERY eCRF.DATE OF SURGERY < Survival Reference Date Hardcode = Scenario 2

Logic 3:

SURGERY eCRF.LLT begins with the word "Biopsy" or contains the word "biopsy"

AND

 SURGERY eCRF.DATE OF SURGERY >= Survival Reference Date Hardcode = Scenario 3

Note 1: Survival Reference Date refers to form. Date of assessment with (Select the Status of the Subject for the Next Trial Segment = Next trial segment)

eg. If form in supporting document = OEDRA, then Survival Reference Date = OEDRA. Date of assessment.

If there are more than one PMS1A.Date that meets the condition, use the one with the latest date.

If either OEDRA or PMS1A or PMST.Date = Null, then Survival Reference Date = System Date.

Note 2: Deleted records and erroneous visits should not be considered for any scenario.

Note 3: Exclude records if SURGERY eCRF.DATE OF SURGERY is null

Note 4: Hardcode SURGERY eCRF.DATE OF SURGERY as below: Month UNK: Jan Day UNK: 01

Note 5:  If supporting doc is not provided, display the message as "ONC_OS_001_JR_STD Supporting Document Not Present for This Trial".

Note 6: Ignore Scenario 1 and Scenario 2 if the item SURGERY eCRF.POST OP RESULT does not exist on the trial.

Note 7. The report will use master supporting document OSOF_supp_doc. This supporting document should be uploaded only once at TA level per the GDO Oncology TAST authorized members and will be used to facilitate programming of the report. Report builder will use all the columns provided in the excel spreadsheet to create the programming code. OSOF eCRF refers to the forms included in the OSOF_supp_doc.

Note 8. The report will use below itemquestions in OS eCRF and OSOF_supp_doc: 'DATE OF SURGERY', 'LLT', 'POST OP RESULT', 'ONCOLOGIC SURGERY','PROCEDURE’.

Note 9: SURGERY eCRF refers to the OS eCRF and all the eCRFs in OSOF_supp_doc.

Requires supporting document to be named ONC_OS_001 _supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each group of the Protocol Milestone eCRF and the next trial segment

1. Form- required enter PMS1A/PMST/OEDRA

2. Next trial segment required for PMS1A/PMST, for OEDRA enter NA

e.g.

Form                   Next trial segment

PMS1A      	Continuing into Survival Follow-Up

PMST		Continuing into Survival Follow-Up

OEDRA		NA

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
A - Yes

There is a biopsy entry in either OS/Oncology Surgery Follow-up Forms and the item Post Op Result <> Complete Resection and the Date of Surgery in Oncology Surgery Follow-up Forms is prior to Survival Reference Date.

B - Yes

There is a biopsy entry in either eCRF OS/Oncology Surgery Follow-up Forms and the item Post Op Result = Complete Resection and the Date of Surgery in Oncology Surgery Follow-up Forms is prior to Survival Reference Date.

C – Yes

There is a biopsy entry in either eCRF OS/Oncology Surgery Follow-up Forms and the Date of Surgery in OS/Oncology Surgery Follow-up Forms is equal or after Survival Reference Date,

D – No

There is an OS/Oncology Surgery Follow-up Forms record with a LLT that does not begin with the word “Biopsy” nor contains the word “biopsy”

Sorting:
Country, Site, Subject number, eCRF, Oncology Surgery Seq, Oncology Surgery Term, Oncology Surgery LLT, Scenario

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Supporting Doc Page (N/Y, Default as N) , SURGERY Form(Text Box, default as ‘ALL’, separate each eCRF by comma)

Form.Item Names:
1. SA.Country

2. SA.Site

3. SA.Subject number

4. SURGERY eCRF.FORM MNEMONIC

5. SURGERY eCRF.SPONSOR ID NUMBER

6. SURGERY eCRF.PROCEDURE/ ONCOLOGIC SURGERY

7. SURGERY eCRF.LLT

8. Display as hardcoded in the Logic.
