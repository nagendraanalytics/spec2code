Report ID: RID334

Report Title:
Duplicate Primary Diagnosis

Description:
This report displays subjects who have the primary diagnosis term entered in the Medical History eCRF (base on matching LLT and/or PT terms)

Column Heading:
1. Country

2. Site

3. Subject Number

4. MH Visit

5. MH Seq

6. MH Term

7. MH LLT

8. MH PT

9. Primary Diagnosis Visit

10. Primary Diagnosis eCRF

11. Primary Diagnosis

Logic:
LOGIC 1 MH. LLT [hidden] <> null AND MH. PT [hidden] <> null;

AND

LOGIC 2 Primary Diagnosis eCRF.Primary Diagnosis/DDRCC.Current Diagnosis/PSD.Parent Study - Primary Diagnosis in Primary Diagnosis eCRF(s) [HDDG, HDDH, HDDB, HDDHN, HDDU, HODD, HDDM, HDDGY, HDDO, CDDO, CDDU, CDDG, CDDB, CDDH, CDDHN, CODD, DDRCC, CDDM, CDDGY, PSD] <> null;

AND

LOGIC 3 MH. LLT [hidden] exactly matches Primary Diagnosis eCRF.Primary Diagnosis/DDRCC.Current Diagnosis/PSD.Parent Study - Primary Diagnosis or the ones provided in supporting document

OR

LOGIC 4 MH. PT [hidden] exactly matches Primary Diagnosis eCRF.Primary Diagnosis/DDRCC.Current Diagnosis/PSD.Parent Study - Primary Diagnosis or the ones provided in supporting document

Notes:

1.Deleted records or erroneous visits will be excluded.

2.If supporting doc is not provided, just check when MH PT/LLT is exactly match with Primary Diagnosis eCRF.Primary Diagnosis/DDRCC.Current Diagnosis/PSD.Parent Study - Primary Diagnosis.

Requires supporting document to be named ONC_MH_001_supp_.csv and will contain the following columns and associated content:

1 row for each group of Disease Details Form and Item Question for Diagnosis in Disease Details Form.

1. Group

2. Form - Disease Details Form

3. Item Question - Item Question for Diagnosis

4. Primary Diagnosis

5. MH PT

6. MH LLT

e.g.

Group,Form,Item Question,Primary Diagnosis,MH PT,MH LLT

1,CODD,Primary Diagnosis,Melanoma,Melanoma,Malignant Melanoma

2,CODD,Primary Diagnosis,Lung cancer,Lung neoplasm malignant,Lung neoplasm malignant

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization". The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
A output = No MH.LLT = null OR MH. PT = null OR Primary Diagnosis = null

B output = No MH.LLT <> Primary Diagnosis AND MH.PT <> Primary Diagnosis

C Output = Yes MH.LLT = Primary Diagnosis OR MH.PT = Primary Diagnosis per supporting document

Sorting:
Country, Site Number, Subject Number, MH Seq Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, Randomized Only, Supporting Doc Page (N/Y, Default as N)
