Report ID: RID364

Report Title:
Constitutional Symptoms review between ORCLL and OSS

Description:
The report will be used to compare the constitutional symptoms information between ORCLL and OSS for consistency

Column Heading:
Table 1:

1.	Country

2.	Site

3.	Subject Number

4.            Sequence Number

5.	ORCLL Date

6.	ORCLL Constitutional Symptoms

Table 2:

1.	Country

2.	Site

3.	Subject Number

4.            Sequence Number

5.	OSS Date

6.	OSS Constitutional Symptoms

Logic:
Logic 1:

Logic 1.1: There is at least one ORCLL record with "Date of Procedure for Overall Response (Scan/Image/Physical Exam)" <> NULL AND "Does the Subject have Disease Related Constitutional Symptoms?" = "Yes"

AND

Logic 1.2: There is NOT at least one OSS record meet the following criteria:

(

Logic 1.3: "Date of Symptom Assessment" within +/- "Window of Days" from the ORCLL.Date of Procedure for Overall Response (Scan/Image/Physical Exam)

AND

Logic 1.4: At least one of the "Constitutional Symptoms" per supporting document = "Present"

)

Logic 2:

Logic 2.1: There is at least one OSS record with "Date of Symptom Assessment" <> NULL AND at least one of the "Constitutional Symptoms" per supporting document = "Present"

AND

Logic 2.2: There is NOT at least one ORCLL record meet the following criteria:

(

Logic 2.3: "Date of Procedure for Overall Response (Scan/Image/Physical Exam)" within +/- "Window of Days" from the OSS.Date of Symptom Assessment

AND

Logic 2.4: "Does the Subject have Disease Related Constitutional Symptoms?" = "Yes"

)

General Notes:

1.	Erroneous visits and deleted records are excluded from programming

2.	"Window of Days" is a prompt

Supporting Document Notes:

1.	Requires supporting document to be named ONC_ORCLL_001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

Constitutional Symptoms

For example:

Constitutional Symptoms

Fever

Night Sweats

Weight Loss

Fatigue

Layout Notes:

1.	For Table 2 and Column 6, display the different constitutional symptoms that are answered as "Present" separated by comma and a single space, for example: Fever, Night Sweats

2.	For any field where a date is displayed, use format "dd-Mmm-yyyy"

Report Scenarios:
As per the defined logic

Sorting:
Table 1: Country, Site, Subject Number, ORCLL Date

Table 2: Country, Site, Subject Number, OSS Date

of Subjects, Randomized Only (N/ default as N), Window of Days (Free textbox, default as 14, user should be allowed to changed anytime, only numeric values are accepted), Supporting Doc Page (Y/N, default as N)
