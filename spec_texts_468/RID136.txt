Report ID: RID136

Report Title:
Listing of items completed with radio button comment

Description:
This report displays a listing of items completed with Not done/Unknown/Not applicable comment

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. DOV

6. eCRF

7. Seq

8. Item Name

9. Required?

10. Comment Radiobutton

11. Comment Text

Logic:
The report displays items completed with item-level or form-level Not Done/Not Applicable/Unknown radio button comments.

Note:

1. Deleted records should not be considered.

2. Data in erroneous visits should not be considered.

3. Column 10. Comment Radiobutton and 11. Comment Text shuld be masked as 'xxxx' for Blinded tables, including SMPB/DISP/SR1 and other forms specified in column 4 - BLINDEDTABLES of supporting doc.

Requires supporting document to be named LST003_supp_<xxxxxxx>.csv (in csv format) and will contain the following columns and associated content (THE FOLLOWING ITEMS DO NOT NEED TO BE PROVIDED AGAIN):

AE - AE Term (For lab AE use the term increased or decreased)

CM - Medication Name

DAR - Autopsy Determined Cause of Death

DEATH - Primary Reported Cause of Death

MH – Medical History Term

PROC - Procedure Term

PDIAG - Primary Diagnosis ; Secondary Diagnosis

SAEI - AE Term (For lab AE use the term increased or decreased) ; Primary Reported Cause of Death

SAEP - AE Term (For lab AE use the term increased or decreased) ; Primary Reported Cause of Death

SLAB - Laboratory Test ; Numeric Result

Column 4 should include the list of eCRF with blinded data (THE FOLLOWING TABLES DO NOT NEED TO BE PROVIDED AGAIN: SMPB/DISP/SR1)

1 row for each required field with the following columns:

      1. VIEWNAME

      2. COLUMNNAME

      3. COLUMNLABEL

      4. BLINDEDTABLES

Eg.

VIEWNAME,COLUMNNAME,COLUMNLABEL,BLINDEDTABLES

CV_LSRIRFM,DT_LSRIRLSDTCIT,Date ~ Date of Assessment,PTHA

CV_LSRIRFM_LSRIR2SN_LSRIR2IS,DT_LSRIRLSDTCEIT,Date ~ Date of Lesion Evaluation,GEFCF

CV_HSUFM,DT_HSUHODTCASMTIT,Date ~ Date and Time of Assessment

CV_ORAD2FM,DT_ORAD2PRDTCIT,Date ~ Date of Assessment

CV_RRIRFM,DT_RRIRRSDTCIT,Date ~ Date Response Determined

CV_ODBFFM,DT_ODBFCMSTDTCIT,Date ~ Start Date of Regimen

CV_PTHAFM,PTHAPHORRESVTIT,Percent of Viable Tumor Cell for the Primary Tumor Specimen

Note:

a. The report 'Data Dictionary Report' in GDMSRPT could be used to prepare the supporting doc for LST003_JR_STD.

b. If supporting doc is not provided or supporting doc do not have column BLINDEDTABLES, show the error message as 'Blinded Tables are not provided for xxxxxxx. Please Update the supporting doc with column BLINDEDTABLES.'

c. Column 'BLINDEDTABLES' is always required. If no blinded form except for SMPB/DISP/SR1, leave it as blank.

d. Please include all the encoded items for the protocol on the supporting doc.

e. Report output will be displayed as .lst(.pdf) and .csv format.

Report Scenarios:
1) Output=YES; Item has an item/form-level Not Done/Not Applicable/Unknown radiobutton commnent with or without comment text.

2) Output=NO; Item only has a comment text.

3) Output=NO; Item does not have am item/form-level Not Done/Not Applicable/Unknown radiobutton commnent.

Sorting:
Country, Site, Subject Number, Visitorder, DOV, Visit, eCRF, Seq, Item Name, Comment Radiobutton

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only, eCRF, Visit.
