Report ID: RID351

Report Title:
Mismatch between Drug regimen and Medication Start/Stop date

Description:
This report will output mismatches between the Start Date of Regimen and the Earliest Start date of Medication in the Regimen. Also, it will display mismatches between the Stop Date of Regimen and the Maximum Stop date of Medication in the Regimen.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Visit Mnemonic

6. Sequence

7. Imputed Start Date of Regimen

8. Earliest Start Date of Medication

9. Imputed Stop Date of Regimen

10. Latest Imputed Stop Date of Medication

Logic:
Logic 1

ODB/ODBF eCRF.IMPUTED START DATE OF REGIMEN <> Earliest ODB/ODBF eCRF.IMPUTED START DATE OF MEDICATION in the Regimen

Logic 2

ODB/ODBF eCRF.IMPUTED STOP DATE OF REGIMEN <> Latest ODB/ODBF.IMPUTED STOP DATE OF MEDICATION in the Regimen

Notes:

1. When imputed Start Date of Regimen blank and Earliest Imputed Start date Medication blank then it is considered a match.

2. When imputed Stop Date of Regimen blank and Latest Imputed Stop date of Medication blank then it is considered a match.

3. Deleted records or erroneous visits will be excluded.

4. Information should be compared within the same form sequence.

5. ODB eCRF includes all eCRFs in ODB_supp_doc.csv

6. ODBF eCRF includes all eCRFs in ODBF_supp_doc.csv

7. If only logic 1 is satisfied, then display column 9 and 10 blank. if only logic 2 is completed then display column 7 and 8 blank. if both logics are completed then display all columns.

8. For the columns where a date is shown in the output, use the format "DDMMMYYYY". For example: "01JAN2021"

9. For logic 2, when the parameter Include Stop Date of Regimen Null? = N, then don’t consider the scenario Stop Date of Regimen is blank. When the parameter Include Stop Date of Regimen Null? = Y, then consider the scenario Stop Date of Regimen is blank.

Report Scenarios:
Scenario 1 output = Yes

Start Date of Regimen <> Earliest Start date of Medication

Scenario 2 output = Yes

Stop Date of Regimen <>Latest Stop date of Medication

Scenario 3  output = No

Start Date of Regimen = Earliest Start date of Medication

Scenario 4  output = No

Stop Date of Regimen = Latest date of Medication

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N), ODB/ODBF Form (free textbox, type in the forms separated by comma, if prompt is left empty the report will compare all the forms available in the study), Include Stop Date of Regimen Null? (Y/N, Defult as N)

6. Forms: ODB, ODBCS, ODBHN, ODBH, ODBF, ODBCF, ODBNF, ODBHF . Sponsor ID Number

7. Forms: ODB, ODBCS, ODBHN, ODBH, ODBF, ODBCF, ODBNF, ODBH. Imputed Start Date of Regimen.
