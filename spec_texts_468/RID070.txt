Report ID: RID070

Report Title:
Unencoded terms on TA forms

Description:
This report identifies unencoded terms on the following forms in InForm: XXXX

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Form

6. Seq

7. Verbatim Term

Logic:
The report should display output if a Verbatim Term is not null and all of the corresponding derived fields are null in any of the following forms: XXXX

Display row count in footer

Report should not display deleted records.

If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.

Requires supporting document to be named ENC004_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each form along with the Verbatim terms and respective Encoding terms.

1)Form – Formrefnames for each form, Not Null

2)Verbatimterms – Verbatim terms for respective form, Not Null

3)Encodingitems – Encoding terms for each form and Verbatim term. If null then provide ‘NA’

E.g:

Form,Verbatimterms,Encodingitems1,Encodingitems2,Encodingitems3,Encodingitems4 Encodingitems5 ,Encodingitems6,Encodingitems7

OS,Procedure,LLT,PT,SOC,NA,NA,NA,NA,

ODB,Oncologic Drug or Biologic Name,Standardized Oncologic Drug,Encoded Oncologic Drug,Broader Term,Medication Class,Medication Class Code,ATC1 Term,ATC2 Term

Report Scenarios:
The report should display output if a Verbatim Term is not null and all of the corresponding derived fields are null in any of the following forms: XXXX

Display row count in footer

Report should not display deleted records.

If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.
