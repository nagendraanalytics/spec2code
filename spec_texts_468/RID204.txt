Report ID: RID204

Report Title:
Missing Required Items - Encoded Standard eCRFs and TA eCRFs

Description:
This report displays all missing required items from the selected Standard and TA eCRF modules which contain encoding.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. DOV

6. eCRF Name

7. Seq

8. Item Name

9. Query Text

10. Query Status

Logic:
This report should display all missing mandatory required items from Standard and TA eCRF modules which contain encoding.

Standard eCRFs include AE, CM, MH, DEATH, DAR, PDIAG, PROC, SAEI, SAEP, SLAB.

TA eCRFs with encoded terms for the trial will be included in the optional supporting document named as TQ009_supp_<xxxxxxx>.csv and will contain the following column and associated content:

1 row for each TA eCRF:

Form

e.g.

Form

OS

OSOF

ODB

ODBF

Note:

1.Items completed with Not Done/Not Applicable/Unknown from the comment bubble should not be displayed.

2.Report should not display deleted records.

3.Report should not display records in erroneous visits.

4.Report should not display Read-only and Hidden Item.

Report Scenarios:
1- Yes

Required items are missing in MH, AE, CM, SLAB, PROC, PDIAG, DAR, DEATH, SAEI, SAEP, <TA eCRFs> forms.

2- No

Required items are completed in MH, AE, CM, SLAB, PROC, PDIAG, DAR, DEATH, SAEI, SAEP,<TA eCRFs>  forms.

3- No

Required items are missing in deleted records on MH, AE, CM, SLAB, PROC, PDIAG, DAR, DEATH, SAEI, SAEP,<TA eCRFs> forms

Sorting:
Country, Site, Subject Number, Visitorder, Visitmnemonic, DOV, eCRF Name, Seq, Item Name

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only, eCRF Name, Hide Query Text & Status (No/Yes, Column Query text and Query status are hidden when Yes is selected, default is No)

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Visits.Visit Mnemonic

5. Visits.DOV

6. Form.Formmnemonic

7. Form.Sequence Number or formidx, and itemsetidx, if applicable

8. Derived: Missing Items

9. Queries.Query Data

10. Queries.Query State
