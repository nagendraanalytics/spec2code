Report ID: RID086

Report Title:
Duplicate GEFCF Records

Description:
This report lists all patients with duplicate GEFCF records based on the parameters selected from the GEFCF items.

LCDM should provide the appropriate prompts to be selected for each Vendor based on protocol team agreement

Logic:
Table 1: The report should output GEFCF records where GEFCF.Site ID or Number, GEFCF.Subject ID or Number, Test and all bellow listed GEFCF items excluding “Sequence Number” are equal.

Table 2: The report should output GEFCF records where GEFCF.Site ID or Number, GEFCF.Subject ID or Number “Category”, “Date/Time of Measurement” and “Result or Finding in Original Units“ are equal for tests “Overall Response” and “Best Overall Response”

Table 3: The report should output GEFCF records where GEFCF.Site ID or Number, GEFCF.Subject ID or Number, Test and all below listed GEFCF items excluding “Sequence Number” and "Specimen ID" are equal.

Note 3) Report should not display deleted records.

Note 4) Collection Date and Time field is formatted according to the ISO standard. An example for 12-Jul-2007 at noon is: 2007-07-12T12:00:00 (yyyy-mm-ddThh:mm:ss). However, not all time parts are always present.
