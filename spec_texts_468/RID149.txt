Report ID: RID149

Report Title:
Blood PK Invoice Scheduled vs Actual  Times Report (Samples after Last Dose)

Description:
This report generates a listing of blood PK Invoice records from the PK04 forms where the elapsed time is not within a window of scheduled time expected compared against the Last Dose Administered.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Phase

6. Period

7. PK Seq

8. Scheduled Time

9. Dose Begin Date/Time

10. Dose End Date/Time

11. Collection Date/Time

12. Elapsed Days

13. Elapsed Time (hrs)

14. Elapsed Time (mins)

15. Analyte

16. Comments

Logic:
For Post dose:

Output is produced if the elapsed time between the sample date/time and the last dosing date/time is outside window provided in supporting document compared to the expected scheduled time for the specific time point. The last dose date/time is taken from the PK04 form if present, or the study medication forms(SM04/SM/SMAU/SMAB). The last dose date/time is taken from Study medication record with the Last Dose Check box

Note1:  This report should not display deleted records and erroneous visits

Note 2: zero dose records should also be excluded from the Study medication forms

 In the PK001_T output, columns Scheduled Time and Elapsed Time (hrs) are highlighted in yellow to aid in data review.  Include Scheduled Time points that are being used per protocol.

Requires supporting document named PK001C_supp_XXXXXXX in csv format

Supporting document structure:

Scheduled Time  Point  Lower Window Limit(Min)   Upper Window Limit(Min)   Analyte     Dose End Date     SM Form

Report Scenarios:
Refer  to Test casebook
