Report ID: RID213

Report Title:
List of Items

Description:
Report added to obtain a list of items per form to include in different reports

Column Heading:
1. Formmnemonic

2. Itemrefname

3. Itemquestion

4. Item Required

5. SDV Required

6. Item property

Logic:
This report will list all forms and items present in the trial.

The output may be used to be copied and pasted in the prompts of other reports.

Only the current item version is displayed.

Report Scenarios:
1) Output=Yes

 Forms and items present in InForm

2) Output=No

  Forms and items not present in InForm

Sorting:
Formmnemonic, Itemquestion, Itemrefname

Parameter Selection:
Formmnemonic Only, Formmnemonic, Itemrefname, Itemquestion, Item(s) Required, SDV Required

Form.Item Names:
1. Forms.Formmnemonic

2. Items.Itemrefname

3. Items.Itemquestion

4. Items.Itemrequired - hardcoded to Y and N

5. Items.Sdvrequired - hardcoded to Y and N

6. Item property - hardcoded to Read-only, Hidden and Entered by Site
