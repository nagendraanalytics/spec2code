Report ID: RID290

Report Title:
GVHD term reconciliation

Description:
This report lists GVHD Adverse Events that do not indicate Hyperacute,  Acute or Chronic in the AE term.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE seq

5. AE Term

Logic:
Logic 1: There is an AE LLT that contains "graft versus host disease"

AND

Logic 2: AE Term does not contain the words "Hyperacute" OR "Acute" OR "Chronic"

Note 1: Please exclude deleted records from programming.

Note 2: The reconciliation should not be case sensitive.

Report Scenarios:
Scenario 1 output Yes:

there is an Adverse Event LLT Graft Versus Host Disease and  AE verbatim term does not indicate Hyperacute, acute or Chronic within the term.

Scenario 2 output No:

there is an Adverse Event LLT Graft Versus Host Disease and  AE verbatim term indicate Hyperacute, acute or Chronic within the term.

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, Site Number, Subject Number, Randomized only, List of subjects

Form.Item Names:
1. SA.Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. AE. Sequence Number

5. AE. AE Term
