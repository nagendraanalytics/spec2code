Report ID: RID405

Report Title:
Form variation dates reconciliation

Description:
This report will list subject that have inconsistent dates between forms variations.

Column Heading:
1.Country

2.Site

3.Suject Number

4. PMS1 Visit Mnemonic

5. PMS1 Date

6. PMS form

7. PMS form Visit Mnemonic

8. PMS form Date

Logic:
Logic:

Logic 1:If PMS1A.Date of Assessment is before PMS1.Date of Assessment for the same treatment phase.

OR

Logic 2: If PMST. Date of Assessment is before PMS1. Date of Assessment

Note 1:

The supporting document is required for all trials if treatment phase is applied to logic, even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required,the order on which phases will appear on protocol

2. Treatment Phase: name of each study phase (Intial Treatment Phase, Neodjuvant Phase, Secon Course Phase)

3. First Visitmnemonic of Treatment Phase: required,the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Note 2:

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: PMS1A/ PMS1.Date of Assessment

Note 3: Do not consider records in erroneous visit.

Report Scenarios:
A-Yes

PMS1A.Date of assessment is before PMS1.Date of Assessment for the same treatment phase.

B-Yes

PMST.Date of assessment is before PMS1.Date of Assessment.

C-No

If PMS1A.Date of assessment is on or after PMS1.Date of Assessment for the same treatment phase.

X-Yes

PMST.Date of assessment is after PMS1.Date of Assessment.

Country, Site, Subject Number
