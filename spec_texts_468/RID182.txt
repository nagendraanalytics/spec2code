Report ID: RID182

Report Title:
First and Last Dose Reconciliation

Description:
Reconciliation of the Actual First and Last Dose of Study Medication administered

14. Min Start Date

15  Max Stop Date

16. Error Message

Logic:
Report output the subjects who meet the following criteria.

Logic1: Start Date/Time of SM record on SM/SMAU/SMAB forms with first dose selected is not the minimum SM Date for each study medication.

or

Logic2: Stop Date/Time of SM record on SM/SMAU/SMAB forms with last dose selected is not the maximum SM Date for each study medication.

or

Logic3: there is more than one SM record with First dose selected for each study medication.

or

Logic4: there is more than one SM record with Last dose selected for each study medication.

Note 1: Deleted record or erroneous visit are excluded from the report.

Note 2: If subject takes more than one study medication, only compare the SM records with same study medication.

Note 3: the subjects who meet logic 3 or logic 4, display column 13, 14, 15 as blank and display multiple SM records with first/last dose entry in a separate row.

Note 4: Time should be considered in logic and display.

Note 5: Display the record when cannot compare the min/max date and time with UNK

Note 6a: If  SM Label Description and SMAU/SMAB Dose Number are exactly matched within forms For SM/SMAU/SMAB Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number directly.

Note 6b: If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_<xxxxxxx>.csv to define the mapping.

The optional supporting document is only required in the following cases:

- SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Optional supporting document should be named as study_med_match_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Label Description or Dose Number present in SM/SMAU/SMAB eCRFs.

1. eCRF – SM/SMAU/SMAB

2. Study Medication – Value of Study Medication

3. Matching Item – SM Label Description or SMAU/SMAB Dose Number

4. Matching Value – Value of SM Label Description or SMAU/SMAB Dose Number
