Report ID: RID098

Report Title:
eCOA records before minimum point per protocol or after maximum point per protocol or after final status for the subject

Description:
This report will output subjects with eCOA records before minimum starting point per protocol or after maximum point per protocol or after final status for the subject

Column Heading:
1. Country

2. Site

3. Subject Number

4. Vendor

5. Category

6. Min eCOA Start Point

7. Max eCOA Stop Point

8. Subject Disposition

9. Date of Last Contact

10. Date of Measurement

11. eCOA Completed/Missmode

12. Issue

Logic:
Vendor Name,  Min Start Visit. Max Stop visit are prompts for user to run the reports. Include DOLC dynamically – a prompt should be available so that the user can select DS01 or DOLC, if DOLC exists in the trial.

Output subject if, for any GEFCF record by Category:

Vendor Name= User selected Vendor Name

AND

[Date/Time of Measurement < user selected minimum start point

OR

(Date/Time of Measurement > user selected maximum stop point

OR

Date/Time of Measurement > Date of Disposition in DS01 or Date of Last Contact in DOLC)]

When 'user selected minimum start point' or 'user selected  maximum stop point' or ' Date of Disposition in DS01 or Date of Last Contact in DOLC' initialized then program corresponding logic.

--If both 'user selected maximum stop point' and 'DS01. Date of Disposition or DOLC. Date of Last Contact'  NOT EXIST, please display blanks for Columns 7, 8, 9.

   If only 'user selected maximum stop point' EXIST, display blanks in Columns 8, 9.

   If only 'DS01. Date of Disposition or DOLC. Date of Last Contact' EXIST, display blanks in Column 7.

--For all dates, please use format DD-Mon-YYYY

--Do not include any programming for erroneous visits/Deleted GEFCF records.

--For missmode, there could be just one record at a maximum per assessment. There could be no record at all if the site/subject has not completed it, and in that case it will need to be left blank.

Report Scenarios:
A- Yes

There is GEFCF record with Date/Time of Measurement < user selected minimum start point

B-Yes

There is GEFCF record with Date/Time of Measurement > user selected maximum stop point

C-Yes

There is GEFCF record with Date/Time of Measurement > Date of Disposition in DS01 or Date of Last Contact in DOLC

D-No

There is NO GEFCF record with Date/Time of Measurement < user selected minimum start point AND > Date of Disposition in DS01 or Date of Last Contact in DOLC
