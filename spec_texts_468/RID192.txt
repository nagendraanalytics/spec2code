Report ID: RID192

Report Title:
Reconciliation between reason for discontinuation in Label Description Status  and Status of Study Medication at the End of This Trial Segment in PMS1

Description:
This report displays inconsistencies between reason for discontinuation from treatment and PMS1 if last dose was indicated for all medications.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. Combo

6. Study Medication form

7. SM Visit

8. SM Label

9.Study Period

10. Scheduled Time

11. SM Start Date/Time

12. SM Last Dose

13. SM Label Description Status

14. PMS1 Status of Study Medication at the End of This Trial Segment

15. AE seq

16. AE term

17. AE onset date

18. AE action taken with SM

19. Error message

Logic:
“Criteria Form1”.” Criteria Itemquestion1” = “Criteria Value1” AND

“Criteria Form2”.” Criteria Itemquestion2” = “Criteria Value2” AND

“Criteria Form3”.” Criteria Itemquestion3” = “Criteria Value3” AND

Logic 1:

[SM Label] has Please Indicate if this is the First Dose for this Label Description=First Dose AND ALL [SM Label] Label Description Status<>NULL AND PMS1. Status of Study Medication at the End of This Trial Segment=NULL.

OR

Logic 2:

[SM Label] the maximum Date of Assessment AND Please Indicate if this is the Last Dose for this Label Description=Last Dose AND Label Description Status<>NULL AND Label Description Status<>Complete, AND Label Description Status<> PMS1. Status of Study Medication at the End of This Trial Segment

OR

Logic 3:

[SM Label] Last Dose corresponding Study Period = [SM Label] Last Dose corresponding Study Period

AND

PMS1. Status of Study Medication at the End of This Trial Segment=Clinical Progression OR Complete Response OR Lost to Follow up OR New Non-Study Anti-Cancer Therapy OR Pregnancy OR Progressive Disease OR Radiographic Progression OR Protocol Violation OR Site Terminated By Sponsor OR Study Terminated By Sponsor OR Withdrawal By Subject.

AND

([SM Label_1] Label Description Status<> PMS1. Status of Study Medication at the End of This Trial Segment) or ([SM Label_2] Label Description Status <>PMS1. Status of Study Medication at the End of This Trial Segment)

OR

Logic 4:

If [SM Label] with Label Description Status=AE

AND

1) There is no AE. Action taken with [SM Label] =Discontinued OR

2) AE. Action taken with [SM Label] =Discontinued AND AE. Onset Date and Time < [SM Label] Last dose date.

OR

Logic 5:

There is AE. Action taken with [SM Label] =Discontinued AND [SM Label]Last dose is checked AND [SM Label] Label Description Status<>AE.

OR

Logic 6:

For each [SM Label], the Max dose with Please Indicate if this is the Last Dose for this Label Description=NULL AND  Label Description Status=Clinical Progression or Complete Response or Lost to Follow up or Death or New Non-Study Anti-Cancer Therapy or Pregnancy or Progressive Disease or Radiographic Progression or Protocol Violation or Site Terminated By Sponsor or Study Terminated By Sponsor or Withdrawal By Subject.

Note:

1. Logic 3 only appropriate for two or more [study medication] used within combo.

2. exclude deleted records.

3. exclude if SMAB/SMAU under erroneous visit.

4. Logic 2 only considered when PMS1<>null.

5. “Label Description Status” item could be “Study Medication Status” in the new versions of SM forms.

6. This Report is not applicable for SMAU forms without study/label description status

7. For Logic 1, if have both SM and SMAB form, consider SM and SMAB together as one form.

Requires supporting document to be named SM026_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Study Medication, SM form, PMS form that are required per protocol.

Combo designed for different arms, for each combo we are going to have the same PMS1 form, same visit for PMS1, same Criteria form, same criteria value, and same specific visit.

And if one arm used different study medications in different study period, for example, used 1454 in initial treatment, and then used 1454 and 3475, they should be separate as different combos in supp doc.

1) Combo - Unique key for group of Arm/Cohort/Stratification for specified study period, NOT NULL

2) Criteria Form1 - Arm/Cohort/Stratification Form Mnemonic (E.g. SR/SRIVRS/TRIG). If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA

3) Criteria Itemquestion1 - Arm/Cohort/Stratification Itemquestion1. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion1 is not applicable for the protocol, enter NA

4) Criteria Value1 - Arm/Cohort/Stratification Value. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the itemValue1 is not applicable for the protocol, enter NA

5) Criteria Form2 - Arm/Cohort/Stratification Form Mnemonic (E.g. SR/SRIVRS/TRIG). If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

6) Criteria Itemquestion2 - Arm/Cohort/Stratification Itemquestion2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion2 is not applicable for the protocol, or is not needed enter NA

7) Criteria Value2 - Arm/Cohort/Stratification Value2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value2 is not applicable for the protocol, enter NA

8) Criteria Form3 - Arm/Cohort/Stratification Form Mnemonic (E.g. SR/SRIVRS/TRIG). If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

9) Criteria Itemquestion3 - Arm/Cohort/Stratification Itemquestion3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion3 is not applicable for the protocol, or is not needed enter NA

10) Criteria Value3 - Arm/Cohort/Stratification Value3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value3 is not applicable for the protocol, enter NA

11)  Study Medication - Value of Study Medication on SM/SMAU/SMAB/STR

12) Specified visit- First visit when Study medication used in specified treatment period. Enter the “Visit mnemonic” as per T&E

13) SM Form - SM/SMAU/SMAB/STR

14) PMS Form - PMS1/PMS1A/PMS1B/PMS1C

15) PMS Visit - Specified when the same PMS form used in different study periods, then located visit should be provided. Otherwise, specified as 'NA'.

Report Scenarios:
Scenario 1a: Output=yes,

All Study medications with Please Indicate if this is the First Dose for this Label Description=First Dose have Label Description Status completed, and PMS1 Status of Study Medication at the End of This Trial Segment was not completed.

Scenario 1b: Output=no,

[SM Label] with Please Indicate if this is the First Dose for this Label Description=First Dose and [SM Label] has Label Description Status completed, and another [SM Label] with Please Indicate if this is the First Dose for this Label Description=First Dose don't have Label Description Status completed, and PMS1 Status of Study Medication at the End of This Trial Segment was not completed.

Scenario 2a: Output=yes,

Maximum last dose reason for discontinuation in Label Description Status is not the same as Status of Study medication at the End of This Trial Segment on PMS1.

Scenario 2b: Output=no,

Maximum last dose reason for discontinuation in Label Description Status is the same as Status of Study medication at the End of This Trial Segment on PMS1.

Scenario 3a: Output=yes,

[SM Label] are discontinued at the same cycle, and Status of Study medication at the End of This Trial Segment on PMS1 is Clinical Progression, Complete Response, Lost to Follow up, New Non-Study Anti-Cancer Therapy, Pregnancy, Progressive Disease, Radiographic Progression, Protocol Violation, Site Terminated By Sponsor, Study Terminated By Sponsor or Withdrawal By Subject, but [SM Label] Label Description Status does not match with the Status of Study medication at the End of This Trial Segment on PMS1.

Scenario 3b: Output=no,

[SM Label] are discontinued at the same cycle, and Status of Study medication at the End of This Trial Segment on PMS1 is Clinical Progression, Complete Response, Lost to Follow up, New Non-Study Anti-Cancer Therapy, Pregnancy, Progressive Disease, Radiographic Progression, Protocol Violation, Site Terminated By Sponsor, Study Terminated By Sponsor or Withdrawal By Subject, and [SM Label] Label Description Status match with the Status of Study medication at the End of This Trial Segment on PMS1.

Scenario 4a: Output=yes,

Label Description Status is selected as Adverse Event for any medication and there is no AE on or after the study medication administration with action taken of Discontinued for the corresponding medication.

Scenario 4b: Output=no,

Label Description Status is selected as Adverse Event for any medication and there is AE on or after the study medication administration with action taken of Discontinued for the corresponding medication.

Scenario 5a: Output=yes,

There is an AE of any study medication last dose with action taken of Discontinued and Label Description Status is not selected as Adverse Event for the corresponding last dose study medication.

Scenario 5b: Output=no,

There is an AE with action taken of Discontinued and Label Description Status is selected as Adverse Event for the corresponding last dose study medication.

Scenario 6a: Output=yes,

if any medications are not indicated as last dose but the maximum last dose reason for discontinuation in Label Description Status is: Clinical Progression, Complete Response, Lost to Follow up, Death, New Non-Study Anti-Cancer Therapy, Pregnancy, Progressive Disease, Radiographic Progression, Protocol Violation, Site Terminated By Sponsor, Study Terminated By Sponsor or Withdrawal By Subject.

Scenario 6b: Output=no,

if any medications are indicated as last dose and the maximum last dose reason for discontinuation in Label Description Status is: Clinical Progression, Complete Response, Lost to Follow up, Death, New Non-Study Anti-Cancer Therapy, Pregnancy, Progressive Disease, Radiographic Progression, Protocol Violation, Site Terminated By Sponsor, Study Terminated By Sponsor or Withdrawal By Subject.
