Report ID: RID120

Report Title:
Missing WBC results

Description:
The report will output subject with missing White Blood Cell Differential (Absolute) specific test and the corresponding White Blood Cell Differential (%) specific test results.

Column Heading:
1.Country

2.Site

3.Subject Number

4.Visit Mnemonic

5.DOV

6.Form Name

7.Date Specimen Collected

8.HLAB/HLB01 Seq

9.Missing WBC differential test

Logic:
Logic 1: HLAB/HLB01 form is initialized

AND

Logic 2: HLAB/HLB01 form. both WBC test result in White Blood Cell Differential (Absolute) section

and corresponding WBC test result in White Blood Cell Differential (%) section are missing in any of the record with same assessment date.

Note 1: For each HLAB/HLB01 in the same date, if more than 1 test is missing, display all missing tests and sequence in 1 row.

Note 2: Report will no generate output if one or both of the tests (Absolute or %) is/are completed  with bubble comment as "Not Done".

        If one of the tests(Absolute or %) is completed as "Unknown" or "Not Applicable" and the other test is empty, output will be present.

        If 2 tests are completed with "Unknown" or "Not Applicable"  output will be present.

Note 3: Exclude deleted data and erroneous visit from programming.

Note 4: If supporting doc is not provided, display the message as "HLAB001_JR_STD Supporting Document Not Present for This Trial"

Note 5: For column 9, If 1 test is missing, display the test name only. E,g, if  both Absolute Neutrophil and Neutrophil (%) are missing, display Neutrophil only in the output

Note 6: If supporting doc is not provided, display the message as "HLAB001_JR_STD Supporting Document Not Present for This Trial".

Report requires supporting document to be named HLAB001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

LCDM to provide the following columns. All columns need to have the same number of rows:

1) Group: numbers that identify the different groups of tests.

2) Formmnemonic: corresponding to the appropriate local lab eCRFs HLAB OR HLB01

3) WBC Differential Test: This column should be completed with test name showed in output when both absolute result and % result missing. Usually it would be the test name of fourth column without  word “Absolute”

4) WBC Differential Absolute Test: enter the name of the absolute test name

5) WBC Differential Absolute Test: enter the name of the % test name

Example for HLAB:

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
A-Yes

HLAB/HLB01 initialized and both absolute result and % result for a certain White Blood Cell Differential test in the same date is missing.

B-No

HLAB/HLB01 initialized and either absolute result  or  % result for White Blood Cell Differential in the same date is completed.

C-No

HLAB/HLB01 not initialized

D-No

Erroneous visit or deleted record

E-Yes

HLAB/HLB01 initialized and both absolute result and % result for a certain White Blood Cell Differential test are marked as ""Unknown"" or ""Not Applicable"" with comment bubble in the same date

F-Yes

HLAB/HLB01 initialized and one of the test result (Absolute or %) is completed with comment bubble as ""Unknown"" or ""Not Applicable"", and another test reuslt is missing in the same date

G-No

HLAB/HLB01 initialized and one or both of absolute result and % result for a certain White Blood Cell Differential test are marked as ""Not Done"" with comment bubble
