Report ID: RID271

Report Title:
Reason for Dose Variation reconciliation between STR and SME for Radiation

Description:
This report will output subjects who do not have a matching Reason for Dose Variation between STR and SME when zero dose record matches.

Column Heading:
1. Country

2. Site

3. Subject Number

4. STR Visitmnemonic

5. STR seq#

6. STR Start Date/Time

7. STR Stop Date/time

8. STR Dose Amount

9. STR Reason for Dose Variation

10. SME Treatment Stop Date

11. SME Treatment Resume Date

12. SME Number of Units Taken

13. SME Reason for Dose Variation

Logic:
Output = Yes

Logic 1: There is an STR record with STR.Dose Amount = 0 record

AND

Logic 2: There is an SME record with SME.Number of Units taken = 0

AND

Logic 3: STR. Start Date/Time AND STR.Stop Date/Time are WITHIN SME.Treatment Stop Date and SME. Treatment Resume Date reported in any of the records on SME

AND

(

Logic 4: Data Entry Method “Daily” is selected in the Parameter Selection

AND

Logic 4.1 SME.Number of Days of Treatment Interruption is = to Number of STR records with STR.Dose Amount = 0 that are entered WITHIN the SME.Treatment Stop Date and SME. Treatment Resume Date reported

AND

Logic 4.2 SME.Reason for Dose Variation <> to al least one of the STR.Reason for Dose Variation entered in one of the STR rows that mets above condition

OR

Logic 5: Data Entry Method “Timeframe” is selected in the Parameter Selection

AND

Logic 5.1: STR. Start Date/Time AND STR. Stop Date/Time records with STR. Dose Amount = 0 are within SME. Treatment Stop Date and SME. Treatment Resume Date AND SME. Number of Units taken = 0

AND

Logic 5.2 (STR. Stop date – STR. Start Date) + 1 is = to SME. Number of Days of Treatment Interruption.

AND

Logic 5.3

SME.Reason for Dose Variation <> to at least one of the STR.Reason for Dose Variation entered in one of the STR rows that mets above condition

)

Notes:

Note 1: For STR. Start Date/Time, SME. Treatment Stop Date and SME. Treatment Resume Date ONLY check the date and not the time

Note 2: For all Scenarios, Report should review ALL records entered in STR and each row in STR should be compared with ALL records entered in SME. An output should be present ONLY for the STR row in which discrepancy is found against all SME data.

Note 3: Do not output for deleted records

Note 4: For al logics, WITHIN means that data in SME.Treatmet Stop Date < STR.Start date < SME.Treatment Resume Date

Report Scenarios:
Output – No: Zero dose between SME and STR do NOT match

Output – Yes:  Zero dose between SME and STR match and Reason for Dose Variation in STR form is not consistent with what is reported in SME form

Output – No: Zero dose between SME and STR match and Reason for Dose Variation in STR form is consistent with what is reported in SME form.

Output – No: Deleted records in STR
