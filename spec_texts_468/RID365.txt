Report ID: RID365

Report Title:
Initial Overall Response vs Lesion Evaluation measurements for Target Lesions

Description:
This listing contains details about the type of lesions reported under Tumor Identification “Target Nodal” OR “Target Extra nodal” OR "Target" on Lesion Evaluation form  and the corresponding RECIST and iRECIST Responses.

- Tumor Identification as "Target" with Longest Diameter will be considered as Target Extra Nodal

-Tumor Identification as "Target" with Short Axis will be considered as Target Nodal

- For the Target lesions (Target or Target Nodal or Target Extra Nodal) the listing will show the Target Lesion

Measurement for each lesion and the Summatory of the diameters (SOD) for the all the lesions evaluated on the same date. If the item "Was the Lesion Evaluable?" is selected as No, the lesion will appears as Not evaluable.

- For the Target lesions, the report will show also the variation from Baseline and Nadir on each evaluation date to easily calculate the Response.

% change from Baseline:

[(SOD from current Timepoint /  Baseline SOD) - 1] x 100

% from Nadir:

[(SOD from current time point – Nadir SOD) / Nadir SOD] x 100%.

Nadir: it the smallest SOD since Baseline

SOD = sum of all Target lesions (nodal and extra-nodal) for each time of assessment.

Logic:
(

Logic 1.1: ORIR.Date AND (ORIR.Overall RECIST Response OR ORIR.Overall iRECIST Response) are not Null

AND

Logic 1.2: LSNIR.Tumor Identification = "Target Nodal" OR "Target Extra Nodal" OR "Target"

AND

Logic 1.3: LSNIR.Date = ORIR.Date in logic 1.1

AND

{

Logic 1.4: ORIR. Target Lesion RECIST Response <> Expected RECIST Response

OR

Logic 1.5: ORIR. Target Lesion (Identified at Baseline) iRECIST Response <> Expected iRECIST Response

}

)

OR

(

Logic 2.1: LSNIR.Date is not Null

AND

Logic 2.2: LSNIR. Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) <> LSNIR. Date

OR

Logic 2.3: There is no ORIR record with ORIR.Date = LSNIR.Date

)

Note 1: Exclude deleted records and erroneous visits from programming.

Note 2: ORIR.Date refer to "Date of Determined" or "Date of Procedure for Overall Response (Scan/Image/Physical Exam)";

LSNIR.Date refer to "Date of Lesion Evaluation" or "Date of Current Lesion Evaluation (Scan/Image/Physical Exam)";

Note 3: The report logic should be checked within the same treatment phase defined in the supporting document.

First Visitmnemonic of Treatment Phase reflects the visit selected as start point of a Treatment phase for the base line assessment. Baseline assessment will be considered the scans done prior to the date on DOV of this visit.

Note 4: Tumor Identification "Target" with Longest Diameter ≠ null will be considered as Extra Nodal; Tumor Identification "Target" with Short Axis ≠ null will be considered as Nodal

12. % Change from Nadir is Calculated as  [(SOD from current Timepoint - SOD from Nadir)/SOD from Nadir]*100%. Nadir SOD corresponds to the smallest SOD of all prior lesion evaluations of current Timepoint, Exclude evaluations that have at least one NE in the SOD. If SOD from Nadir is equal to 0, ignore calculation and display "Nadir is zero".

13. % Change from Baseline is calculated as [(SOD from current Timepoint - SOD from Baseline)/SOD from Baseline]*100%. Baseline SOD corresponds to the SOD of the Baseline assessment, i.e., evaluation done prior first Dose. If SOD from Baseline is equal to 0, ignore calculation and display "Baseline is zero".

Target Lesion (Identified at Baseline) iRECIST Response” is blank.
