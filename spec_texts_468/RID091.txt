Report ID: RID091

Report Title:
Unique Test Names

Description:
This reports lists unique test names from External Data loaded to InForm Reporting Schema. The list of unique test names across the study is compared to the Protocol Specific Addendum (PSA).

Column Heading:
1. eCRF

2. Vendor

3. Lab Test ID

4. Lab Test Name

5.  Test ID

6.  Test Name

7. Units

8. Range Low

9. Range High

10. Record Count

Logic:
The report should check for records in LABS, GEF and CIMG views if available in a study.

This report should contain a unique list of Lab Test ID, Lab Test Name,  Test ID,  Test Name, Units and the record count of each combination from the LABS view.

This report should contain a unique list of Test Short Name, Test, Original Units and the record count of each combination from the GEFCF view. Test short name should not be 'FBR'.

This report should contain a unique list of Test Short Name, Test, Original Units and the record count of each combination from the CIMG view.

Report should not display deleted records.

Report Scenarios:
A- Yes

unique test names from External Data loaded to InForm Reporting Schema.

B- No

Deleted record

Sorting:
eCRF, Vendor, Lab Test ID, Lab Test Name,  Test ID

Parameter Selection:
eCRF, Lab Test ID, Vendor
