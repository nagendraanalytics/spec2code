Report ID: RID373

Report Title:
Non-Target Lesion Response Reconciliation

Description:
This listing contains details about the type of lesions reported under Tumor Identification "Non-Target Nodal" OR "Non-Target Extra nodal" on Lesion Evaluation form and the corresponding RECIST and iRECIST Responses.

For the Non Target lesions the listing will show the Non-Target Lesion Status for each lesion and the value of "ORIR. Non-Target Lesion RECIST Response" AND the value of "ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response".

Column Heading:
1. Country

2. Site

3. Subject Number

4. LSNIR Seq#

5. Date of Lesion Evaluation

6. Was lesion evaluable?

7. Non-Target Lesion Status

8. ORIR Seq#

9. Date Response

10. Non-Target Response

11. Worsening

12. Expected RECIST Response

13. Expected iRECIST Response

Logic:
{

[

Logic 1: ORIR.'Date of Procedure for Overall Response (Scan/Image/Physical Exam)' AND ['Overall RECIST Response' OR  'Overall iRECIST Response' are not NULL]

AND

Logic 2.1: LSNIR.Evaluation Entry with 'Date of Lesion Evaluation' OR 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam)' match with ORIR.'Date of Procedure for Overall Response (Scan/Image/Physical Exam)'

AND

Logic 2.2: LSNIR.'Date of Lesion Evaluation' OR 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam)' <> LSNIR.’Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam)’

AND

Logic 3: LSNIR.'Tumor Identification'="Non-Target Extra Nodal" OR "Non-Target Nodal" OR “Non-Target”

]

OR

[

Logic 4: ORIR.'Date of Procedure for Overall Response (Scan/Image/Physical Exam)' AND ['Overall RECIST Response' OR  'Overall iRECIST Response' are not NULL]

AND

Logic 5: No LSNIR.'Date of Lesion Evaluation' OR 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam)' match with ORIR.’Date of Procedure for Overall Response (Scan/Image/Physical Exam)’

AND

Logic 6: LSNIR record in logic 5 has LSNIR.'Tumor Identification'="Non-Target Extra Nodal" OR "Non-Target Nodal" OR “Non-Target”

]

}

AND

[

Logic 7: ORIR. Non-Target Lesion RECIST Response <> ‘RECIST Expected Response’

OR

Logic 8:  ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response <> ‘iRECIST Expected Response’

]

Notes:

Note 1: Disregard deleted records

Note 2: The report logic should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: LSNIR.Date of Current Lesion Evaluation (Scan/Image/Physical Exam)/LSNIR.Date of Lesion Evaluation, ORIR.Date of Procedure for Overall Response (Scan/Image/Physical Exam)

Note 3: The supporting document is required for all trials if treatment phase is applied to logic even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required,the order on which phases will appear on protocol

2. Treatment Phase: name of each study phase (Intial Treatment Phase, Neodjuvant Phase, Secon Course Phase)

3. First Visitmnemonic of Treatment Phase: required,the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Note 4: Show ‘Expected RECIST Response’ column in blank  if there is an Overall RECIST Response as PD in the previous record.

Note 5: Show ‘Expected iRECIST Response’ column in blank if there is not an Overall RECIST Response as PD in the same record or previous records.

Report Scenarios:
A-Yes

List ORIR records and its corresponding LSNIR records according to dates.

B- Yes

List ORIR records which has no corresponding LSNIR record

C-No

Deleted record

Sorting:
Country, Site, Subject Number, Date of Procedure for Overall Response (Scan/Image/Physical Exam) (ORIR)  OR 'Date of Current Lesion Evaluation (Scan/Image/Physical Exam) (LSNIR).

If some rows of output have both ORIR date and LSNIR date, consider sort by LSNIR date first then ORIR date

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, default as N), Study Phase Page (N/Y, Default as N)

Form.Item Names:
1. SA Form. Site Country

2. SA Form. Site Mnemonic

3. SA Form. Subject Number

4. LSNIR. Associated Lesion Number (if there are more than one Lesion number for each Tumor Identification, display them all and joined by commas.)

5. LSNIR. Date of Current Lesion Evaluation (Scan/Image/Physical Exam).

6. LSNIR. Was the Lesion Evaluable? (display in one row for all lesions with the same Identification and Date, separated by commas. Display as “Y=<total number as Yes>” and “N=<total number as No>”.

7. Display the value of “Non-Target Lesion Status”.

Should display as below format:

“Absent=<total number>” , “Present=<total number>”, “Worsening=<total number>” OR (Enlargement From Nadir=<total number>,  Further Enlargement From Nadir=<total number>) , “Not Evaluable=<total number with item Was the Lesion Evaluable? as No>”  in sequence. If there are multiple status, display them all in this column separated by commas.

8. ORIR. Sponsor ID Number

9. ORIR. Date of Procedure for Overall Response

10. Display the value of  “ORIR. Non-Target Lesion RECIST Response” AND the value of “ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response” separated by commas.

11. Display the value of  “ORIR. Non-Target Lesions Worsening”. If item is blank, display the column blank

12. Display “Progressive Disease” if at least one lesion has “LSNIR. Non-Target Lesion Status” as ‘Worsening’/’Enlargement From Nadir’ AND the previous ORIR record, “ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response” is blank.

Display "Complete Response" if ALL lesions have Non-Target Lesion Status as Absent AND previous ORIR record “ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response” is blank.

Display “Not evaluable” if criteria for “Progressive Disease” are not met AND on column 6 there is at least one lesion as No

Display “Not Applicable” if there are no lesions with Tumor Identification “Non-Target Nodal” or “Non-Target Extra Nodal” or “Non-target”

Display "Non-CR/Non-PD " if there are no previous records with “ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response” completed AND there is at least one LSNIR. Non-target lesion status = PRESENT.

Otherwise leave blank

13. Display “iUPD” if at least one lesion has “LSNIR. Non-Target Lesion Status” as ‘Worsening’/’Enlargement From Nadir’ AND ( the previous ORIR record, “ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response” is blank OR previous ORIR record is completed but is not “iUPD” or “iCPD” )

Display “iCPD” if “ORIR. Non-Target Lesions Worsening” is yes AND the previous ORIR record is “iUPD” or “iCPD” AND Non-Target Lesion Status = ‘Worsening’/’Further Enlargement From Nadir’

Display "iCR" if all lesions have Non-Target Lesion Status as Absent AND previous ORIR record “ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response” is completed.

Display “NE” if criteria for “Progressive Disease, iUPD” or “iUPD” or “iCPD” are not met AND on column 6 there is at least one lesion as No

Display “NA” if there are no lesions with Tumor Identification “Non-Target Nodal” or “Non-Target Extra Nodal” OR “Non-target”

Display "Non-iCR/Non-iUPD" if there are previous records with “ORIR. Non-Target Lesion (Identified At Baseline) iRECIST Response” completed.

Otherwise leave blank

Notes

Note 1:  If there is not matching LSNIR form for a ORIR record display column 4 to 7 blank.

Note 2: Previous ORIR record would be the immediate previous according to dates.
