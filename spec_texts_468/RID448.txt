Report ID: RID448

Report Title:
STR Last dose date and PMS1/PMST date reconciliation

Description:
This report will output subjects with STR Last Dose date not consistent with PMS1/PMST date for each treatment phase.

Column Heading:
1. Country

2. Site

3. Subject Number

4. STR Visit

5. STR Sequence

6. STR Start Date/Time

7. PMS1/PMST Visit

8. PMS1/PMST Date of assessment

Logic:
Logic 1.1: STR. Start Date/Time <> Null AND STR. Please Indicate if this is the Last Dose for this Label Description <> Null

AND

Logic 1.2: PMS1 Date of Assessment <> NULL AND PMS1/PMST Date of Assessment is before/before or equal/Equal (according to prompt STR date vs PMS1/PMST Date) to STR. Start Date/Time from logic 1.1

Note 1:

The supporting document should be named as study_phase_supp_</Vxxxxxxx>.csv and

will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required, the order on which phases will appear on protocol

2. Treatment Phase: required, name of each study phase (Initial Treatment

Phase, Neodjuvant Phase, Second Course Phase)

3. First Visitmnemonic of Treatment Phase: required, the first visit on which

treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the optional supporting doc can be

outputted by selecting Y in the parameter "Study Phase Page".

Note 2:

The report logic should be checked within the same treatment phase defined in the

supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

Notes:

Note 1: Please exclude deleted records and erroneous visits form programming.

Note 2: use prompt STR date vs PMS1/PMST Date to determine if the comparison to be used is: “Equal” then STR date of last dose and PMS1/PMST date should be equal, “STR before or equal to PMS1/PMST” then STR date of last dose should be before or equal to PMS1/PMST date, “STR before PMS1/PMST date” then STR date of last dose should be before PMS1/PMST date.

Parameter :

a) STR date vs PMS1/PMST Date = “Equal”, Output if PMS1/PMST date <> STR date;

b) STR date vs PMS1/PMST Date =“STR before or equal to PMS1/PMST date”, Output if STR date > PMS1/PMST date;

c) STR date vs PMS1/PMST Date =“STR before PMS1/PMST date” , Output if STR date >= PMS1/PMST date

Note 3: STR and PMS1/PMST should be on the same treatment phase, the treatment phase will be defined by the dates of each visit selected on “First cycle visit for each treatment phase” prompt. The check should be done for STR and PMS1/PMST between the dates of each treatment phase (start and end date inclusive). If user selects Visit 1, Visit 2, Visit 3; then the treatment phases are defined by:

Visit 1 and Visit 2 dates

Visit 2 and Visit 3 dates

Visit 3 date and after

For example: site selects “Cycle 1” and “Cycle 1 second treatment phase”, then reports should check for an STR last dose and a PMS1/PMST Date of Assessment between “Cycle 1” DOV (inclusive) and “Cycle 1 second treatment phase” DOV (inclusive) AND for an STR last dose and a PMS1/PMST Date of Assessment After “Cycle 1 second treatment phase” (inclusive). If none is selected, then all STR Last dose and PMS1/PMST records should be checked.

Note 4: check all records with Last dose checked for a mismatch in each treatment phase.

Report Scenarios:
Scenario 1 output yes

There is an STR date of last dose and PMS1/PMST date of assessment is before/before or equal/Equal (according to prompt) STR date in the treatment phase.

Scenario 2 Output No

There is an STR date of last dose and PMS1/PMST date of assessment is after or equal (according to prompt) STR date in the treatment phase.

Scenario 3 Output No

There is no PMS1/PMST Date of assessment in the treatment phase.

Scenario 4 Output No

There is no STR with date of last dose in the treatment phase.

Scenario 5 Output No

There is an STR date of last dose and PMS1/PMST date of assessment is before or equal (according to prompt) STR date in the treatment phase, but STR record is deleted.

Sorting:
Country, Site, Subject Number, Visit Mnemonic

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, default as N), Study Phase Page (N/Y, default as N). STR date vs PMS1/PMST Date (required, single selection, display options “Equal”, “STR before or equal to PMS1/PMST date”, “STR before PMS1/PMST date”)
