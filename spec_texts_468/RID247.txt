Report ID: RID247

Report Title:
Tablet or Patch check

Description:
Output is produced if the Start Date Day 1-7 are incorrectly entered based on the Dose Form of medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. ANL Sponsor ID Number

5. ANL Start Date

6. ANL Stop Date

7. CM Sequence

8. CM Dose Form

9. Error Message

Logic:
Scenario 1:

ANL.Associated CM Sequence Number = CM. Sequence Number

AND

CM. Dose Form or CM. Route of Administration is different to that provided in supporting document

AND

all of ANL. Start Date Day “Corresponding Day” is NOT NULL

Note 1: Display Scenario 1 in Error message.

Note 2: Erroneous visits and deleted records and add-entry records are excluded from programming

Scenario 2:

ANL.Associated CM Sequence Number = CM. Sequence Number

AND

CM. Dose Form and CM.Route of Administration is equal to that provided in supporting document.

AND

any of ANL. Start Date Day “Corresponding Day” is NULL

Note 3: Display Scenario 2 in Error message.

Note 4: Please disregard deleted rows and add-entry records in ANL.

Note 5:

Requires supporting document to be named ONC_ANL_003_supp_xxxxxxx.csv and

will contain the following columns and associated content:

One row for each Dose Form and Route of Administration combination

1. Dose Form

2. Route of Administration – can be completed as NA if all routes should be considered

e.g.

Dose Form    Route of Administration

Tablet            NA

Capsule         NA

Caplet            NA

Pill                  NA

Solution        Oral

Powder         Oral

Liquid            Oral

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

If supporting doc is not provided, display the message as “ONC_ANL_003_JR_STD Supporting Document Not Present for This Trial”

Report Scenarios:
Scenario 1:

Start Date Day 1-7 is completed but the associated medication is not provided as per supporting document.

Scenario 2:

Start Date Day 1-7 is blank but the associated medication is provided as per supporting document.

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y), Supporting Doc Page (N/Y)

Form.Item Names:
1. SA. Country

2. SA. Site

3. SA. Subject Number

4. ANL. Sponsor ID Number

5. ANL. Start Date of Analgesic Log Per Period

6. ANL. Stop Date of Analgesic Log Per Period

7. CM. Sequence Number

8. CM. Dose Form

9. Error Message: If applies logic 1 please display “Scenario 1” If applies logic 2 please display “Scenario 2” If ANL record is associate with Deleted CM record. Please display in error message: "CM row Deleted"
