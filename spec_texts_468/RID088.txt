Report ID: RID088

Report Title:
Visits Missing External Vendor Data - External Vendor Data with No Corresponding Visit Date - Date Mismatch between InForm vs Vendor

Description:
This report displays the following pts scenario

1. Scheduled visit date is entered at particular visit, but there are no corresponding external data records with a collection date equal to the visit date.

2. External vendor record is present with a Visit Type of 'S' and a Collection Date that has no corresponding scheduled Visit Date.

3. Data from both Inform & external vendor is present with same visit description with different dates

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. InForm Visit Number

6. InForm Visit Date

7. Days since Visit Date

8. eCRF

9. Vendor

10. Specimen ID

11. Visit ID or Number

12. Collection Date/Time

13. Requisition number

14. Issue

Logic:
Scenario 1: No External data

Output is produced if patient has a Date of Visit entered for a scheduled visit and there are no corresponding external records in the LABS/GEFCF/PFT/CECG eCRFs with the same Collection Date.

Hardcode the issue as ""Missing External Data""

Scenario 2: No Inform data

Output is produced if patient has external records in LABS/GEFCF/PFT/CECG eCRFs for scheduled visits and there is no corresponding scheduled Date of Visit. This output is typically produced if DOV is not entered yet or if the wrong label was used.

Hardcode the issue as ""Missing Visit in InForm""

Scenario 3: Data from both InForm & external vendor is present with same visit description with different dates.

Output is produced for mismatches between external Collection Date and Date of visit for each Visit in InForm and external vendor.

Hardcode the issue as ""Date Mismatch""

Visits should have the Erroneous visit checkbox unchecked.

Test Status for LABS should not be 'X' or 'N'.

Visit is not matched for PFT records since the Visit ID or Number does not exist on the eCRF.

Report should not consider deleted records.

1 row for each visit.

1)Visit name : Vistmnemonic from T&E.

2)Visit type : To be given as 1 for all Scheduled visits.

3)eCRF: Formmnemonic of External vendor data.

4)Vendor:Vendor name as per PSA

5)Visitid or number : visit number's given in column 'Visit ID or Number' as per PSA
