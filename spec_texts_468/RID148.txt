Report Title:

Note 1: This report should not display deleted records and erroneous visits.

Note 2: Zero dose records should be excluded from the Study medication forms.

Note 3: If on PK04/SM time is collected and it is UNK - the report should display output.

Note 4: SM Dosing date/time will be either Start Date/Time or Stop Date/Time based on supporting document provided.

Note 5: For SM/SMAU/SMAB Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number directly. If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_<xxxxxxx>.csv to define the mapping.

Note 6: If Criteria(s) are provided as 'NA' in the supporting doc (columns 15-23), check the logic for all subjects.

Note 7: PK04 “Sample Date” refers to: DATE AND TIME SAMPLE OBTAINED, DATE AND TIME OF SAMPLE COLLECTION.

Note 8: PK04 "Last Dose Date" refers to: LAST DOSE DATE AND TIME PRIOR TO SAMPLE, LAST DOSE DATE AND TIME PRIOR TO SAMPLE COLLECTED, LAST DOSE DATE AND TIME PRIOR TO PK SAMPLE OBTAINED.

Note 9: If Compare Form use PK04, (1) for Pre-dose, use PK04 "Last Dose Date" in the first PK post record in same PK04 form. (2) for Post-dose, just use the corresponding PK04 "Last Dose Date".

Report Scenarios:
Scenario 1:

A output = No

if the elapsed time between the sample date/time and the next dosing date/time from SM eCRF is within the window for predose

B output = Yes

if the elapsed time between the sample date/time and the next dosing date/time from SM eCRF is outside of window for predose

Scenario 2:

A output = No

when PK04 "Last Dose Date" exist, if the elapsed time between the sample date/time and the PK04 "Last Dose Date" is within the window for postdose

B output = Yes

when PK04 "Last Dose Date" exist, if the elapsed time between the sample date/time and the PK04 "Last Dose Date" is outside of window for postdose

C output = No

when PK04 "Last Dose Date" does not exist, if the elapsed time between the sample date/time and the maximum SM Date from supp doc is within the window for postdose

D output = Yes

when PK04 "Last Dose Date" does not exist, if the elapsed time between the sample date/time and the maximum SM Date from supp doc is outside of window for postdose

Scenario 3:

A output = No

if there is dosing date/time from PK04/SM eCRF to be compared with PK04 sample date/time for Postdose or Predose record, and not meet scenario 1 and scenario 2 logic

B output = Yes

if there is no dosing date/time from PK04/SM eCRF to be compared with PK04 sample date/time for Postdose or Predose record
