Logic:
Logic 1:

If there are more than one PMS1A with Date of Assessment in the same treatment phase

Logic 2:

Logic 2.1: If there is a Date Response Determined during treatment phase X on the selected eCRF in the "Response Form" column from supporting document > PMS1 with Date of assessment in treatment phase X

AND

Logic 2.2: If for the entry of the selected eCRF in the "Response Form" on Logic 2.1 the Overall response = Progressive Disease

AND

Logic 2.3: There is no PMS1A with Date of Assessment in treatment phase X

Logic 3:

Logic 3.1: If there is a PMS1 with Date of Assessment in treatment phase X AND with Select the Status of the Subject for the Next Trial Segment = “Next Trial Segment” from supporting document

AND

Logic 3.2: There is not a PMS1A with Date of Assessment in treatment phase X

Logic 4:

Logic 4.1: At least one of the eCRFs: “ODBF” or “ODBHF” or “ODBNF” or “ODBCF” or “ORAD2” or “OSOF” or "OSOFL" is initialized. See Note 3

AND

Logic 4.2: ORAD2.Reason for Radiation is <> ‘Palliative Treatment or Symptom Control’ OR ‘Palliative Treatment or Symptom Control of Metastatic Disease’

AND

Logic 4.3: There is no PMS1A with Date of Assessment in treatment phase X

Logic 5:

Logic 5.1: If there is a PMS1 with Date of Assessment in treatment phase X AND with Status of Study Medication at the End of This Trial Segment = Progressive Disease

AND

Logic 5.2: There is no PMS1A for the treatment phase X

Notes:

1-      Overall reponse = Progressive Disease in Logic 2.2 should be defined as:

ORST. Overall Response = Progressive Disease

RRIR. Overall RECIST Response = Progressive Disease

RRIR.Overall IRRECIST Response = irProgressive Disease

ORLLG. Overall Response (includes Target, Non Target, New, Spleen, Liver, PET and BM Assessments) = Progressive Disease

ORPC. Overall Response = Progressive Disease

ORL. Overall Response = Progressive Disease

ORM. Overall Response = Progressive Disease

ORPI. Overall Response (PCWG-Modified RECIST) = Progressive Disease

ORPI. Overall Response (PCWG-Modified irRECIST) = Progressive Disease

ORML.Hematologic response=Progressive Disease

ORIR. Overall RECIST Response= Progressive Disease

ORIR. Overall iRECIST Response= iUPD

ORIR. Overall iRECIST Response= iCPD

OABC.Overall Response=Progressive Disease

Depending of the eCRF selected in the Response Form eCRF

2-      Erroneous visits and deleted records are excluded from programming.

3-      For all logics, the report will output only if there is at least one record in SM, SMAU, SMAB, STR eCRFs, whichever is present in the study. This is to avoid fake output for those subjects who are randomized but never treated since PMS1 or PMS1A forms are not applicable in such cases.

4-      If a date is displayed in the output, please use format “dd-Mmm-yyyy” for example “01-Jan-2021”

Supporting Documents Notes:

1-      For Logic 2 and Logic 3: Requires supporting document to be named ONC_PMS1_003_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each eCRF or Next Trial Segment value depending on the scenario

1. eCRF – Required for Scenario 2, enter ORST/RRIR/ORLLG/ORPC/ORL/ORM/ORPI/ORIR/ORML/OABC. For Scenario 3 simply enter “NA”

2. Next Trial Segment – Required for Scenario 3, enter PMS1 value from item Select the Status of the Subject for the Next Trial Segment. For Scenario 2, enter “NA”

3. Scenario – Enter “2” or “3”.

e.g.

eCRF,Next Trial Segment,Scenario

ORIR,NA,2

NA,Continuing into Survival Follow-up,3

NA,Continuing into Crossover Phase,3

NA,Not continuing into any trial phase,3

If supporting doc is not provided, display the message as "ONC_PMS1_003_JR_STD Supporting Document Not Present for This Trial".

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

2-      The report logic should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: PMS1.Date of Assessment, PMS1A.Date of Assessment, Response Form. Date Response Determined

Response Form: ORST/RRIR/ORLLG/ORPC/ORL/ORM/ORPI/ORIR/ORML/OABC

3-        This is a required supporting document for all studies with one or more phases.

This supporting document is required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Required supporting document should be named as study_phase_supp <xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: the order on which phases will appear on protocol

2. Treatment Phase: this information is the phase name given in the protocol (Initial Treatment Phase/Second Course Phase/Crossover/Neoadjuvant)

3. First Visitmnemonic of Treatment Phase: the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".
