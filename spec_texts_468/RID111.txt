Report ID: RID111

Report Title:
Existing results for NOT DONE records at LABS, GEFCF, CIMG, SME.

Description:
This report displays all LABS, GEFCF, CIMG, SME records with ANY value at the results fields but also has a Status entered as "NOT DONE".

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. Vendor

6. eCRF

7. Visit ID or Number

8. Visit Name

9. Visit Type

10. Collection/Measurement Date and Time

11. Accession/sample ID

12. Lab Test Name

13. Scenarios

Logic:
Logic 1

This report will retrieve the LABS, GEFCF, CIMG, SME records with Test Status item='X' or ‘N’ or 'NOT DONE', which corresponds to a Not Done Test, and any Test Result item is not null.

Logic 2a

Records with  Test Status item='X' or ‘N’ or 'NOT DONE' and Reason Item= null.

Logic 2b

Records with Reason item<> null and Test Status item= null.

Note:

Report should not display deleted records.

Requires supporting document to be named EVD038_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each required field with the following columns:

1. eDT - Table Name

2. Vendor Item Name

3. Vendor Name - Vendor Name as it is loaded

4. Test Status Item Name - Specified in PSA, item Name in eDT showing test status

5. Test Status Item Value – Specified in PSA, value when test status is not done

6. Test result Item 1 - Specified in PSA, item Name in eDT showing test result

7. Test result Item 2 - Specified in PSA, item Name in eDT showing test result (can leave blank if only 1 result item)

8. Test result Item 3 - Specified in PSA, item Name in eDT showing test result (can leave blank if only 1 result item)

9. Reason Item Name- Specified in PSA, item Name in eDT showing test not done reason

eg.

eDT, Vendor Item Name, Vendor Name, Test Status Item Name, Test Status Item Value, Test result Item 1, Test result Item 2, Test result Item 3, Reason Item Name

CV_LABSFM, Transmission Source ID, Q2LAB, Test Status, X, Reported Text Result, Reported Numeric Result, , ,Test Level Comments

CV_LABSFM, Transmission Source ID, Q2LAB, Test Status, N, Reported Text Result, Reportedl Numeric Result, , ,Test Level Comments

CV_GEFCFFM, Vendor Name, Q2LAB, Complete Status, NOT DONE, Result or Findings in Original Units, Character Result/Finding in Std Format, Numeric Result/Finding in Standard Units, Reason Not Performed

CV_CIMGFM, Vendor Name, PAREXEL, Complete Status, NOT DONE, Result or Findings in Original Units, Character Result/Finding in Std Format, Numeric Result/Finding in Standard Units, Reason Lesion Status Not Done

CV_SMEFM, Vendor Name, QARC, Completion Status, NOT DONE, , , , Reason not performed

Report Scenarios:
Output - Yes

Test status item is X or N or NOT DONE, but any of Test result item present

Output - No

Test status item is X or N or NOT DONE and all Test result item are NULL

Output-Yes

Test Status item is X or N or NOT DONE and Reason Item is NULL

Output-No

Test Status item is X or N or NOT DONE and Reason Item is not NULL.
