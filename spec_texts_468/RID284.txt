Report ID: RID284

Report Title:
Missing Oncology End of Follow-up and Oncology End of Disease Response Assessment

Description:
The report will output subjects who have discontinued the treatment, finished the follow-up phase and have OEFU missing. The report will also output subjects who have disontinued the treatment and have entered the survival follow-up phase or have discontinued from the study and have OEDRA missing.

Column Heading:
1. Country

2. Site

3. Subject Number

4. PMS1/PMST Date of Assesment

5. PMS1/PMST Reason for Discontinuation

6. PMS1/PMST Next Trial Segment

7. OEFU Status for Last Treatment Phase

8. Treatment Phase

9. SFU DOV

10. DS01 Date of Disposition

11. Scenario

Logic:
Logic 1:

There is PMS1/PMST with "Select the Status of the Subject for the Next Trial Segment" completed as provided in the supporting doc

AND

(DOV in Survival Follow-up visit is completed OR DS01 "Date of Disposition" is completed OR Next Treatment Phase visit is initiated)

AND

OEFU "Date of Assessment" is missing for this trial phase

Logic 2a:

There is PMS1/PMST in any treatment phase with "Select the Status of the Subject for the Next Trial Segment" completed

AND

(DOV in Survival Follow-up visit is completed OR DS01 "Date of Disposition" is completed)

AND

OEDRA "Date of Assessment" is missing.

Logic 2b:

There is PMS1/PMST any treatment phase with "Select the Status of the Subject for the Next Trial Segment" completed

AND

There is OEFU record in last treatment phase with "Select the Status of the Subject for the Next Trial Segment" completed

AND

OEDRA "Date of Assessment" is missing.

Note 1: Next Treatment Phase visit is initiated means that a DOV "Date of Visit" is provided for the "First cycle visit mnemonic for this treatment phase" in the subsequent "Treatment phase ", as defined in the supporting doc.

Note 2: Last treatment phase is the "Treatment phase" with the highest 'Treatment phase order' provided in the supporting doc.

Note 3: Logic 2a and 2b only check form listed on supporting doc.

Note 4: Leave Column 7 blank for Logic 1 and 2a

Note 5: In logic 1 display the PMS1/PMST for the same treatment phase as missing OEFU; for logic 2a and 2b, in case there is more than one PMS1/PMST, display the one with max Date of Assessment

Note 6: If supporting doc is not provided, display the message as "ONC_FU_001_JR_STD Supporting Document Not Present for This Trial" or "study_phase_supp_<xxxxxxx>.csv Not Present for This Trial"

Note 7: The logic 1 should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Treatment Phase Order, Treatment phase,First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: PMS1.Date of Assessment, PMST.Date of Assessment, DOV.Date of Visit, DS01.Date of Disposition, OEFU.Date of Assesment

Note 8:

The supporting document is required for all trials if treatment phase is applied to logic，even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required,the order on which phases will appear on protocol

2. Treatment Phase: name of each study phase (Intial Treatment Phase, Neodjuvant Phase, Secon Course Phase)

3. First Visitmnemonic of Treatment Phase: required,the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Note 9:

Requires supporting document to be named ONC_FU_001_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1.Treatment phase order - Treatment Phase chronological order. Required, enter "1" if only one treatment phase in study

2.Form name - Required, enter "PMS1" or "PMST"

3.PMS1/PMST Next trial segment status for follow-up. Required, Value from PMS1.Select the Status of the Subject for the Next Trial Segment or PMST.Select the Status of the Subject for the Next Trial Segment according to eCRF selected

e.g.

Treatment phase order,Form name, PMS1/PMST next trial segment status for follow-up

1,PMS1,Continuing into First Course Follow-up Phase

2,PMS1,Continuing into Second Course Follow-up Phase

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
A – logic 1, NO

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is blank OR PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed different than provided in the supporting doc

B - logic 1, NO

DOV in Survival Follow-up visit is blank AND DS01 "Date of Disposition" is blank AND Next Treatment Phase visit DOV is blank

C - logic 1, YES

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed as provided in the supporting doc AND (DOV in Survival Follow-up visit is completed OR DS01 "Date of Disposition" is completed OR Next Treatment Phase visit is initiated) AND OEFU "Date of Assesment" is missing for the same treatment phase as PMS1/PMST

D – logic 1, NO

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed as provided in the supporting doc AND (DOV in Survival Follow-up visit is completed OR DS01 "Date of Disposition" is completed) AND OEFU "Date of Assesment" is completed for the same treatment phase as PMS1/PMST

E – logic 2, YES

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed for any treatment phase AND (DOV in Survival Follow-up visit is completed OR DS01 "Date of Disposition" is completed) AND OEDRA "Date of Assesment" is missing

F – logic 2, NO

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed for any treatment phase AND (DOV in Survival Follow-up visit is completed OR DS01 "Date of Disposition" is completed) AND OEDRA "Date of Assesment"  is completed

G – logic 2, YES

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed for any treatment phase AND (DOV in Survival Follow-up visit is completed OR DS01 "Date of Disposition" is completed) AND the OEFU record in last treatment phase with "Select the Status of the Subject for the Next Trial Segment" is not completed AND OEDRA "Date of Assesment" is missing

H – logic 2, NO

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed AND (The SFU "Date of Contact or Last Attempt of Contact" is completed OR DS01 "Date of Disposition" is completed) AND the OEFU record in last treatment phase with "Select the Status of the Subject for the Next Trial Segment" is not completed AND OEDRA "Date of Assesment" is completed

I – logic 2, YES

The PMS1/PMST "Select the Status of the Subject for the Next Trial Segment" is completed for any treatment phase AND DOV in Survival Follow-up visit is blank AND DS01 "Date of Disposition" is missing AND there is OEFU record in last treatment phase with "Select the Status of the Subject for the Next Trial Segment" completed AND OEDRA "Date of Assessment" is missing

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N set default to N), Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
1. SA.Country

2. SA.Site

3. SA.Subject Number

4. PMS1.Date of Assessment/PMST.Date of Assessment

5. PMS1.Status of Study Medication at the End of This Trial Segment/PMST.Status of Subject at end of all Study Treatments

6. PMS1.Select the Status of the Subject for the Next Trial Segment/PMST.Select the Status of the Subject for the Next Trial Segment

7. OEFU.Select the Status of the Subject for the Next Trial Segment

8. Display Treatment phase for missing OEFU (Logic 1), as provided in supporting document. Leave blank for Logic 2a and 2b

9. DOV.Date of Visit for Survival Follow-up visit

10. DS01.Date of Disposition

11. Scenario. please display "Scenario 1" if Logic 1 is fulfilled or "Scenario 2" if Logic 2a or Logic 2b is fulfilled.
