Report ID: RID084

Report Title:
CECG Records with Missing Values

Description:
This report displays all Central ECG records with null values in madatory fields according to the supporting document provided.

Column Heading:
1. Country

2. Site

3. InForm Screening Number

4  InForm Subject Number

5. Visit ID or Number

6. Collection Date and Time

7. Missing Field

Logic:
This report should display subjects who have a null value in Mandatory Fields Provided by Supporting document in CECG form.

Requires supporting document to be named EVD004_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1)Vendor Name : Vendor name as per PSA.

2)Mandatory Fields: List all the mandatory items that should not be null

Notes:

1. Collection Date and Time field is formatted according to the ISO standard. An example for 12-Jul-2007 at noon is: 2007-07-12T12:00:00 (yyyy-mm-ddThh:mm:ss). However, not all time parts are always present.

2. The column Inform Subject Number only  should display values if the subject is randomized, otherwise, should be null.
