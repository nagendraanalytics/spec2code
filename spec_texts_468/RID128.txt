Report ID: RID128

Report Title:
Incorrect Subject Level Normal Ranges

Description:
This report matches subject level normal range data from Local Lab Normal Range eCRFs (CNR, HNR, ONR) with derived normal ranges for each test from the Site-level Normal Range eCRFs (SLCNR, SLHNR, SLONR) and Local Lab eCRFs (CLAB, HLAB and OLAB). The report will output any mismatches found with data present in SL NR Effective Date.

Logic:
Determine the age at collection date for each subject on 1. Derive the normal ranges from site level local lab normal range eCRFs:

Determine the age at collection date for each subject on the local lab eCRF from Date of Birth on the Demographics eCRF.

1. For each subject on the local lab eCRF, match each site, test, units, specimen type (where applicable), laboratory name, age at collection and sex with site, test, units, specimen type, laboratory name, age range, sex, and closest effective date on the site level local lab normal range eCRF.

Output mismatches in LL associated sequence number and SLNR sequence number corresponding to the closest normal range effective date.

Closest normal range effective date would be the greatest date that is prior or equal to the collection date of the lab test.

Each HLAB and CLAB test is a field on the local lab eCRF, with the field name specifying the test.

2. For each subject, associated NR sequence number and test, output mismatches in normal ranges, units, specimen type and lab name, effective date between NR (CNR, HNR and ONR) and SLNR; and mismatches in units between LL and NR.

3. Output missing subject level normal ranges.

Assumptions for the site level local lab normal ranges (SLNR) for each vendor:

a. Each set of new test ranges will be entered in a new record with a corresponding sequence number and a current effective date.

b. The set of new test ranges will be considered as cumulative with the previous entered test ranges. Previous valid test ranges will not be re-entered in the new record.

c. If any of the new test ranges already existed in previous records, then the previous test range will be considered valid from the previous effective date to the new effective date and the new test range will be considered valid from the new effective date.

d. There could be valid records for the same lab, test, gender, age range but different units, so all those records should be considered as range reference.

Assumptions for the subject level local lab normal ranges (NR) for each vendor:

a. The previous test ranges will need to be considered as having the new test ranges' sequence number and effective date.

b. If the new test ranges with new sequence number and current effective date update a given test that has not been performed by the subject, then these other tests will be matched to sequence number and effective dates corresponding the last record with any of those tests.

Notes:

1. Do not include deleted records.

2. Do not include data from Erroneous Visits.

3. Do not output for site level local lab normal ranges Effective Date in blank.

4. Report output will be displayed as .lst(.pdf) and .csv format
