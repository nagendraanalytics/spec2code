Report ID: RID016

Report Title:
AE Causality vs. Study Medication

Description:
The report generates a listing of subjects who have AE Relationship with Study Medication as "Related" and AE Onset date is after Maximum non-zero Study Medication Date. A window of days is provided as a selection parameter and this defaults to 0 if not entered.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Term

6. AE Onset Date

7. Study Medication

8. SM Visit

9. SM Form

10. SM Seq

11. Max SM Stop Date

12. AE Date-Max SM Date

13. DS01 Status

14. SAE

Logic:
Logic:

Logic1: AE Relationship with Study Medication [x] = "Related" AND

Logic2: AE Onset date - Maximum non-zero Study Medication [x] Stop Date > window of days

Notes:

1. Consider Date field only in this report.

2. Maximum non-zero dose is derived as the maximum stop date of the study medication where last dose checkbox is selected and Number of Units Taken is not null or zero across SM, SMAU, SMAB, STR.

3. For AE’s that have any of the serious criteria selected the window of days for logic 2 corresponds to the column “Window of days for SAE” in the supporting document. For AEs that don’t have any serious criteria selected the window of days for logic 2 corresponds to the column “Window of days for NSAE” in the supporting document.

4. An AE record is considered an SAE if any of the 8 serious AE criteria is marked Yes or "Is the AE an Event of Clinical Interest?" selected Yes.

5. If in supporting document “Include SAE” is = N or BLANK, exclude SAE from Logic.

6. For studies with single study medication, Overall Relationship is checked and a match on Study Medication name is not performed.

7.[x] may range from 1 to 10.

8. Exclude deleted data and erroneous visit from programming

9. If "Randomized only" parameter selection checkbox is checked, the report should only output subjects with Randomization number that is not null.

10: Requires supporting document to be named AE024_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1.SM Form

2.Study Medication – Value of Study Medication

3.Window of days for NSAE-Window of days for washout period for non-serious AE’s. Please provide window of days as 0 if no washout period.

4.Window of days for SAE-Window of days for washout period for serious AE’s. Please provide window of days as 0 if no washout period. If Include SAE = N, leave as 'NA'.

5. Include SAE (Y/N)

Include SAE =’N’, means report only show output for non-SAE. Then disregard Window of days for SAE in Supporting document.

Include SAE =’Y’, means report show output for non-SAE and SAE.

E.g. SM Form, Study Medication, Window of days:

SMAU,3475/Placebo,x,x, N

SM Form,  Study Medication, Window of days for NSAE, Window of days for SAE, Include SAE

SMAU,        3475/Placebo,      30,	3  ,  N

SMAU,        3475/Placebo,      15,	0  ,  Y

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

 11. If SM/STR Label Description and SMAU/SMAB Dose Number are exactly matched within forms For SM/SMAU/SMAB Study Medication, use SM.Label Description/STR.Label Description/SMAU.Dose Number/SMAB.Dose Number directly.

The optional supporting document is only required in the following cases:

 - SM/STR Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

2. Study Medication – Value of Study Medication

3. Matching Item – SM/STR Label Description or SMAU/SMAB Dose Number

4. Matching Value – Value of SM/STR Label Description or SMAU/SMAB Dose Number

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Med Match Page".

Report Scenarios:
Scenario 1 - Yes AE Relationship with Study Medication = "Related" and AE Onset date is after Maximum non-zero Study Medication Date plus an allowable window as defined by user. Scenario 2 - No AE Relationship with Study Medication = "Related" and AE onset date not after Maximum non-zero Study Medication Date plus an allowable window as defined by user. Scenario 3 - No AE Relationship with Study Medication = "Not Related" and AE onset date is after Maximum non-zero Study Medication Date plus an allowable window as defined by user.
