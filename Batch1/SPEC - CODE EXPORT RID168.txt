2. LOGIC UNDERSTANDING
======================================================================
This report cross-references SCI (specimen collection) records against Study Medication (SM/SM01-04/SMAU/SMAB) dosing records to flag specimens whose collection time falls outside a protocol-defined window relative to the nearest dose (Stop time for Post Dose, Start time for Pre Dose), where the applicable window, matching criteria, and study period/time-point matching rules are all externally parameterized via a per-study supporting CSV document rather than hard-coded in the spec. Records are excluded if deleted, tied to erroneous visits, or reflect zero-dose SM entries, but are forced to output if no comparable SM dose exists or if a time value is UNK. The core pass/fail logic (Report Scenarios 1 & 2) hinges entirely on whether computed elapsed time falls within the Lower/Upper Window Limit for the matched supporting-document group.

1. The report starts from SCI (Specimen Collection Invoice) form records and applies a set of Criteria filters: Criteria Form 1/Itemquestion 1 = Criteria Value 1 AND Criteria Form 2/Itemquestion 2 = Criteria Value 2 AND Criteria Form 3/Itemquestion 3 = Criteria Value 3. These criteria values are not hard-coded in the spec itself but are supplied per-scenario by the external supporting document (SCI005_supp_<xxxxxxx>.csv), which defines, for each 'Group', which stratification form/item/value combination determines that subjects' SCI records qualify for that group's window rule.
2. For each qualifying SCI record, the report determines a 'Study Period SM' value from the matched Study Medication record: if the SM Form is exactly 'SM' and SM.Scheduled Time is present, Study Period SM = '<SM.Study Period> <SM.Scheduled Time>' (e.g., 'Cycle 1 Day 1'); if SM Form = 'SM' but SM.Scheduled Time is not present, Study Period SM = just SM.Study Period; if SM Form is anything other than 'SM' (i.e., SM01/SM02/SM03/SM04/SMAU/SMAB), Study Period SM is taken directly from that SM_Table's Study Period field.
3. In parallel, the report computes a 'Supporting Document Study medication' value using the supporting document's own Study Period and Scheduled time SM columns: if Scheduled time <> 'NA', concatenate as '<Study Period> <Scheduled time>' (e.g., 'Cycle 1 Day 1'); if Scheduled time = 'NA', use just the Study Period value.
4. The two derived Study Period strings (Study Period SM from the actual SM form data, and Supporting Document Study medication from the supporting doc's expected values) are compared to match the correct SM record(s)/group against the SCI record's expected time point/protocol requirement.
5. For Post Dose SCI time points: the 'last dosing date/time' is derived as the most recent Study Medication Stop Date/Time that is prior to (before) the sample (specimen collection) date/time. The elapsed time is calculated between the sample date/time and this last dosing Stop Date/Time.
6. For Pre Dose SCI time points: the 'most recent dosing date/time' is derived as the most recent Study Medication Start Date/Time that occurs after the sample date/time. The elapsed time is calculated between the sample date/time and this Start Date/Time.
7. The calculated elapsed time (expressed as Elapsed Days, Elapsed Time (hrs), Elapsed Time (mins)) is compared against the Lower Window Limit and Upper Window Limit (in minutes) specified in the matched supporting document row for that SCI Form + Scheduled Time Point + Post_Pre Dose combination.
8. If the elapsed time falls within the Lower/Upper Window Limit range defined for that specific time point, the record is considered compliant and Output = NO (per Report Scenario 1) -- meaning it is not listed on the report.
9. If the elapsed time falls outside the Lower/Upper Window Limit range, Output = YES (per Report Scenario 2) and the SCI record is listed on the report as an exception.
10. Per Note 3, if there is no SM dose record available at all to compare against a given SCI Post Dose or Pre Dose record, the report should still output that SCI record (treated as an exception/flag since compliance cannot be confirmed).
11. Per Note 4, if either the SCI or SM time value collected is 'UNK' (unknown), the report should display that record as output as well, since elapsed time cannot be reliably determined as within window.
12. Per Note 1 and Report Scenario 3, deleted study medication records and SCI/SM records tied to erroneous visits are excluded entirely from the comparison and must never be output (Output = NO), regardless of elapsed time results.
13. Per Note 2, zero dose records within the Study Medication forms are excluded from consideration when identifying the last/most recent dose date/time for elapsed time calculations.
14. Per the second example table's note, when a Group in the supporting document lists multiple SM Forms/rows as candidates, each SCI record is compared against the single most recent SM record among all SM records listed for that group (not evaluated against each candidate SM independently).
15. The final output listing is sorted by Country, Site, Subject Number, SCI Visit, SCI Form, SCI Seq, and Date/Time Specimen(s) Obtained.

SELECT
  sci.`@HDR`.`Site`.`Country` AS `Country`,
  sci.`@HDR`.`Site`.`Number` AS `Site`,
  sci.`@HDR`.`Subject`.`Name` AS `Subject Number`,
  sci.`@HDR`.`Event`.`Name` AS `SCI Visit`,
  sci.`@Form`.`Name` AS `SCI Form`,
  SCICEBESPIDIT AS `SCI Seq`,
  SCICETPTIT AS `SCI Scheduled Time`,
  DATE_FORMAT(RAWDATE(CONCAT(SCICESTDTCSOIT, ' ', SCICESTDTCSOTMIT)), '%d-%m-%Y %H:%i') AS `Date/Time Specimen(s) Obtained`,
  sm.StudyMedication AS `Study Medication`,
  DATE_FORMAT(sm.StartDT, '%d-%m-%Y %H:%i') AS `Start Date/Time`,
  DATE_FORMAT(sm.StopDT, '%d-%m-%Y %H:%i') AS `Stop Date/Time`,
  (CASE
     WHEN sm.SchedTime IS NOT NULL AND sm.SchedTime <> '' THEN CONCAT(sm.StudyPeriod, ' ', sm.SchedTime)
     ELSE sm.StudyPeriod
   END) AS `SM Study Period`,
  sm.SchedTime AS `SM Schedule Time`,
  DATEDIFF(RAWDATE(CONCAT(SCICESTDTCSOIT, ' ', SCICESTDTCSOTMIT)), sm.RefDoseDT) AS `Elapsed Days`,
  TIMESTAMPDIFF(HOUR, sm.RefDoseDT, RAWDATE(CONCAT(SCICESTDTCSOIT, ' ', SCICESTDTCSOTMIT))) AS `Elapsed Time (hrs)`,
  TIMESTAMPDIFF(MINUTE, sm.RefDoseDT, RAWDATE(CONCAT(SCICESTDTCSOIT, ' ', SCICESTDTCSOTMIT))) AS `Elapsed Time (mins)`,
  SCICESPCLSTATIT AS `Specimen Collection Status`
FROM `EDC`.`SCIFM` sci
LEFT JOIN
  (
    SELECT `@HDR`.`Subject`.`ID` AS SubjID,
      SMEXTRTIT AS StudyMedication,
      RAWDATE(SMEXSTDTCIT) AS StartDT,
      RAWDATE(SMEXENDTCIT) AS StopDT,
      SMEXCATIT AS StudyPeriod,
      SMEXINTDSIT AS SchedTime,
      RAWDATE(SMEXENDTCIT) AS RefDoseDT
    FROM `EDC`.`SMFM`
    WHERE `@Form`.`Status` = 'submitted__v'
      AND (DELETEDFM = 'N' OR DELETEDFM IS NULL)
      AND IFNULL(SMEXDOSEIT, 0) <> 0
  ) sm
  ON sm.SubjID = sci.`@HDR`.`Subject`.`ID`
  AND sm.StopDT = (
        SELECT MAX(RAWDATE(sm2.SMEXENDTCIT))
        FROM `EDC`.`SMFM` sm2
        WHERE sm2.`@HDR`.`Subject`.`ID` = sci.`@HDR`.`Subject`.`ID`
          AND sm2.`@Form`.`Status` = 'submitted__v'
          AND (sm2.DELETEDFM = 'N' OR sm2.DELETEDFM IS NULL)
          AND IFNULL(sm2.SMEXDOSEIT, 0) <> 0
          AND RAWDATE(sm2.SMEXENDTCIT) <= RAWDATE(CONCAT(sci.SCICESTDTCSOIT, ' ', sci.SCICESTDTCSOTMIT))
      )
WHERE sci.`@Form`.`Status` = 'submitted__v'
  AND (sci.DELETEDFM = 'N' OR sci.DELETEDFM IS NULL)
  AND (
        ABS(TIMESTAMPDIFF(MINUTE, sm.RefDoseDT, RAWDATE(CONCAT(sci.SCICESTDTCSOIT, ' ', sci.SCICESTDTCSOTMIT)))) > @UpperWindowLimit
        OR ABS(TIMESTAMPDIFF(MINUTE, sm.RefDoseDT, RAWDATE(CONCAT(sci.SCICESTDTCSOIT, ' ', sci.SCICESTDTCSOTMIT)))) < @LowerWindowLimit
        OR sm.RefDoseDT IS NULL
      )
ORDER BY `Country`, `Site`, `Subject Number`, `SCI Visit`, `SCI Form`, `SCI Seq`, `Date/Time Specimen(s) Obtained`
