Report ID: RID129

Report Title:
Incorrect Subjects with Site Level Normal Range Data

Description:
This report outputs incorrect subject(s) with the Site Level Normal Range (SLNR) eCRF initialized. SLNR data should only be entered for one subject per site and whose Screening  number ends in '00001'

MODULES USED: SLCNR, SLHNR, SLONR

Column Heading:
1. Country

2. Site

3. Subject Number

4. Screening Number

5. Local Lab eCRF

Logic:
The report checks for the screening number that has SLNR (SLCNR, SLHNR, SLONR)  data and produces output if it does not end in '00001'.

Do not include deleted records

Report Scenarios:
1 - Yes

Subject has SLNR (SLCNR, SLHNR, SLONR)  data and the Screening number does not ends in '00001'

2 - No

Subject has SLNR (SLCNR, SLHNR, SLONR)  data and the Screening number ends in '00001'

Sorting:
Country, Site, Screening Number, Site Level NR eCRF

Parameter Selection:
Country, Site, Site Level NR eCRF

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subject Assignment.Subject Number

4. Subject Assignment.Screening Number

5. Hardcode: 'CLAB' / 'HLAB'/ 'OLAB'
