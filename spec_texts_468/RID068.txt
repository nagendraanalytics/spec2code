Report ID: RID068

Report Title:
Inconsistent Encoding of Verbatim Terms

Description:
This report generates a listing of verbatim terms which were encoded to more than one Preferred Term.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Seq

6. Verbatim Term

7. Encoded Term

Logic:
The report should display output if verbatim terms from Adverse Events, Medical History, Procedures, Primary Diagnosis, Death Autopsy Results, Death, MHA, SAEI, SAEP, APAE, APMH, APPRC which were encoded to more than one Preferred term.  Comparisons should not be case-sensitive, and report should not compare terms across fields or forms.

Display row count in footer

Report should not display deleted records.

If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
1) Output=Yes

If verbatim terms from Adverse Events, Medical History, Procedures, Primary Diagnosis, Death Autopsy Results, Death, MHA, SAEI, SAEP, APAE, APMH, APPRC which were encoded to more than one Preferred term.

2) Output=No

If verbatim terms from Adverse Events, Medical History, Procedures, Primary Diagnosis, Death Autopsy Results, Death, MHA, SAEI, SAEP, APAE, APMH, APPRC which were encoded to one Preferred term respectively.

3) Output=No

Deleted record
