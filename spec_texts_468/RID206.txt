Report ID: RID206

Report Title:
Missing required item in PRG form

Description:
Report lists all pregnancy data in the study that has a required field  missed but have a radio button comment attached to the required field.

Column Heading:
1. Country

2. Site

3. Subject Number

4. eCRF

5. Seq

Logic:
This report should display the records from PRG01, PRG02, PRG03 and PRG04 Forms when a sequence number (Formidx) is visible, but any required item has  a radio button comment attached to the required field.

*Report should not display deleted records.

*If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
A-No

No required field not populated with Radio Button Comment

B-No

All Required field populated.

C-No

Any of  Required field not populated with text comment.

D-No

Deleted record.

E-Yes

Any of Required field not populated with Radio Button Comment

Sorting:
Country, Site, Subject Number, eCRF

Parameter Selection:
Country, Site, Subject Number, eCRF, Randomized Only

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. PRG01/PRG02/PRG03/PRG04.Formmnemonic

5. PRG01/PRG02/PRG03/PRG04.Formidx
