Report ID: RID294

Report Title:
Reconciliation between OAGVH and AOGHV dates associated to the same AEs

Description:
This report will output when Associated AE Sequence Number in OAGVH and AOGVH match but Start or Stop Date do not match

Column Heading:
1. Country

2. Site

3. Subject Number

4. OAGVH Seq

5. OAGVH Associated AE

6. OAGVH Onset Date

7. OAGVH Stop Date

8. AOGVH Seq

9. AOGVH Associated AE

10. AOGVH Onset Date

11. AOGVH Stop Date

12. Scenario

Logic:
Logic 1: OAGHV.Associated AE Sequence Number (From AE Form) = AOGVH.Associated AE Sequence Number (From AE Form)

AND

Scenario 1:

Logic 1.1: Minimum OAGVH.GVHD Grade Onset Date <> minimum AOGVH.GVHD Stage Onset Date

OR

Scenario 2:

Logic 1.2: Maximum OAGVH.GVHD Grade Onset Date <> maximum AOGVH.GVHD Stage Onset Date

Note 1: Deleted records should not be taken into account.

Note 2: Logic 1 is met if at least one Associated AE Sequence Number matches

Note 3: When there are two AOGVH entries related to one OAGVH entry; please merge both AOGVH records in one and use minimum AOGVH.GVHD Grade Onset Date and maximum AOGVH.GVHD Grade Stop Date for this new record. For example:

On InForm:

AOGVH Seq = 1 ; AOGVH Associated AE = 2 ; AOGVH Onset Date = 1-Jan-15 ; AOGVH Stop Date = 10-Feb-15

AOGVH Seq = 2 ; AOGVH Associated AE = 3 ; AOGVH Onset Date = 5-Feb-15 ; AOGVH Stop Date = 10-Mar-15

Expected output:

AOGVH Seq = 1,2 ; AOGVH Associated AE = 2,3 ; AOGVH Onset Date = 1-Jan-15 ; AOGVH Stop Date = 10-Mar-15

Report Scenarios:
A – Yes

OAGVH and AOGVH are associated to the same AEs and minimum GVHD Stage Onset Dates do not match

B – No

OAGVH and AOGVH are associated to the same AEs and minimum GVHD Stage Onset Dates match

C – Yes

OAGVH and AOGVH are associated to the same AEs and maximum GVHD Stage Stop Dates do not match

D – No

OAGVH and AOGVH are associated to the same AEs and maximum GVHD Stage Stop Dates do not match

E – No

OAGVH and AOGVH are associated to different AEs

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, Site Number, Subject Number, List of Subjects

Form.Item Names:
1. SA.Country

2. SA.Site

3. SA.Subject number

4. OAGVH.Sponsor ID Number

5. OAVH.Associated AE Sequence Number (From AE Form)

6. Minimum OAGVH.GVHD Grade Onset Date (show blank if Logic 1.2 is met)

7. Maximum OAGVH.GVHD Grade Stop Date (show blank if Logic 1.1 is met)

8. AOGVH.Sponsor ID Number

9. AOGVH.Associated AE Sequence Number (From AE Form)

10. Minimum AOGVH.GVHD Grade Onset Date (show blank if Logic 1.2 is met)

11. Maximum AOGVH.GVHD Grade Stop Date (show blank if Logic 1.1 is met)

12. Display: “1” if Logic 1.1 is met or “2” if Logic 1.2 is met
