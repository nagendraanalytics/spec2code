Report ID: RID133

Report Title:
Duplicate Site Level Normal Range Data sets

Description:
This report outputs Duplicate records on the Site Level Normal Range (SLNR) eCRFs and if there is an overlap in age range based on Laboratory Name, Effective Date, Specimen Type and Unit.

Logic:
Logic 1:

The report displays duplicate rows in Site-level normal ranges eCRFs (SLCNR, SLHNR, SLONR).

Duplicate rows are defined within each subject and form as follows:

- SLCNR, SLHNR: Duplicate Laboratory Name, Effective Date and Specimen Type.

- SLONR: Duplicate Laboratory Name, Effective Date.

Each of the components of the duplicates has to be available. Row with null values are not considered.

Only the alphanumerical parts of the Laboratory Names are considered for the comparison.

Deleted records are not considered.

Output for Logic 1 is displayed in Table 1.

Logic 2:

The report displays records for the same Tests reported with overlapping age range in Site-level normal ranges eCRFs (SLCNR, SLHNR, SLONR).

Overlapping records are defined within each subject and form as follows:

- SLCNR, SLHNR, SLONR: Laboratory Name, Effective Date, Sex, Specimen Type, unit and Test Name is the same and age ranges are overlapping. Age ranges may be defined using the same or different units (years, months, days).

If the sex in one record is entered as "Both" and for the second record it is entered as "Male" or "Female", this should be considered by the report as the same sex.

Each of the components of the overlaps has to be available. Row with null values are not considered.

Only the alphanumerical parts of the Laboratory Names are considered for the comparison.

Deleted records are not considered.

Output for Logic 2 is displayed in Table 2.

Report Scenarios:
1) Output=Yes

Two or more rows have the same Laboratory Name, Effective Date and Specimen Type on SLCNR/SLHNR for the same subject.

2) Output=Yes

Two or more rows have the same Laboratory Name and Effective Date on SLONR for the same subject.

3) Output=No

Only one row has the combination of Laboratory Name, Effective Date and Specimen Type on SLCNR/SLHNR for the same subject.

4) Output=No

Only one row has the combination of Laboratory Name and Effective Date on SLONR for the same subject.

5) Output=No

Laboratory Name, Effective Date and/or Specimen Type is null on SLCNR/SLHNR

6) Output=No

Laboratory Name and/or Effective Date is null on SLONR

7) Output=Yes

There is an overlap in age range for the same Test Name in SLCNR/SLHNR/SLONR for the same subject. Laboratory Name, Effective Date, Sex, Specimen Type, unit is the same.

8) Output= No

There is no overlap in age range for the same Test Name in SLCNR/SLHNR/SLONR for the same subject.

9) Output = No

There is an overlap in age range for the same Test Name in SLCNR/SLHNR/SLONR for the same subject but Laboratory Name and/or Effective Date and/or Sex and/or Specimen Type and/or unit is the different or is null.
