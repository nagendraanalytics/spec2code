Report ID: RID153

Report Title:
Missing Items in PK External Vendor

Description:
This report displays all Aspera records (Data loaded by the vendor) with null values in required fields from External Data transfer performed for BA and Central vendors. Required fields may vary depending on the vendor and the external data collected. Fields to be checked for missing values should be confirmed with the QP2 of each study.

Comments:

1. Parameter selection for Vendor. If Vendor = ALL, Central Vendor file and BA Vendor file should be included, if Vendor = BA, only BA Vendor file should be included, if Vendor = Central, only Central Vendor file should be included. Parameter selection is default ALL.

2. Parameter selection for DTM. If DTM are not applicable for study they should be N (No) in parameter selection. Parameter selection is default Y (Yes).

3. If more than one value = NULL and REFID, SCRNID match between files we expect cumulated error message e.g Missing NOMDAY in BA and NOMHOUR in CV' when Parameter for Vendor is ALL

4. When SCRENID match but REFID does not, output should be present in separate rows.

5. When Parameter selected is BA or Central only data columns for selected vendor should be present, columns for other vendor should be hidden.

6.When individual vendor is selected there is no need of cummulative message.

7.When selected parameter Vendor= ALL then sorting should consider variables mentioned in sorting columns from both files.
