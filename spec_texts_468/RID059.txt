Report ID: RID059

Report Title:
Missing DOV in Visits with Initialized forms

Description:
The report outputs initialized visits with missing DOV.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Date of first initialized eCRF

6. eCRF initialized (if more than one please lists them in the same output)

Logic:
Logic 1:

The report outputs initialized visits with missing DOV.

# Days is calculated based on the Date entered on first eCRF Initialized.

Scenario 1 example: Report ran on 26/Sep/2020

- Allowed window days= 15 days

- Form Initialized Date=  06/Sep/2020

- DOV= Null OR DOV =Null and IVR contact date completed AND erroneous visit not checked.

AND DOV is not provided and the difference between the date when the form was initialized (06/Sep/2020) and the Current date (26/Sep/2020) is greater than the number of days selected on the prompt (15 Days).

NOTE:

1. For logic 1: Any of the forms in the visit is initialized or completed and DOV field is missing and erroneous check box is blank

2. Visit is consider intilialized even if any form was completed and then information deleted

3. For the scenario when Visit is initialized due to a bubble comment AND DOV = NULL AND erroneous visit not checked. All forms should be considered if the visit was initiated with a bubble comment.

For example, if a bubble comment was added in ECOG, and this comment initiated the visit, with DOV=NULL and the ""Erroneous visit"" checkbox not checked, the expected output should be produced.

4. Common visit will be excluded. No output is expected.

Report Scenarios:
1) Output=YES

Visit with any form initialized and DOV=Null AND the number of days between the date when the first visit form was initialized is greater than the number of days used on the prompt ""Allowed window days""

2) Output=NO

Visit not initialized at all

3) Output =NO

Visit with any form initialized  AND DOV <> NULL

4) Output = NO

Visit with any form initialized AND DOV=NULL AND erroneous visit checked

5) Output = YES

DOV = Not Done/Not Applicable/Unknown radiobutton AND erroneous visit not checked

 6) Output = NO

DOV = Not Done/Not Applicable/Unknown radiobutton AND erroneous visit checked

 7) Output = YES

Visit is initialized due to a manual query or autoquery AND DOV = NULL AND erroneous visit not checked

8) Output = YES

Visit is initialized due to a bubble comment AND DOV = NULL AND erroneous visit not checked

 9) Output = YES

Visit is initialized due to the Data Review Checkbox being checked and DOV = NULL

10) Output = YES

Visit is initialized due to IVR contact date completed AND DOV = NULL AND erroneous visit not checked

11) Output = YES

Any form in the visit is intialized and information was then removed later AND DOV=NULL AND erroneous visit not checked

Special considerations for the following prompts:

- Visit may be used to include or exclude any visit. All visits are included by default except visits do not have DOV (date of visit) i.e.  Final Status

- Please exclude visits with DOV entered except when DOV is completed via radio button Not Done/Not Applicable/Unknown.

- On the ""allowed window days"" prompt the person who runs the report should be able to write any number.

NOTE: Please consider the date for first initialized eCRF’ column from  ‘FMINSTARTEDSTATE’

Country, Site, Subject Number, Visit

Parameter Selection:
Country, Site, Subject Number, Number of Days(By default 0) , Visit, Include/Exclude (dynamic)
