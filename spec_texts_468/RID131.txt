Report ID: RID131

Report Title:
Local Lab Data mismatches between visit level and site level eCRFs

Description:
This report derives visit level data from local lab (CLAB, HLAB, OLAB) eCRFs and determines mismatches with Site-level Normal Range eCRF (SLCNR, SLHNR, SLONR) based on the test, collection date, age at collection, sex and the normal range effective date.

Logic:
Visit Level eCRFs - HLAB,CLAB,OLAB (include variations of each form if exists for study: for OLAB, OLABA,OLABB,OLABC……)

Site Level eCRFs- SLHNR,SLCNR,SLONR

For each subject on the local lab eCRF, match each site, laboratory name, test, collection date, age at collection, specimen type (where applicable), units and sex with site, laboratory name, test, age at collection, specimen type (where applicable), units and sex and closest effective date on the site level local lab normal range eCRF

There is mismatch between Visit Level eCRF and Site Level eCRF for All/Some key fields <Test, collection date, specimen type, age at collection, unit, sex and the normal range effective date>

NOTES

1. Determine the age(in years, months and days) at collection date for each subject on the local lab eCRF from Date of Birth on the Demographics eCRF.

2. Ageindays = Extract local lab collection date - Demographics.dob

3. If month is missing or UNK in DM.dob  then consider Jun as month and If day is missing or UNK in DM.dob the consider 15th as Day.

4. Ageindays calculation :

All the ageing days are converted into days and leap year also taken into consideration while calculating ageing days for both months and years.

5. Closest normal range effective date would be the greatest date that is prior or equal to the collection date of the lab test.

6. Text comparison should not be case sensitive.

7. Each HLAB and CLAB test is a field on the local lab eCRF, with the field name specifying the test.

8. Do not include deleted records.

9. Do not include data from Erroneous Visits.

10. The following units need to be standardized to avoid mismatches between forms:

- 'GM' to 'G'

- 'GRAM' to 'G'

- 'MOLE' to 'MOL'

- 'MICRO' to U'

- 'MILLI' to 'M'

- 'UG/L' to 'NG/ML'

11. Logic only consider mismtach/missing data for result reported as Numeric results.

12. For the Testname INR there will not be any units.

Assumptions for the site level local lab normal ranges (SLNR) for each vendor:

a. Each set of new test ranges will be entered in a new record with a corresponding sequence number and a current effective date.

b. The set of new test ranges will be considered as cumulative with the previous entered test ranges, and the previous test ranges will need to be considered as having the new test ranges' sequence number and effective date. Previous valid test ranges will not be re-entered in the new record.

c. If any of the new test ranges already existed in previous records, then the previous test range will be considered valid from the previous effective date to the new effective date and the new test range will be considered valid from the new effective date.

d. There could be valid records for the same lab, test, gender, age range but different units, so all of those records should be taken into account as range reference.

Report Scenarios:
A-Yes

There is no record match between Visit Level eCRF and Site Level eCRF i.e test entered in local lab and there is no corresponding entry in site level normal range form

B-No

There is no missing normal range in Site Level eCRF

C-No

Record match between Visit Level eCRF and Site Level eCRF

D-No

Mismatch/missing data for Character results
