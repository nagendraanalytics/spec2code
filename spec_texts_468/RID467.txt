Report ID: RID467

Report Title:
Missing Hematological Disease Assessment or Lesion Evaluation   - Baseline

Description:
This report will list subjects who are missing a Baseline Disease Evaluation.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Start Date and Time First Dose Administered/Received (SM01)

5. Lesion Number

6. Date of Assessment

Logic:
Report should output subjects who meet the following criteria:

SM01 "Start Date and Time First Dose Administered/Received" <> NULL

AND

HDA OR LSNEV is not initialized

OR

There is no HDA or LSNEV Date of Evaluation for each lesion within minimum "SM01 Start Date (inclusive) and xxx

days prior to minimum SM01 Start Date" (inclusive).

HDA (Hematological Disease Asessment) and LSNEV (Lesion Evaluation) can be interchanged depending on protocol requirements

NOTE:  DMS should provide input on the eCRF usage (HDA or LSNEV be used) and the number of days for baseline assessment

All lesions identified at study start must have a baseline evaluation. If a new lesion is discovered during the study, it is Progressive Disease and it will not have a baseline evaluation.

For any deleted records, do not use in the report analysis and do not report in the output.

The user should provide value for below parameters:

-eCRF : the eCRF usage (HDA or LSNEV be used)

-Number of days for baseline assessment : xxx days prior to minimum SM01 Start Date

e.g.

-eCRF : LSNEV

-Number of days for baseline assessment : 28

For SM01, check for the date of earliest SM record, if there is more than 1 section completed.

Report Scenarios:
A - No:

SM01 is not initialized or Start Date and Time First Dose Administered/Received is blank in SM01

B - No

Date of evaluation of HDA OR LSNEV occurs within 28 days prior to minimum Start Date (inclusive) and Time First Dose

Administered/Received (from SM01) (inclusive)

C - Yes

SM01 is initialized and item 'Start Date and Time First Dose Administered/Received' entered and HDA OR LSNEV is not initialized

D - Yes

No Date of HDA OR LSNEV within 28 days prior to minimum Start Date and Time First Dose Administered/Received

(from SM01)

E - Yes

SM01 is initialized and item 'Start Date and Time First Dose Administered/Received' entered and HDA record OR LSNEV record is entered and then deleted.

Parameter Selection:
Country, Site Number, Subject Number,eCRF,Number of days for baseline assessment

Form.Item Names:
1. Subject Assessment.Country

2. Subject Assessment.Site Mnemonic

3. Subject Assessment.Subject Number

4. DATE OF FIRST DOSE. Date ~ Start Date and Time First Dose Administered Received

5. Lesion Number

6. Date of Lesion Evaluation OR HDA Disease Assessment
