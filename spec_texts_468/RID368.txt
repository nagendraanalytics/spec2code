Report ID: RID368

Report Title:
Non-Target Worsening reconciliation

Description:
This report will output if worsening of Non-Target lesions is entered incorrectly.

Column Heading:
Table 1:

1.Country

4.ORIR seq#

6.ORIR Date of Assessment

8.Scenario

Table 2

1.Country

2.Site

4.ORIR seq#

6.ORIR Date of Assessment

7.LSNIR seq#

8.LSNIR Date of Lesion Evaluation

9.Non-Target Lesions Worsening

10.LSNIR Non-Target Lesion Status

11.Scenario

Logic:
Logic 1.1:  ORIR entry Non-Target Lesions Worsening <> NULL

AND

Logic 1.2: No immediately preceding ORIR entry Non-Target Lesion (Identified At Baseline) iRECIST Response = iUPD

Table 2:

{Logic 2.1: ORIR Non-Target Lesions Worsening = ‘Yes’

AND

Logic 2.2: LSNIR Date of Current Lesion Evaluation (Scan/Image/Physical Exam)/ Date of Current Lesion Evaluation = ORIR Date of Procedure for Overall Response (Scan/Image/Physical Exam)

AND

Logic 2.3: Tumor Identification= ‘Non-Target Extra Nodal’ OR ‘Non-Target Nodal’ OR "Non-Target"

AND

Logic 2.4: There is not at least one LSNIR entry with Non-Target Lesion Status = (“Worsening” OR “Enlargement From Nadir” OR “Further Enlargement From Nadir”)

AND

Logic 2.5: There is at least one previous ORIR entry with Non-Target Lesion (Identified At Baseline) iRECIST Response = iUPD}

OR

{Logic 3.1: ORIR Non-Target Lesions Worsening = NULL

AND

Logic 3.2: There is immediately preceding ORIR entry with Non-Target Lesion (Identified At Baseline) iRECIST Response = iUPD

OR

{Logic 4.1: ORIR Non-Target Lesions Worsening = ‘No’

AND

Logic 4.2: LSNIR Date of Current Lesion Evaluation (Scan/Image/Physical Exam)/ Date of Current Lesion Evaluation = ORIR Date of Procedure for Overall Response (Scan/Image/Physical Exam)

AND

Logic 4.3: Tumor Identification= ‘Non-Target Extra Nodal’ OR ‘Non-Target Nodal’ OR "Non-Target"

AND

Logic 4.4: There is at least one LSNIR entry with Non-Target Lesion Status = (“Worsening” OR “Enlargement From Nadir” OR “Further Enlargement From Nadir”)

AND

Logic 4.5: There is at least one previous ORIR entry with Non-Target Lesion (Identified At Baseline) iRECIST Response = iUPD}

Requires a supporting document should be named as study_phase_supp <xxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: the order on which phases will appear on protocol

2. Treatment Phase: this information is the phase name given in the protocolo (Initial Treatment Phase/Second Course Phase/Crossover/Neoadjuvant)

3. First Visitmnemonic of Treatment Phase: the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Study Phase Page".

Notes:

1. Exclude deleted records and erroneous visits

2. For logic 1.2, please check chronologically every previous ORIR entry.

3. For logics in table 2, please output a single record for each timepoint and only check non-target nodal, non-target extra nodal and non-target lesions

4. For logics in table 2, column 6: please list all the non-target lesion numbers in a single row and separate them with a comma (,)

5. For logic 3.1 and 3.2, please order all ORIR responses chronologically (from oldest to newest entry).

6. Immediately preceding ORIR in logic 1.2, 3.2 refers to previous non-deleted ORIR entry with max Date of Procedure for Overall Response (Scan/Image/Physical Exam).

7. Logic 1, 2, 3 and 4 should only check ORIR and LSNIR entries within the same Treatment Phase, as per study_phase_supp document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase, Cycle 1 Course 2

The treatment phase will be identified as following:

Initial Treatment Phase: Cycle 1 <= Form.Date < Cycle 1 Course 2

Second Course Phase: Cycle 1 Course 2 <= Form.Date

Form.Date include: LSNIR.Date of Current Lesion Evaluation (Scan/Image/Physical Exam)/LSNIR.Date of Lesion Evaluation, ORIR.Date of Procedure for Overall Response (Scan/Image/Physical Exam)

8. If there is NO response of Non-Target Lesion Status = (“Worsening” OR “Enlargement From Nadir” OR “Further Enlargement From Nadir”) the report will not generate output for Logic 2. There will be output for logic 1, 3 and 4 only.
