Report ID: RID423

Report Title:
Missing Survival Follow-Up Assessment

Description:
This report displays subjects who have missing an SFU Date of Contact.

Column Heading:
1. Country

2. Site

3. Subject Number

4. eCRF

5. eCRF Date

6. Max SFU Date of Contact

7. Scenario

Logic:
(Logic 1.1: "Form".Date of Assessment is NOT NULL OR "Form".Select the Status of the Subject for the Next Trial Segment/Select the Status of the Subject for the Next Trial Segment Phase = "Next Trial Segment"

OR

Logic 1.2: OSOF eCRF.DATE OF SURGERY is NOT NULL AND OSOF eCRF.INTENT OF SURGERY is NOT "Palliative"/"Yes"

OR

Logic 1.3: ORAD2.Start Date is NOT NULL

OR

ORAD2.Reason for Radiation is NOT "Palliative Treatment or Symptom Control"/"Palliative Treatment or Symptom Control of Metastatic Disease"

OR

Logic 1.4: ODBF eCRF.IMPUTED START DATE OF REGIMEN/IMPUTED START DATE OF MEDICATION is NOT NULL)

AND

(Logic 1.5: System date > (the date selected in Logic 1.1, Logic 1.2, Logic 1.3 or Logic 1.4 + "Window of Days" + "Upper Limit of Days" + "Data Entry Window")

AND

Logic 1.6: There is NOT at least one SFU record with Date of contact or last attempt of contact NOT NULL)

AND

(Logic 1.7: DS01.Date of Disposition is NULL

OR

Logic 1.8: DS01.Date of Disposition > (the date selected in Logic 1.1, Logic 1.2, Logic 1.3 or Logic 1.4 + "Window of Days" + "Upper Limit of Days"))

Logic 2:

Logic 2.1: The SFU record with the maximum Date of contact or last attempt of contact has the SFU.Survival Status <> Lost to Follow-up/Dead/Subject Withdrew Consent

AND

Logic 2.2: System date > (Max SFU.Date of contact or last attempt of contact + "Window of Days" + "Upper Limit of Days" + "Data Entry Window")

AND

(Logic 2.3: DS01.Date of Disposition is NULL

OR

Logic 2.4: DS01.Date of Disposition > (Max SFU.Date of contact or last attempt of contact + "Window of Days" + "Upper Limit of Days"))

Logic 3:

Logic 3.1: There is NOT at least one SM eCRF record in the whole subject with the START DATE/START DATE AND TIME FIRST DOSE ADMINISTERED/RECEIVED NOT NULL

AND

Logic 3.2: ITT End Point = Yes

AND

Logic 3.3: System Date > (SR.Date of Assessment + "Window of Days" + "Upper Limit of Days" + "Data Entry Window")

AND

Logic 3.4: There is NOT at least one SFU record with Date of contact or last attempt of contact NOT NULL

AND

(Logic 3.5:  DS01.Date of Disposition is NULL

OR

Logic 3.6: DS01.Date of Disposition > (SR.Date of Assessment + "Window of Days" + "Upper Limit of Days"))

Requires supporting document to be named ONC_SFU_002_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

1. Form: Type in PMS1A, OEFU, RNT, OEDRA for Scenario 1. For Scenario 2 and 3 type in "NA"

2. Next Trial Segment: Type in the next trial segment that will be used to define the start of the survival follow-up phase (e.g. "Continuing into Survival Follow-up"). This column is only applicable to Scenario 1 (except form OEDRA), for Scenario 1 – OEDRA form, Scenario 2 and 3 simply enter "NA"

3. Window of Days: Type in the window of days per protocol in which each SFU contact should occur e.g. "Per protocol SFU contacts will occur every 84 days + 7" then type in the 84. This window of days is applicable to each of the scenarios although the number may differ between them

4. Upper Limit of Days: Type in the amount of days from the upper limit for each of the "Window of Days" value, e.g. "Per protocol SFU contacts will occur every 84 days + 7", then enter the 7

5. ITT Endpoint: This column is only applicable to Scenario 3 if the trial does NOT use the form RNT, if trial uses the form RNT then do NOT provide a row in the supporting document for Scenario 3 since the review is covered by Scenario 1. Type in "Yes" if per protocol subjects who are randomized not treated are allowed to continue in the Survival Follow-up phase and type in "No" if per protocol subjects who are randomized not treated are not supposed to continue in the Survival Follow-up phase.  For Scenario 1 and 2 simply type in "NA"

6.Oncology Surgery Form: Form of oncologic surgery from which the next Survival Follow-Up entry is calculated if dated prior to PMS1A, OEFU, RNT, OEDRA. Complete with NA if all oncologic surgery forms apply.

7. Scenario: Type in "1", "2", "3" according to each scenario.

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page"

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

Notes:

1-	Deleted records and erroneous visits are excluded from programming

2-	If the date is UNK on ORAD2, ODBF or OSOF eCRF, please use the minimum date of the month

3-	For ODBF eCRF, if IMPUTED START DATE OF REGIMEN is not present then use IMPUTED START DATE OF MEDICATION. If IMPUTED START DATE OF MEDICATION is not present, then use IMPUTED START DATE OF REGIMEN. If both are present, then use IMPUTED START DATE OF REGIMEN

4-	In Logic 1.2, eCRFs and items will be retrieved from OSOF_supp_doc

5-	In Logic 1.4, eCRFs and items will be retrieved from ODBF_supp_doc

6-	In Logic 3.1, eCRFs and items will be retrieved from SM_supp_doc

7-	If ITT Endpoint = No, then do not run Logic 3

8-          Logic 1.2 should be reviewed against the information in column 6 of supp_doc

9- 	"Next Trial Segment" from logic 1.1 should be taken from supporting document

Layout Notes:

1-	For Logic 1, column 4 should be completed with the form mnemonic with the earliest date of Logic 1.1, Logic 1.2, Logic 1.3 or Logic 1.4. For Logic 2, column 4 should be blank. For Logic 3, column 4 should be completed as "SR"

2-	For Logic 1, column 5 should display the actual date of the form mnemonic displayed in column 4. For Logic 2 column 5 should be blank. For Logic 3 display the date on the SR.Date of Assessment

3-	For Logic 1 and Logic 3, column 6 should be blank. For Logic 2, column 6 will display the date of the maximum SFU.Date of contact or last attempt of contact.

4-	Column 7 will display "Scenario 1" if Logic 1 is satisfied, "Scenario 2" if Logic 2 is satisfied and "Scenario 3" if Logic 3 is satisfied

5-	The format in Column 5 and 6 should be "DDMMMYYYY", for example, "01JAN2021"
