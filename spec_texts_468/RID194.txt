Report Title:
Drug-holiday schedule for different Arm/Treatment ID/Cohort

Description:
This report will verify, if drug-holiday schedule is performed appropriately as per assigned Arm/Treatment ID/Cohort

Logic:
This report will produce an output only for records following each other:

Scenario 1:

Logic 1. If Study medication is Un-Interrupted: then in the same batch of consecutive specified study medication records

Maximum  Stop Date/Time - Minimum Start Date/Time<> X days/hours

Logic 2. If Study medication is Interrupted: for the same study medication record Stop Date/Time - Start Date/Time<> X days/hours

Scenario 2:

Logic 3. If the GAP diff between current Start Date/Time - previous Stop Date/Time for specified study medication record which is greater than 1 day or 24 Hours

And

GAP <> Y days/hours

Notes:

1. Sort Study Medication records by Date firstly.

2. Un-Interupted Study medication: The diff between Current Stop date- Pervious Stop is less than equals to 1 day or 24 Hours

Interupted Study medication: The diff between Current Stop date- Pervious Stop is more than 1 day or 24 Hours

3. This report will provide outputs for every patient with specified Arm Code/Treatment ID/Cohort as provided in supporting document.

4. Study medicaiton name should be specified in supporting document, and check within study medication.

5. Dosing window X and Gap window Y should be provided in supporting document.

6. Days/Hours should be provided in supporting document.

7. Batch - a dosing period (consecutive records of Study Medication, including zero doses)

8. one consecutive Study Medication record(s) is the integer number N

9. Start Date refers to Start Date/Time and Stop Date refers to Stop Date/Time item on Study Medication form

10. When Days selected, only consider date; When Hours selected, both date and time considered

11. Output should not be considered, when Start Date/Time or Stop Date/Time on Study Medication form = NULL

12. Study Medication form include SMAU, SMAB, SM, SM01, SM02, SM04

13. Deleted records and Zero dose should not be considered.

14. Scenario 1 output on corresponding tab "Scenario 1"; Scenario 2 output on corresponding tab "Scenario 2"

15. Display the UNK Time for SM Date and Time as UNK:UNK.

Report Scenarios:
If subject is in specified Arm Code/Treatment ID/Cohort and meet below scenarios:

Scenario 1A/ Yes

The dosing period between Maximum Stop Date/Time and Minimum Start Date/Time  in the same batch of consecutive specified study medication records is more/ less than X days/hours.

Scenario 1B/ No

The dosing period between Maximum Stop Date/Time and Minimum Start Date/Time  in the same batch of consecutive specified study medication record is equal to X days/hours.

Scenario 2A/ Yes

The gap between Stop Date/Time of Study Medication record (previous)  and Start Date/Time of the next specified study medication record (current) is more/less than Y days/hours.

Scenario 2B/No

The gap between Stop Date/Time of Study Medication record (previous) and Start Date/Time of the next specified study medication record (current) is equal to Y days/hours.

Scenario 3/No

Zero dose don't need to be considered
