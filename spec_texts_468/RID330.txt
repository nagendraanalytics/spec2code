Report ID: RID330

Report Title:
Target Response vs Lesion Evaluation measurements for Target Lesions

Description:
This listing contains details about the type of lesions reported under Tumor Identification "Target" on Lesion Evaluation form LSNRN  and the corresponding RANO Response.

Column Heading:
1. Country

2. Site

3. Subject Number

4. LSNRN Seq#

5. Date of Lesion Evaluation

6. Was lesion evaluable?

7. Target Lesion SPD

8. ORRN Seq#

9. Date Response

10. Target Response

11. % Change from nadir

12. % Change from baseline

13. Expected RANO Response

Logic:
(

Logic 1.1: ORRN.Date Response Determined AND ORRN.Overall Response is not Null

AND

Logic 1.2: LSNRN.Lesion Identification = "Target"

AND

Logic 1.3: LSNRN.Date of Lesion Evaluation = ORRN.Date Response Determined in logic 1.1

AND

{

Logic 1.4: ORRN. Target Lesion Response <> Expected RANO Response

}

)

OR

(

Logic 2.1: LSNRN.Date of Assessment is not Null

AND

Logic 2.2: LSNRN. Date of Lesion Evaluation <> LSNRN.Date of Assessment

AND

Logic 2.3: There is no ORRN record with ORRN.Date Response Determined = LSNRN. Date of Lesion Evaluation

)

OR

(

Logic 3.1: ORRN.Date Response Determined is not Null

AND

Logic 3.2: There is no LSNRN record with LSNRN. Date of Lesion Evaluation = ORRN.Date Response Determined

)

Note 1: Exclude deleted records and erroneous visits from programming.

Note 2: If there is no Matching ORRN form for a LSNRN record display columns 8 to 12 blank.

Note 3: if there are is no Matching LSNRN form for a ORRN record display columns 4 to 7 and Column 11 to 13 blank.

Note 4: For column 11 and 12 for SPD or NADIR, consider all previous lesions with 'Lesion Identification'= "Target"

Note 5: NE is when in LSNRN entry "Was the Lesion Evaluable" is entered as "No"

Note 6: For Form Item 7: If we have two or more lesions with 'Lesion Identification' of 'Target' in LSNRN form for the same ‘Date of Lesion Evaluation’ then please calculate the Sum of Product of Diameters for all records as below.

A1*B1+ A2*B2+A3*B3: Longest Diameter=A; Longest Perpendicular Diameter=B; 1=Target Lesion 1; 2= Target Lesion 2; 3= Target Lesion 3

For Example :

1/Jan/2021: 20*10+14*2+13*2

1/Feb/2021: 17*8+12*3+2*3

20/Feb/2021: 14*5+9*5+1*4

15/Mar/2021: 6*9+6*9+5*7

14/Apr/2021: 4*3+5*9+6*12

Display the whole addition expression like “20*10+14*2+13*2=254”, not only “254”.

Display the values in the sum, in the same order as column Lesions are listed in column 4.

If a lesion meets above criteria, and has item “Was the Lesion Evaluable?” As “No” then display the lesion on the whole addition expression as NE and use the value of 0 for the sum (20*10+14*2+NE=228).

Note 7: For the Target lesions the listing will show the product of Longest Diameter and Longest Perpendicular Diameter for each lesion and the Summatory of the product of diameters (SPD) for the all the lesions evaluated on the same date. If the item "Was the Lesion Evaluable?" is selected as No, the lesion will appears as Not evaluable.

Note 8: For the Target lesions, the report will show also the variation from Baseline and Nadir on each evaluation date to easily calculate the Response.

% change from Baseline:

[(SPD from current Timepoint - Baseline SPD)/Baseline SPD]*100%

% from Nadir:

[(SPD from current Timepoint - Nadir SPD)/Nadir SPD]*100%

Nadir: it the smallest SPD since Baseline

Baseline: it is the first SPD (SPD for the earliest Date of Lesion Evaluation in LSNRN)

SPD: it is The Sum of Product of Diameters for each time of assessment.

Note 9: Column 11 and 12 should display rounded values.

Report Scenarios:

B- Yes

List ORRN records which has no corresponding LSNRN record OR LSNRN record which has no corresponding ORRN record.

C- NO

Target Lesion Response EQUALS from information on column expected response

D-No Deleted record

Sorting:
Country, Site, Subject Number, Date Response Determined (ORRN) OR Date of Lesion Evaluation (LSNRN). If some rows of output have both ORRN date and LSNRN date, consider sort by LSNRN date first then ORRN date

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized only (Y/N, Default as N)

Form.Item Names:
1. SA Form. Site Country

2. SA Form. Site Mnemonic

3. SA Form. Subject Number

4. LSNRN. Associated Lesion number (if there are more than one Lesion number for the same Date of Lesion Evaluation, display them all and joined by commas.)

5. LSNRN. Date of Lesion Evaluation.

6. LSNRN. Was the Lesion Evaluable? (display in one row for all lesions with the same Identification and Date, separated by commas. Display as “Y=<total number as Yes>” and “N=<total number as No>”. if there are no lesions as “No” do not display “N=0”

7. SPD The Sum of Product of Diameters should be calculated as follows: (A1*B1+ A2*B2: Longest Diameter=A; Longest Perpendicular Diameter=B; 1=Target Lesion 1; 2= Target Lesion 2)

8. ORRN. Sponsor ID Number

9. ORRN. Date Response Determined

10. Display the value of “ORRN. Target Lesion Response”

11. % Change from Nadir is Calculated as  [(SPD from current Timepoint - Nadir SPD)/Nadir SPD]*100%. Nadir SPD corresponds to the smallest SPD of all prior lesion evaluations of current Timepoint, Exclude evaluations that have at least one NE in the SPD. If SPD from Nadir is equal to 0, ignore calculation and display "Nadir is zero".

12. % Change from Baseline is calculated as [(SPD from current Timepoint - SPD from Baseline)/SPD from Baseline]*100%. Baseline SPD corresponds to the SPD of the Baseline assessment, i.e., evaluation done prior first Dose. If SPD from Baseline is equal to 0, ignore calculation and display "Baseline is zero".

13.Display “Not applicable” if there are no previous lesions with Lesion Identification "Target"

Display "Progressive Disease" if calculated % Change from Nadir is >= 25%.

Display "Partial Response" if calculated  % Change from Baseline is <=-50% AND >-100%.

Display "Complete Response" if All Target Lesions have measurements of 0 mm.

Display “Not evaluable” if criteria for “Progressive Disease” are not met AND on column 6 there is at least one lesion as No.

Otherwise display "Stable Disease".
