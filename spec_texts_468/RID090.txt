Report ID: RID090

Report Title:
Screening and Subject Number Comparison

Description:
This report displays patients where the Screening or Subject Number on the Subject Assignment  eCRF does not match the Screening or Subject Number transmitted from an External Vendor.

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. eCRF

6. Vendor

7. Visit ID or Number

8. Sample ID

9. Category

10. External Subject Number

11. External Screening Number

12. Mismatching

Logic:
The report should display output if subjects have external data with Screening or Subject Numbers different from the Screening and Subject Numbers on the Subject Assignment form.

InForm Screening number format is 9 digits and Subject Number format for randomized subjects is 12 digits.

External Screening number format is 9 digits and Subject Number format for randomized subjects is 6 digits.

Therefore, the mismatch in Subject Number should only consider the last 6 digits.

Screening number mismatch should not be checked on PFT form.

Report should not display deleted records.

Report Scenarios:
1 - Output=YES

IF Screening Number <> External Screening Number and

IF Subject Number <> External Subject Number

2 - Output=YES

IF Screening Number <> External Screening Number and

IF Subject Number = External Subject Number

3 - Output=YES

IF Screening Number = External Screening Number and

IF Subject Number <> External Subject Number

4 - Output=NO

IF Screening Number = External Screening Number and

IF Subject Number = External Subject Number

Output when the Mismatching prompt left blank.
