Report ID: RID452

Report Title:
Mismatch between Study Period and visit

Description:
This report will list subjects where Study Period in STR does not match with the corresponding visit.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. STR Seq

6. Start Date/time

7. Stop Date/Time

8. Study Period

9. Expected Study Period

Logic:
This report will list subjects where Study Period field entered in STR does not match with the corresponding visit where the STR is entered.

If STR is a common form, Study period for STR records are slotted in the immediately prior non-erroneous initialized visit.

Note 1. Deleted records should not output.

Note 2. STR records in erroneous visits should not output.

Note 3. If DOV for a visit has not been entered (visit was not initialized) or is erroneous, please output if visit was selected in the Study Period item within STR.

Note 4: If supporting doc is not provided, display the message as "ONC_STR_007_JR_STD Supporting Document Not Present for This Trial".

Requires supporting document to be named ONC_STR_007_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1) Group

2) Visit

3) Expected Study Period

e.g.

Group, Visit, Expected Study Period

1, Cycle 1 Day 8 Treatment 1, Treatment 1 Cycle 1

2, Cycle 1 Day 15 Treatment 1, Treatment 1 Cycle 1

3, Cycle 2 Day 1 Treatment 1, Treatment 1 Cycle 2

4, Cycle 2 Day 8 Treatment 1, Treatment 1 Cycle 2

5, Cycle 2 Day 15 Treatment 1, Treatment 1 Cycle 2

6, Cycle 3 Day 1 Treatment 1, Treatment 1 Cycle 3

7, Cycle 3 Day 8 Treatment 1, Treatment 1 Cycle 3

8, Cycle 3 Day 15 Treatment 1, Treatment 1 Cycle 3

9, Cycle 4 Day 1 Treatment 1, Treatment 1 Cycle 4

10, Cycle 5 Day 1 Treatment 1, Treatment 1 Cycle 5

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
SCENARIO 1: NO

Combination of Visit, eCRF, Study Period are according to the spreadsheet provided by the user

SCENARIO 2= YES

Combination of Visit, eCRF, Study Period are not according to the spreadsheet provided by the user.

SCENARIO 3=YES

If DOV for a visit has not been entered (visit was not initiliazed) or is erroneous, please output if visit was selected in the Study Period item within STR

SCENARIO 4= NO

Deleted study medication records or records in erroneous visits

Sorting:
Country, Site, Subject Number, STR Seq

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Number

4. Date of Visit Form.Visit Mnemonic

5. STR.Sponsor ID number

6. STR.Start Date/Time

7. STR.Stop Date/Time

8. STR. Study Period

9. Expected Study Period hardcoded from the supp document
