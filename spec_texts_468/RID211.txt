Report ID: RID211

Report Title:
Missing scheduled assessment against date of a specific timepoint

Description:
This report outputs  subjects with no assessment/test date within an acceptable range of days as compared to the specified reference timepoint.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Reference form

5. Study Medication

6. Reference timepoint

7. Visit

8. Form

9. Condition

Logic:
<Criteria Form1>.<Criteria Itemquestion1> = <Criteria Value1>  AND

<Criteria Form2>.<Criteria Itemquestion2> = <Criteria Value2> AND

<Criteria Form3>.<Criteria Itemquestion3> = <Criteria Value3> AND

Output subjects who meet following criteria:

Logic1: Start Date of First dose of specified Treatment label in SM form is not null OR Date of Assessment in SR is not null

AND

Logic2: for each specified condition on specified form in specified visit, there is no at least one record with "Date of Assessment" is not null and the gap between Date of Assessment and start date of first dose of SM OR Date of Assessment in SR is as below:

VS01; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

VS02; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

LECG; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

HLAB; Screening; -10 <= (Date of assessment - Date of first dose) <= 0 day

CLAB; Screening; -10 <= (Date of assessment - Date of first dose) <= 0 day

ULAB; Screening; -10 <= (Date of assessment - Date of first dose) <= 0 day

OLAB; Screening; -10 <= (Start Date of Collection - Date of first dose) <= 0 day

OLABA; Screening; -10 <= (Start Date of Collection - Date of first dose) <= 0 day

OLABB; Screening; -10 <= (Start Date of Collection - Date of first dose) <= 0 day

OLABC; Screening; -10 <= (Date of assessment - Date of first dose) <= 0 day

ECOG; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

DLCO; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

PFTL; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

PO; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

From; visit; Lower range; Upper range; SM;  Condition

OLAB; Screening; (Start Date of Collection - Date of first dose  for 0000) <-10, or > 0 day;SM1;  test 1

OLAB; Screening; (Start Date of Collection - Date of first dose  for 0000) <-20, or > 0 day;SM1;  test 2

OLAB; Screening; (Start Date of Collection - Date of first dose  for 0000) <-30, or > 0 day;SM1;  test 3

OLAB; Screening; (Start Date of Collection - Date of first dose  for 0000) <-15, or > 0 day;SM2;  test 1

OLAB; Cycle 1; (Start Date of Collection - Date of first dose  for 0000) <-25, or > 0 day;SM1;  test 1

If same group is used for multiple rows only output if all the conditions are NOT met. For example:

1; LECG; Screening; -28 <= (Date of assessment - Date of first dose) <= 0 day

1; LECG; Cycle 1; -28 <= (Date of assessment - Date of first dose) <= 0 day

Output should only be display if there is no Date of Assessment within the Specified range in LECG form in neither Screening or Cycle 1

Notes:

(1) for different study, first dose of SM is different:

*if there is SM01 form, use the dose in SM01 form as the first dose.

*Use 'Study Medication' directly in SM/SME form. While for SMAU/SMAB,  'Study medication' should be retrieved from SMPU/SMPB form by using 'Dose Number+ Visit Number' between SMAU/SMAB and SMPU/SMPB. It will not use Study Medication item from SMA directly.

(2) Time should be considered if Time is available.

(3) If Date contains UNK, output the records.

(4) Deleted records and Erroneous visit should be excluded.

(5) When specific form was not even initiated, it should be present in outputs.
