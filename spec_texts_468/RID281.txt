Report ID: RID281

Report Title:
Inconsistencies between MMR Result and Marker Level Interpretation

Description:
This report displays inconsistencies between MMR overall result and Marker Level Interpretation

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. Vendor

6. Visit Name

7. Collection Date/Time

8. Sequence number

9. Test short name

10. Test

11. Result or Findings in Original Units (ORRES)

12. Blinding Flag

13. Scenario

Logic:
LOGIC 1:

Logic 1.1:

GEFCF.Test Short Name = MLH1 AND GEFCF.Result or Finding in Original Units = LOSS

OR

GEFCF.Test Short Name = PMS2 AND GEFCF.Result or Finding in Original Units = LOSS

OR

GEFCF.Test Short Name = MSH2 AND GEFCF.Result or Finding in Original Units = LOSS

OR

GEFCF.Test Short Name = MSH6 AND GEFCF.Result or Finding in Original Units = LOSS

AND

Logic 1.2:

there is no (GEFCF.Test Short Name = MMRPINTP AND At least one GEFCF.Result or Finding in Original Units <> DEFICIENT)

LOGIC 2:

Logic 2.1:

GEFCF.Test Short Name = MLH1 AND GEFCF.Result or Finding in Original Units = INTACT

AND

GEFCF.Test Short Name = PMS2 AND GEFCF.Result or Finding in Original Units = INTACT

AND

GEFCF.Test Short Name = MSH2 AND GEFCF.Result or Finding in Original Units = INTACT

AND

GEFCF.Test Short Name = MSH6 AND GEFCF.Result or Finding in Original Units = INTACT

AND

Logic 2.2:

there is no (GEFCF.Test Short Name = MMRPINTP AND  at least one GEFCF.Result or Finding in Original Units <> PROFICIENT)

Note:

1. Report should not consider deleted records.

2. Report should not consider Erroneous visits.

2. If Blinding flag='B' for test, then the following fields should display 'xxxx': Result or Findings in Original Units (ORRES)

Report Scenarios:
Output will be displayed for below two scenarios:

1. Result is LOSS for one of the MMR tests and the Marker Level Interpretation is not DEFICIENT

2. Result is INTACT for all MMR tests and the Marker Level Interpretation is not PROFICIENT
