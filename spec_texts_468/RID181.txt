Report ID: RID181

Report Title:
Study Medication Entry Not Current-Missing records

Description:
This report displays subjects who are  missing a Study Medication records between Max SM entry and current DOV. The purpose of the report is to ensure that SM entry is current.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Current Visit

5. Current DOV

6. SM Form

7. SM Visit

8. SM Seq

9. Study Medication

10. Label Description/Dose Number

11. Study Period

12. Max SM Stop date

13. Gap between SM and DOV

Logic:
Logic 1: Current visit DOV.Date of Visit <> NULL

AND

Logic 2: SM_Form.Study Medication = Study Medication on supporting doc

AND

Logic 3: SM_Form.Study Period = Study Period on supporting doc

AND

Logic 4: Current visit DOV.Date of Visit - Maximum SM_Form.Stop Date/Time > Allowed Gap Days on supporting doc

Note:

1. SM_Form include SM/SMAU/SMAB/SM02

2. Please exclude deleted records and erroneous visits from programming.

3. Just consider date for Logic 5

4. Output is not produced if any SM_Form record for specified Study Medication and Study Period in each group with last dose checked (item "Please Indicate if this is the Last Dose for this Label Description" is checked)

5. If supporting doc is not provided, display the message as "SM012A_JR_STD Supporting Document Not Present for This Trial".

6a: IF SM Label Description and SMAU/SMAB/SM02 Dose Number are exactly matched within forms For SM/SMAU/SMAB/SM02 Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number/SM02.Dose Number directly.

6b: If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_<xxxxxxx>.csv to define the mapping.
