Report ID: RID188

Report Title:
Mismatch between Study Period-Scheduled Time and visit or duplicate Study Period for the same medication

Description:
This report will list subjects where Study Period/Scheduled Time/Start date/ Stop date in Study med does not match with the corresponding visit or there is a duplicate Study Period for the same medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. eCRF

6. Seq

7. Study Period & Scheduled Time

8. Expected Study Period

9. Expected Scheduled Time

10.  Study Medication

11. Error Message

Logic:
<Criteria Form1>.<Criteria Itemquestion1> = <Criteria Value1>  AND

<Criteria Form2>.<Criteria Itemquestion2> = <Criteria Value2> AND

<Criteria Form3>.<Criteria Itemquestion3> = <Criteria Value3> AND

This report lists SMAU/SMAB/SM/SM01/SM02/SM04/TACE records where Study Period does not match the corresponding visit per Study Medication and Criteria Value1/2/3 or when there is a duplicate study period for the same medication

Logic 1:

Scenario 1:

Study Period on SMAU/SMAB record <> expected Study Period as per supporting document per Visit, Study Medication and Criteria Value1/2/3

OR

Study Period on SM/SM01/SM04/TACE record is not present in the supporting document per Visit, Study Medication and Criteria Value1/2/3

Logic 2:

Study Period and Scheduled Time on Common log records - eg. SM/SM02, report should consider both Start Date and Stop Date of SM record.

Study Period on TACE form, report should consider Date of TACE of the record.

Scenario 2:

Start Date of Common log records or Date of TACE will be slotted in the immediately prior non-erroneous initialized visit that is present in the supporting document per Visit, Study Medication and Criteria Value1/2/3

AND

If (visit mnemonic (as slotted per Start Date)= sup.visitmnemonic and (sm/TACE.Study Period <> sup.study period OR SM/TACE.Scheduled time on <> sup.Scheduled time)), report should display output

Scenario 3:

Stop Date of Common log records will be slotted in the immediately prior non-erroneous initialized visit that is present in the supporting document per Visit, Study Medication and Criteria Value1/2/3

AND

If (visit mnemonic (as slotted per Stop Date)= sup.visitmnemonic and (sm/TACE.Study Period <> sup.study period OR SM/TACE.Scheduled time on <> sup.Scheduled time)), report should display output

If both scenario 2 and 3 are fulfilled, report should display only output for Scenario 2

Logic 3

Scenario 4

report should display output, when two seq of same Study Medication has the same Study Period of SMAU/SMAB/SM/SM01/SM02/SM04/TACE for the same visit.

Notes:

1.	Deleted records should not be considered.

2.	Records in erroneous visits should not be considered.

3.	Do not output for Logic 3 if there is an output for logic 1 and logic 2.

4.	Do not output for logic 3 if the parameter “Exclude scenario 4 (YES/NO)” is entered as YES

5.	Do not consider erroneous visits to calculate expected study period for logic 2

6.	Do not consider the scheduled time on the logic 2 if column 13 in the supporting document is entered as NA.

7.	If the parameter “Exclude Study Period blank (YES/NO)” is entered as YES, do not show output for SM.Study Period = NULL.  If the parameter “Exclude Study Period blank (YES/NO)” is entered as NO, show output for SM.Study Period = NULL.
