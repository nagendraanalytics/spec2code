Report ID: RID073

Report Title:
Missing Prior Concomitant Medication/Associated Persons Concomitant Medications Derivations

Description:
This report displays a listing of all Prior Concomitant Medication/Associated Persons Concomitant Medications terms where Encoded Drug Name is not null but at least one of following is null: Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term OR where Encoded Drug Name is null, but at least one of the following is not null: Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Seq

5. Medication Name

6. Encoded Drug name

7. Standardized Medication Name

8. Broader term

9. Medication Class Code

10. Medication Class Term

11. ATC1 Term

12. ATC2 Term

Logic:
The report should display output if

1) Encoded Drug Name is not null but at least one of following is null:  Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term or

2) Encoded Drug Name is null, but at least one of the following is not null:  Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term

Display row count in footer

Report should not display deleted records.

If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization number that is not null.

Report Scenarios:
A- Yes

Encoded Drug Name is not null but at least one of following is null:  Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term or Encoded Drug Name is null, but at least one of the following is not null:  Standardized Medication Name, Broader term, Medication Class Term, Medication Class Code, ATC1 Term or ATC2 Term

B- No

Deleted record
