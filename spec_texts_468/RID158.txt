Report ID: RID158

Report Title:
Reconciliation of PMS1/PMS1A/PMST entries with duplicate value in Trial Segment Reference

Description:
This report will display subjects with the same Trial Segment Reference on more than one PMS1, PMS1A, PMST entry.

Column Heading:
1. Country

2. Site

3. Subject Number

4. PMS1/PMS1A/PMST Visit mnemonic 1

5. PMS1/PMS1A/PMST Trial Segment Reference 1

6. PMS1/PMS1A/PMST Visit mnemonic 2

7. PMS1/PMS1A/PMST Trial Segment Reference 2

Logic:
LOGIC 1

Logic 1.1: PMS1/PMS1A/PMST.Date of Assessment <> NULL

AND

Logic 1.2: PMS1/PMS1A/PMST.Trial Segment Reference = Any previous PMS1/PMS1A/PMST.Trial Segment Reference (PMS1/PMS1A/PMST.Date of Assessment <>NULL)

Note 1: Please excluse subjects with SA.Treatment/Randomization Number=BLANK from programming

Note 2: If there is more than one duplicate display in separate rows

Report Scenarios:
Scenario A, Output =Yes

Output is produced if there is any previous PMS1/PMS1A/PMST with same Trial Segment Reference

Scenario B, Output = No

Output is not produced if there is no PMS1/PMS1A/PMST with the same Trial Segment Reference

Sorting:
Default

Parameter Selection:
Default

Form.Item Names:
1. SA. Country

2. SA.Site Mnemonic

3. SA. Subject Number

4. Visit mnemonic 1

5. PMS1/PMS1A/PMST.Trial Segment Reference 1

6. Visit mnemonic 2

7. PMS1/PMS1A/PMST.Trial Segment Reference 2
