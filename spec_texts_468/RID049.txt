Report ID: RID049

Report Title:
Missing Concomitant Medication

Description:
This report will list subjects who are receiving Study medication and are missing the required concomitant medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. SM Visit

5. Study Medication

6. SM Seq

7. SM Stop Date/Time

Logic:
Prior to processing the logic, apply condition(s) according to the supporting doc to check if subjects match the criterial or not.

Logic 1: "SM Form". Study Medication = "Study Medication"

AND

Logic 2: "SM Form". Stop Date is not null

AND

Logic 3: There is not at least one CM record with the following data:

Logic 3.1 CM. “Medication Itemquestion” = “Medication Name” (in “Medication Name” in the same “Medication Group”)

AND

Logic 3.2 CM. Medication Category = [Prophylaxis OR Adverse Event OR Steroid Taper]

AND

Logic 3.3 CM. Imputed Start Date and Time is between “SM Form”. Stop Date/Time PLUS “Window of days” for each Study Period present for “SM Form”. Study Medication = “Study Medication”

Example:

“Window of Days” = 10

“SM Form” record #1 Stop Date = 01-Jan-2024, “SM Form”. Study Medication = -2140, AND “SM Form”. Study Period = Cycle 1 Day 1

“SM Form” record #2 Stop Date = 22-Jan-2024, “SM Form”. Study Medication = -2140, AND “SM Form”. Study Period = Cycle 2 Day 1

“SM Form” record #3 Stop Date = 14-Feb-2024, “SM Form”. Study Medication = -2140, AND “SM Form”. Study Period = Cycle 3 Day 1

“SM Form” record #4 Stop Date = 08-Mar-2024, “SM Form”. Study Medication = -2140, AND “SM Form”. Study Period = Cycle 4 Day 1

CM record #1 Imputed Start Date = 10-Jan-2024, CM. “Medication Itemquestion” = Medication Class, “Medication Name” = "Colony Stimulating Factors" AND CM. Medication Category = Prophylaxis OR Adverse Event OR Steroid Taper

CM record #1 Imputed Start Date = 13-Feb-2024, CM. “Medication Itemquestion” = Medication Class, “Medication Name” = "Colony Stimulating Factors" AND CM. Medication Category = Prophylaxis OR Adverse Event OR Steroid Taper

THEN

Two outputs should appear for missing CM record one between Cycle 2 Day 1 and Cycle 3 Day 1 Study Periods and another between Cycle 3 Day 1 and Cycle 4 Day 1 Study Periods

Notes:

1. Please exclude deleted record and erroneous visit from programming.

2. "SM Form", "Study Medication", "Medication Itemquestion", "Medication Name", "Medication Group", "Window of Days" are from supporting document.

3. "Date Only" is from supporting document, if set as 'Yes' then will only consider date when comparing date, if set as 'No', then will consider both date and time.

4. Time UNK will consider UNK/UNK=23:59

5. Please do not consider “Medication Name” case-sensitive.

6. When displaying SM. Stop Date in the table, please consider the earliest date from SM comparison.

7. For each individual Logic 3.3 check please consider:

If SM Stop Date #2- SM Stop Date #1< Window of Days, then Window of Days = SM Stop Date #2 - SM Stop Date #1, then check

SM # 1 Stop Date< CM Imputed Start Date < SM # 1 Stop Date+ Window of Days

8. Do not consider UNK dates if present on any case.

Requires supporting document to be named CM021_supp_<xxxxxxx>.csv and will contain the following columns and associated content.

Definition of Criteria: value specified in Criteria Value column entered in item specified in Criteria Itemquestion column on form specified in Criteria Form column.

For NA in all three mentioned columns please ignore Criteria condition and display output for all subjects.

1)Criteria Form - Optional, enter 'NA' if logic is checked for all subjects

2)Criteria Itemquestion - Optional, enter 'NA' if logic is checked for all subjects

3)Criteria Value - Optional, enter 'NA' if logic is checked for all subjects

4)SM Form - Required

5)Study Medication – Required, Medication related to the prophylaxis requirement

6)Medication Itemquestion - Required, enter Standardized Medication Name/Medication Class Code/Medication Class

7)Medication Name - Required, enter corresponding value of Medication Itemquestion

8)Medication Group - Required, if more than one Medication is acceptable, please put them in the same group. [IMPORTANT] Please associate only ONE grouping number per each Criteria Form, Criteria Itemquestion, and Criteria Value combination.

9)Date Only - Required, enter Yes/No, if speified as 'Yes' then will only consider date when comparing date, if specified as 'No', then will consider both date and time

10)Window of Days – Required (defined as maximum window between SM Stop Date to missing CM Start Date)
