Report ID: RID035

Report Title:
Unique Lot Trace IDs

Description:
This report will display unique Lot Trace IDs from GCS and Inform in separate tables.

Column Heading:
Table 1:

Lot Trace ID from GCS

Table 2:

Lot Trace ID from InForm

eCRF Name

Logic:
This report will display unique Lot Trace IDs from GCS and Inform (SMPB/DISP) in two separate tables. The first table will list Lot Trace ID from GCS, the second table will list Lot Trace ID from selected eCRF (SMPB OR DISP) in InForm.

Report will be sorted by Lot Trace ID.

Sorting:
Table 1: Lot Trace ID

Table 2: Lot Trace ID

Parameter Selection:
Country, Site, Subject Number, Randomized Only, Blinded eCRF Name(s): (Selection list with SMPB and DISP, default as 'SMPB')

Form.Item Names:
Table 1:

1. GCS File.Lot_ID_FnshdGood

Table 2:

1. SMPB.Lot Trace ID/SMPB.LOT ID/DISP.Lot Number

2. SMPB. Form mnemonic/DISP. Form mnemonic
