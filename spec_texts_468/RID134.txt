Report ID: RID134

Report Title:
Duplicate reconciliation between interchangeable Labs

Description:
The report displays subjects who have duplicate lab tests with the same date of assessment.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit 1

5. LL Collection Date 1

6. Form 1

7. Seq 1

8. Test 1

9. Result 1

10. Unit 1

11. Visit 2

12. LL Collection Date 2

13. Form 2

14. Seq 2

15. Test 2

16. Result 2

17. Unit 2

Logic:
For the tests within the same group entered in the supporting document:

Logic 1

[Form1] AND [Form2] have the same date of assessment AND

[Form1].[Test1].result1 AND [Form1].[Test1].units1  =

[Form2].[Test2].result AND [Form2].[Test2].units2

Notes:

1. For logic 1 the comparison should be made within forms entered with the same date of assessment.

2. For logic 1 please look for Labs with the same date of assessment, disregarding the visit mnemonic.

3. For logic 1 compare all the [Forms].[Test] within the same group number according to the supporting document.

4. Do not consider deleted records.

5. Do not consider visits with DOV marked as erroneous.

6. Output one row for each duplicate test.

7. Duplicated results for outputs from different groups should not be outputted.

8. If the Date is Null for all Test, then duplicate result should be checked based on just group.

e.g.: 2 different tests of same group have the same result AND units, AND both has date null = output.

9. If date is Null for one test AND present forthe other test, AND they have the same result AND units, Date should be considered different, then NO output is expected.

Requires supporting document to be named “LLNR012_supp_<xxxxxxx>.csv”. It will contain the following columns and associated content:

1. Group - numbers that identify the different groups of tests. If different tests are considered duplicates, then the same number should be used.

2. Form - Local lab eCRFs

3. Test - Test on the Local lab eCRFs. Please enter the two interchangeable tests according to the protocol (each test in a different row).

Eg.

Group,Form,Test

1,CLAB,Bicarbonate

1,OLAB,Carbon Dioxide

2,CLAB,Blood Urea Nitrogen

2,CLAB,Urea

3,OLAB,Reticulocytes

3,OLAB,Reticulocytes/Erytrocytes

Note: if more than two tests are interchangeable per protocol, please enter all possible combinations in different groups:

E.g.: Interchangeable tests: Free T3, Amylase and Free Thyroxine.

Group,Form,Test

1,OLAB,Free T3

1,CLAB,Amylase

2,OLAB,Free Thyroxine

2,OLAB,Free T3

3,CLAB,Amylase

3,OLAB,Free Thyroxine

Report Scenarios:
Scenario 1 (only scenario) – Yes:

Two of the tests within the same group are entered with the same date of assessment AND with the same result and units

Scenario 1 (only scenario) – Yes:

Two of the tests within the same group are entered with the same result and units and the date of assessment are “Null”

Scenario 1 (only scenario) – No:

Only one of the tests within the same group is entered for the date of assessment with the same result and units and the other one is missing

Scenario 1 (only scenario) - No:

Two tests within the same group are entered with the same date of assessment but the result OR units are different.

Scenario 1 (only scenario) - No:

Two of the tests within the same group are entered with the same result and units but at least one of the test’s date of assessment is blank

Sorting:
Defaulted to Country, Site, Subject Number

Parameter Selection:
Defaulted to Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N set default to N)

Form.Item Names:
1. Subject Assessment.Country

2. Subject Assessment.Site Mnemonic

3. Subject Assessment.Subject Number

4. Display the form visit mnemonic according to Logic 1, for duplicate Test1.

5. FormN.Date specimen collected, for duplicate Test1. If Date specimen collected is blank show “Null”.

6. Display the form included in the supporting document, for duplicate Test1, within the same group that meet the Logic 1.

7. Form.seq ID, for duplicate Test1

8. Test.ID included in the supporting document, for duplicate Test1, within the same group that meet the Logic 1.

9. Form1.Test1.result1, for duplicate Test1

10. Form1.Test1.result1.units1, for duplicate Test1

11. Display the form visit mnemonic according to Logic 1, for duplicate Test2.

12. FormN.Date specimen collected, for duplicate Test2. If Date specimen collected is blank show “Null”.

13. Display the form included in the supporting document, for duplicate Test2, within the same group that meet the Logic 1.

14. Form.seq ID, for duplicate Test2

15. Test.ID included in the supporting document, for duplicate Test2, within the same group that meet the Logic 1.

16. Form2.Test2.result2, for duplicate Test2

17. Form2.Test2.result2.units2, for duplicate Test2
