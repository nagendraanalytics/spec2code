Report ID: RID190

Report Title:
SM records with inappropriate dose amount

Description:
This report lists SM records with dose amount different than assigned per arm/cohort

Column Heading:
1. Country

2. Site

3. Subject Number

4. SM Form

5. SM Seq

6. Study Medication

7. Dose Amount

8. Dose Unit

9. Reason for Dose Variation

10. Expected Dose Amount

11. Expected Dose Unit

Logic:
Output is produced when subject meets Criteria specified in supporting document for specified study medication in SM/SM02, while Dose Amount is not equal to the expected Dose Number and expected Dose Unit.

Note:

   1. Report requires supporting document, if it is not provided, display the message as "SM023_JR_STD Supporting Document Not Present for This Trial".

   2. Please exclude deleted records from programming.

   3. Please exclude the output when Dose Amount is not entered.

Requires supporting document to be named SM023_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each group of SM/SM02 Study Medication records based on Criteria, SM Form, Study Medication and Expected Dose Amount that are required per protocol.

If two or more dose amount are allowed for each Study Medication, i.e. SM1 allows dose amount 100 mg and 200 mg, specify them in seperate lines.

Definition of Criteria: value specified in 4th column entered in item specified in 3rd column on form specified in 2nd column. For NA in all three mentioned columns please ignore Criteria condition and display output for all subjects.

1) Criteria Form - SR/TIRG

2) Criteria Itemquestion - Arm/Cohort and so on

3) Criteria Value - Value of Criteria

4) SM Form - SM/SM02

5) Study Medication

6) Expected Dose Amount

7) Expected Dose Unit

Criteria Form,Criteria Itemquestion,Criteria Value,SM Form,Study Medication,Expected Dose Amount,Expected Dose Unit

SR,Arm,Arm 1,SM,SM1,100,mg

SR,Arm,Arm 1,SM,SM1,200,mg

SR,Arm,Arm 2,SM,SM2,300,mg

SR,Cohort,Cohort 1,SM,SM3,400,ml

TRIG,'Based on the criteria specified above, select the appropriate response for this subject',SM,SM4,500,ml

NA,NA,NA,SM02,SM5,600,mg

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

Report Scenarios:
Scenario 1: Output = Yes

When subject is in the Specified condition group, [Study Medication] Dose Amount <> Expected Dose Amount [Expected Dose Unit]

Scenario 2: Output = No

When subject is in the Specified condition group, [Study Medication] Dose Amount = Expected Dose Amount [Expected Dose Unit]
