Report ID: RID147

Report Title:
Reconciliation for Protocol amendment Number

Description:
This report will display incorrect or duplicate Protocol amendment Number.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Sponsor ID

6. Protocol Amendment Number

7.  Site Protocol Amendment Approval Date

8. Scenario

Logic:
Scenario 1: Check within one site

Logic 1A, Output is produced for Protocol Amendment Number provided less than previous amendment number with earlier Site Protocol Amendment Approval Date

Logic 1B, Output is produced for same Protocol Amendment Number with different Site Protocol Amendment Approval Date

Logic 1C, Output is produced for different Protocol Amendment Number with same Site Protocol Amendment Approval Date

Scenario 2: Check within one subject

Logic 2, Protocol Amendment Number is duplicate between PAMI records within same subject

Note:

Report should not consider deleted records.

Site Protocol Amendment Approval Date will be used to sort the PAMI records in one site in ascending order for logic 1A

Report Scenarios:
Scenario 1:

Scenario 1A-

Output Yes

Output is produced for PAMI record with smaller numbers but later dates than other one in same site

Output No

Output is not produced for PAMI record with larger numbers and later dates than other one in same site

Scenario 1B-

Output Yes

Output is produced for same Protocol Amendment Number with different Site Protocol Amendment Approval Date in one site

Output No

Output is produced for same Protocol Amendment Number with same Site Protocol Amendment Approval Date in one site

Scenario 1C-

Output Yes

Output is produced for different Protocol Amendment Number with same Site Protocol Amendment Approval Date in one site

Output No

Output is produced for same Protocol Amendment Number with same Site Protocol Amendment Approval Date in one site

Scenario 2:

Output Yes

Protocol Amendment Number is duplicate between records within same subject

Output No

Protocol Amendment Number is different between records within same subject

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, Site, Subject Number

Form.Item Names:
1.	SA. Site Country

2.	SA. Site Mnemonic

3.	SA. Subject Number

4.	PAMI. Form Mnemonic

5.	PAMI. Sponsor ID

6.	PAMI. Protocol Amendment Number

7.	PAMI. Site Protocol Amendment Approval Date

8.             Display 'Scenario 1A' if Logic 1A is met, 'Scenario 1B' if Logic 1B is met, 'Scenario 1C' if Logic 1C is met, 'Scenario 2' if Logic 2 is met
