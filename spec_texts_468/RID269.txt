Report ID: RID269

Report Title:
Mismatch of Body Site Location between STR and SME for Radiation.

Description:
This report will output subjects with mismatching Body Site Location between STR and SME for Radiation.

Column Heading:
1. Country

2. Site

3. Subject Number

4. STR Visit

5. STR Sequence

6. STR Start Date/Time

7. STR Body Site Location

8. SME Sequence

9. SME Start Date/Time

10. SME Stop Date/Time

11. SME Body Site Location

12. Scenario

Logic:
Scenario 1

(

Logic 1.1: SME. Start Date/Time < =STR. Start Date/Time <=SME. Stop Date/Time

AND

Logic 1.2: SME.Please Indicate if this is the First Dose for this Label Description <> NULL for ANY record AND SME.Please Indicate if this is the Last Dose for this Label Description <> NULL for ANY record

AND

Logic 1.3: The location entered in STR. Body Site Location of Administration 1 to 10 or Body Site Location of Administration Other is not present in SME. Body Site Location of Administration.

)

OR

Scenario 2

(

Logic 2.1: Any location entered in SME. Body Site Location of Administration is not present in STR. Body Site Location of Administration 1 to 10.

)

Note 1: Erroneous visits and deleted records are excluded from programming.

Note 2: Please check logic 1.2 only, if ‘First/Last dose selected’ parameter is checked as Y. If ‘First/Last dose selected’ parameter is checked as N, ignore logic 1.2

Note 3: Please check logic 1.3 between all SME records that meet STR. Start Date/Time = SME. Start Date/Time. For example, if STR. Body Site Location of Administration 1 and STR. Body Site Location of Administration 2 are completed, then there should be two SME records with STR. Start Date/Time = SME. Start Date/Time AND each one with a matching Body Site Location of Administration.

Note 4: For logic scenario 1 output all locations entered in STR. Body Site Location of Administration 1 to 10 or Body Site Location of Administration Other that are not present in the corresponding SME. Body Site Location of Administration. Check among all SME records that meet the date condition.

Note 5:  For Logic 2.1, SME. Body Site Location can be present in any of the STR. Body Site Location of Administration 1 to 10 at least once.

Note 6: For scenario 1, display columns 8, 9, 10, 11 blank. For scenario 2 display columns 4, 5, 6, 7 blank

Note 7: for Body Site Location of Administration Other, the text entered should match exactly with SME Location, match is not case sensitive

Note 8: Disregard time for comparison.
