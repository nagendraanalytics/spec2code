Report ID: RID306

Report Title:
Baseline locations in Lesion Evaluation Form missing in applicable Current disease detail form or viceversa

Description:
This report will list subjects where baseline evaluation location entered in the Lesion Evaluation Form is not matching any of the locations in applicable Current disease detail form or vice versa.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Current Disease Details Visit

5. Current Disease Details Form

6. Current Disease Details Location

7. Lesion Evaluation Form

8. Lesion Number

9. Date of Baseline Evaluation

10. Location

11. Error message

Logic:
Report should output subjects who meet the following criteria:

Logic 1.1: “Location” from “ITEMQUESTION” column on LSN_supp_doc.csv <> blank on Lesion Evaluation form with Date of Assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) prior or equal to min [SM, SMAU, SMAB, SM01] start date (ignore time)

AND

 Logic 1.2: There is not a Location of metastases OR Location/Tumor Location on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] form = Location (in logic 1.1).]

OR

Logic 2.1: [Location of metastases OR Location/Tumor Location on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] <> Blank

AND

Logic 2.2: There is not a “Location” on Lesion Evaluation form with Date of Assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) prior or equal to min [SM, SMAU, SMAB, SM01] start date (ignore time) = Location of metastases OR Location/Tumor Location (in logic 2.1).

Note 1: The item "Location" should be used from master LSN_supp_doc.csv

Note 2: For logics 1.2 and 2.1 both Location 1-10 and Location of Metastases 1-10 need to be checked. For CDDB form, Primary tumor location needs to be checked against "breast" location in Lesion evaluation form. For CDDG, CDDGY form, Primary Location 1-10 and Location of Metastases 1-10 need to be checked. for CDDH Location and Location 1-10 need to be checked

Note 3: Erroneous visits and deleted records should not be considered in the programming and output.

Note 4: For logic 1, if there are multiple Lesion evaluation form record meeting the criteria, please check them all.

Note 5: For locations entered in the field "Other" at Lesion evaluation form, verify if the field "Other Location" (if present) OR ["Other Location of Metastases"/”Tumor Location Other” for [CDDB, CDDHN, CCDO, CCDU, CDDM, CODD, ODD] OR ["Location of Metastases Other" for CDDG, CDDGY] OR ["Other Tumor Lesion Location" for DDRCC] OR ["Other Primary Location" for CDDH] OR ["Primary Location Other" for CDDGY] contains the location entered at "Other" Lesion evaluation form. No case sensitive for this comparison.

Note 6: For logics 1 and 2, output should be present when both forms (Lesion evaluation form and [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] are initialized).

Note 7: If for Logic 1.2 there is no Lesion evaluation form record that matches [CDDB, CDDHN, CCDO, CCDU, CDDM, CODD, DDRCC, ODD, CDDGY, CDDH] by location, please display Lesion evaluation form columns blank. If for Logic 2.2 there is no [CDDB, CDDHN, CCDO, CCDU, CDDM, CODD, DDRCC, ODD, CDDGY, CDDH] record that matches Lesion evaluation form by location, please diplay [CDDB, CDDHN, CCDO, CCDU, CDDM, CODD, DDRCC, ODD, CDDGY, CDDH] columns blank.

Note 8: Location selected in the "Location which corresponds to primary diagnosis" prompt, should be excluded from the reconciliation.

Report Scenarios:
A-Yes Location/Lesion Location <> blank on Lesion Evaluation form with Date of Assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) prior or equal to min [SM, SMAU, SMAB] start date (ignore time) and there is not a Location OR Location of metastases/Tumor Location on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] form = Location (in logic 1.1).

B-No Location/Lesion Location <> blank on Lesion Evaluation form with Date of Assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) after min [SM, SMAU, SMAB, SM01] start date (ignore time)

C-No Location/Lesion Location <> blank on Lesion Evaluation form with Date of Assessment / Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) is prior or equal to min [SM, SMAU, SMAB, SM01] start date (ignore time) and there is a Location OR Location of metastases/Tumor Location on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] form = Location (in logic 1.1).

 D-No Location/Lesion Location = blank on Lesion Evaluation form with Date of Assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) is prior or equal to min [SM, SMAU, SMAB, SM01] start date (ignore time) or Lesion Evaluation form is not initialized

E-Yes Location OR Location of metastases/Tumor Location on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] <> Blank and there is not a Location/Lesion Location on Lesion Evaluation form with Date of Assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) prior or equal to min [SM, SMAU, SMAB] start date (ignore time) = Location OR Location of metastases/Tumor Location (in logic 2.1).

F-No Location OR Location of metastases/Tumor Location on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] <> Blank and there is a Location/Lesion Location on Lesion Evaluation form with Date of Assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) prior or equal to min [SM, SMAU, SMAB] start date (ignore time) = Location OR Location of metastases/Tumor Location (in logic 2.1).

G-No [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] forms are not initialized

H-No Location OR Location of metastases/Tumor Location on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH] <> Blank and there is not a Location on LSRIR/LSNEV form = Location OR Location of metastases/Tumor Location and Date of assessment/ Date of Initial Lesion Identification for This Trial (Scan/Image/Physical Exam) in Lesion Evaluation is after min [SM, SMAU, SMAB, SM01] start date (ignore time)

I-No Erroneous visit or deleted record

J-No Location "Other" on Lesion Evaluation form matches "Other Location" (if present) OR Location of metastases "Other"/Tumor Location “Other” on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH]

K-No Location "Other" on Lesion Evaluation form is contained in "Other Location" (if present) OR Location of metastases "Other"/Tumor Location “Other” on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH]

L-Yes Location "Other" on Lesion Evaluation form is neither contained nor matches any "Other Location" (if present) OR Location of metastases "Other"/Tumor Location “Other” on [CDDB, CDDG, CDDHN, CDDO, CODD, CDDM, CDDU, DDRCC, ODD, CDDGY, CDDH]

Sorting:
