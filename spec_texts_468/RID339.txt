Report ID: RID339

Report Title:
Multiple entries in Add Entry section reconciliation

Description:
This report will list subjects with more than one entry in Add Entry section at NATS eCRF

Column Heading:
1. Country

2. Site

3. Subject

4. Visit

5. Sequence Number

6. Date of Assessment

Logic:
There is more than one Associated Sponsor ID within the add entry section of the same Sponsor ID Number

Note 1: Deleted record will not be considered in the programming or output.

Report Scenarios:
A – Yes:

If Sponsor ID Number<> null AND there is more than one Associated Sponsor ID Number within the Add Entry section of this Sponsor ID Number.

B – No:

If Sponsor ID Number<> null AND there is only one Associated Sponsor ID Number within the Add Entry section of this Sponsor ID Number.

Sorting:
Country, Site, Subject Number, Visit Mnemonic, Sequence Number

Form.Item Names:
1. SA.Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. NATS.Visit Mnemonic

5. NATS.Sponsor ID Number

6. NATS.Date of Assessment
