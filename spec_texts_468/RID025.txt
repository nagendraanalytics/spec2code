Report ID: RID025

Report Title:
AE Action Taken with Study Medication reconciliation report

Description:
Adverse events that have "Action taken with Study Medication" selected as Reduced, Interrupted, Discontinued, Increased, Not Applicable, Unknown which is not allowed per protocol for Study Medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq#

5. AE Term

6. Study Medication

7. AE Action(s) taken

Logic:
Report output the subjects who meet the criteria:

AE action taken with Study Medication [x] is selects as parameter user defines: Reduced, Interrupted, Discontinued, Increased, Not Applicable, Unknown

User can specify Study medication [x] in parameter. When SM is selected, only the AE action taken matching selected SM need output.

If no Study medication [x] is selected, check all AE action taken items in AE form.

If Study medication [x] is selected, AE action taken items were not selected, check all AE action taken for selected Study medication [x].

Report Scenarios:
Refer to Test Case Workbook

Scenario A - Yes

Any user defined "Action taken with the Study Medication (user specify in parameter)" is selected: Reduced, Interrupted, Discontinued, Increased, Not Applicable, Unknown.

Scenario B - No

Any user defined "Action taken with the Study Medication (user specify in parameter)" is NOT selected: Reduced, Interrupted, Discontinued, Increased, Not Applicable, Unknown.

Scenario C -No

Deleted Records

Sorting:
Country, Site, Subject Number, AE seq#

Parameter Selection:
Randomized Only, Country, Site, Subject Number, List of Subject, Study Medication, AE Action(s) taken

Form.Item Names:

3. Subject Assignment.Subject Number

5. Adverse Events Form.AE Term

6. Derived from the Adverse action taken with Study Medication [x] in AE form.
