Report ID: RID034

Report Title:
Associated Patient Procedure Adverse Event Reconciliation

Description:
This report lists subjects who have APPRC with Procedure Start Date before APAE Onset Date which is associated by AE Sequence Number in APPRC form.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. APPRC Sequence Number

6. APPRC date

7. APAE date

8. Associated APAE Sponsor ID

Logic:
Procedure Start Date on APPRC is before Onset Date on APAE which is associated by AE Sequence Number in APPRC form

Note: Exclude deleted rows and erroneous visits

If any part of Start Date on APPRC or Onset Date and Time (Lab Collection Date if Lab Adverse Events) on APAE is UNK display in output

Report Scenarios:
Yes: Display output that satisfy the logic

No: Do not display output that do not satisfy the logic

Form.Item Names:
1. SA.Site Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. APPRC.Visit Mnemonic

5. APPRC. FORMIDX

6. APPRC.Procedure Start Date

7. APAE. Onset Date and Time Lab Collection Date if LAb Adverse Events

8. APAE. Sponsor ID
