Report ID: RID018

Report Title:
AE Action vs Dose Variation

Description:
This report reconciles Dose Variation and Study Medication Status vs Action Taken of Increased, Discontinued, Reduced, or Interrupted within a window of days.

Column Heading:
For Scenario 1:

1. Country

2. Site

3. Subject Number

4. SM Visit

5. SM eCRF

6. SM Seq

7. Study Medication

8. Label Description/Dose Number

9.Start Date/Time

10. Reason for Dose Variation

11. Expected AE duration

17. Scenario

For Scenario 2, 2a, 2b, 3:

1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Term

6. AE Onset Date

7. AE End Date

8. Study Medication

9. AE Action Taken with Study Medication

10. AE Relationship to Study Medication

11. Expected SM Start Date

12.Date on PMS1/PMST

13. Status of Study Medication/ Subject from PMS1/PMST

14.Scenario

Logic:
Scenario 1:

Logic1: SM forms. Reason for Dose Variation = < SM Reason for Dose Variation> as per supporting document

AND

Logic2: There is no AE with action taken of < AE action taken with Study Medication > as per supporting document within [X] days (inclusive) before the SM Start Date

If include AE Relationship to Study Medication?=No, then output by Scenario 2:

Scenario 2:

Logic1: AE action taken = < AE action taken with Study Medication > as per supporting document AND

Logic2: There is no SM record with Reason for dose variation = < SM Reason for Dose Variation> as per supporting document from AE Start Date to AE end date (inclusive) or [X] days after AE end date, if available.

If include AE Relationship to Study Medication? = Yes, then output by Scenario 2a and 2b:

Scenario 2a:

Logic1: AE action taken = < AE action taken with Study Medication > as per supporting document   AND

Logic2: AE Relationship to Study Medication = Related AND

Logic3: There is no SM record with Reason for dose variation = Toxicity from AE Start Date to AE end date (inclusive) or [X] days after AE end date, if available.

Scenario 2b:

Logic1: AE action taken = < AE action taken with Study Medication > as per supporting document AND

Logic2: AE Relationship to Study Medication = Not Related AND

Logic3: There is no SM record with Reason for dose variation = Adverse Event from AE Start Date to AE end date (inclusive) or [X] days after AE end date, if available.

Scenario 3

Logic1: AE action taken = Discontinued AND

Logic2: There is no SM/SMAU/SMAB record with Study Medication Status or Label Description Status = <SM Study Medication/Label Description Status > as per supporting document and Stop Date and Time before the AE end date (inclusive)

Requires supporting document to be named AE027_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1 row for each Study Medication name, SM Reason for Dose Variation, SM Study Medication/Label Description Status, AE action taken of Study Medication or AE action taken of Study Medication present in AE/SM/SMAU/SMAB eCRFs.

1.Scenario:  enter 1 for scenario 1; 2 for scenario 2; 3 is for scenario 3.

If item SM Study Medication/Label Description Status is not available for the study, only provide scenarios 1 and 2.

2. Study Medication name: specify as ‘All’ if different Study Medications have the same window of days. Complete as 'NA' for scenario 3.

3. Window of Days:  specify window of days for each of the Study Medications for scenarios 1 and 2. Complete with ‘NA’ for scenario 3.

4.SM Reason for Dose Variation:  specified as ‘All’ if all SM Reasons for Dose Variation need to be checked for scenarios 1 or 2. Complete as ‘NA’ for scenario 3.

5.AE action taken with Study Medication:  specified as ‘All’ if all AE Action Taken with Study Medication need to be checked for scenarios 1 or 2.  Complete as ‘NA’ for scenario 3.

6.Include AE Relationship to Study Medication:  complete as ‘NA’ for scenarios 1 and 3; specify as ‘Yes’ or ‘No’ for scenario 2.

7.SM Study Medication/Label Description Status: complete as ‘NA’ for scenarios 1 and 2; specify for scenario 3.

e.g.:

Scenario, Study Medication name, Window of days, SM Reason for Dose Variation, AE action taken of Study Medication, Include AE Relationship to Study Medication? SM Study Medication/Label Description Status

1, ALL, 3, ALL, ALL, NA, NA

2, Cisplatin, 5, ALL, Increased, No, NA

2, Cisplatin, 5, ALL, Reduced, No, NA

2, 3475/Placebo, 3, Increased, No, NA, NA

3, NA, NA, NA, NA, Adverse Event

3, NA, NA, NA, NA, Clinical progression

3, NA, NA, NA, NA, Progressive disease

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Yes in the parameter "Supporting doc Page".

Note

1. Display the output from Scenario 1 in Table 1; display output from Scenarios 2,2a,2b and 3 in Table 2.

2. For studies with multiple study medications, match AE action taken with Study Medication [x] and Relationship to Study Medication [x] with Study Medication [x] on SM/SMAU/SMAB.

For studies with single study medication, Overall Action Taken and/or Overall Relationship to Study Medication is checked and a match on Study Medication name is not performed.

3. If pulldown lists Study Medication 1, Study Medication 2 etc. are available in the AE form, match the Action taken with Study Medication [x] and Relationship to Study Medication [x] with pulldown list value provided in Study Medication [x] and with Study Medication [x] on SM/SMAU/SMAB.

4. Consider date field only in this report.

5. Exclude deleted data and erroneous visit from programming.

6. For scenario 1 logic2, if any day on the AE duration is within the window days prior to the SM start date, output will not appear. E.g, AE duration (Oct 21 ~ Dec 16), SM duration (Nov 24 ~ Nov 30), window is 5 days. then expected AE should be between Nov19 and Nov25, and there are AE dates in this period so there will not be output.

7. For SM/SMAU/SMAB Study Medication, use SM.Label Description/SMAU.Dose Number/SMAB.Dose Number directly. If SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication, using the optional supporting doc study_med_match_supp_.csv to define the mapping.

The optional supporting document is only required in the following cases:

- SM Label Description and SMAU/SMAB Dose Number are not exactly matched with Study Medication. This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

Optional supporting document should be named as study_med_match_supp_.csv and will contain the following columns and associated content:

1 row for each Label Description or Dose Number present in SM/SMAU/SMAB eCRFs.

1. eCRF – SM/SMAU/SMAB

2. Study Medication – Value of Study Medication

3. Matching Item – SM Label Description or SMAU/SMAB Dose Number

4. Matching Value – Value of SM Label Description or SMAU/SMAB Dose Number eCRF,Study Medication,Matching Item,Matching Value

SM,-1439,Label Description,-1439 100 mg

SM,Methadone,Label Description,Methadone Tablet 5 mg

SM,Methadone,Label Description,Methadone Tablet 10 mg

SMAB,3475/Placebo,Dose Number,3475/Placebo

SMAU,Carboplatin,Dose Number,Carboplatin

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 1

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 2

SMAU,Carboplatin,Dose Number,Carboplatin - Dose 3

The actual information provided by the optional supporting doc can be outputted by selecting Y in the parameter "Study Med Match Page".

8. For Scenario 3, if there is no Study Medication Status item in SM forms, use Label Description Status. If both Study Medication Status and Label Description Status are not available, exclude Scenario 3 from the final output.

-AE start date and end date (with allowed window) are prior SM start date .

-AE start date if after SM start date

Output is not produced if:

-AE start date is prior SM start date and AE is ongoing

-AE start date is prior SM start date and AE end date is after SM start date.
