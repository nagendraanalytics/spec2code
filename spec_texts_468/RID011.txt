Report ID: RID011

Report Title:
Lab AEs with no matching lab results

Description:
This report displays subjects who have lab AEs with no corresponding lab tests done on the date of the AE.

Please note that a list of lab AEs and corresponding lab tests is provided per study.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Term

6. AE Onset Date

Logic:
Report should display subjects with lab AEs that have no corresponding lab tests with results performed on either Onset date OR End Date (only when date is entered using the pick list) of the AE. The report should limit the check of lab AE terms and corresponding lab test names to the ones listed in the supporting document provided by the requestor. When the same associated AE may be triggered by different lab tests or lab tests on different eCRFs, if one lab test is present for the AE, the reconciliation is satisfied and no output is expected. Lab Category should be the same. Report should not display deleted records.

Data in erroneous visits should not be considered. AE PT should be used for the comparison.

If "Randomized only" parameter selection checkbox is checked, the report should only output subjects with Randomization number that is not null.

Note: CLAB, HLAB, OLAB, ULAB, SLAB and CLB01,HLB01,OLB01,UA,CLBL,HLBL,ULBL, OLBL are considered as local lab forms

Report Scenarios:
Possible scenarios (not exhaustive).

For further scenarios, refer to the Test Case Workbook.

1) Two AE records on the same date for the same Lab Test, but one missing Lab Test: the two AE records will be outputted because there is no way to know which AE has the missing Lab Test record.

e.g.

AE data:

AE1 - 10Nov

AE2 - 10Nov

Lab data:

Lab Test1 - 10Nov

Supporting data:

eCRF1-Lab Category1-Lab Tests-eCRF2-Lab Category2-Lab test SLAB- AEPT1-AEPT2-..AEPTn

2) One AE record that may be triggered by different Lab Tests of the same Category, and one Lab Test record: no output to be produced.

e.g.

AE data:

AE1 - 10Nov

Lab data:

Lab Test1 - 10Nov

Supporting data:

eCRF1-Lab Category1-Lab Tests-eCRF2-Lab Category2-Lab test SLAB- AEPT1-AEPT2-..AEPTn

3) Lab test 1 and lab test 2 has same AE1, but lab data only has lab test 2,  so there is no test support AE2, AE2 should be outputted.

AE data:

AE2 - 15 Feb 2019

Lab data:

Lab Test2 – 15 Feb 2019

Supporting data:

eCRF1-Lab Category1-Lab Tests-eCRF2-Lab Category2-Lab test SLAB- AEPT1-AEPT2-..AEPTn
