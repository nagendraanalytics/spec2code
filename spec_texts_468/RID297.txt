Report ID: RID297

Report Title:
Missing record in LOEL form for B-cell NHL patients

Description:
This report will list subjects who have missing record at baseline in LOEL form for B-cell NHL patients

Column Heading:
1. Country

2. Site

3. Subject number

4. C1D1 Date of Visit

5. CDD form

6. Primary Diagnosis

7. Scenario

Logic:
Scenario 1: Output if CDD.Primary Diagnosis <> NULL and C1D1 Date of Visit <> NULL and there is no  LOEL.lesion Identification = “Target Nodal” or “Target Extra Nodal” AND LOEL.Date of Initial Lesion Identification for This Trial (Scan Image Physical Exam) within 28 days prior to C1D1 Date of Visit.

Scenario 2: Output if CDD.Primary Diagnosis <> NULL and C1D1 Date of Visit <> NULL and there is no LOEL. Lesion Identification= Non-Target Nodal or Non-Target Extra Nodal AND LOEL.Date of Initial Lesion Identification for This Trial (Scan Image Physical Exam) within 28 days prior to C1D1 Date of Visit.

Scenario 3: Output if CDD.Primary Diagnosis <> NULL and C1D1 Date of Visit <> NULL and there is no LOEL.Organ or System Assessment Location= Liver AND LOEL.Date of Initial Lesion Identification for This Trial (Scan Image Physical Exam) within 28 days prior to C1D1 Date of Visit.

Scenario 4: Output if CDD.Primary Diagnosis <> NULL and C1D1 Date of Visit <> NULL and there is no LOEL.Organ or System Assessment Location= Spleen AND LOEL.Date of Initial Lesion Identification for This Trial (Scan Image Physical Exam) within 28 days prior to C1D1 Date of Visit.

Scenario 5: Output if CDD.Primary Diagnosis <> NULL and C1D1 Date of Visit <> NULL and there is no LOEL. Organ or System Assessment Location= Whole Body Assessment by FDG-PET AND LOEL.Date of Initial Lesion Identification for This Trial (Scan Image Physical Exam) within 28 days prior to C1D1 Date of Visit.

Scenario 6: Output if CDD.Primary Diagnosis <> NULL and C1D1 Date of Visit <> NULL and there is no LOEL.Organ or System Assessment Location= Bone Marrow Assessment by FDG-PET AND LOEL.Date of Initial Lesion Identification for This Trial (Scan Image Physical Exam) within 28 days prior to C1D1 Date of Visit.

Note 1: If there is more than one CDD form in protocol please show outputs according to “CDD form” provided in parameter selection. If this field is blank show outputs for all CDD forms present in protocol.
