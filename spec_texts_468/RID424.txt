Report ID: RID424

Report Title:
Death vs SFU reconciliation

Description:
This report will show inconsistencies between deaths reported in DEATH, SFU, VST or DS01, depending on SAE reporting period.

Column Heading:
1. Country

2. Site

3. Subject Number

4. DEATH Date of death

5. Date of Last Dose

6. SFU Seq

7. Survival Status

8. SFU Date of Death

9. Difference in Days

10. VST Seq

11. VST Status

12. DS01 Status

13. Scenario

Logic:
Scenario 1:

Logic 1.1: If DEATH. Date/Time of Death = Null AND there is an SFU entry with SFU. Survival Status = Dead AND

Logic 1.2: If there is no entry in ODB Follow-up form with minimum Start Date of Medication after Date of Last Dose or no entry in OS Follow-up form with Date of Surgery/Date and Time Performed after Date of Last Dose or there is no entry in ORAD2 form with Date of Assessment after Date of Last Dose AND (SFU. Date of Death- Date of Last Dose) <= SAE period without new anticancer therapy (provided in prompts) OR

Logic 1. 3: If there is an entry in ODB Follow-up form with minimum Start Date of Medication after Date of Last Dose or there is an entry in OS Follow-up form with Date of Surgery/Date and Time Performed after Date of Last Dose or there is an entry in ORAD2 form with Date of Assessment after Date of Last Dose AND (SFU. Date of Death- Date of Last Dose) <= SAE period with new anticancer therapy (provided in prompts)

Scenario 2: Logic 2.1: If DEATH. Date/Time of Death <> Null AND there is no SFU entry with SFU. Survival Status = Dead

Scenario 3: Logic 3.1: there is VST. Indicate the Vital Status of the Subject= Dead but there is no (DEATH. Date/Time of Death <> Null and SFU. Survival Status = Dead) OR Logic 3.2: there is DS01. Select the Status of the Subject for the Study= Death but there is no (DEATH. Date/Time of Death <> Null and SFU. Survival Status = Dead)

Note 1: Date of Last Dose should be obtained based on the SM forms present for the study. If Using SM/SMAU/SMAB Date of Last dose corresponds to the Start Date/Time of the SM record where the "Please Indicate if this is the Last Dose for this Label Description" field is checked. If there is more than 1 SM form with "Please Indicate if this is the Last Dose for this Label Description" field checked, use the one with maximum Start Date/Time. If using SM04 Date of Last Dose corresponds to the Maximum Stop Date and Time Last Dose Administered/Received.

Note 2: ODB Follow-up form corresponds to ODBF, ODBHF, ODBCF or ODBNF depending on study design.

Note 3: OS Follow-up form corresponds to OSOF, OSOFL, OSOC

Note 4: If Start Date of Medication is not available in the ODB Follow-up form, use the Start Date of Regimen instead.

Note 5: Please ignore Time for calculations.

Note 6: In case day is entered as UNK, use the first day of the month in the logic; in case month is entered as UNK, use January of the same year.

Note 7: For scenario 2: Please only output when SFU has already been initialized, and please display columns 6-9 blank.

Note 8: For scenario 1, 2 display columns 10, 11, 12 blank.

Note 9: For Scenario 3 display column 4,5, 6, 7, 8, 9 blank

Note 10: For scenario 1: Please consider ‘SAE period with new anticancer therapy’ and ‘SAE period without new anticancer therapy’ as an enterable value that can vary depends on protocol requirements and is provided in report prompts
