Report ID: RID287

Report Title:
Imaging Date Mismatch with External Data

Description:
The report will output when there is an Imaging date with no matching record in the external vendor transfer file or when there is a record in the external vendor transfer file that has no matching  Imaging date.

Notes:

Parameter:

1- ‘Global Reads’, ‘Imaging Form’, ‘Vendor’, ‘Cut-Off Date’ are values from prompts

2- For prompt ‘Imaging Form’, if left empty the report will output for all the forms available in the study. If multiple forms are provided, then the report will output for all the forms provided.

3- For prompt ‘Vendor’, if left blank the report will output for all the vendors provided in the supporting document. If prompt is not left blank, the report will output for all vendor provided in the prompt

4- For prompt ‘Cut-Off Date’, if left blank, then consider system date.

5- ‘Form’, ‘Next Trial Segment’, ‘External Form’, ‘Imaging Vendor’ are values from ONC_GEFCF_001_supp_</Vxxxxxxx>.csv

6- Global Reads prompt should only be used for Logic 1A/Logic 1B/Logic 1C/Logic 1D. Logics 2A and 2B is independent of this prompt.

7- When prompt ‘Does this trial use PR domain?’ is answered ‘N’ then logics 1A, 1B, 1D, 2A are applicable. When prompt ‘Does this trial use PR domain?’ is answered ‘Y’, logics 1A/1B/1C/1D/2A/2B are applicable.

Explanation for proper noun:

8- IMAGING_FORM: LSRIR, LSNEV, HDA, LSNPC, OSCN, LSNBC

9- EXT_FORM: GEFCF, CIMG

10- EXT_FORM.Date = GEFCF.Date/Time of Measurement OR CIMG.Date of Imaging

11- IMAGING_FORM.Date = OSCN.Scan Date OR LSRIR/LSNEV/LSNPC/LSNBC/HDA.Date of Lesion Evaluation OR LSRIR/LSNEV/LSNPC/LSNBC/HDA.Date of Current Lesion Evaluation

12- IMAGING_FORM.Scan Collection Status = OSCN.Scan Collection Status

13- EXT_FORM.Procedure = CIMG.Procedure

14- EXT_FORM.Domain Abbreviation = CIMG.Domain Abbreviation

Added Logic:

15- OSCN.Scan Collection Status was not implemented for all trials; therefore, if the item is not available for a trial the report will ignore Logic 1.6, Logic 1.16, Logic 1.27

16- For Logic 1A/1B/1C/1D: If OSCN.Type of Image = ‘Physical Examination’ then no output is produced.

17- For Logic 1A/1B/1C/1D: If LSRIR/LSNEV/LSNPC/LSNBC/HDA.Method of Assessment = ‘Physical Exam’, ‘Physical Examination’, then no output is produced

18- Logic 1.10, Logic 1.21, 1.28, Logic 2.6 will output when there is not at least one matching record between IMAGING_FORM.Date and EXT_Form.Date. If one is already matching, then no output is expected

19 – Logic 1C and 2B are only applicable when prompt ‘Imaging Form’ is completed with ‘OSCN’ or contains ‘OSCN’ among all listed eCRFs or when prompt item is left blank AND OSCN form exists in the trial.

If study do not have item EXT_FORM.Procedure output is expected for all Logics except 1C and 2B.

20- Erroneous visits and deleted records will not be considered for programming.

21- Compare only the date, disregard time.

22- For Logic 1.1/Logic 1.2/Logic 1.11/Logic 1.12/Logic 1.22/Logic 1.23: Older trials use PMS1A while newer trials use OEDRA/OEFU and/or PMST. Please consider only the form that is available on each study. If multiple forms are available in the study and completed at the same time, consider only the ‘Form’ with the minimum Date of Assessment.

23- For Logic 2A and 2B, when IMAGING_FORM = OSCN: If logic is worked and the only matching record between EXT.FORM.Date and IMAGING_FORM.Date is an OSCN record with Scan Collection Status <> Performed, then output should be produced. If multiple records are matching but one is an OSCN record with Scan Collection Status = Performed and the other is an OSCN record with Scan Collection Status <> Performed, then no output should be produced.

24- The intention of Logic 1.9/Logic 1.19/Logic 1.30/Logic 2.5/Logic 2.11 is to include in the reconciliation only those scans that have a date that belongs to the treatment phase provided in the ONC_GEFCF_001_supp_</Vxxxxxxx>.csv. To do that, the report will identify first to which treatment phase the scan belongs to using the study phase supp doc and thereafter it will identify if the scan belongs to the treatment phase provided in the ONC_GEFCF_001_supp_</Vxxxxxxx>.csv using the ‘Phase Order’ as matching value between both. This will prevent fake output for those studies where only scans for certain treatment phases are being transferred/read by the vendor.

25- If in ONC_GEFCF_001_supp_</Vxxxxxxx>.csv, 'Form' and 'Next Trial Segment' are all 'NA': Ignore Logic 1.1,Logic 1.11 and Logic 1.22. And in Logic 1.20, only have to compare against ‘Form’.Date of Assessment from record on Logic 1.12

26 – In Logic 1.31 and Logic 2.13 EXT_FORM.Procedure value should be identifying a matching option using ONC_GEFCF_001_supp2_</Vxxxxxxx>.csv supporting document.

If prompt ‘Does this trial use PR domain?’ is selected as ‘N’, then report should not require ONC_GEFCF_001_supp2_</Vxxxxxxx>.csv supporting document to work.

When prompt ‘Does this trial use PR domain?’ is selected as ‘Y’ and trial does not have ONC_GEFCF_001_supp2_</Vxxxxxxx>.csv supporting document, and prompt ‘Imaging Form’ identifies that report should consider OSCN eCRF per Note 19, report should not execute.

If prompt ‘Does this trial use PR domain?’ is selected as ‘Y’ and trial does not have ONC_GEFCF_001_supp2_</Vxxxxxxx>.csv supporting document, and prompt ‘Imaging Form’ identifies that report should NOT consider OSCN eCRF per Note 19, report should skip ONC_GEFCF_001_supp2_</Vxxxxxxx>.csv supporting document and execute.

Display:

27- If a date is displayed in the output, the report will show it in format ‘DDMMMYYYY’ e.g. 01JAN2020

28- For Scenario 1 and Column 6, the report will show the formidx even if the date was reported in the ‘add-entry’ section of the eCRF e.g., 1(2)

29- For Scenario 1 and Column 7, the report will show the method of assessment even if it was written on the ‘other’ textbox

30- The purpose of Scenario 2A and 2B and Column 5 (‘Form’) is to show on the report output the IMAGING_FORM provided in prompt ‘Imaging Form’. If prompt is left blank, then display all the IMAGING_FORM (for example: LSRIR, LSNEV, HDA, LSNPC, OSCN, LSNBC) available in the study.

31 – For Table 2 when prompt ‘Does this trial use PR domain?’ is answered ‘Y’ AND if prompt ‘Imaging Form’ is completed with ‘OSCN’ or contains ‘OSCN’ among all listed eCRFs or when prompt item is left blank and trial does use ‘OSCN’ display Column 8 (‘Method of Assessment’).

If prompt ‘Does this trial use PR domain?’ is answered ‘N’ OR ‘Imaging Form’ is completed and does not contain ‘OSCN’ OR trial does not use OSCN form leave Column 8 (‘Method of Assessment’) blank.

If study does not have EXT_FORM.Procedure item leave Column 8 (‘Method of Assessment’) blank.

Supporting Document:

32- The supporting document is required for all trials if treatment phase is applied to logic even if only one treatment phase is present.

This supporting document is only required to be created once per trial. If it was already created and uploaded, there is no need to duplicate it.

The supporting document should be named as study_phase_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

One row for each Treatment Phase

1. Phase Order: required, the order on which phases will appear on protocol

2. Treatment Phase: required, name of each study phase (Initial Treatment Phase, Neodjuvant Phase, Second Course Phase)

3. First Visitmnemonic of Treatment Phase: required, the first visit on which treatment is expected to be administered on each phase.

e.g.

1, Initial Treatment Phase, Cycle 1

2, Second Course Phase, Cycle 1 Course 2

3, Crossover Phase, Crossover Cycle 1

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter ""Study Phase Page"".

The report logic should be checked within the same treatment phase defined in the supporting document.

For example, if user provides two Treatment Phases in supporting document like below:

Phase Order, Treatment phase, First Visitmnemonic of Treatment Phase

1,Initial Treatment Phase,Cycle 1

2,Second Course Phase,Second Course Cycle 1

The treatment phase will be identified as following:

Initial Treatment Phase: Form.Date < Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: IMAGING_FORM.Date, EXT_FORM.Date

35- The correct use of the prompts will guarantee the correct output

- Global Reads: Required – Select as Y if vendor performs global read process during in-life of the study. Select N if vendor does not perform global read process at all OR during DBL.

- Imaging Form: Optional – Type in the form mnemonic that captures scans in Inform e.g., OSCN. Multiple forms can be provided separated by comma e.g., OSCN,LSRIR. If left blank, the report will compare all forms available in the study.

- Vendor: Optional – Type in the vendor name that transfers imaging scans data. This value should match with Vendor Name column from reports EVD013B_STD/EVD013E_STD. If prompt is left empty, the report will output for all vendors provided in the supporting document.

- Cut-Off Date: Optional –  Value should be provided in format DDMMMYYYY. For each individual transfer contact the vendor POC and request the Cut-Off Date which is the last date when scans are considered for each transfer. E.g., If Cut-Off Date was on 15JUN2020 it means that only scans with a date on or before 15JUN2020 were transferred. The use of this prompt will avoid fake output for Scenario 1 when the scan date is after the Cut-Off Date.

LCDM is responsible to provide protocol specific guidance about how to run the report for each vendor used in the study based on the standard guidance.
