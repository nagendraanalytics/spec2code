Report ID: RID254

Report Title:
Reconciliation between CM, SCTB and SCTF information related to 'Stem Cell Transplant' terms.

Description:
This report displays all concomitant medications listed with Standardized Medication Name entered as 'stem cells (as drug)', that should be entered at SCTB or SCTF eCRF.

Column Heading:
1. Country

2. Site

3. Subject Number

4. CM sequence number

5. CM Standardized Medication Name

6. CM Imputed Start Date

7. SM form

8. Date of first dose

9. Scenario

Logic:
Logic 1

CM.Standardized Medication Name='stem cells (as drug)'

AND

CM. Imputed Start Date and Time < Min.Date of First Dose

Logic 2

CM.Standardized Medication Name='stem cells (as drug)'

AND

CM. Imputed Start Date and Time >= Min.Date of First Dose

Notes:

1. Please do not consider deleted records nor erroneous visits.

2. In the logic use date only, do not use time.

3. Use only study medication forms that are available in the study (for example if a study is using only SM and SMAU forms, please ignore the logic corresponding to SM01 and SMAB forms). In case there are multiple study medication forms within a study (for example, both SM and SMAU), use the study medication form with the minimum Start Date/Time of First Dose in the logic.

4. Date of First Dose refers to SM01. Start Date and Time First Dose Administered/Received

or

SM.Start Date/Time for the entry with SM. Please Indicate if this is the First Dose for this Study Medication checked or Please Indicate if this is the First Dose for this Label Description checked

or

SMAU/SMAB. Start Date/Time for the entry with SMAU/SMAB. Please Indicate if this is the First Dose for this Label Description checked

Note 5. Minimun first dose should be calculated across SM/SMAB/SMAU/SM01 Form

Report Scenarios:
1. Output: YES

CM Standardized Medication Name is 'stem cells (as drug)' and Date of First Dose is provided

2. Output: No

CM Standardized Medication Name is 'stem cells (as drug)' and Date of First Dose is not provided

3. Output: No

CM Standardized Medication Name is 'stem cells (as drug)' and eCRF with Date of First Dose is not initialized

4. Output: No

CM Standardized Medication Name is not 'stem cells (as drug)'

5. Output: No

Date of First Dose is blank or provided with radio button comment

6. Output: No

Date of First Dose is selected in SM01 or SMAU or SMAB that is entered on an erroneous visit

Sorting:
Country, Site Number, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (N/Y, Default as N).

Form.Item Names:
1. SA. Country

2. SA. Site

3. SA. Subject Number

4. CM. Sequence Number

5. CM. Standardized Medication Name

6. CM. Imputed Start Date and Time

7. Form name for SM eCRF (SM01/SM/SMAU/SMAB)

8. SM01. Start Date and Time First Dose Administered/Received      or SM.Start Date/Time or SMAU. Start Date/Time or SMAB. Start Date/Time depending on parameter selection

9. Display ‘Scenario 1’ for Logic 1 or ‘Scenario 2’ for Logic 2
