Report ID: LLNR001_T

Report Title:
Mismatch in sequence numbers between Local Lab and Local Lab NR

Description:
This report outputs subjects who have a local lab (CLAB, HLAB, OLAB) associated normal sequence number that does not match any subject level local lab normal range (CNR, HNR, ONR) sequence number, or the local lab associated normal sequence number is blank. This report also outputs subjects who have a subject level local lab normal range (CNR, HNR, ONR) sequence number that does not match any local lab (CLAB, HLAB, OLAB) associated normal sequence number, or the subject level local lab normal range sequence number is blank.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Local Lab eCRF

5. Visit

6. Local Lab Seq

7. Local Lab Associated NR Sequence number

8. NR Sequence number

Logic:
Report should display subjects who have

1. local lab (CLAB, HLAB, OLAB) associated normal sequence number that does not match any local lab normal range (CNR, HNR, ONR) sequence number, or the local lab associated sequence number is blank. Hard-code 'null' when sequence number is blank.

2. local lab normal range (CNR, HNR, ONR) sequence number that does not match any local lab (CLAB, HLAB, OLAB) associated normal sequence number, or the local lab normal range sequence number is blank. Hard-code 'null' when sequence number is blank.

Records in erroneous visits should not be considered.

Report should not display deleted records. If "Randomized only" parameter selection checkbox  is checked, the report should only output subjects with Randomization  number that is not null.

Report Scenarios:
A1-Yes. local lab (CLAB, HLAB, OLAB) associated normal sequence number that does not match any local lab normal range (CNR, HNR, ONR) sequence number, or the local lab associated sequence number is blank. Hard-code 'null' when sequence number is blank.

A2-Yes. local lab normal range (CNR, HNR, ONR) sequence number that does not match any local lab (CLAB, HLAB, OLAB) associated normal sequence number, or the local lab normal range sequence number is blank. Hard-code 'null' when sequence number is blank.
