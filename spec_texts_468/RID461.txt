Report ID: RID461

Report Title:
Biopsy type per cohort

Description:
This report will output subjects  for whom at least one TSIF record with the Biopsy Type selected was not entered

Column Heading:
1. Country

2. Site

3. Subject Number

4. Cohort

5. Expected Tissue Acquisition Type

6. Expected Visit

Logic:
Logic 1.1: Criteria Form.Criteria Item = "Criteria Value" per supp doc

AND

Logic 1.2: There is NOT at least one TSIF record with the following criteria: (TSIF.Tissue Acquisition Type = "Tissue Acquisition Type" per supp doc AND TSIF.Specimen Collection Status <> "Not Obtained") in the specified "Visit" per supporting document

Notes:

1-	Erroneous visits and deleted records will be excluded from programming

2-	If Criteria Form, Criteria Item and Criteria Value = "NA", then Logic 1.1 will be ignored

Requires supporting document to be named ONC_TSIF_001_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

1. Criteria Form - Form with criteria that report will use to distinguish groups of patients (eg. SR eCRF); enter NA if your study has the same requirement for all patients

2. Criteria Item - Item within 'Criteria Form' that will allow to distinguish different groups of patients (eg. Cohort on SR eCRF); enter NA if your study has the same requirement for all patients

3. Criteria Value - Value for 'Criteria Item'; when met the report will use specified settings for this group (eg. cohort A in item 'Cohort' on SR eCRF); enter NA if your study has the same requirement for all patients

4. Visit - Enter the visit mnemonic per T&E where the TSIF entry is expected

5. Tissue Acquisition Type - Enter the Tissue Acquisition Type that is expected in the specified visit

Criteria Form, Criteria Item, Criteria Value, Visit, Tissue Acquisition Type

SR, Cohort, 3475 and Axitinib, Screening, Archival

SR, Cohort, 3475 and Axitinib, Cycle 1, Newly

TRIGA, Arm, Arm 1, Screening, Archival

NA, NA, NA, Cycle 1, Newly

The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

If supporting doc is not provided, display the message as "ONC_TSIF_001_JR_STD Supporting Document Not Present for This Trial".

Report Scenarios:
As per the test data and Logic

Sorting:
Country, Site, Subject Number, Cohort

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N), Supporting Doc Page (N/Y, Default as N)

Form.Item Names:
1. SA.Site Country

2. SA.Site Mnemonic

3. SA.Subject Number

4. Criteria Form.Criteria Item

5. Tissue Acquisition Type as per supporting document

6. Visit per supporting document
