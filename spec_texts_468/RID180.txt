Report ID: RID180

Report Title:
Specific timeframe between Study Medications

Description:
This report will display subjects with Study Medication 2 administered at specific timeframe after Study Medication 1 is completed.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Study Medication 1

6. Study Period

7. Stop Date/Time

8. Study Medication 2

9. Start Date/Time

Logic:
Scenario 1:

Output is produced when "Study Medication 2" is administered less than Lower Window of minutes after "Study Medication 1" infusion is complete.

Scenario 2:

Output is produced when "Study Medication 2" is administered greater than Upper Window of minutes after "Study Medication 1" infusion is complete.

Notes:

1. Please do not consider deleted records

2. Please only consider randomized subjects

3. Please display output if Time is UNK

Requires supporting document to be named SM010_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1) Criteria Form -  Optional, enter 'NA' if logic is checked for all subjects

2) Criteria itemquestion -  Optional, enter 'NA' if logic is checked for all subjects

3) Criteria Value -  Optional, enter 'NA' if logic is checked for all subjects

4) Study Period: Study Period from SM in which oral and IV Study Medication are both administered

5) Form: SM Form

6) Study Medication 1 - Value for Oral/IV Study Medication expected to be administered first

7) Item 1: SM item to start the 30 X minutes window count

8) Study Medication 2 - Value for Oral/IV Study Medication expected to be administered after SM1

9) Item 2: SM item to finish the 30 X minutes window count

10) Lower Window of Minutes- Minimum time expected in minutes for SM2 to be administered after SM1 administration

11) Upper Window of Minutes - Maximum time expected in minutes for SM2 to be administrated after SM1 administration

i.e

Criteria Form,Criteria itemquestion,Criteria Value,Study Period, Form, Study Medication 1, Item 1, Study Medication 2, Item 2, Lower Window of Minutes, Upper Window of Minutes

NA,NA,NA, Cycle 1 Day 1, SM, -3475, Stop Date and Time, -6482, Start Date and Time, 25, 35

Report Scenarios:
Scenario 1:

Output YES: if Study Period is the same and Start Time of Study Medication 2 is less than Lower Window of minutes from Study Medication 1 Stop Time

Output NO: if logic is not met.

Scenario 2:

Output YES: if Study Period is the same and Start Time of Study Medication 2 is greater than Upper Window of minutes from Study Medication 1 Stop Time

Output NO: if logic is not met.
