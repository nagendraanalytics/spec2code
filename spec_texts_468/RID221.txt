Report ID: RID221

Report Title:
Missing Derived Items

Description:
This report displays issues when the derivations are not working as expected.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Form

6. Sequence

7. Edit Check ID

8. Primary Item

9. Related Item

10. Scenario

Logic:
Logic 1: Scenario 1

"Itemrefname" from subgroup 0 = NULL AND "Itemrefname" from subgroup <> 0 and the conditions defined per supporting document are met

Logic 2: Scenario 2

Form.Itemrefname = 0

OR

Form.Itemrefname <> Numeric value

Notes:

1-	Exclude data in erroneous visits and deleted records

2-	If "Edit Check ID" uses information from more than one eCRF, for example, item X is populated when item Y in eCRF A is not null and when item Z in eCRF B is not null, then consider that eCRFs A and B should be in the same visit.

3-	When there are multiple column names sharing the same Itemrefname, then, the report will check that at least one column name fulfills the condition per supporting document

4-  For Scenario 2, if "Itemrefname" is NULL or completed with bubble comment of "Not Done", "Not Applicable" or "Unknown", then, no output is produced

5-  For Scenario 1, if "Itemrefname" is completed with bubble comment of "Not Done", "Not Applicable" or "Unknown", then no output is produced

Supporting Document Notes:

1-	Requires supporting document to be named TQ039_supp_</Vxxxxxxx>.csv and will contain the following columns and associated content:

2-	The number of rows in the supporting document will be represented in the Report Header as "# of rows for Supporting doc".

3-	The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".

4-	If supporting doc is not provided, display the message as "TQ039_JR_STD Supporting Document Not Present for This Trial".

Explanation for Scenario 1:

1. Edit Check ID: Type in the EC ID as present in the EC file. This column will not be used for programming, but it will be used to display the EC ID in the output

2. Form: Enter the Form Mnemonic where the Itemrefname is located

3. Subgroup: Type in "0" if the column "Itemrefname " refers to the primary item of the EC. Create different subgroups based on the explanation below if the column "Itemrefname " refers to a related item(s) of the EC. 3.1. If multiple "Itemrefname " share the same subgroup then the report will consider "OR" between each condition. 3.2. If "Itemrefname " have different numbers in the subgroup column then the report will consider "AND" between each condition

4. Itemrefname: Enter the Itemrefname of the Primary Item or Related Item(s) of each EC. Use TQ028_JR_STD to get itemrefnames. Please review they match the items in the ECs by removing the IT at the end of the refname, e.g.: TSIFBSDTCIT will be found in the eCRFs or ECs as TSIFBSDTC

5. CONDSYMBOL: Type in "=", "<>", "<", ">". This only applies to subgroups <> 0, the only exception is when the condition is "<> NULL", for that condition simply type in "NA". If subgroup is 0 type "NA".

6. CONDRESULT: Type the value the item should have to match the condition. If no CONDRESULT is needed then type “NA”.

7. Scenario: Type in "1"

Edit Check ID,Form,Subgroup,Itemrefname,CONDSYMBOL,CONDRESULT,Scenario

TSIF114,TSIF,0,TSIFBSDTCIT,NA,NA,1

TSIF114,TSIF,1,TSIFBSORRESSCSIT,NA,NA,1

TSIF114,DOV,2,DOV,NA,NA,1

LECG73,LECG,0,LECGEGORRESQFIT,NA,NA,1

LECG73,LECG,1,LECGEGORRESQTIIT,NA,NA,1

LECG73,LECG,1,LECGEGORRESVRIT,NA,NA,1

Explanation for Scenario 2: Fill out all the columns with "NA" except for: "Edit Check ID", "Form", "Itemrefname" and "Scenario"

1. Edit Check ID: Type in the EC ID as present in the EC file. This column will not be used for programming, but it will be used to display the EC ID in the output

2. Form: Enter the Form Mnemonic where the Itemrefname is located

3. Subgroup: Type in "NA".

4. Itemrefname: Enter the Itemrefname of the Primary Item or Related Item(s) of each EC. Use TQ028_JR_STD to get itemrefnames. Please review they match the items in the ECs by removing the IT at the end of the refname, e.g.: TSIFBSDTCIT will be found in the eCRFs or ECs as TSIFBSDTC

5. CONDSYMBOL: Type in "NA"

6. CONDRESULT: Type in "NA"

7. Scenario: Type in "2"

Example Scenario 2

Edit Check ID,Form,Subgroup,Itemrefname,CONDSYMBOL,CONDRESULT,Scenario

ODBF01,ODBF,NA,ODBFCMSPIDIT,NA,NA,2

Layout Notes:

1- Colum 5 will be populated with the value provided in “Form” that has the “Subgroup” as 0

2- Column 7 will be populated with the text used in the "Edit Check ID" from supporting document

3- Column 8 will be populated with the value provided in the "Itemrefname" column if "Subgroup" = 0 for Scenario 1. Column 7 will be populated with the value provided in the "Itemrefname" column for Scenario 2

4- Column 9 will be populated with the value provided in the "Itemrefname" column if "Subgroup" <> 0 for Scenario 1. Column 8 will be blank for Scenario 2

5- For Column 10 display according to the logic that is satisfied
