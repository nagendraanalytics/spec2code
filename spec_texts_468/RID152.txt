Report ID: RID152

Report Title:
PK record missing in InForm or Vendor transfer file

Description:
PK eCRF AND CENTRAL LAB/BA VENDOR RECONCILIATION

The report will output when there is a PK record in eCRF with no matching record in the external vendor transfer file.

The report will also output when there is a PK record in the external vendor transfer file that has no matching record in Inform.

Logic:
Scenario 1

1A

Output is displayed when a combination of screening number and Specimen ID entered in InForm cannot be found in vendor data. Output error message "Missing in Vendor".

1B

Output is displayed when a combination of screening number and Specimen ID loaded from vendor cannot be found in InForm data. Output error message "Missing in InForm".

Notes: 1. Logic considers specimen ID in InForm only when "If Sample Was Collected But Not Sent, Indicate Reason" and “Check if Sample Was Not Collected” in PK eCRF are blank.

2. Please do not consider deleted records from PK forms in this logic.

3. No case sensitive when comparing Specimen ID from INFORM and Vendor data

4. DOV should be initialized, and visit should not be erroneous for the record to be considered in the logic.

5. SITEID is always a 4-digit number, SCRNID is a 9-digit number and SUBJID is a 6-digit number if any of them have a smaller number of digits please complete with zeros at the left to make the comparison, i.e. SITEID: 100 should be 0100 to match with Site from InForm.

6. It should be one tab for BA and another for Central Lab if data of both is included using the prompts.

7.	For Missing in InForm scenario "Site and Screening Number" column, information missing will be populated using SITEID and SCRNID from vendor file.

8.	For Missing in InForm scenario for "Subject Number" column, information missing will be populated from vendor file as the following concatenate (BA/Central.SITEID + "--" + BA/Central. SUBJID).

Report Scenarios:
Scenario 1

1A Output = Yes

Output is displayed when a combination of screening number and Specimen ID entered in InForm cannot be found in vendor data.

1A Output = No

Output is not displayed when a combination of screening number and Specimen ID entered in InForm can be found in vendor data.

1B Output = Yes

Output is displayed when a combination of screening number and Specimen ID loaded from vendor cannot be found in InForm data.

1B Output = No

Output is not displayed when a combination of screening number and Specimen ID loaded from vendor can be found in InForm data.
