Report ID: RID185

Report Title:
Consecutive Zero Dose Records for Study Medication

Description:
This report will display output when consecutive ZERO doses by date are entered for an individual Study Medication

Column Heading:
1. Country

2. Site

3. Subject Number

4. Form

5. Study Medication

6. SM Start Visit

7. SM Start Seq

8. Start Date

9. SM Stop Visit

10. SM Stop Seq

11. Stop Date

12. Number of consecutive days

Logic:
<Criteria Form1>.<Criteria Itemquestion1> = <Criteria Value1>  AND

<Criteria Form2>.<Criteria Itemquestion2> = <Criteria Value2> AND

<Criteria Form3>.<Criteria Itemquestion3> = <Criteria Value3> AND

Logic 1: Sort the Study Medication Form (SM and SMAB and SMAU as defined in supporting document) records by Start Date/Time

AND

Logic 2: If the Study Medication is selected when running the report, then only check the SM and SMAB and SMAU records within that selected label; otherwise, check all SM and SMAB and SMAU records together

AND

Logic3: look at the consecutive Study Medication duration without gap or overlap AND number of units taken/Dose amount/Infusion Rate = 0  AND  last Study Medication stop date/time – first Study Medication start date/time +1 day >= defined number of consecutive days

AND

Logic 4: the consecutive Study Medication duration can be recorded as an individual SM record or several single Study Medication records.

Example: when Study Medication is recorded as following

Jan1 – Jan5    0 dose

Jan6 -  Jan6    0 dose

Jan8 - Jan10  1 dose

Jan11-Jan11   0 dose

Jan12-Jan12   0 dose

Jan13-Jan13   0 dose

Jan14-Jan14   0 dose

Jan15-Jan19   1 dose

In this example, there are 2 SM duration with 0 doses

-     Jan1-Jan6,  last SM stop – first SM start +1 = Jan6 – Jan1 +1 = 6 days

-     Jan11- Jan14,  last SM stop – first SM start +1 = Jan14-Jan11+1=4 days

Notes:

Note 1: Deleted records and records in erroneous visit should be ignored.

Note 2. For logic use the Study Medication Form and Study Medication provided in Supporting document.

Requires Supporting Document to be named SM017_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Criteria Form1 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA

2. Criteria Itemquestion1 - Arm/Cohort/Stratification Itemquestion1. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion1 is not applicable for the protocol, enter NA

3. Criteria Value1 - Arm/Cohort/Stratification Value. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the itemValue1 is not applicable for the protocol, enter NA

4. Criteria Form2 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

5. Criteria Itemquestion2 - Arm/Cohort/Stratification Itemquestion2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion2 is not applicable for the protocol, or is not needed enter NA

6. Criteria Value2 - Arm/Cohort/Stratification Value2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value2 is not applicable for the protocol, enter NA

7. Criteria Form3 - Arm/Cohort/Stratification Form Mnemonic SR/SRIVRS/TRIG. If applies for all subjects regardless the Arm/Cohort/Stratification, or is not needed enter NA

8. Criteria Itemquestion3 - Arm/Cohort/Stratification Itemquestion3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Itemquestion3 is not applicable for the protocol, or is not needed enter NA

9. Criteria Value3 - Arm/Cohort/Stratification Value3. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the Value3 is not applicable for the protocol, enter NA

10. Study Medication Form – Study Medication Form Mnemonic

11: Study Medication – Value for each specific Study Medication

12. Number of consecutive days – Number of consecutive days to check, depend on the dose schema.

e.g.

SR, Arm, Arm 1, SR, Stratification, Strat1, SR, Arm Code, 0010, SMAU, 3475/Placebo, 84

SR, Arm, Arm 1, SR, Stratification, Strat1, NA, NA, NA, SM, Capecitabine, 21

SR, Arm, Arm 1, SR, Stratification, Strat2, NA, NA, NA, SM, Oxaliplatin, 21

TRIGA, Arm, Arm 2, NA, NA, NA, NA, NA, NA, SM, Lenvatinib, 28

The number of rows in the supporting document will be represented in the Report Header as "# of rows for customization".

The actual information provided by the supporting doc can be outputted by selecting Y in the parameter "Supporting doc Page".
