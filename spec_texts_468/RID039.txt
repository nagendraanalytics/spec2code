Report ID: RID039

Report Title:
Oxygen Saturation result and Hypoxia adverse event reconciliation

Description:
This report displays subjects with pulse oximetry finding of <88% with no corresponding hypoxia AE recorded or subjects having hypoxia AE with no PO assessment done on the date of AE.

Column Heading:
1. Country

2. Site

3. Subject Number

4. AE Seq

5. AE Onset date

6. AE End date

7. LLT

8. PO Seq

9. PO Date of Assessment

10. O2 Saturation

11. Message

Logic:
Logic 1:

PO.O2 Saturation < 88%

AND

There is no AE.LLT= 'Hypoxia'

OR There is AE.LLT= 'Hypoxia' AND PO.O2 Saturation < 88% is not within  AE.Onset Date and Time (Lab Collection Date If Lab AE) and AE. End Date and Time

Logic 2:

AE.LLT = "Hypoxia"

AND

There is no PO.O2 Saturation < 88% with PO.Date/Time of Assessment = AE.Onset Date

Note 1. Deleted record should not be considered in the programming.

Note 2. If AE.End Date and Time is 'Ongoing', please display 'Ongoing'.

Note 3. Only compare date between AE and PO.

Note 4: For logic 1, the output will not generate when ‘PO. Date/Time of Assessment’ is equal to ‘AE. Onset Date and Time’ or ‘AE. End Date and Time.

Note 5. Leave columns 8,9,10 blank for logic 2.

Note 6. Leave columns 4,5,6,7 blank  for Logic 1.

Report Scenarios:
Scenario 1- Yes:

There is PO record with O2 Saturation result < 88% but no corresponding AE Term ‘Hypoxia’ where PO Date/Time of Assessment is between Onset and End date or ongoing inclusive.

Scenario 2 – No:

There is PO record with O2 Saturation result < 88% with Date/Time of Assessment within AE duration (between Onset and End date inclusive).

Scenario 3 – Yes:

There is AE Term ‘Hypoxia’ entered but the Onset Date is different than Date/Time of Assessment of PO record with O2 Saturation result < 88%.

Scenario 4 – No:

There is AE Term ‘Hypoxia’ entered with the Onset Date equal Date/Time of Assessment of PO record with O2 Saturation result < 88%.
