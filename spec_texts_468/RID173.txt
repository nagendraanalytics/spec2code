Report ID: RID173

Report Title:
Tab 1: SCI Invoice and BA Vendor reconciliation

Description:
This report will output mismatches between INFORM, Central Lab and/or BA vendor.

In case all 3 databases need to be reconciled (Inform - BA file and Central Lab), the report will show 2 TABS: eCRF Invoice VS BA file and eCRF invoice VS Central Lab.

Logic:
This report displays subjects who have mismatches for either Visit, Subject Number, Schedule Time, Analyte (Form) and Date and Time of Sample Collection between Inform vs BA vs Central.

The initial comparison should be Subject Assignment. Screening Number+ Subject Assignment. Specimen ID vs SCRNID+ REFID. Then the following scenarios should be look into:

1.	Scheduled Time different than NOMHOUR (BA/Central). If different, output should be produced, and Scenario displayed as Schedule Time mismatch.

2.	IF Visit Mnemonic is different than NOMDAY, output should be produced, and Scenario displayed as Visit mismatch.

3.	IF the form is different than the expected per supp doc and ANALYTE (BA/Central), output should be produced, and Scenario displayed as Analyte mismatch.

4.	IF Date/Time Specimen(s) Obtained-Date or Date Specimen(s) Obtained is different than DDT, output should be produced, and Scenario displayed as Date mismatch.

5.	IF Date/Time Specimen(s) Obtained -Time or Time Specimen Obtained is different than DTM, output should be produced, and Scenario displayed as Time mismatch.

6.	If Treatment/Randomization Number is different than SUBJID, output should be produced, and Scenario displayed as PNE.

Notes:

1.	Please use the Supporting Document as guide to see which visit corresponds to the NOMDAY, the Schedule Time to the NOMHOUR and the form to the ANALYTE matching.

2.	Exclude samples from Inform when deleted records OR “If Sample Was Collected But Not Sent”.

3.	DOV should be initialized, and visit should not be erroneous for all scenarios.

4. No case sensitive when comparing Specimen ID from INFORM and Vendor data.

5. SITEID is always a 4-digit number, SCRNID is a 9-digit number and SUBJID is a 6-digit number if any of them have a smaller number of digits please complete with zeros at the left to make the comparison, i.e. SITEID: 100 should be 0100 to match with Site from InForm

6.	It should be one tab for BA and another for Central Lab if data of both is included using the prompts.

7.	For the same Subject Assignment. Screening Number+ Subject Assignment. Specimen ID it should show all the discrepancies in only one output concatenating the issue messages i.e. “Visit Mismatch, Analyte mismatch, Specimen Type mismatch”.

8.	If Scheduled Time in Inform is “UNSCHEDULED”, for Visit mismatch scenario please use Unscheduled as Visit Mnemonic in the logic based on the relation (Visit Mnemonic-NOMDAY) present in the supporting document. The report output should display the real visit mnemonic in which the record in InForm is found. If Unscheduled is not included in the supporting document, please use the relation Unscheduled (Visit Mnemonic) – 997 (NOMDAY).

9.	If the trial does not collect the time in Inform, this scenario should not be evaluated, and outputs are not expected for Time mismatch scenario.

10.	For Time mismatch and Date mismatch scenarios please use the item present in the eCRF correspondingly (Date/Time Specimen(s) Obtained, Date Specimen(s) Obtained or Time Specimen Obtained)

11.	SCI form mentioned in the logic applies for SCI and its variations, this mean, SCI in the logic can be replaced to SCI/SCIA/SCIB/SCIC/SCID/SCIE, etc… according to each trial requirements.

12.	For Analyte mismatch scenario each ANALYTE from vendor should be completed in a specific form in Inform, if it is completed in another form, please show output (i.e. Supp doc is completed as SCIA – 2140, but in Inform, this Subject Assignment. Screening Number+ Subject Assignment. Specimen ID is completed in SCIB, then an output of Analyte mismatch is expected.

13.	For PNE scenario subject number should be displayed from Vendor files “SITEID+“--"+ SUBJID”.

Requires supporting document to be named SCI010_supp_XXXXXXX.csv (in csv format) and will contain the following columns and associated content:

1. Analyte Inform Form: Please complete with the form where each Analyte is expected to be completed adding the word FORM at the end without spaces (i.e if form is SCI, please complete as SCIFORM)

2. Analyte BA: This column matches with Analyte Inform Form column (Column 1), please complete with the ANALYTE as completed by the BA vendor in the recon file.

3. Analyte Central: This column matches with Analyte Inform Form column (Column 1), please complete with the ANALYTE as completed by the Central vendor in the recon file.

4. Visit Mnemonic:  Please include all timepoints from specification. i.e. Unscheduled, Discontinuation, Early Discontinuation, etc..

5. NOMDAY: This column matches with Visit Mnemonic column (Column 3).

6. Scheduled Time: Include all options present in your eCRFs.

7. NOMHOUR: This column matches with Scheduled Time column (Column 5).

Note to LCDM: NOMDAY and NOMHOUR should match with the NOMDAY NOMHOUR specification sent to vendor.

Each pair of columns in supporting document is independent of the others (1&2&3, 4&5, 6&7) and they could have different number of rows.

Example:

Analyte Inform Form,Analyte BA,Analyte Central,Visit Mnemonic,NOMDAY,Scheduled Time,NOMHOUR

SCIFORM,FREE CARBOPLATIN,FREE CARBOPLATIN,Screening,1,Pre Dose,0

SCIAFORM,Total CARBOPLATIN,Total CARBOPLATIN,Cycle 1 Day 1,11, 0-4 Hours Post Dose,3

SCIBFORM,-2118,2118,,,Scheduled,20

This report can be run on BA or Central Lab files or both.
