Report ID: RID228

Report Title:
First query-related action taken in the database by each Sponsor user

Description:
The report lists the first query-related action that was taken by each sponsor user in the database

Column Heading:
1.	Query Status

2.	Country

3.	Site

4.	Subject Number

5.	Visit Mnemonic

6.	eCRF Name

7.	Seq

8.	Item Name

9.	Action User

10.	Query Text

11.	First Action Taken

12.	Date of First Action Taken

Logic:
This report will list the query in which each sponsor user took the first action in the database. These queries can be only one (whichever happened first) of the following options:

- The first manual query or autoquery that was closed by each sponsor user

- The first query that was open by each sponsor user

- The first query that was created in candidate by each sponsor user

- The first query that was reissued in candidate or reissued in opened status by each sponsor user

Notes:

1.	The column first query text from Blinded Forms provided in the supporting document and SMPB/DISP/SR1 will be masked as 'xxxx'.

2.	Requires supporting document to be named TQ054_supp_<xxxxxxx>.csv) and will contain the following columns and associated content:

Blinded Forms: Type in the list of eCRFs that have blinded data in it. For example:

Headers:

Blinded Forms

Content:

SMPB

If the trial does not use any blinded form, upload the supporting document with the headers and in the content type in NA. For example:

Headers:

Blinded Forms

Content:

NA

3.	Column 1 will populate the current Query Status of the query

4.	Column 5 will populate the Visit Mnemonic where the query was found, for example, "Screening" or "Cycle 1 Day 1"

5.	Column 6 will populate the Form Mnemonic where the query was found, for example, "DOV" or "SLAB"

6.	Column 7 will populate the Form Index where the query was found, for example, "1" or "2"

7.	Column 8 will populate the Item Mnemonic where the query was found, for example, "Date of Visit" or "Race"

8.	Column 9 will populate with the ISID of the person who took the query-related action, for example, "DMS3" or "CS1"

9.	Column 10 will populate the query text used in the query-related action that was found for the corresponding user

10.	Column 11 will populate with the following messages depending on what the first query-related action was, as follows:

-	If the first query-related action that the user took was to close a query, then display: "Query was Closed"

-	If the first query-related action that the user took was to create a query in Opened status, then display: "Query Created in Opened Status"

-	If the first query-related action that the user took was to create a query in Candidate status, then display: "Query Created in Candidate Status"

-	If the first query-related action that the user took was to reissue a query in Opened status, then display: "Query Reissued in Opened Status"

-	If the first query-related action that the user took was to reissue a query in Candidate status, then display: "Query Reissued in Candidate Status"

11.	Column 12 will populate with the date in which the first action by the user was taken in the database, specifying date and time of such action.
