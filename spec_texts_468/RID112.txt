Report ID: RID112

Report Title:
Existing results for NOT DONE records at LABS

Description:
This report displays all LABS records with ANY value at the results fields but also has a Status entered as "NOT DONE".

Column Heading:
1. Country

2. Site

3. Screening Number

4. Subject Number

5. eCRF

6. Seq

7. Transmission Source ID

8. Visit ID or Number

9. Visit Name

10. Visit Type

11. Accession ID or Number

12. Actual Collection Date and Time

13. Battery ID

14. Lab Test ID

15. Lab Test Name

16. Test ID

17. Test Name ID

18. Specimen ID

19. Sub Specimen ID

Logic:
This report will retrieve the LABS records with Test Status='X' or ‘N’, which corresponds to a Not Done Test, and Conventional Text Result or Conventional Numeric Result is not null.

AND

LABS records with  Test Status='X' or ‘N’ and Test Level Comments = null.

Note:

Report should not display deleted records.

Report Scenarios:
Output - Yes

Test status is X or N, but test result presents

Output - No

Test status is X or N and test result is blank

Output-Yes

Test Status is X or N and Test Level Comments is blankl

Output-No

Test Status is X or N and Test Level Comments is complete.
