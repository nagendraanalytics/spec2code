Report ID: RID197

Report Title:
Cycle started with zero dose or no entry at all for particular study medication

Description:
Report will output when only zero doses are entered on the day a cycle begins or there is no SM/SMAB/SMAU entry for particular study medication.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Date of Visit

6. Study Medication

7. SM form

8. SM sequence

9. Study Period

10. Min Start Date

11. Scenario

Logic:
Logic 1:

for MINIMAL Start Date/Time equal to DOV in study period specified in the Supporting document for ALL medications specified on the Supporting document reported on SM/SMAU/SMAB and there is no Matching item (SM/SMAB/SMAU) <> 0 (Dose amount/No of units taken)

Examples:

C2D1=1Feb2022, SM#3 1Feb2022 Dose=0, SM#4 3Feb2022 Dose=100. Output is expected for SM#3 since the SM minimal date is equal to DOV, but it is a zero dose

Note 1: NULL value in this scenario should NOT be considered as ZERO

Note 2: Report should consider one minimal date entry for each SM per Study Period

Note 3: If medications with minimal date equal to DOV have only ZERO dose, report should show output.

Note 4: Compare Same visitmnemonic with same study period and Same Dates(both SM/SMAB/SMAU and DOV) as per supporting document. For example:

For logic 1: Visitmnemonic is Cycle 1 and DOV is 01-Jan-2022, so corresponding SM/SMAB entry should also have study period as Cycle 1 and DOV as 01-Jan-2022.

Logic 2:

For specified Visitmnemonic given in supporting document DOV.date ≠ null and There is no corresponding SM/SMAU/SMAB entry with the same study period/visitmnemonic for each study medication specified in supporting.

Examples:

When DOV (date 2Jun2019) on Visitmnemonic Cycle 7 is completed and there is no SM/SMAU/SMAB form for each Study medication, Study Period=Cycle 7, in the same visit where DOV is completed output is expected.

Logic 3:

For specified Visitmnemonic given in supporting document DOV.date ≠ null and There is no corresponding SM/SMAU/SMAB entry with the same study period and date for each study medication specified in supporting.

Examples:

When DOV (date 1Aug2020) on Visitmnemonic Cycle 3 is completed and there is no SM/SMAU/SMAB form for each Study medication, Start Date and Time=1Aug2020, in the same visit where DOV is completed output is expected.

Note 1:	Deleted record should not be considered

Note 2: Entries for Study Period with Erroneous Visit checked should not be considered

Note 3: Do not output if for specified Visitmnemonic DOV is NOT entered

Note 4: Compare Same visitmnemonic with same study period (both SM/SMAB/SMAU and DOV) as per supporting document. For example:

For logic 2: Visitmnemonic is Cycle 1, so corresponding SM/SMAB entry should also have study period as Cycle 1.

Note 5: Look for the particular missing Study Medication ONLY if First Dose is checked for this SM (for example there are four study medications for the study, but each patient takes only two of them – then the other two should not be outputted as missing if there is no first dose on SM for that medication), and only for the study period after the first dose was already checked:

For example: There are five study medications on a study: 3475/Placebo which is applicable for all of the patients; and then Bevacizumab, Paclitaxel, Cisplatin and Carboplatin – but each patient is not having all of those four SMs are administered. Therefore, the report should list the missing SM entry for scenario 2 only for those SMs which have first dose checked – if it’s not checked, then it means that the patient is not taking this medication at all, so it should not be outputted as missing.

Another example: First dose checked for SM with Study Period Cycle 10 - output for missing SM expected only for Study Period Cycle 11 and so on, until the last dose is checked.

Note 6: After Last Dose is checked for the particular study medication, then it should no longer be outputted as missing on the next cycles. After last dose is checked on all study medications, output will no longer be expected for the patient.

For example: Subject might be taking 3475/Placebo, Paclitaxel and Bevacizumab. Paclitaxel might be discontinued after two doses, but other SMs might still be administered on the next visits – but since Paclitaxel was discontinued (Last Dose was checked), then it should not  be outputted as missing on the next visits.

Requires supporting document to be named SM031_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1) SM Form: SM/SMAU/SMAB

2) Study Medication: Study medication expected to be administered

3) Matching Item: SM Volume Administered/Dose Amount or SMAB/SMAU number of units taken

4) Study Periods from SM for which the cycle cannot start with zero dose e.g. Cycle 1 Day 1, Visit 1, Cycle 1.

5) Visitmnemonic e.g. Cycle 1 Day 1, Visit 1, Cycle 1.

6) Visit Order

Note 1: All the columns in supporting document are mandatory and there should be no blanks or 'NA'.

Note 2: Report will only work for studies which have same study medication and visitmnemonic.

e.g.

SM,Pemetrexed,Volume Administered, Cycle 1, Cycle 1,1

SM,-6482,Dose Amount, Cycle 1 Day 1 Cycle 1 Day 1,1

SMAB,-3475, number of units taken, Visit 1, Visit 1,1

Report Scenarios:
Use the supporting document to get the study medications use on the study and study periods that report should check

A-      Output Yes

Scenario 1:

for MINIMAL Start Date/Time equal to DOV in study period specified in the Supporting document for ALL medications specified on the Supporting document reported on SM/SMAU/SMAB and there is no Matching item (SM/SMAB/SMAU) <> 0 (Dose amount/No of units taken)

Scenario 2:

For specified Visitmnemonic DOV.date ≠ null and There is no corresponding SM/SMAU/SMAB entry with same study period (which means SM/SMAB/SMAU forms are not initialized or deleted then output is expected)

Scenario 3:

For specified Visitmnemonic DOV.date ≠ null and There is no corresponding SM/SMAU/SMAB entry with same date

B-      Output No

Scenario 1:

Matching item (SM/SMAB/SMAU) is different to zero for MINIMAL Start Date/Time equal to DOV in the same study period specified on the Supporting document for at least one medication of the medications specified on the Supporting document reported on SM/SMAU/SMAB

Scenario 2:

When for specified Visitmnemonic there is DOV entered, and there are SM/SMAB/SMAU entries for each study medication specified in supporting document, output should not be present

Scenario 3:

For specified Visitmnemonic DOV.date ≠ null and There is corresponding SM/SMAU/SMAB entry with same date
