Report ID: RID175

Report Title:
Study Medication Overdose

Description:
This report lists subjects who have greater than study specified number of doses. The report is run by selecting the medication label and the number of doses.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Treatment phase

6. eCRF

7. SM Seq

8. Study Medication

9. Dose Administered

10. SM Start Date/Time

11. SM Stop Date/Time

12. AE Seq

13. AE Onset Date/Time

14. AE End Date/Time

15. AE Worsened Date

Logic:
List subjects who have study medication dosage (described by matching value) greater than specified in supp doc.

The report should also list any AE with an LLT term of ""Overdose"" or ““Accidental Overdose””  or Serious Criteria equal to ""Overdose"" with a Start date or Date of Worsening greater than or equal to the SM overdose record start date. If there is no any SM overdose record, AE with an LLT term of ""Overdose"" or ““Accidental Overdose”” or Serious Criteria equal to ""Overdose"" should also be outputted. If the AE is not found, the column should be left blank.

SM Start Date should include the time portion where applicable.

The default duration is 1.

Report should not display deleted records.

Records in erroneous visits should not be considered.

If ""Randomized only"" parameter selection checkbox is checked, the report should only output subjects with Randomization number that is not null.

* SMA form (SMAU, SMAB), 'Study medication' should be derived from SMPU/SMPB form by using 'Dose Number+ Visit Number' between SMAU/SMAB and SMPU/SMPB. It will not use 'Study Medication' item from SMA directly.

Note 1: SMPB is only used to populate study medication in SMAB, SMPB data should not be showed in the report output.

Requires supporting document to be named SM002A_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1) Criteria Form - Specify as 'NA' if is not considered to be checked

2) Criteria Itemquestion - Specify as 'NA' if is not considered to be checked

3) Criteria Value - Specify as 'NA'  if is not considered to be checked Arm

4) Treatment phase - Name of each study phase (Initial Treatment Phase, Neodjuvant Phase, Second Course Phase)

5) eCRF – SM/SMAU/SMAB/SMPU

6) Study Medication Label – Value of Study Medication

7) Matching Item – Item that define the overdose value

8) Matching Value – Value of SM or SMAU/SMAB/SMPU dosage for overdose

9) Duration/Number of Days >=

Note 2: If SMPB data is provided in the supporting document, the report should not run and an display an error message saying "SMPB should not be included in the supporting document".

Note 3: The Supporting Document will indicate the eCRF that will be considered for the report output: SM, SMAU, SMAB and the Study Medication on this form, the item that will define the overdose and the dosage for overdose.

Note 4: The treatment phase will be identified as following as specified in the supporting document:

Initial Treatment Phase: Cycle 1 <= Form.Date < Second Course Cycle 1

Second Course Phase: Second Course Cycle 1 <= Form.Date

Form.Date include: SMAB/SMAU/STR/SM.Start Date, SMAB/SMAU/STR/SM.Start Date/Time

Note 5: If any treatment phase is not stated but there is AE overdose recorded, then for column 5, display blank as Treatment phase.

Note 6: If there is no SM overdose but AE have overdose display blank for columns 6 – 11 ( eCRF, SM Seq, Study Medication,  Dose Administered,SM Start Date/Time, SM Stop Date/Time).

Report Scenarios:
A- YES

Number of doses entered on the SM forms > Number of doses specified in the supporting document

B- NO

Number of doses entered on the SM forms <= Number of doses specified in the supporting document
