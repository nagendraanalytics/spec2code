Report ID: RID029

Report Title:
First Dose versus Adverse Event reconciliation

Description:
This Report displays subjects that have Adverse Event with Onset Date prior to date of first Dose Study Medication administration

Column Heading:
1.Country

2.Site

3.Subject Number

4.Form Name

5.Study Medication

6.Start Date

7.AE Seq number

8.AE Term

9.AE Onset Date

Logic:
Output is shown when AE Onset date is less than first dose of Study Medication

AE.AEAESTDTC<SMAU.SMAUEXSTDTC OR

AE.AEAESTDTC<SM.SMEXSTDTC OR

AE.AEAESTDTC<SMAB.SMABEXSTDTC

Note1. For SMAU/SM/SMAB Start Date please select the earliest Start Date

Note2. Deleted records should be excluded

Note3. Erroneous visits should be excluded

Note4. Study Medication should be mandatorily entered

Note5. Exclude SAEs/ECIs

Report Scenarios:
Display outputs that satisfy the logic.

Do not display outputs that do not satisfy the logic.

Form.Item Names:
1.SA.Site Country

2.SA.Site Mnemonic

3.SA.Subject Number

4.SM/SMAU/SMAB.Form Name

5.SM/SMAU/SMAB.Study Medication

6.SM/SMAU/SMAB.Start Date and Time

7.AE.formidx

8.AE.AE Term For lab AE use the term increased or decreased

9.AE.Onset Date and Time Lab collection date if lab AE
