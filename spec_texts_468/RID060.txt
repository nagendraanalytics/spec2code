Report ID: RID060

Report Title:
Skipped required visits

Description:
This report will list all the skipped visits required per protocol based on the last visit completed.

Column Heading:
1. Country

2. Site

3. Subject Number

4. Visit

5. Date of Visit

6. Erroneous Visit

Logic:
This report outputs subjects with skipped visits up to the last available visit.

Only the visits between the first and last visits are going to be shown.

If the cutoff visit is present and there is a gap between the last visit and the cutoff visit, then that gap should not be shown.

In case of multiple segments/phases, the missing visits will be considered independently by segment/phase and taking into account the corresponding cutoff visit.

Visits will be considered completed if the Date of Visit is completed and erroneous visit is not checked. They will not appear on the report.

Date of Visits completed with radiobutton comments will be considered incomplete visits and will appear on the report.

Erroneous visits will be considered incomplete visits and will appear on the report.

Requires supporting document to be named DOV010_supp_<xxxxxxx>.csv and will contain the following columns and associated content:

1. Criteria Form 1 - Arm/Cohort/Stratification Form Mnemonic (E.g SR/SRIVRS/TRIG). If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA.

2. Criteria Itemquestion1 - Arm/Cohort/Stratification Itemquestion1. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA or if the itemquestion1 is not applicable for the protocol, enter NA.

3.  Criteria Value1 - Arm/Cohort/Stratification Value1, If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the itemValue1 is not applicable for the protocol, enter NA.

4. Criteria Form 2 - Arm/Cohort/Stratification Form Mnemonic (E.g SR/SRIVRS/TRIG). If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA.

5. Criteria Itemquestion2 - Arm/Cohort/Stratification Itemquestion2. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA or if the itemquestion1 is not applicable for the protocol, enter NA.

6.  Criteria Value2 - Arm/Cohort/Stratification Value2, If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the itemValue1 is not applicable for the protocol, enter NA.

7. Criteria Form 3 - Arm/Cohort/Stratification Form Mnemonic (E.g SR/SRIVRS/TRIG). If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA.

8. Criteria Itemquestion3 - Arm/Cohort/Stratification Itemquestion1. If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA or if the itemquestion1 is not applicable for the protocol, enter NA.

9.  Criteria Value3 - Arm/Cohort/Stratification Value1, If applies for all subjects regardless the Arm/Cohort/Stratification, enter NA OR if the itemValue1 is not applicable for the protocol, enter NA.

10. EXPECTED_ORDER- unique sequence number for each visit

11. VISITMNEMONIC-required visits

12. CUTOFF-required Cutoff visit

Eg:

Criteria_Form1,Criteria_Itemquestion1,Criteria_Value1,Criteria_Form2,Criteria_Itemquestion2,Criteria_Value2,Criteria_Form3,Criteria_Itemquestion3,Criteria_Value3,EXPECTED_ORDER,VISITMNEMONIC,CUTOFF

SR, Arm, Arm1, SR, Cohort, Cohort A, SR, Stratification, CAPOX,1,Screening,Discontinuation Visit

SR, Arm, Arm1, SR, Cohort, Cohort A, SR, Stratification, FOLFOX,2,Cycle 1,Discontinuation Visit

NA, NA, NA, NA, NA, NA, NA, NA, NA,3,Cycle 2,Discontinuation Visit

Note: - “Cutoff Visit” has to update in supporting document for each row of visit mnemonic.

Report Scenarios:
A) Output=YES

A visit that should have occurred prior to the last DOV available does not have the Date of Visit completed.

B) Output=NO

A visit that should occur after the last DOV available does not have the Date of Visit completed.

C) Output=YES

Visits with Date of Visit completed with Not Done/Not Applicable/Unknown radiobutton comment.

D) Output=YES

Visits with Erroneous Visit checkbox selected.

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, Site, Subject, Randomized Only, List of Subjects, Remove ND/NA/UNK Visit, Remove Erroneous Visits

Form.Item Names:
1. Subject Assignment.Site Country

2. Subject Assignment.Site Mnemonic

3. Subjects.Subject Numbers

4. Date of Visit Form.Visitmnemonic

5. Date of Visit Form.Date of Visit or ND radiobutton comment

6. If Date of Visit Form.Erroneous visit is not null then "YES", else "NO"
