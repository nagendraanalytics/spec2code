Report ID: RID246

Report Title:
Analgesic Log period and Start Date reconciliation

Description:
Output is produced if the CM  was taken outside the entered Analgesic Log Period or Start Date Day 1-7

Column Heading:
1. Country

2. Site

3. Subject Number

4. ANL sequence

5. ANL Start Date

6. ANL Stop Date

7. Associated CM sequence

8. Associated CM seq. Start Date and Time

9. Associated CM seq. Stop Date and Time

10. Scenario

Logic:
Scenario 1:

Logic 1: ANL. Associated CM Sequence Number (From Concomitant Medication form) = CM. Sequence Number

AND

ANL. Start Date of Analgesic Log PerPer Period > CM. Imputed Stop Date and Time

Scenario 2:

Logic 1: ANL. Associated CM Sequence Number (From Concomitant Medication form) = CM. Sequence Number

AND

ANL. StopStop Date of Analgesic Log PerPer Period < CM. Imputed Start Date and Time

Scenario 3:

ANL. Associated CM Sequence Number (From Concomitant Medication form) = CM. Sequence Number

AND

ANL. Number of Pain Tablet(s) or Patch(es) used on Day “Corresponding Day” <> 0

AND

ANL. Start Date Day “Corresponding Day” does not meet the following criteria:

CM. Imputed Start Date and Time <= ANL. Start Date Day “Corresponding Day” <= CM. Imputed Stop Date and Time

Note 1: “Corresponding Day” refers to numbers 1,2,3,4,5,6,7 and the matching will be done as per the example below:

Example: When “Corresponding Day” = 1, then Number of Pain Tablet(s) or Patch(es) used on Day “Corresponding Day” = Number of Pain Tablet(s) or Patch(es) used on Day 1

AND Start Date Day “Corresponding Day” = Start Date Day 1. And so on for the subsequent numbers

Note 2: Erroneous visits and deleted records are excluded from programming.

Note 3: Exclude zero dose records.

Report Scenarios:
Yes: Which satisfy the logic

No: 1.- Stop Date and Time of the CM is after the Start Date Analgesic Log Period

       2.- Start Date and Time of the CM is before the Stop Date Analgesic Log Period

       3.- Start Date Day 1-7 in ANL is as Zero dose

       4.- Start Date Day 1-7 of non-zero dose is already included in the CM sequence (From ANL. Associated CM Sequence Number)

Sorting:
Country, Site, Subject Number

Parameter Selection:
Country, First Site, Last Site, First Subject, Last Subject, List of Subjects, Randomized Only (Y/N),

Form.Item Names:
1. SA. Country

2. SA. Site

3. SA. Subject Number

4. ANL. Form IDX

5. ANL. Start Date of Analgesic Log Per Period

6. ANL. Stop Date of Analgesic Log Per Period

7. ANL. Associated CM Sequence Number (From Concomitant Medication form)

8. CM (From Associated CM Sequence Number). Start Date and Time

9. CM (From Associated CM Sequence Number). Stop Date and Time

10. Error Message: If applies logic 1 please display “Scenario 1” If applies logic 2 please display “Scenario 2”  and if applies logic 3 display “Scenario 3”
